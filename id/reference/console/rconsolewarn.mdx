Menulis nol atau beberapa nilai ke Windows console saat ini melalui stdout dengan warning console text attribute. Jika tidak ada console window, pemanggilan kembali tanpa mengonversi atau menulis apa pun. Saat console ada, setiap argument dikonversi dengan Lua string conversion, digabungkan dengan karakter tab, lalu ditulis melalui runtime value. Jika Lua string conversion memunculkan error, rconsolewarn tidak menangkapnya. Function ini mengatur console text attribute ke FOREGROUND_RED | FOREGROUND_GREEN | FOREGROUND_INTENSITY sebelum menulis, lalu mengaturnya ke default console text color setelahnya. Function ini tidak menambahkan newline, tidak menambahkan warning prefix, tidak membuat atau menampilkan console, dan tidak memanggil Luau warn atau Roblox Output. consolewarn adalah alias untuk function yang sama.

## Sintaks

```lua
rconsolewarn(...values?: ...any)
```

## Alias

- `consolewarn`

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Nilai opsional. Jika console ada, setiap value dikonversi dengan Lua string conversion dan digabungkan dengan karakter tab sebelum ditulis. |

## Contoh

Write values to the current Windows console with the warning console text attribute. Values are tab-separated, no newline or warning prefix is added, and consolewarn is the same function.

```lua
rconsolecreate()
rconsolewarn("Retrying request", 3)
rconsolewarn("\n")
```
