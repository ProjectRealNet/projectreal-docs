<div className="real-function-page">

```lua
rconsoleprint(...values?: ...any)
```

## Alias

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Argumen

<ParamField path={"...values"} type={"...any"}>
Nilai opsional. Jika console ada, setiap value dikonversi dengan Lua string conversion dan digabungkan dengan karakter tab sebelum ditulis.
</ParamField>

## Contoh

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
