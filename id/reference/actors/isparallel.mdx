<div className="real-function-page">

```lua
isparallel(): boolean
```

## Alias

- `checkparallel`

## Return

<ResponseField name={"parallel"} type={"boolean"}>
true saat parallel execution status pada DataModel saat ini disetel; false saat flag tidak disetel atau tidak ada DataModel yang tersedia.
</ResponseField>

## Contoh

Read whether the current DataModel is in the parallel phase.

```lua
local parallel = isparallel()
print(parallel)

print(checkparallel())
```
