Mengembalikan Actor Instance yang terkait dengan Luau thread saat ini. Function tidak menerima arguments. Function me-resolve Luau thread saat ini melalui actor resolver yang sama seperti getactorfromthread: thread data harus ada, Actor reference harus ada, reference count harus lebih besar dari 0, dan the associated Actor harus berisi non-expired weak reference. Jika tidak ada valid actor reference, function mengembalikan nil.

## Sintaks

```lua
getcurrentactor(): Instance | nil
```

## Alias

- `get_current_actor`

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `actor` | `Instance \| nil` | Actor Instance yang di-resolve dari the associated Actor weak reference milik thread saat ini, atau nil saat tidak ada valid actor reference. |

## Contoh

Resolve the Actor Instance associated with the current Luau thread.

```lua
local actor = getcurrentactor()

print(actor)
```
