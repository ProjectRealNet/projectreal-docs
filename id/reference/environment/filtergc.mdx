<div className="real-function-page">

```lua
filtergc(filterType: string, options: table, returnOne?: boolean): table | function | nil
```

## Argumen

<ParamField path={"filterType"} type={"string"} required>
GC object type yang dicari. Nilai diubah ke lowercase dan harus "table" atau "function".
</ParamField>

<ParamField path={"options"} type={"table"} required>
Filter table. function searches membaca Name, Hash, StartLine, IgnoreExecutor, IgnoreSyn, Environment, Constants, dan Upvalues. table searches membaca Metatable, Keys, Values, dan KeyValuePairs.
</ParamField>

<ParamField path={"returnOne"} type={"boolean"}>
Optional optional boolean handling flag. Saat true, mengembalikan matching object pertama atau nil, bukan array table.
</ParamField>

## Return

<ResponseField name={"result"} type={"table | function | nil"}>
Saat returnOne false atau omitted, array table of matches. Saat returnOne true, matching table/function object pertama atau nil.
</ResponseField>

## Contoh

Find GC tables by key filters without relying on result order.

```lua
local marker = {
    RealDocsMarker = true,
}

local matches = filtergc("table", {
    Keys = { "RealDocsMarker" },
})

for _, value in ipairs(matches) do
    if value == marker then
        print("found marker")
        break
    end
end

local first = filtergc("table", {
    Keys = { "RealDocsMarker" },
}, true)

print(first ~= nil)
```
