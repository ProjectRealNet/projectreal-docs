<div className="real-function-page">

```lua
getscriptglobals(): table
```

## Return

<ResponseField name={"globals"} type={"table"}>
Fresh table dengan _G dan shared fields yang disalin dari LUA_GLOBALSINDEX.
</ResponseField>

## Contoh

Read the _G and shared values copied from LUA_GLOBALSINDEX.

```lua
local globals = getscriptglobals()

print(globals._G)
print(globals.shared)
```
