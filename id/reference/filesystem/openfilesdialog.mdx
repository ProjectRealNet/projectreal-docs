Membuka Windows file-open dialog melalui Windows file picker dengan multi-select aktif dan mengembalikan file yang dipilih sebagai nilai file item.

## Sintaks

```lua
openfilesdialog(options?: DialogOptions): { FileSystemItem } | nil
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `options` | `DialogOptions` | No | Optional table. Untuk openfilesdialog, title, defaultPath, dan extensionFilter digunakan. extensionFilter adalah table berisi extension strings; awalan . atau *. dihapus sebelum setiap filter menjadi *.&lt;extension>. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `files` | `&#123; FileSystemItem &#125; \| nil` | Array table berisi nilai file item untuk file yang dipilih, atau nil saat dialog dibatalkan atau tidak ada selected filesystem paths yang dikembalikan. Dialog failures melempar Failed to open file dialog. |

## Tipe

### DialogOptions

Mengonfigurasi dialog pemilihan file atau folder asli.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `title` | `string` | No | Menetapkan judul jendela dialog. |
| `defaultPath` | `string` | No | Memilih direktori yang ditampilkan saat dialog terbuka. |
| `extensionFilter` | `&#123;string&#125;` | No | Membatasi file yang dapat dipilih ke ekstensi yang tercantum, dengan atau tanpa titik di depannya. |
| `suggestedName` | `string` | No | Memberikan nama file awal dalam dialog penyimpanan. |
| `defaultExtension` | `string` | No | Menetapkan ekstensi yang digunakan ketika nama file yang dimasukkan tidak ada. |

## Contoh

Buka file picker untuk memilih satu atau beberapa file dan tangani setiap selected file item.

```lua
local files = openfilesdialog({
    title = "Choose source files",
    defaultPath = ".",
    extensionFilter = { "lua", "luau", "txt" },
})

if files then
    for _, file in ipairs(files) do
        print(file:GetName())
        print(file:IsFile())
    end
else
    print("No files selected")
end
```
