Menghapus regular file yang ada di dalam workspace.

## Sintaks

```lua
delfile(path: string)
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path yang diselesaikan di dalam workspace setelah separator normalization dan workspace-boundary checks. Target harus ada dan berupa regular file; folders tidak diterima. |

## Contoh

Hapus workspace file yang sudah ada.

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
