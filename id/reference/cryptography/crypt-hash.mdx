Meng-hash byte Lua string dengan algoritma crypto library hash yang didukung dan mengembalikan lowercase hexadecimal digest.

## Sintaks

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Byte Lua string yang diteruskan ke crypto library HashFilter. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Nama algoritma hash case-sensitive. Default-nya sha256. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest tanpa prefix atau separators. |

## Contoh

Hash byte Lua string dengan algoritma default atau nama yang didukung secara eksplisit.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
