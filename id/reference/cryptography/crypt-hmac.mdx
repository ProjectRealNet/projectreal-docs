<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumen

<ParamField path={"key"} type={"string"} required>
Byte raw Lua string yang dipakai sebagai HMAC key. key tidak di-Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Byte Lua string yang diteruskan ke HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Nama HMAC algorithm case-sensitive. Default-nya sha256.
</ParamField>

## Return

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output tanpa line breaks.
</ResponseField>

## Contoh

Hitung Base64 HMAC output dari raw Lua string key dan data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
