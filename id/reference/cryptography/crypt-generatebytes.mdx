<div className="real-function-page">

```lua
crypt.generatebytes(size: number): string
```

## Argumen

<ParamField path={"size"} type={"number"} required>
Angka yang melewati integer conversion sebelum alokasi. Nilai kurang dari atau sama dengan 0 diubah menjadi 1.
</ParamField>

## Return

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding dari raw bytes yang dihasilkan. Panjang string yang dikembalikan bukan jumlah byte yang diminta.
</ResponseField>

## Contoh

Hasilkan byte dan dekode hasil Base64 saat raw bytes dibutuhkan.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
