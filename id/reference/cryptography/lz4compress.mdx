<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## Alias

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Argumen

<ParamField path={"data"} type={"string"} required>
Byte Lua string yang diteruskan ke LZ4 block compression.
</ParamField>

## Return

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes yang dikembalikan sebagai string Lua. original size tidak disimpan dalam output.
</ResponseField>

## Contoh

Kompres byte Lua string dan pulihkan dengan meneruskan original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
