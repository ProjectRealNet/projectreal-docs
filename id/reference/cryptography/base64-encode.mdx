Mengenkode byte Lua string dengan Base64 encoder, memakai = padding dan tanpa line break.

## Sintaks

```lua
base64_encode(data: string): string
```

## Alias

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Byte Lua string yang diteruskan ke Base64 encoder. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `encoded` | `string` | Output Base64 yang dikembalikan sebagai string Lua. |

## Contoh

Enkode Lua string dan cetak output Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
