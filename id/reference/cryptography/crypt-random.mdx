Menghasilkan raw random bytes dengan random byte generator dan mengembalikannya sebagai string Lua.

## Sintaks

```lua
crypt.random(size: number): string
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Angka yang melewati integer conversion sebelum alokasi. Nilai kurang dari atau sama dengan 0 memunculkan argument error. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes yang dikembalikan sebagai string Lua. Panjang string yang dikembalikan cocok dengan jumlah byte yang dialokasikan. |

## Contoh

Hasilkan raw bytes dan cetak panjang string Lua yang dikembalikan.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
