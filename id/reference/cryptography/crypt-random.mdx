<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Argumen

<ParamField path={"size"} type={"number"} required>
Angka yang melewati integer conversion sebelum alokasi. Nilai kurang dari atau sama dengan 0 memunculkan argument error.
</ParamField>

## Return

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes yang dikembalikan sebagai string Lua. Panjang string yang dikembalikan cocok dengan jumlah byte yang dialokasikan.
</ResponseField>

## Contoh

Hasilkan raw bytes dan cetak panjang string Lua yang dikembalikan.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
