<div className="real-function-page">

```lua
json.quote(text: string): string
```

## Argumen

<ParamField path={"text"} type={"string"} required>
String yang akan di-quote. Function membaca argument ini dengan string type checking.
</ParamField>

## Return

<ResponseField name={"quoted"} type={"string"}>
Complete JSON string literal termasuk opening dan closing quote. Quotes, backslashes, common control characters, dan bytes below 0x20 di-escape.
</ResponseField>

## Contoh

Convert string menjadi complete quoted JSON string literal.

```lua
local source = "Real Docs" .. string.char(10) .. [[Documentation "A"]]
local quoted = json.quote(source)

print(quoted)
```
