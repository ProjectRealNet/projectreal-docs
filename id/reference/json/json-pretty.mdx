```lua
json.pretty(value: any, options?: EncodeOptions): string
```

## Argumen

<ParamField path={"value"} type={"any"} required>
Value yang di-encoded. nil, booleans, numbers, strings, tables, dan json.null ditangani langsung. Unsupported Lua types di-encoded sebagai null kecuali errorOnUnsupported bernilai true.
</ParamField>

<ParamField path={"options"} type={"EncodeOptions"}>
Optional encode options. json.pretty membaca options yang sama seperti json.encodePretty, lalu memaksa pretty menjadi true. Tanpa options, fungsi memakai two-space indent. number mengatur indent width dengan clamp ke 0.16, string mengatur indent text, dan table dapat mengatur sortKeys, emptyTableAsArray, errorOnUnsupported, encodeInvalidNumbersAsNull, maxDepth, dan indent.
</ParamField>

## Return

<ResponseField name={"json"} type={"string"}>
Readable formatted JSON string. Encoding errors dilempar sebagai Luau errors.
</ResponseField>

## Tipe

### EncodeOptions

Mengontrol serialisasi dan pemformatan JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `pretty` | `boolean` | No | Mengaktifkan keLua runtime JSON multi-baris yang diformat. |
| `sortKeys` | `boolean` | No | Mengurutkan kunci objek sebelum pengkodean. |
| `emptyTableAsArray` | `boolean` | No | Mengkodekan tabel kosong sebagai array, bukan objek. |
| `errorOnUnsupported` | `boolean` | No | Menimbulkan kesalahan alih-alih mengganti nilai yang tidak didukung. |
| `encodeInvalidNumbersAsNull` | `boolean` | No | Mengkodekan NaN dan angka tak terbatas sebagai JSON null. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |
| `indent` | `string` | No | Menyetel string indentasi, dibatasi hingga 32 karakter. |

## Contoh

Encode JSON-compatible values sebagai readable formatted JSON memakai json.encodePretty alias.

```lua
local text = json.pretty({
    category = "JSON",
    tags = json.array({ "pretty", "alias" }),
    missing = json.null,
}, {
    sortKeys = true,
})

print(text)
```
