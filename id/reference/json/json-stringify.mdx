Menserialisasi Lua value menjadi JSON string memakai function yang sama seperti json.encode.

## Sintaks

```lua
json.stringify(value: any, options?: EncodeOptions): string
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `value` | `any` | Yes | Value yang di-encode. nil, booleans, numbers, strings, tables, dan json.null ditangani langsung. Unsupported Lua types di-encode sebagai null kecuali errorOnUnsupported true. |
| `options` | `EncodeOptions` | No | Optional encode options. boolean men-toggle pretty output. number mengaktifkan pretty output dengan jumlah spaces tersebut yang di-clamp ke 0.16. string mengaktifkan pretty output dengan indent tersebut. table dapat mengatur pretty, sortKeys, emptyTableAsArray, errorOnUnsupported, encodeInvalidNumbersAsNull, maxDepth, dan indent. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `json` | `string` | Encoded JSON string. Encoding errors dilempar sebagai Luau errors. |

## Tipe

### EncodeOptions

Mengontrol serialisasi dan pemformatan JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `pretty` | `boolean` | No | Mengaktifkan keLua runtime JSON multi-baris yang diformat. |
| `sortKeys` | `boolean` | No | Mengurutkan kunci objek sebelum pengkodean. |
| `emptyTableAsArray` | `boolean` | No | Mengkodekan tabel kosong sebagai array, bukan objek. |
| `errorOnUnsupported` | `boolean` | No | Menimbulkan kesalahan alih-alih mengganti nilai yang tidak didukung. |
| `encodeInvalidNumbersAsNull` | `boolean` | No | Mengkodekan NaN dan angka tak terbatas sebagai JSON null. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |
| `indent` | `string` | No | Menyetel string indentasi, dibatasi hingga 32 karakter. |

## Contoh

Encode JSON-compatible values memakai function yang sama seperti json.encode.

```lua
local text = json.stringify({
    status = "ready",
    count = 3,
    tags = json.array({ "stringify", "alias" }),
    missing = json.null,
}, {
    sortKeys = true,
})

print(text)
```
