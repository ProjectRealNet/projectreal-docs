</Card>
<Card title="json.format" href="./json-format">
Mem-parse JSON string lalu meng-encode ulang sebagai readable formatted JSON memakai Real JSON parser dan encoder.
</Card>
<Card title="json.getPath" href="./json-getpath">

</Card>
<Card title="json.isArray" href="./json-isarray">
Mengembalikan apakah value treated as a JSON array oleh Real JSON table detection.
</Card>
<Card title="json.isNull" href="./json-isnull">
Mengembalikan apakah value adalah Real JSON null sentinel, json.null.
</Card>
<Card title="json.isObject" href="./json-isobject">
Mengembalikan apakah value treated as a JSON object oleh Real JSON table detection.
</Card>
<Card title="json.keys" href="./json-keys">
Mengembalikan visible keys dari table dalam new table marked as a JSON array.
</Card>

</Card>

Membuat new table marked as a JSON object agar Real JSON encoder memperlakukannya sebagai object.

</Card>

Menserialisasi Lua value menjadi JSON string memakai function yang sama seperti json.encode.

</Card>
<Card title="json.unescape" href="./json-unescape">

</Card>
