<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumen

<ParamField path={"json"} type={"string"} required>
JSON text untuk di-parse. argument ini diperiksa sebagai string sebelum parse errors ditangkap.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean mengatur useNull secara langsung. table dapat mengatur useNull dan maxDepth; maxDepth di-clamp dari 1 sampai 4096. Invalid option argument types diperiksa sebelum parse errors ditangkap.
</ParamField>

## Return

<ResponseField name={"success"} type={"boolean"}>
True saat parsing berhasil, false saat parser melaporkan error.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value saat sukses, nil saat parse failure. JSON false yang valid mengembalikan success sebagai true dan decoded sebagai false, jadi periksa success return value.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message saat parse failure, selain itu nil. Pesan menyertakan json.decodeSafe prefix dan parser position.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position saat parse failure, selain itu nil.
</ResponseField>

## Tipe

### DecodeOptions

Mengontrol perilaku penguraian JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Mewakili JSON null dengan penjaga null perpustakaan, bukan nihil. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |

## Contoh

Parse JSON dan gunakan success return value untuk memisahkan valid false atau nil results dari parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
