Mencoba parse JSON string memakai function yang sama seperti json.decodeSafe dan mengembalikan status values untuk parse errors.

## Sintaks

```lua
json.tryDecode(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string yang di-parse. Function membaca argument ini dengan string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options. boolean mengatur useNull. table dapat mengatur useNull dan maxDepth. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `success` | `boolean` | true saat parsing berhasil, false saat parsing gagal di dalam protected parse block. |
| `decoded` | `any \| nil` | Decoded value saat success. Saat parse failure, return ini nil. |
| `errorMessage` | `string \| nil` | Error message saat parse failure. Message memiliki prefix json.decodeSafe dan menyertakan near-position suffix. |
| `errorPosition` | `number \| nil` | Parser byte position dari parser saat parse failure. Return ini hanya ada saat failure. |

## Tipe

### DecodeOptions

Mengontrol perilaku penguraian JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Mewakili JSON null dengan penjaga null perpustakaan, bukan nihil. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |

## Contoh

Decode JSON dengan status returns memakai json.decodeSafe-compatible alias.

```lua
local ok, value, message, position = json.tryDecode('{"ready":true,"missing":null}', {
    useNull = true,
})

if ok then
    print(value.ready)
    print(json.isNull(value.missing))
else
    warn(message, position)
end
```
