```lua
json.parse(json: string, options?: DecodeOptions): any
```

## Argumen

<ParamField path={"json"} type={"string"} required>
JSON string yang di-parse. Function membaca argument ini dengan string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean mengatur useNull. table dapat mengatur useNull dan maxDepth.
</ParamField>

## Return

<ResponseField name={"decoded"} type={"any"}>
Decoded value. JSON objects dan arrays menjadi tables dengan JSON type markers, strings menjadi Lua strings, numbers menjadi Lua numbers, booleans menjadi booleans, dan null menjadi json.null kecuali useNull false.
</ResponseField>

## Tipe

### DecodeOptions

Mengontrol perilaku penguraian JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Mewakili JSON null dengan penjaga null perpustakaan, bukan nihil. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |

## Contoh

Parse JSON dengan function yang sama seperti json.decode.

```lua
local settings = json.parse('{"volume":0.75,"theme":"dark","missing":null}', {
    useNull = true,
})

print(settings.volume)
print(settings.theme)
print(json.isNull(settings.missing))
```
