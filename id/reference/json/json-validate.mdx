<div className="real-function-page">

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Argumen

<ParamField path={"json"} type={"string"} required>
JSON string yang akan di-validate. Function membaca argument ini dengan string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean mengatur useNull. table dapat mengatur useNull dan maxDepth. maxDepth di-clamp dari 1 sampai 4096.
</ParamField>

## Return

<ResponseField name={"valid"} type={"boolean"}>
true saat parsing satu complete JSON value berhasil. false saat parsing gagal di dalam protected parse block.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message saat parse failure. Message diberi prefix json.validate dan menyertakan near-position suffix. Return ini hanya ada saat failure.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position dari parser saat parse failure. Return ini hanya ada saat failure.
</ResponseField>

## Tipe

### DecodeOptions

Mengontrol perilaku penguraian JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Mewakili JSON null dengan penjaga null perpustakaan, bukan nihil. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |

## Contoh

Memeriksa apakah sebuah string berisi tepat satu complete JSON value.

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
