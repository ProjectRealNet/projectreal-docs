<div className="real-function-page">

```lua
json.format(json: string, encodeOptions?: EncodeOptions, decodeOptions?: DecodeOptions): string
```

## Argumen

<ParamField path={"json"} type={"string"} required>
JSON string yang di-parse sebelum formatting. Function membaca argument ini dengan string type checking.
</ParamField>

<ParamField path={"encodeOptions"} type={"EncodeOptions"}>
Optional encode options yang diteruskan ke re-encode step. json.format membaca encode options yang sama seperti json.encode, lalu memaksa pretty menjadi true.
</ParamField>

<ParamField path={"decodeOptions"} type={"DecodeOptions"}>
Optional decode options yang dipakai saat parsing input JSON. boolean mengatur useNull. table dapat mengatur useNull dan maxDepth.
</ParamField>

## Return

<ResponseField name={"formatted"} type={"string"}>
Readable formatted JSON string yang dibuat setelah parsing dan re-encoding input.
</ResponseField>

## Tipe

### EncodeOptions

Mengontrol serialisasi dan pemformatan JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `pretty` | `boolean` | No | Mengaktifkan keLua runtime JSON multi-baris yang diformat. |
| `sortKeys` | `boolean` | No | Mengurutkan kunci objek sebelum pengkodean. |
| `emptyTableAsArray` | `boolean` | No | Mengkodekan tabel kosong sebagai array, bukan objek. |
| `errorOnUnsupported` | `boolean` | No | Menimbulkan kesalahan alih-alih mengganti nilai yang tidak didukung. |
| `encodeInvalidNumbersAsNull` | `boolean` | No | Mengkodekan NaN dan angka tak terbatas sebagai JSON null. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |
| `indent` | `string` | No | Menyetel string indentasi, dibatasi hingga 32 karakter. |

### DecodeOptions

Mengontrol perilaku penguraian JSON.

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Mewakili JSON null dengan penjaga null perpustakaan, bukan nihil. |
| `maxDepth` | `integer` | No | Menyetel kedalaman sarang maksimum, dijepit dari 1 hingga 4096. |

## Contoh

Parse existing JSON lalu re-encode sebagai readable formatted JSON.

```lua
local compact = '{"b":2,"a":1}'
local formatted = json.format(compact, {
    pretty = true,
    sortKeys = true,
}, {
    useNull = true,
})

print(formatted)
```
