Membaca nested value dari table memakai dotted string path atau array table of keys.

## Sintaks

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Alias

- `json.getpath`

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `object` | `table` | Yes | Root table yang dibaca. Function mewajibkan argument ini berupa table. |
| `path` | `string \| table` | Yes | Path yang diikuti. string di-split pada dots; integer string tokens dibaca dengan raw array indexing. table path memakai array entries dari 1 sampai #path sebagai keys. |
| `defaultValue` | `any` | No | Fallback value yang dikembalikan saat traversal mencapai nil atau non-table sebelum path selesai. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `pathValue` | `any \| nil` | Value pada requested path. Jika path hilang, mengembalikan defaultValue bila disediakan, jika tidak nil. |

## Contoh

Baca nested table value dari dotted string path atau array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
