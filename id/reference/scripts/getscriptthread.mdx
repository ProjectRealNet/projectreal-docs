Mengembalikan Lua thread yang terkait dengan script object saat Real dapat menemukannya. Argument harus berupa object. Function membaca field ClassName pada nilai dan memunculkan "not a valid Instance" jika field itu bukan string. Nilai ClassName yang diterima adalah Script, LocalScript, dan ModuleScript; nilai lain memunculkan "Script expected". Function pertama memeriksa ScriptThreadCache milik Real berdasarkan script reference. Pada cache hit, function mengembalikan Luau thread yang di-cache sebagai thread. Pada cache miss, nilai Script harus memiliki RunContext Client atau function memunculkan "Expected a Script with RunContext set to Client". Kemudian function berjalan melalui the live Luau thread list, mengikuti first weak thread reference setiap thread node ke LiveLuaRef, melewati missing thread data atau expired Script stored references, dan membandingkan setiap script reference dengan script yang diminta. Jika menemukan match, function mengembalikan Luau thread itu sebagai thread. Jika tidak ada match, function mengembalikan nil.

## Sintaks

```lua
getscriptthread(script: userdata): thread | nil
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `script` | `userdata` | Yes | Script object untuk dicari. Nilai ClassName yang diterima adalah Script, LocalScript, dan ModuleScript. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `thread` | `thread \| nil` | Lua thread terkait, atau nil saat tidak ada matching live thread yang ditemukan. |

## Contoh

Read the Luau thread associated with a supported script Instance when one is available.

```lua
local targetScript

for _, descendant in ipairs(game:GetDescendants()) do
    if descendant:IsA("LuaSourceContainer") then
        targetScript = descendant
        break
    end
end

if targetScript then
    local thread = getscriptthread(targetScript)
    print(thread)
end
```
