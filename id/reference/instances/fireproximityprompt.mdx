Memicu ProximityPrompt melalui ProximityPrompt trigger milik Real. Argumen prompt harus berupa object dengan field ClassName yang sama dengan "ProximityPrompt". Jika nilai bukan object, pemanggilan menghasilkan type error. Jika ClassName tidak ada atau bukan string, pemanggilan menghasilkan "Invalid Instance". Jika ClassName bukan "ProximityPrompt", pemanggilan menghasilkan "ProximityPrompt expected". Function ini tidak menerima optional arguments dan tidak mengembalikan apa pun.

## Sintaks

```lua
fireproximityprompt(prompt: Instance)
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `prompt` | `Instance` | Yes | Instance yang ClassName-nya harus ProximityPrompt. |

## Contoh

Memicu ProximityPrompt dengan satu-satunya argumen yang diperlukan.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
