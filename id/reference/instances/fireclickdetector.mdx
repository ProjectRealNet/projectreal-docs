Argumen pertama harus berupa Instance dengan ClassName ClickDetector. distance bersifat opsional dan default-nya 0. clickOption bersifat opsional, dibandingkan tanpa memperhatikan huruf besar kecil, dan default-nya \"mouseclick\". <div className="real-function-page">

```lua
fireclickdetector(detector: Instance, distance?: number, clickOption?: "mouseclick" | "rightmouseclick" | "mousehoverenter" | "mousehoverleave")
```

## Argumen

<ParamField path={"detector"} type={"Instance"} required>
Instance yang ClassName-nya harus ClickDetector.
</ParamField>

<ParamField path={"distance"} type={"number"}>
Nilai distance opsional. Default-nya 0 dan diteruskan sebagai float untuk "mouseclick" dan "rightmouseclick".
</ParamField>

<ParamField path={"clickOption"} type={"\"mouseclick\" | \"rightmouseclick\" | \"mousehoverenter\" | \"mousehoverleave\""}>
Pemilih interaction opsional. Dibaca sebagai string, dibandingkan tanpa memperhatikan huruf besar kecil, dan default-nya "mouseclick".
</ParamField>

## Contoh

Memicu interaction "mouseclick" default pada ClickDetector.

```lua
local detector = workspace.InteractivePart.ClickDetector

fireclickdetector(detector)
```
