Mengembalikan game:CoreGui lookup.RobloxGui. Function ini tidak menerima arguments. Jika CoreGui lookup mengembalikan nil, atau jika RobloxGui pada nilai itu nil, function mengembalikan nil. Function tidak membuat container dan tidak menggunakan nilai cache CoreGui.

## Sintaks

```lua
gethui(): Instance | nil
```

## Alias

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | Nilai RobloxGui yang dibaca dari CoreGui, atau nil saat CoreGui atau RobloxGui tidak tersedia. |
