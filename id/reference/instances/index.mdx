Penemuan instans dan pembantu interaksi.

| Navigasi fungsi | Deskripsi |
| --- | --- |
| [`fireclickdetector`](./fireclickdetector) | Memicu interaksi ClickDetector untuk pemain lokal. Argumen pertama harus berupa Instance dengan ClassName ClickDetector. distance bersifat opsional dan default-nya 0. clickOption bersifat opsional, dibandingkan tanpa memperhatikan huruf besar kecil, dan default-nya "mouseclick". Opsi yang didukung adalah "mouseclick", "rightmouseclick", "mousehoverenter", dan "mousehoverleave". Opsi klik meneruskan distance sebagai float ke Roblox click helper, sementara opsi hover mengabaikan distance. Jika Players atau Players.LocalPlayer tidak tersedia, function kembali tanpa memicu apa pun. clickOption yang tidak dikenal juga tidak menghasilkan interaksi. Function tidak mengembalikan apa pun. |
| [`fireproximityprompt`](./fireproximityprompt) | Memicu ProximityPrompt melalui ProximityPrompt trigger milik Real. Argumen prompt harus berupa object dengan field ClassName yang sama dengan "ProximityPrompt". Jika nilai bukan object, pemanggilan menghasilkan type error. Jika ClassName tidak ada atau bukan string, pemanggilan menghasilkan "Invalid Instance". Jika ClassName bukan "ProximityPrompt", pemanggilan menghasilkan "ProximityPrompt expected". Function ini tidak menerima optional arguments dan tidak mengembalikan apa pun. |
| [`firetouchinterest`](./firetouchinterest) | Memicu Real touch interest event untuk dua BasePart instances. Dua argumen pertama harus berupa Instance object dan kedua nilai harus lulus IsA("BasePart"). Argumen state wajib dan harus number atau boolean. Saat state berupa number, hanya 1 menjadi true dan number lain menjadi false. Saat state berupa boolean, nilai boolean-nya diteruskan. Jika salah satu part tidak memiliki touch data, atau part pertama tidak memiliki overlap reference, function kembali tanpa memicu apa pun. Function tidak mengembalikan apa pun. Makna begin/end yang tepat dari boolean yang diteruskan ke helper adalah: Nicht aus der Codebasis verifizierbar. |
| [`getcallbackvalue`](./getcallbackvalue) | Membaca Lua callback function yang tersimpan di callback property pada Instance. Argumen pertama harus Instance object dan argumen kedua harus string property name. instance reference harus valid. property name diselesaikan melalui Roblox property metadata dan harus merujuk ke property dengan tipe LUA_CALLBACK. Jika property descriptor tidak ada, property bukan LUA_CALLBACK, callback field offset tidak ada, tidak ada callback tersimpan, LiveLuaRef tidak ada, callback milik Lua global state lain, atau nilai yang direferensikan bukan function, function mengembalikan nil. Ini juga memeriksa async callback field fallback saat callback slot pertama tidak memiliki callback. Function tidak memperbarui property. |
| [`gethui`](./gethui) | Mengembalikan game:CoreGui lookup.RobloxGui. Function ini tidak menerima arguments. Jika CoreGui lookup mengembalikan nil, atau jika RobloxGui pada nilai itu nil, function mengembalikan nil. Function tidak membuat container dan tidak menggunakan nilai cache CoreGui. |
| [`getinstances`](./getinstances) | Mengembalikan array table baru yang berisi setiap object value yang saat ini tersimpan di Instance cache. Function ini tidak menerima arguments. Function tidak memfilter berdasarkan Parent, ClassName, DataModel fieldship, nil-parent state, atau Instance validity selain memeriksa bahwa setiap registry value adalah object. Entries disalin ke table yang dikembalikan pada sequential numeric indexes mulai dari 1. iteration order berasal dari table iteration atas cache dan tidak diurutkan oleh function. |
| [`getnilinstances`](./getnilinstances) | Returns a new array table containing cached Instance values whose Parent field is nil. The function takes no arguments. It does not sort the returned entries. |
| [`isnetworkowner`](./isnetworkowner) | Mengembalikan hasil membaca hidden property "NetworkOwnerV3" dari Instance dan memeriksa apakah nilai pertama yang dikembalikan, dikonversi dengan integer conversion, lebih besar dari 2. Argumen harus Instance object. Function memanggil the hidden property reader secara dan tidak menangkap error dari pemanggilan itu, sehingga Invalid Instance values, missing properties, atau non-property metadata dapat menghasilkan error yang sama seperti gethiddenproperty. Function mengembalikan satu boolean. Apakah peer_id > 2 secara tepat berarti local network ownership adalah: Nicht aus der Codebasis verifizierbar. |
