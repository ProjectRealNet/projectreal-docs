<div className="real-function-page">

```lua
mousemoverel(x: number, y: number)
```

## Argumen

<ParamField path={"x"} type={"number"} required>
Relative X movement delta yang dibaca sebagai Lua number dan dikonversi dengan integer conversion sebelum diteruskan sebagai dx ke mouse input.
</ParamField>

<ParamField path={"y"} type={"number"} required>
Relative Y movement delta yang dibaca sebagai Lua number dan dikonversi dengan integer conversion sebelum diteruskan sebagai dy ke mouse input.
</ParamField>
