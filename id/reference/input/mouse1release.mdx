Mengirim left mouse up event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim left mouse down event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false.

## Sintaks

```lua
mouse1release()
```
