Mengirim right mouse down event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim right mouse up event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false.

## Sintaks

```lua
mouse2press()
```
