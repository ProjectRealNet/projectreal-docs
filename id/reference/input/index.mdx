Peristiwa masukan keyboard dan mouse.

| Navigasi fungsi | Deskripsi |
| --- | --- |
| [`isrbxactive`](./isrbxactive) | Mengembalikan apakah current foreground window adalah Roblox window yang ditemukan oleh Real. Real menemukan window itu dengan enumerating windows untuk proses saat ini dan memilih window dengan class name Roblox window. Function ini tidak menerima arguments dan mengembalikan false saat tidak ada foreground window atau matching Roblox window. |
| [`keyclick`](./keyclick) | Mengirim key down event diikuti key up event saat Roblox window aktif. Argumen keyCode diperiksa sebagai Lua number, dikonversi dengan integer conversion, dipetakan dari Windows virtual-key code ke scan code dengan Windows key mapping, lalu dikirim melalui keyboard input dengan KEYEVENTF_SCANCODE. Jika isrbxactive bernilai false, function kembali tanpa mengirim input. |
| [`keypress`](./keypress) | Mengirim key down event saat Roblox window aktif. Argumen keyCode diperiksa sebagai Lua number, dikonversi dengan integer conversion, dipetakan dari Windows virtual-key code ke scan code dengan Windows key mapping, lalu dikirim melalui keyboard input dengan KEYEVENTF_SCANCODE. Function ini tidak mengirim key up event. Jika isrbxactive bernilai false, function kembali tanpa mengirim input. |
| [`keyrelease`](./keyrelease) | Mengirim key up event saat Roblox window aktif. Argumen keyCode diperiksa sebagai Lua number, dikonversi dengan integer conversion, dipetakan dari Windows virtual-key code ke scan code dengan Windows key mapping, lalu dikirim melalui keyboard input dengan KEYEVENTF_SCANCODE \| KEYEVENTF_KEYUP. Function ini tidak mengirim key down event. Jika isrbxactive bernilai false, function kembali tanpa mengirim input. |
| [`mouse1click`](./mouse1click) | Mengirim left mouse down event dan left mouse up event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mouse1press`](./mouse1press) | Mengirim left mouse down event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim left mouse up event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mouse1release`](./mouse1release) | Mengirim left mouse up event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim left mouse down event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mouse2click`](./mouse2click) | Mengirim right mouse down event dan right mouse up event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mouse2press`](./mouse2press) | Mengirim right mouse down event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim right mouse up event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mouse2release`](./mouse2release) | Mengirim right mouse up event saat Roblox window aktif. Real memanggil mouse input dengan the requested mouse action dan tanpa movement atau wheel data. Function ini tidak menerima arguments, tidak mengembalikan apa pun, tidak mengirim right mouse down event pasangan, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mousemoveabs`](./mousemoveabs) | Menggerakkan mouse memakai Windows absolute mouse input saat Roblox window aktif. Argumen x dan y diperiksa sebagai Lua numbers dan dikonversi dengan integer conversion. Real memperlakukannya sebagai koordinat relative to active foreground window client area, menambahkan posisi layar client area itu dengan ClientToScreen, melakukan scaling memakai GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) - 1 dan integer math, lalu memanggil mouse input dengan the requested mouse action. Jika isrbxactive bernilai false, function kembali tanpa mengirim input. |
| [`mousemoverel`](./mousemoverel) | Menggerakkan mouse dengan relative delta saat Roblox window aktif. Argumen x dan y diperiksa sebagai Lua numbers dan dikonversi dengan integer conversion, lalu diteruskan langsung ke mouse input dengan the requested mouse action sebagai dx dan dy. Function ini tidak menggunakan the requested mouse action, tidak melakukan client-area conversion, tidak mengembalikan apa pun, dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
| [`mousescroll`](./mousescroll) | Mengirim mouse wheel event saat Roblox window aktif. Argumen amount diperiksa sebagai Lua number, dikonversi dengan integer conversion, dan diteruskan langsung sebagai nilai dwData ke mouse input dengan the requested mouse action. Real tidak menormalisasi amount atau menambahkan movement data. Function ini tidak mengembalikan apa pun dan kembali tanpa mengirim input saat isrbxactive bernilai false. |
