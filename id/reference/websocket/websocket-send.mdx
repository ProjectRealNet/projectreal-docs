<div className="real-function-page">

```lua
WebSocket.Send(socket: WebSocket, message: string, isBinary?: boolean)
```

## Argumen

<ParamField path={"socket"} type={"WebSocket"} required>
WebSocket table yang dikembalikan oleh WebSocket.connect. Send di-resolve dari WebSocket object methods, jadi bentuk panggilan yang didokumentasikan adalah socket:Send(..).
</ParamField>

<ParamField path={"message"} type={"string"} required>
Lua string payload yang diteruskan ke curl_ws_send dengan explicit byte length.
</ParamField>

<ParamField path={"isBinary"} type={"boolean"}>
Saat argument ini ada dan bernilai true, Send menggunakan CURLWS_BINARY. Jika tidak, Send menggunakan CURLWS_TEXT.
</ParamField>

## Contoh

Send text or binary data through a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Send("hello")
socket:Send(string.char(0, 1, 2, 3), true)
```
