<div className="real-function-page">

```lua
setrenderproperty(object: any, property: any, value: any)
```

## Argumen

<ParamField path={"object"} type={"any"} required>
Nilai yang di-index dan diberi assignment. Dengan Drawing object, RealDrawingObject __newindex handler digunakan.
</ParamField>

<ParamField path={"property"} type={"any"} required>
property key yang digunakan untuk assignment. Drawing object properties berbasis strings.
</ParamField>

<ParamField path={"value"} type={"any"} required>
Nilai yang ditetapkan ke object[property]. Argumen ini harus diberikan; nil tetap merupakan nilai yang diberikan.
</ParamField>

## Contoh

Perbarui properti gambar melalui pembantu properti generik.

```lua
local line = Drawing.new("Line")
setrenderproperty(line, "Thickness", 3)
setrenderproperty(line, "Visible", true)

print(line.Thickness)
print(line.Visible)
```
