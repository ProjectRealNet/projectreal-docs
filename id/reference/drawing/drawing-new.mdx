<div className="real-function-page">

```lua
Drawing.new(objectType: "Image" | "Line" | "Text" | "Circle" | "Square" | "Quad" | "Triangle"): DrawingObject
```

## Argumen

<ParamField path={"objectType"} type={"\"Image\" | \"Line\" | \"Text\" | \"Circle\" | \"Square\" | \"Quad\" | \"Triangle\""} required>
Nama Drawing type yang tepat untuk dibuat. Nilai yang didukung adalah "Line", "Text", "Circle", "Square", "Quad", "Triangle", "Image".
</ParamField>

## Return

<ResponseField name={"object"} type={"DrawingObject"}>
Drawing object yang dibuat dengan Drawing object type.
</ResponseField>

## Contoh

Buat persegi yang terlihat dan konfigurasikan properti gambar dasarnya.

```lua
local square = Drawing.new("Square")
square.Position = Vector2.new(120, 120)
square.Size = Vector2.new(220, 120)
square.Color = Color3.fromRGB(120, 170, 255)
square.Filled = true
square.Visible = true
```
