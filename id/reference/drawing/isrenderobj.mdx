<div className="real-function-page">

```lua
isrenderobj(object: any): boolean
```

## Argumen

<ParamField path={"object"} type={"any"} required>
Nilai yang akan diuji. Non-object values dan object tanpa Drawing object type mengembalikan false.
</ParamField>

## Return

<ResponseField name={"isDrawingObject"} type={"boolean"}>
True ketika nilai adalah object dengan methods yang cocok dengan RealDrawingObject; jika tidak false.
</ResponseField>

## Contoh

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
