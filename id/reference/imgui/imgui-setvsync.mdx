Memperbarui vertical synchronization preference milik ImGui renderer. Presentation path saat ini menyimpan preference ini, tetapi tidak menerapkannya.

## Sintaks

```lua
imgui.setvsync(enabled: boolean)
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `enabled` | `boolean` | Yes | `true` untuk meminta vertical synchronization; `false` untuk meminta uncapped presentation. |
