sidebarTitle: "ImGuiWindow.SliderFloat"
description: "Menambahkan SliderFloat element ke window. label, value, minimum, dan maximum dibaca dari argumen 2 sampai 5, dengan argumen numerik diperiksa oleh number type checking. Saat rendering, Real memanggil a floating-point slider dengan nilai dan rentang yang disimpan. Ketika ImGui melaporkan nilai berubah, onChange dimasukkan ke queue lalu dipanggil nanti dengan satu Lua number. Real tidak menambahkan validasi minimum <= maximum terpisah di closure ini."
keywords: ["ImGuiWindow.SliderFloat","ImGui"]

<div className="real-function-page">

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argumen

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow yang dikembalikan oleh imgui.create. Jika object tidak valid atau sudah dihancurkan, method memunculkan Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Slider label yang dibaca dengan string type checking.
</ParamField>

<ParamField path={"value"} type={"number"} required>
Nilai awal slider yang dibaca dengan number type checking dan disimpan sebagai nilai float saat ini.
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
Minimum value yang dibaca dengan number type checking dan diteruskan ke a floating-point slider.
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
Maximum value yang dibaca dengan number type checking dan diteruskan ke a floating-point slider.
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Callback function yang disimpan di Lua registry. Saat slider berubah selama rendering, callback dipanggil nanti dengan nilai numerik terbaru.
</ParamField>

## Return

<ResponseField name={"window"} type={"ImGuiWindow"}>
ImGuiWindow object yang sama, sehingga pemanggilan method dapat dirangkai.
</ResponseField>
