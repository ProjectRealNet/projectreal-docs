Menambahkan SliderFloat element ke window. label, value, minimum, dan maximum dibaca dari argumen 2 sampai 5, dengan argumen numerik diperiksa oleh number type checking. Saat rendering, Real memanggil a floating-point slider dengan nilai dan rentang yang disimpan. Ketika ImGui melaporkan nilai berubah, onChange dimasukkan ke queue lalu dipanggil nanti dengan satu Lua number. Real tidak menambahkan validasi minimum &lt;= maximum terpisah di closure ini.

## Sintaks

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow yang dikembalikan oleh imgui.create. Jika object tidak valid atau sudah dihancurkan, method memunculkan Lua error. |
| `label` | `string` | Yes | Slider label yang dibaca dengan string type checking. |
| `value` | `number` | Yes | Nilai awal slider yang dibaca dengan number type checking dan disimpan sebagai nilai float saat ini. |
| `minimum` | `number` | Yes | Minimum value yang dibaca dengan number type checking dan diteruskan ke a floating-point slider. |
| `maximum` | `number` | Yes | Maximum value yang dibaca dengan number type checking dan diteruskan ke a floating-point slider. |
| `onChange` | `(number) -> ()` | Yes | Callback function yang disimpan di Lua registry. Saat slider berubah selama rendering, callback dipanggil nanti dengan nilai numerik terbaru. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `window` | `ImGuiWindow` | ImGuiWindow object yang sama, sehingga pemanggilan method dapat dirangkai. |
