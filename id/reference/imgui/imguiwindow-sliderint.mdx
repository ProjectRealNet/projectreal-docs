Adds an integer slider to the window. The label, value, minimum, and maximum arguments are required. When the user changes the slider, the callback receives the updated integer value.

## Sintaks

```lua
ImGuiWindow.SliderInt(window: ImGuiWindow, label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()): ImGuiWindow
```

## Argumen

| Name | Type | Required | Deskripsi |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow returned by imgui.create. If the object is invalid or has already been destroyed, the method raises a Lua error. |
| `label` | `string` | Yes | Slider label required to be a string. |
| `value` | `integer` | Yes | Initial slider value required to be an integer and stored as the current int value. |
| `minimum` | `integer` | Yes | Minimum value required to be an integer and passed to an integer slider. |
| `maximum` | `integer` | Yes | Maximum value required to be an integer and passed to an integer slider. |
| `onChange` | `(number) -> ()` | Yes | Callback called with the updated integer value when the slider changes. |

## Return

| Name | Type | Deskripsi |
| --- | --- | --- |
| `window` | `ImGuiWindow` | The same ImGuiWindow object, allowing chained method calls. |

## Tipe

### ImGuiWindow

Pegangan dikembalikan oleh imgui.create. Metode pembuatan kontrol mengembalikan pegangan yang sama sehingga panggilan dapat dirangkai.
