เข้าถึงสภาพแวดล้อมรันไทม์และออบเจ็กต์ที่รวบรวมขยะ

## ฟังก์ชันที่ใช้ได้

<CardGroup cols={2}>
<Card title="filtergc" href="./filtergc">
ค้นหา live garbage-collected tables หรือ functions ที่ตรงกับ filters ที่ให้มา filterType ต้องเป็น "table" หรือ "function" และ options ต้องเป็น table
</Card>
<Card title="getgc" href="./getgc">
Returns an array table of live Luau garbage-collected objects visible to the API. Functions and userdata-like objects are included by default. Tables are included only when includeTables is true. get_gc_objects is an alias.
</Card>
<Card title="getgenv" href="./getgenv">
คืน current executor environment table โดย pushing LUA_ENVIRONINDEX. function ไม่รับ arguments, คืน exactly one value, และไม่มี registered alias. call-sites ใน repository ใช้ returned table เพื่ออ่านและเขียน shared executor globals เช่น __siApiCache และ saveinstance.
</Card>
<Card title="getrenv" href="./getrenv">
Returns the Roblox global environment table. The function takes no arguments and returns exactly one value.
</Card>
<Card title="getscriptglobals" href="./getscriptglobals">
คืน new table ที่มี current LUA_GLOBALSINDEX values สำหรับ _G และ shared. function ไม่รับ arguments, สร้าง fresh table, กำหนด _G จาก LUA_GLOBALSINDEX._G และ shared จาก LUA_GLOBALSINDEX.shared, แล้วคืน exactly one value. ไม่ได้คืน full global table และไม่มี alias ที่ register สำหรับ getscriptglobals.
</Card>
<Card title="gettenv" href="./gettenv">
Returns the environment table stored on a Luau thread. getstateenv is an alias.
</Card>
<Card title="setclipboard" href="./setclipboard">
Writes one value to the Windows system clipboard as text. The value is converted to a string. The function returns no status value, whether the clipboard write succeeds or fails. toclipboard is an alias.
</Card>
<Card title="setrbxclipboard" href="./setrbxclipboard">
Writes a required string to the Windows clipboard using Roblox Studio clipboard data format. The function returns no status value, whether the clipboard write succeeds or fails.
</Card>
</CardGroup>
