คืน current executor environment table โดย pushing LUA_ENVIRONINDEX. function ไม่รับ arguments, คืน exactly one value, และไม่มี registered alias. call-sites ใน repository ใช้ returned table เพื่ออ่านและเขียน shared executor globals เช่น __siApiCache และ saveinstance.

## ไวยากรณ์

```lua
getgenv(): table
```

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `environment` | `table` | Table ที่เก็บอยู่ใน LUA_ENVIRONINDEX สำหรับ state นี้ในตอนนี้. |

## ตัวอย่าง

Read and write values on the current executor environment table.

```lua
local env = getgenv()

env.RealDocsValue = "ready"

print(getgenv().RealDocsValue)
```
