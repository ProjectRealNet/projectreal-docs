คืนค่าว่า value เป็น object ที่มี Drawing object type หรือไม่ นี่เป็นเพียง methods check เท่านั้น ไม่ได้ตรวจว่า Drawing object ภายในยัง active, tracked หรือ destroyed อยู่หรือไม่ the Drawing API ลงทะเบียน API นี้เฉพาะเมื่อ the required rendering environment is active เป็น true หากการตรวจสอบนี้เป็น false initializer จะกลับก่อนสร้าง globals เหล่านี้

## ไวยากรณ์

```lua
isrenderobj(object: any): boolean
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `object` | `any` | Yes | ค่าที่จะทดสอบ non-object values และ object ที่ไม่มี Drawing object type จะคืนค่า false |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `isDrawingObject` | `boolean` | True เมื่อ value เป็น object ที่ methods ตรงกับ RealDrawingObject มิฉะนั้น false |

## ตัวอย่าง

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
