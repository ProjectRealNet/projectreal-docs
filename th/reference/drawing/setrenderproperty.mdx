<div className="real-function-page">

```lua
setrenderproperty(object: any, property: any, value: any)
```

## Arguments

<ParamField path={"object"} type={"any"} required>
ค่าที่จะถูก index และกำหนดค่า เมื่อใช้ Drawing object จะใช้ RealDrawingObject __newindex handler
</ParamField>

<ParamField path={"property"} type={"any"} required>
property key ที่ใช้สำหรับ assignment โดย Drawing object properties ใช้ strings
</ParamField>

<ParamField path={"value"} type={"any"} required>
ค่าที่กำหนดให้ object[property] ต้องส่งอาร์กิวเมนต์นี้; nil ยังถือว่าเป็นค่าที่ถูกส่งมา
</ParamField>

## ตัวอย่าง

อัปเดตคุณสมบัติการวาดผ่านตัวช่วยคุณสมบัติทั่วไป

```lua
local line = Drawing.new("Line")
setrenderproperty(line, "Thickness", 3)
setrenderproperty(line, "Visible", true)

print(line.Thickness)
print(line.Visible)
```
