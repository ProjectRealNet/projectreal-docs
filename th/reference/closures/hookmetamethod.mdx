<div className="real-function-page">

```lua
hookmetamethod(object: any, metamethod: string, replacement: function): function
```

## Arguments

<ParamField path={"object"} type={"any"} required>
Value ที่ methods ถูกตรวจด้วย raw metafield lookup
</ParamField>

<ParamField path={"metamethod"} type={"string"} required>
Metafield name ที่ส่งให้ raw metafield lookup
</ParamField>

<ParamField path={"replacement"} type={"function"} required>
Function ที่ส่งให้ hookfunction เป็น replacement สำหรับ found metamethod function
</ParamField>

## Returns

<ResponseField name={"original"} type={"function"}>
Cloned original metamethod closure ที่ hookfunction คืน
</ResponseField>

## ตัวอย่าง

Hook an existing metamethod function.

```lua
local object = setmetatable({}, {
    __index = function(_, key)
        return key
    end,
})

local original
original = hookmetamethod(object, "__index", function(self, key)
    if key == "Name" then
        return "Real"
    end

    return original(self, key)
end)
```
