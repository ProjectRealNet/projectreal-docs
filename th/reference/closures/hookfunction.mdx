<div className="real-function-page">

```lua
hookfunction(target: function, replacement: function): function
```

## Aliases

- `hookfunc`
- `replaceclosure`
- `detourfunction`
- `detour_function`

## Arguments

<ParamField path={"target"} type={"function"} required>
Function ที่จะ patch การส่ง non-function จะทำให้เกิด type error
</ParamField>

<ParamField path={"replacement"} type={"function"} required>
Function ที่ function ถูก install หรือ map ไปยัง target การส่ง non-function จะทำให้เกิด type error
</ParamField>

## Returns

<ResponseField name={"original"} type={"function"}>
Cloned copy ของ original target closure ที่สร้างก่อน install hook
</ResponseField>

## ตัวอย่าง

Patch a function closure and keep a cloned original.

```lua
local function target(value)
    return value + 1
end

local original
original = hookfunction(target, function(value)
    return original(value) * 2
end)
```
