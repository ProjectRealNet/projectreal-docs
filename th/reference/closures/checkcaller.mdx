คืนว่า current Luau thread อยู่ใน Real caller context หรือไม่ function นี้ไม่รับ arguments และ push boolean result จาก the current caller context function ไม่ตรวจ Lua call stack หรือ function object

## ไวยากรณ์

```lua
checkcaller(): boolean
```

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `isCaller` | `boolean` | true เมื่อ current Luau thread ถูก tracked ใน Real caller context; มิฉะนั้น false |

## ตัวอย่าง

Check whether the current thread is tracked by Real.

```lua
local tracked = checkcaller()
print(tracked)
```
