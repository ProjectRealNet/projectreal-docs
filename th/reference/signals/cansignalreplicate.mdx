ตรวจสอบว่า RBXScriptSignal ส่งผ่าน NetworkClient replication layer ปัจจุบันได้อย่างถูกต้องหรือไม่ function ตรวจสอบ argument แรกว่าเป็น RBXScriptSignal อ่าน source instance และ event descriptor ของ signal แล้วคืนค่า boolean จาก replication layer signal replication validation หากค่า reference ของ replication layer ที่ resolve ได้เป็น 0 จะคืน false arguments เพิ่มเติมจะไม่ถูกอ่าน function นี้ตรวจสอบ signal เท่านั้น และไม่ fire หรือ replicate signal นั้น ตาราง whitelist ที่ getsignalwhitelist คืนค่าไม่ได้ถูกใช้ใน code path นี้

## ไวยากรณ์

```lua
cansignalreplicate(signal: RBXScriptSignal): boolean
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | Signal ที่ต้องตรวจสอบ argument แรกต้องเป็น object ที่มี Luau type name เป็น RBXScriptSignal |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `canReplicate` | `boolean` | ค่า boolean ที่คืนจากการตรวจสอบ replication layer signal replication validation หรือ false เมื่อค่า reference ของ replication layer ที่ resolve ได้เป็น 0 |

## ตัวอย่าง

Check whether an RBXScriptSignal is legal to send before attempting to replicate it.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    print(cansignalreplicate(remote.OnClientEvent))
end
```
