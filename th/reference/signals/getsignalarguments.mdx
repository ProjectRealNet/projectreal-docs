คืน array table ของ type names ที่อ่านจาก event descriptor signature ของ RBXScriptSignal argument แรกต้องเป็น object ที่มี Luau type name เป็น RBXScriptSignal function อ่าน event descriptor ของ signal เดินผ่าน signature slots ด้วย argument stride ของ function อ่าน argument type reference แต่ละรายการ แล้ว push type name string ที่ resolve ได้สำหรับแต่ละ slot ไม่คืน captured runtime argument values หากอ่าน signature ไม่ได้หรือไม่มี entries ถูก push table ที่คืนมาจะมี fallback entry หนึ่งรายการคือ "Variant"

## ไวยากรณ์

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | Signal ที่ต้องตรวจสอบ event descriptor signature object ที่ไม่ใช่ RBXScriptSignal จะทำให้เกิด type error |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `arguments` | `&#123;string&#125;` | Array table ของ argument type name strings จะคืน fallback table ที่มี "Variant" เมื่ออ่าน signature data ไม่ได้หรือไม่มี argument entries ถูกสร้าง |

## ตัวอย่าง

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
