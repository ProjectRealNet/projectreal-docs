คืนค่า array table ใหม่ที่มี whitelist entry แบบคงที่ 6 รายการตามที่กำหนดใน function: OnClientEvent/RemoteEvent, OnServerEvent/RemoteEvent, OnClientInvoke/RemoteFunction, OnServerInvoke/RemoteFunction, OnClientEventUnreliable/UnreliableRemoteEvent, and OnServerEventUnreliable/UnreliableRemoteEvent แต่ละ entry เป็น table ที่มี string field ชื่อ Event และ Parent function นี้ไม่รับ arguments และไม่ตรวจสอบ game state ปัจจุบัน

## ไวยากรณ์

```lua
getsignalwhitelist(): table
```

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `signals` | `table` | Array table ของ whitelist entry แบบคงที่ แต่ละ entry มี string field ชื่อ Event และ Parent |
