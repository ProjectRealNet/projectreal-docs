คืนค่า game:CoreGui lookup.RobloxGui function นี้ไม่รับ arguments หาก CoreGui lookup คืน nil หรือหาก RobloxGui บนค่านั้นเป็น nil function จะคืน nil function ไม่สร้าง container และไม่ใช้ค่า cached CoreGui

## ไวยากรณ์

```lua
gethui(): Instance | nil
```

## Aliases

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | ค่า RobloxGui ที่อ่านจาก CoreGui หรือ nil เมื่อ CoreGui หรือ RobloxGui ไม่พร้อมใช้งาน |
