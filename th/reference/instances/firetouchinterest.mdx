<div className="real-function-page">

```lua
firetouchinterest(partA: Instance, partB: Instance, state: number | boolean)
```

## Aliases

- `firetouchtransmitter`

## Arguments

<ParamField path={"partA"} type={"Instance"} required>
Instance object ตัวแรก ต้องผ่าน IsA("BasePart") touch data และ overlap reference ของค่านี้จะถูกใช้ใน call
</ParamField>

<ParamField path={"partB"} type={"Instance"} required>
Instance object ตัวที่สอง ต้องผ่าน IsA("BasePart") touch data ของค่านี้จะถูกใช้ใน call
</ParamField>

<ParamField path={"state"} type={"number | boolean"} required>
ค่า state ที่จำเป็น numbers จะถูกแปลงด้วย state == 1; booleans จะถูกส่งต่อโดยตรง
</ParamField>

## ตัวอย่าง

ส่งค่า BasePart สองค่าและค่า state ที่ระบุชัดเจนไปยัง firetouchinterest

```lua
local players = game:GetService("Players")
local character = players.LocalPlayer.Character or players.LocalPlayer.CharacterAdded:Wait()
local rootPart = character:WaitForChild("HumanoidRootPart")
local targetPart = workspace.TouchTarget

firetouchinterest(rootPart, targetPart, true)
```
