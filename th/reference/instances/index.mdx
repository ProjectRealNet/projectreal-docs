ตัวช่วยในการค้นพบอินสแตนซ์และการโต้ตอบ

## ฟังก์ชันที่ใช้ได้

<CardGroup cols={2}>
<Card title="fireclickdetector" href="./fireclickdetector">
เรียกใช้ interaction ของ ClickDetector สำหรับผู้เล่น local อาร์กิวเมนต์แรกต้องเป็น Instance ที่มี ClassName เป็น ClickDetector distance เป็นค่าเสริมและค่าเริ่มต้นคือ 0 clickOption เป็นค่าเสริม เปรียบเทียบแบบไม่สนตัวพิมพ์ใหญ่เล็ก และค่าเริ่มต้นคือ "mouseclick" option ที่รองรับคือ "mouseclick", "rightmouseclick", "mousehoverenter" และ "mousehoverleave" option แบบ click จะส่ง distance เป็น float ไปยัง Roblox click helper ส่วน option แบบ hover จะไม่ใช้ distance หาก Players หรือ Players.LocalPlayer ไม่พร้อมใช้งาน function จะกลับโดยไม่เรียกใช้อะไร clickOption ที่ไม่รู้จักก็จะไม่สร้าง interaction เช่นกัน function นี้ไม่คืนค่าใดๆ
</Card>
<Card title="fireproximityprompt" href="./fireproximityprompt">
เรียกใช้ ProximityPrompt ผ่าน ProximityPrompt trigger ของ Real อาร์กิวเมนต์ prompt ต้องเป็น object ที่มีฟิลด์ ClassName เท่ากับ "ProximityPrompt" หากค่าไม่ใช่ object การเรียกจะเกิด type error หาก ClassName หายไปหรือไม่ใช่ string จะเกิด "Invalid Instance" หาก ClassName ไม่ใช่ "ProximityPrompt" จะเกิด "ProximityPrompt expected" function นี้ไม่รับ optional arguments และไม่คืนค่าใดๆ
</Card>
<Card title="firetouchinterest" href="./firetouchinterest">
เรียกใช้ Real touch interest event สำหรับ BasePart instances สองค่า อาร์กิวเมนต์สองตัวแรกต้องเป็น Instance object และทั้งสองค่าต้องผ่าน IsA("BasePart") อาร์กิวเมนต์ state จำเป็นและต้องเป็น number หรือ boolean เมื่อ state เป็น number เฉพาะ 1 จะกลายเป็น true และ number อื่นทั้งหมดจะเป็น false เมื่อ state เป็น boolean ค่า boolean นั้นจะถูกส่งต่อ หาก part ใดไม่มี touch data หรือ part แรกไม่มี overlap reference function จะกลับโดยไม่เรียกใช้อะไร function นี้ไม่คืนค่าใดๆ ความหมาย begin/end ที่แน่นอนของ boolean ที่ส่งไปยัง helper คือ: Nicht aus der Codebasis verifizierbar.
</Card>
<Card title="getcallbackvalue" href="./getcallbackvalue">
อ่าน Lua callback function ที่เก็บอยู่ใน callback property บน Instance อาร์กิวเมนต์แรกต้องเป็น Instance object และอาร์กิวเมนต์ที่สองต้องเป็น string property name instance reference ต้องถูกต้อง property name จะถูก resolve ผ่าน Roblox property metadata และต้องอ้างถึง property ที่มีชนิดเป็น LUA_CALLBACK หากไม่มี property descriptor, property ไม่ใช่ LUA_CALLBACK, ไม่มี callback field offset, ไม่มี callback ที่เก็บไว้, ไม่มี LiveLuaRef, callback อยู่ใน Lua global state อื่น หรือค่าที่อ้างถึงไม่ใช่ function function จะคืน nil และยังตรวจ async callback field fallback เมื่อ callback slot แรกไม่มี callback function นี้ไม่อัปเดต property
</Card>
<Card title="gethui" href="./gethui">
คืนค่า game:CoreGui lookup.RobloxGui function นี้ไม่รับ arguments หาก CoreGui lookup คืน nil หรือหาก RobloxGui บนค่านั้นเป็น nil function จะคืน nil function ไม่สร้าง container และไม่ใช้ค่า cached CoreGui
</Card>
<Card title="getinstances" href="./getinstances">
คืน array table ใหม่ที่มี object value ทุกค่าที่เก็บอยู่ใน Instance cache ในขณะนั้น function นี้ไม่รับ arguments ไม่กรองตาม Parent, ClassName, DataModel fieldship, nil-parent state หรือ Instance validity นอกจากตรวจว่าแต่ละ registry value เป็น object entries จะถูกคัดลอกเข้า table ที่คืนค่าด้วย sequential numeric indexes เริ่มที่ 1 iteration order มาจาก table iteration บน cache และ function ไม่ได้ sort
</Card>
<Card title="getnilinstances" href="./getnilinstances">
Returns a new array table containing cached Instance values whose Parent field is nil. The function takes no arguments. It does not sort the returned entries.
</Card>
<Card title="isnetworkowner" href="./isnetworkowner">
คืนผลลัพธ์จากการอ่าน hidden property "NetworkOwnerV3" จาก Instance และตรวจว่าค่าแรกที่คืนมาเมื่อแปลงด้วย integer conversion มากกว่า 2 หรือไม่ อาร์กิวเมนต์ต้องเป็น Instance object function เรียก the hidden property reader ภายในและไม่จับ errors จากการเรียกนั้น ดังนั้น Invalid Instance values, missing properties หรือ non-property metadata อาจเกิด errors เดียวกับ gethiddenproperty function คืน boolean หนึ่งค่า การที่ peer_id > 2 หมายถึง local network ownership อย่างแม่นยำหรือไม่คือ: Nicht aus der Codebasis verifizierbar.
</Card>
</CardGroup>
