ส่ง left mouse down event และ left mouse up event เมื่อ Roblox window active Real เรียก mouse input ด้วย the requested mouse action โดยไม่มี movement หรือ wheel data function นี้ไม่รับ arguments ไม่คืนค่า และ return โดยไม่ส่ง input เมื่อ isrbxactive จะเป็น false

## ไวยากรณ์

```lua
mouse1click()
```
