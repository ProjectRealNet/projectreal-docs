ส่ง mouse wheel event เมื่อ Roblox window active อาร์กิวเมนต์ amount ถูกตรวจเป็น Lua number แปลงด้วย integer conversion และส่งตรงเป็นค่า dwData ไปยัง mouse input พร้อม the requested mouse action Real ไม่ normalize amount และไม่เพิ่ม movement data function นี้ไม่คืนค่าและ return โดยไม่ส่ง input เมื่อ isrbxactive จะเป็น false

## ไวยากรณ์

```lua
mousescroll(amount: number)
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `amount` | `number` | Yes | Wheel dwData value ที่อ่านเป็น Lua number และแปลงด้วย integer conversion ก่อนส่งไปยัง mouse input |
