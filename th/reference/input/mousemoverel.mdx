เลื่อน mouse ด้วย relative delta เมื่อ Roblox window active อาร์กิวเมนต์ x และ y ถูกตรวจเป็น Lua numbers และแปลงด้วย integer conversion จากนั้นส่งตรงไปยัง mouse input พร้อม the requested mouse action เป็น dx และ dy function นี้ไม่ใช้ the requested mouse action ไม่ทำ client-area conversion ไม่คืนค่า และ return โดยไม่ส่ง input เมื่อ isrbxactive จะเป็น false

## ไวยากรณ์

```lua
mousemoverel(x: number, y: number)
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `x` | `number` | Yes | Relative X movement delta ที่อ่านเป็น Lua number และแปลงด้วย integer conversion ก่อนส่งเป็น dx ไปยัง mouse input |
| `y` | `number` | Yes | Relative Y movement delta ที่อ่านเป็น Lua number และแปลงด้วย integer conversion ก่อนส่งเป็น dy ไปยัง mouse input |
