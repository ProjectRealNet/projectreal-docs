```lua
delfolder(path: string)
```

## Arguments

<ParamField path={"path"} type={"string"} required>
Path ที่ถูก resolve ภายใน workspace หลัง separator normalization และ workspace-boundary checks เป้าหมายต้องมีอยู่และเป็น directory; files ไม่ถูกยอมรับ
</ParamField>

## ตัวอย่าง

ลบ workspace folder ที่มีอยู่และเนื้อหาภายใน

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
