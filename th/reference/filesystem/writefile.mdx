<div className="real-function-page">

```lua
writefile(path: string, content: string)
```

## Aliases

- `writefileasync`

## Arguments

<ParamField path={"path"} type={"string"} required>
File path ที่ถูก resolve ภายใน workspace หลัง separator normalization, workspace-boundary checks และ filename/extension checks. Absolute paths จะถูกยอมรับเฉพาะเมื่อ resolve อยู่ภายใน workspace.
</ParamField>

<ParamField path={"content"} type={"string"} required>
Lua string bytes ที่จะเขียน. ข้อมูลถูกเขียนใน binary truncate mode; writefile ไม่เพิ่ม newlines, BOM bytes, null terminators หรือ extra bytes อื่น.
</ParamField>

## ตัวอย่าง

เขียน bytes ไปยัง workspace file และแทนที่ existing contents.

```lua
local path = "examples/config.json"

writefile(path, '{"enabled":true}')
print(readfile(path))

writefile(path, "")
print(#readfile(path))
```
