<div className="real-function-page">

```lua
getcustomasset(path: string): string
```

## Aliases

- `getsynasset`

## Arguments

<ParamField path={"path"} type={"string"} required>
Path ที่ถูก resolve ภายใน workspace หลัง separator normalization และ workspace-boundary checks เป้าหมายต้องมีอยู่และเป็น regular file; folders, invalid filenames, DOS device names และ blocked extensions ไม่ถูกยอมรับ
</ParamField>

## Returns

<ResponseField name={"assetId"} type={"string"}>
String ในรูปแบบ rbxasset://&lt;hwid>/&lt;workspace-relative-path> โดย relative path ใช้ forward slashes
</ResponseField>

## ตัวอย่าง

คัดลอก workspace file ที่มีอยู่ไปยัง asset folder และพิมพ์ rbxasset path ที่คืนมา

```lua
local path = "assets/example.txt"
writefile(path, "asset bytes")

local assetId = getcustomasset(path)
print(assetId)
print(getsynasset(path))
```
