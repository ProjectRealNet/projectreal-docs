Returns whether a path resolved inside the workspace exists and is a directory.

## ไวยากรณ์

```lua
isfolder(path: string): boolean
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path resolved inside the workspace after separator normalization and workspace-boundary checks. Invalid or outside-workspace paths error before a boolean is returned. |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `isFolder` | `boolean` | True only when the resolved path exists and is a directory; files and missing paths return false. |

## ตัวอย่าง

ตรวจสอบว่า workspace path resolve เป็น directory ที่มีอยู่หรือไม่

```lua
local folderPath = "examples"
local filePath = "examples/config.json"

makefolder(folderPath)
writefile(filePath, "{}")

print(isfolder(folderPath))
print(isfolder(filePath))
print(isfolder("examples/missing"))
```
