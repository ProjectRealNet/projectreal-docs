<div className="real-function-page">

```lua
makefolder(path: string)
```

## Arguments

<ParamField path={"path"} type={"string"} required>
Directory path ที่ถูก resolve ภายใน workspace หลัง separator normalization และ workspace-boundary checks empty, invalid หรือ outside-workspace paths จะเกิด error ก่อนพยายามสร้าง
</ParamField>

## ตัวอย่าง

สร้าง workspace directory และ missing parent directories

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
