สร้าง directory ภายใน workspace ด้วย recursive folder creation รวมถึง missing parent directories

## ไวยากรณ์

```lua
makefolder(path: string)
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Directory path ที่ถูก resolve ภายใน workspace หลัง separator normalization และ workspace-boundary checks empty, invalid หรือ outside-workspace paths จะเกิด error ก่อนพยายามสร้าง |

## ตัวอย่าง

สร้าง workspace directory และ missing parent directories

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
