<div className="real-function-page">

```lua
delfile(path: string)
```

## Arguments

<ParamField path={"path"} type={"string"} required>
Path ที่ถูก resolve ภายใน workspace หลัง separator normalization และ workspace-boundary checks เป้าหมายต้องมีอยู่และเป็น regular file; folders ไม่ถูกยอมรับ
</ParamField>

## ตัวอย่าง

ลบ workspace file ที่มีอยู่

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
