อ่าน เขียน และจัดการไฟล์และโฟลเดอร์

## ฟังก์ชันที่ใช้ได้

<CardGroup cols={2}>
<Card title="appendfile" href="./appendfile">
Appends raw Lua string bytes to a workspace file using binary append mode. The file may be created if its parent folder exists.
</Card>
<Card title="delfile" href="./delfile">
ลบ regular file ที่มีอยู่ภายใน workspace
</Card>
<Card title="delfolder" href="./delfolder">
ลบ folder ที่มีอยู่ภายใน workspace แบบ recursive ด้วย recursive folder deletion
</Card>
<Card title="getcustomasset" href="./getcustomasset">
คัดลอก regular workspace file ที่มีอยู่ไปยัง ExtraContent/&lt;hwid>/ และคืน rbxasset:// string สำหรับ asset path ที่ถูกคัดลอก
</Card>
<Card title="isfile" href="./isfile">
Returns whether a path resolved inside the workspace exists and is a regular file.
</Card>
<Card title="isfolder" href="./isfolder">
Returns whether a path resolved inside the workspace exists and is a directory.
</Card>
<Card title="listfiles" href="./listfiles">
Returns an array table of the direct children of an existing workspace directory.
</Card>
<Card title="loadfile" href="./loadfile">
Reads a workspace file, compiles its contents with the Luau compiler, and returns the loaded Luau function without executing it.
</Card>
<Card title="makefolder" href="./makefolder">
สร้าง directory ภายใน workspace ด้วย recursive folder creation รวมถึง missing parent directories
</Card>
<Card title="openfiledialog" href="./openfiledialog">
เปิด Windows file-open dialog ผ่าน Windows file picker และคืนไฟล์ที่เลือกเป็น file item
</Card>
<Card title="openfilesdialog" href="./openfilesdialog">
เปิด Windows file-open dialog ผ่าน Windows file picker โดยเปิดใช้ multi-select และคืนไฟล์ที่เลือกเป็นค่า file item
</Card>
<Card title="openfolderdialog" href="./openfolderdialog">
เปิด Windows folder picker ผ่าน Windows file picker พร้อม folder selection mode และคืนโฟลเดอร์ที่เลือกเป็น file item
</Card>
<Card title="readfile" href="./readfile">
อ่าน existing regular file ภายใน workspace ใน binary mode และคืน bytes เป็น Lua string
</Card>
<Card title="savefiledialog" href="./savefiledialog">
เปิด Windows save dialog ผ่าน Windows save dialog เขียน Lua string bytes ที่ส่งเข้ามาไปยัง selected path และคืน saved file เป็น file item
</Card>
<Card title="writefile" href="./writefile">
เขียน Lua string bytes ไปยังไฟล์ภายใน workspace สร้าง missing parent directories และแทนที่ file contents ถ้าไฟล์มีอยู่แล้ว
</Card>
</CardGroup>
