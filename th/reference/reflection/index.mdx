ตัวช่วยการสะท้อนสำหรับอินสแตนซ์และคุณสมบัติ

| การนำทางฟังก์ชัน | คำอธิบาย |
| --- | --- |
| [`gethiddenproperty`](./gethiddenproperty) | อ่าน Roblox property ผ่าน reflection metadata รวมถึง non-scriptable properties อาร์กิวเมนต์แรกต้องเป็น Instance object และอาร์กิวเมนต์ที่สองต้องเป็น string property name instance reference ต้องถูกต้อง หาก property descriptor หายไปจาก Roblox property metadata function จะคืนเฉพาะ nil หาก descriptor มีอยู่แต่ไม่ resolve เป็น property entry จะเกิด "Not a property" สำหรับ reflection types Bool, Int, Float, Double, String, SystemAddress, SharedString และ Vector3 function จะเรียก getter และคืน value พร้อม boolean ที่เท่ากับ !IsScriptable() SystemAddress คืน RemoteId.PeerId เป็น integer SharedString คืน Content เป็น string Vector3 อ่านจาก instance primitive Size offset และเกิด "can't get value" หาก touch data หายไป property types อื่นอ่านผ่าน normal Lua field access หลังจากตั้ง property scriptable flag เป็น true ชั่วคราว; BinaryString จะถูกปฏิบัติเป็น String ชั่วคราวสำหรับการอ่านนั้น original scriptable flag และ BinaryString type จะถูกคืนค่าก่อน return |
| [`isscriptable`](./isscriptable) | ตรวจสอบ scriptable flag ของ Roblox property บน Instance function จะคืนค่า scriptable ที่อยู่ใน cache ก่อน หากมีค่าสำหรับ instance reference และ property name เดียวกัน เมื่อเกิด cache miss จะ resolve property name ผ่าน Roblox property metadata และ Instance class descriptor หากไม่มี descriptor หรือ field ที่ resolve ได้ไม่มีอยู่หรือไม่ใช่ property entry function จะคืนค่า nil เมื่อพบ property entry function จะอ่าน scriptable state เก็บค่านั้นใน scriptable override cache สำหรับ instance และ property แล้วคืนค่า boolean function นี้ไม่เปลี่ยน scriptable flag |
| [`sethiddenproperty`](./sethiddenproperty) | Sets a Roblox property with reflection metadata. The first argument must be Instance object, the second argument must be a string property name, and the third argument must be present. The instance reference must be valid. If the property descriptor is missing from Roblox property metadata, the function returns nil. If the descriptor exists but does not resolve to a property entry, it raises "Not a property". Bool values use luaL_checkboolean. Int and SystemAddress values use integer type checking, with SystemAddress writing RemoteId.PeerId. Float and Double values use number type checking. String, SharedString, and BinaryString values use string type checking before calling the setter. For other property types, the function temporarily calls setscriptable(instance, property, true), assigns instance[property] = value with normal Lua field assignment, then restores the original scriptable state with setscriptable(instance, property, isScriptable). On successful writes, the return value is a boolean equal to !IsScriptable() from before the write. |
| [`setscriptable`](./setscriptable) | เก็บ scriptable override สำหรับ Roblox property ไว้ใน scriptable override cache และคืน previous scriptable state อาร์กิวเมนต์แรกต้องเป็น Instance object อาร์กิวเมนต์ที่สองต้องเป็น string property name และอาร์กิวเมนต์ที่สามต้องเป็น boolean หากมี cache entry อยู่แล้วสำหรับ instance reference และ property name เดียวกัน cached scriptable value จะถูกแทนที่และคืนค่า cached value เก่า เมื่อเกิด cache miss จะ resolve property name ผ่าน Roblox property metadata และ Instance class descriptor หากไม่มี descriptor หรือ field ที่ resolve ได้ไม่มีอยู่หรือไม่ใช่ property entry function จะคืนค่า nil เมื่อพบ property entry function จะอ่าน scriptable state เก็บ boolean ที่ขอพร้อม property reference ใน scriptable override cache แล้วคืน previous scriptable state value GameIndexHook และ GameNewIndexHook จะใช้ cache นี้ภายหลังโดยตั้ง property field scriptable flag ชั่วคราวสำหรับ indexed read หรือ write หนึ่งครั้ง แล้วคืน previous field flag |
