<div className="real-function-page">

```lua
isscriptable(instance: Instance, property: string): boolean | nil
```

## Arguments

<ParamField path={"instance"} type={"Instance"} required>
Instance object ที่ต้องตรวจสอบ property scriptable state.
</ParamField>

<ParamField path={"property"} type={"string"} required>
Property name ที่ resolve ผ่าน Roblox property metadata และ Instance class descriptor.
</ParamField>

## Returns

<ResponseField name={"scriptable"} type={"boolean | nil"}>
ค่า scriptable state จาก cache หรือค่าปัจจุบัน หรือ nil เมื่อ property descriptor/field ไม่มีอยู่หรือไม่ใช่ property entry.
</ResponseField>

## ตัวอย่าง

Check whether a property is scriptable on an Instance.

```lua
local scriptable = isscriptable(workspace, "Name")
print(scriptable)
```
