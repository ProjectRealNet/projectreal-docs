<div className="real-function-page">

```lua
crypt.generatebytes(size: number): string
```

## Arguments

<ParamField path={"size"} type={"number"} required>
ตัวเลขที่ผ่าน integer conversion ก่อน allocation ค่าที่น้อยกว่าหรือเท่ากับ 0 จะถูกเปลี่ยนเป็น 1
</ParamField>

## Returns

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding ของ raw bytes ที่สร้างขึ้น ความยาวของ string ที่คืนค่าไม่ใช่จำนวน byte ที่ขอ
</ResponseField>

## ตัวอย่าง

สร้าง bytes และ decode ผลลัพธ์ Base64 เมื่อต้องใช้ raw bytes

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
