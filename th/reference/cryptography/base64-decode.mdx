ถอดรหัสอินพุต Base64 ด้วย Base64 decoder และคืนค่า byte ที่ถอดรหัสแล้วเป็น Lua string

## ไวยากรณ์

```lua
base64_decode(data: string): string
```

## Aliases

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `data` | `string` | Yes | อินพุต Base64 ที่ส่งให้ Base64 decoder |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `decoded` | `string` | byte ที่ถอดรหัสแล้วซึ่งคืนค่าเป็น Lua string พร้อมความยาวแบบ explicit |

## ตัวอย่าง

ถอดรหัสข้อมูล Base64 และอ่าน Lua string ที่คืนค่า

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
