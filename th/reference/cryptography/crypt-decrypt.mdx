<div className="real-function-page">

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Arguments

<ParamField path={"data"} type={"string"} required>
Base64 ciphertext ที่ถูก decode ก่อนถอดรหัส
</ParamField>

<ParamField path={"key"} type={"string"} required>
Base64 key ที่ถูก decode ก่อนส่งให้ AES
</ParamField>

<ParamField path={"iv"} type={"string"} required>
Base64 IV ที่ถูก decode ก่อนประมวลผล mode อาร์กิวเมนต์นี้จำเป็น รวมถึง ECB
</ParamField>

<ParamField path={"mode"} type={"\"CBC\" | \"ECB\" | \"AES-CBC\" | \"AES-ECB\""}>
AES mode ถ้ามี prefix AES- จะถูกลบ ค่าเริ่มต้นคือ AES-CBC
</ParamField>

## Returns

<ResponseField name={"plaintext"} type={"string"}>
byte plaintext ที่คืนค่าเป็น Lua string
</ResponseField>

## ตัวอย่าง

ถอดรหัส ciphertext ที่ crypt.encrypt คืนค่าโดยใช้ IV ที่คืนมา

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
