<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Arguments

<ParamField path={"key"} type={"string"} required>
byte ของ raw Lua string ที่ใช้เป็น HMAC key โดย key จะไม่ถูก Base64-decode
</ParamField>

<ParamField path={"data"} type={"string"} required>
byte ของ Lua string ที่ส่งเข้า HMAC calculation
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
ชื่อ HMAC algorithm แบบ case-sensitive ค่าเริ่มต้นคือ sha256
</ParamField>

## Returns

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output ที่ไม่มี line breaks
</ResponseField>

## ตัวอย่าง

คำนวณ Base64 HMAC output จาก raw Lua string key และ data

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
