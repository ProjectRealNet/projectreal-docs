<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Arguments

<ParamField path={"size"} type={"number"} required>
ตัวเลขที่ผ่าน integer conversion ก่อน allocation ค่าที่น้อยกว่าหรือเท่ากับ 0 จะทำให้เกิด argument error
</ParamField>

## Returns

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes ที่คืนค่าเป็น Lua string ความยาวของ string ที่คืนค่าตรงกับจำนวน byte ที่ allocation
</ResponseField>

## ตัวอย่าง

สร้าง raw bytes และพิมพ์ความยาวของ Lua string ที่คืนค่า

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
