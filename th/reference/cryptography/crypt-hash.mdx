hash byte ของ Lua string ด้วยอัลกอริทึม crypto library hash ที่รองรับ และคืนค่า lowercase hexadecimal digest

## ไวยากรณ์

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `data` | `string` | Yes | byte ของ Lua string ที่ส่งให้ crypto library HashFilter |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | ชื่ออัลกอริทึม hash แบบ case-sensitive ค่าเริ่มต้นคือ sha256 |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest ที่ไม่มี prefix หรือ separators |

## ตัวอย่าง

hash byte ของ Lua string ด้วยอัลกอริทึมเริ่มต้นหรือชื่อที่รองรับแบบ explicit

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
