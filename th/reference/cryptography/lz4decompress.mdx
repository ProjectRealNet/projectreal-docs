```lua
lz4decompress(data: string, originalSize?: number): string
```

## Aliases

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Arguments

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes ที่ส่งให้ LZ4 block decompression
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size ที่ส่งเป็น dstCapacity สำหรับ output จาก lz4compress ให้ส่งความยาว bytes เดิมก่อนบีบอัด หากไม่ระบุ จะใช้ความยาวของ input ที่ถูกบีบอัด
</ParamField>

## Returns

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes ที่คืนเป็นสตริง Lua output อาจสั้นกว่า originalSize ได้
</ResponseField>

## ตัวอย่าง

แตก LZ4 bytes โดยส่งขนาดเดิมก่อนบีบอัด

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
