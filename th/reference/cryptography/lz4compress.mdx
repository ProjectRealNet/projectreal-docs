```lua
lz4compress(data: string): string
```

## Aliases

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Arguments

<ParamField path={"data"} type={"string"} required>
byte ของ Lua string ที่ส่งให้ LZ4 block compression
</ParamField>

## Returns

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes ที่คืนค่าเป็น Lua string โดย original size ไม่ได้ถูกเก็บไว้ใน output
</ResponseField>

## ตัวอย่าง

บีบอัด byte ของ Lua string และกู้คืนโดยส่ง original size

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
