```lua
crypt.generatekey(): string
```

## Returns

<ResponseField name={"key"} type={"string"}>
Base64 encoding ของ raw bytes 32 byte ที่สร้างขึ้น string ที่คืนค่าไม่ได้ยาว 32 ตัวอักษร
</ResponseField>

## ตัวอย่าง

สร้าง Base64 key และ decode เพื่อตรวจจำนวน raw bytes

```lua
local key = crypt.generatekey()
local raw = base64_decode(key)

local ciphertext, iv = crypt.encrypt("hello world", key)

print(key)
print(#raw)
print(ciphertext, iv)
```
