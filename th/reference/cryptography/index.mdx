การเข้ารหัส การแฮช การเข้ารหัส และการบีบอัด

## ฟังก์ชันที่ใช้ได้

<CardGroup cols={2}>
<Card title="base64_decode" href="./base64-decode">
ถอดรหัสอินพุต Base64 ด้วย Base64 decoder และคืนค่า byte ที่ถอดรหัสแล้วเป็น Lua string
</Card>
<Card title="base64_encode" href="./base64-encode">
เข้ารหัส byte ของ Lua string ด้วย Base64 encoder โดยใช้ = padding และไม่มี line break
</Card>
<Card title="crypt.decrypt" href="./crypt-decrypt">
ถอดรหัส Base64 ciphertext ด้วย key ที่ decode จาก Base64 และ Base64 IV ที่ต้องมี โดยใช้ AES CBC หรือ ECB
</Card>
<Card title="crypt.encrypt" href="./crypt-encrypt">
เข้ารหัส byte ของ Lua string ด้วย AES CBC, ECB หรือ CTR โดยใช้ key ที่ decode จาก Base64 แล้วคืนค่า Base64 ciphertext และผลลัพธ์ IV
</Card>
<Card title="crypt.generatebytes" href="./crypt-generatebytes">
สร้าง byte แบบสุ่มด้วย random byte generator และคืนค่าเป็น Base64-encoded ในรูปแบบ Lua string
</Card>
<Card title="crypt.generatekey" href="./crypt-generatekey">
สร้าง raw bytes แบบสุ่ม 32 byte ด้วย random byte generator และคืนค่าเป็น Base64-encoded ในรูปแบบ Lua string
</Card>
<Card title="crypt.hash" href="./crypt-hash">
hash byte ของ Lua string ด้วยอัลกอริทึม crypto library hash ที่รองรับ และคืนค่า lowercase hexadecimal digest
</Card>
<Card title="crypt.hmac" href="./crypt-hmac">
คำนวณ crypto library HMAC บน byte ของ Lua string โดยใช้ raw Lua string key และคืนค่า Base64 digest
</Card>
<Card title="crypt.random" href="./crypt-random">
สร้าง raw random bytes ด้วย random byte generator และคืนค่าเป็น Lua string
</Card>
<Card title="lz4compress" href="./lz4compress">
บีบอัด byte ของ Lua string ด้วย LZ4 block compression และคืนค่า raw compressed bytes เป็น Lua string
</Card>
<Card title="lz4decompress" href="./lz4decompress">
แตก raw LZ4 block bytes ด้วย LZ4 block decompression และคืน raw decompressed bytes เป็นสตริง Lua
</Card>
</CardGroup>
