<div className="real-function-page">

```lua
getscriptbytecode(script: userdata): string | nil
```

## Arguments

<ParamField path={"script"} type={"userdata"} required>
Script object ที่จะอ่าน ค่า ClassName ที่รองรับคือ ModuleScript, LocalScript, CoreScript และ Script ที่มี RunContext Client
</ParamField>

## Returns

<ResponseField name={"bytecode"} type={"string | nil"}>
Decompressed bytecode bytes เป็น Luau string, DecompressBytecode error text bytes หรือ nil เมื่อไม่มี embedded bytecode ที่ใช้งานได้
</ResponseField>

## ตัวอย่าง

Read decompressed bytecode from a supported Roblox script Instance.

```lua
local targetScript

for _, descendant in ipairs(game:GetDescendants()) do
    if descendant:IsA("LuaSourceContainer") then
        targetScript = descendant
        break
    end
end

if targetScript then
    local bytecode = getscriptbytecode(targetScript)
    print(bytecode)
end
```
