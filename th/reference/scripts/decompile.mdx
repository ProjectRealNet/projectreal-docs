decompile Roblox script และคืน source text ที่สร้างขึ้นเมื่อมี bytecode ให้ใช้ argument ต้องเป็น script Instance ที่รองรับ ถ้าไม่มี bytecode ที่ใช้ได้ function จะคืน nil

## ไวยากรณ์

```lua
decompile(script: userdata): string | nil
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `script` | `userdata` | Yes | Script object ที่ต้อง decompile ค่า ClassName ที่รองรับคือ ModuleScript, LocalScript, CoreScript และ Script ที่มี RunContext Client. |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `source` | `string \| nil` | Decompiler output string, caught decompiler exception text, หรือ nil เมื่อไม่มี usable embedded bytecode. |

## ตัวอย่าง

Decompile a supported Roblox script Instance. To decompile a whole game, iterate its descendants or use a saveinstance workflow.

```lua
local targetScript

for _, descendant in ipairs(game:GetDescendants()) do
    if descendant:IsA("LuaSourceContainer") then
        targetScript = descendant
        break
    end
end

if targetScript then
    local source = decompile(targetScript)

    if source then
        print(source)
    end
end
```
