อัปเดต vertical synchronization preference ของ ImGui renderer โดย presentation path ปัจจุบันเก็บ preference นี้ไว้แต่ไม่ได้ใช้งาน

## ไวยากรณ์

```lua
imgui.setvsync(enabled: boolean)
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `enabled` | `boolean` | Yes | `true` เพื่อขอ vertical synchronization; `false` เพื่อขอ uncapped presentation |
