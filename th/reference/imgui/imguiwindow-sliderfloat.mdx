<div className="real-function-page">

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Arguments

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow ที่ส่งคืนจาก imgui.create หาก object ไม่ถูกต้องหรือถูก destroy ไปแล้ว method จะทำให้เกิด Lua error
</ParamField>

<ParamField path={"label"} type={"string"} required>
Slider label ที่อ่านด้วย string type checking
</ParamField>

<ParamField path={"value"} type={"number"} required>
ค่าเริ่มต้นของ slider ที่อ่านด้วย number type checking และเก็บเป็นค่า float ปัจจุบัน
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
Minimum value ที่อ่านด้วย number type checking และส่งต่อไปยัง a floating-point slider
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
Maximum value ที่อ่านด้วย number type checking และส่งต่อไปยัง a floating-point slider
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Callback function ที่เก็บใน Lua registry เมื่อ slider เปลี่ยนระหว่าง rendering จะถูกเรียกภายหลังด้วยค่าตัวเลขที่อัปเดตแล้ว
</ParamField>

## Returns

<ResponseField name={"window"} type={"ImGuiWindow"}>
ImGuiWindow object เดิม ซึ่งทำให้เรียก method ต่อกันเป็น chain ได้
</ResponseField>
