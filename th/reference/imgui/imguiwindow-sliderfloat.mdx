เพิ่ม SliderFloat element ไปยัง window โดยอ่าน label, value, minimum และ maximum จากอาร์กิวเมนต์ 2 ถึง 5 และตรวจอาร์กิวเมนต์ตัวเลขด้วย number type checking ระหว่าง rendering Real จะเรียก a floating-point slider ด้วย value และ range ที่เก็บไว้ เมื่อ ImGui รายงานว่า value เปลี่ยน onChange จะถูกใส่ใน queue และถูกเรียกภายหลังด้วย Lua number หนึ่งค่า Real ไม่เพิ่มการตรวจ minimum &lt;= maximum แยกต่างหากใน closure นี้

## ไวยากรณ์

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow ที่ส่งคืนจาก imgui.create หาก object ไม่ถูกต้องหรือถูก destroy ไปแล้ว method จะทำให้เกิด Lua error |
| `label` | `string` | Yes | Slider label ที่อ่านด้วย string type checking |
| `value` | `number` | Yes | ค่าเริ่มต้นของ slider ที่อ่านด้วย number type checking และเก็บเป็นค่า float ปัจจุบัน |
| `minimum` | `number` | Yes | Minimum value ที่อ่านด้วย number type checking และส่งต่อไปยัง a floating-point slider |
| `maximum` | `number` | Yes | Maximum value ที่อ่านด้วย number type checking และส่งต่อไปยัง a floating-point slider |
| `onChange` | `(number) -> ()` | Yes | Callback function ที่เก็บใน Lua registry เมื่อ slider เปลี่ยนระหว่าง rendering จะถูกเรียกภายหลังด้วยค่าตัวเลขที่อัปเดตแล้ว |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `window` | `ImGuiWindow` | ImGuiWindow object เดิม ซึ่งทำให้เรียก method ต่อกันเป็น chain ได้ |
