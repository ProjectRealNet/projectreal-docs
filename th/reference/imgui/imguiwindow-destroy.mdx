```lua
ImGuiWindow.destroy(window: ImGuiWindow)
```

## Arguments

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object ที่ส่งคืนโดย imgui.create ค่าที่ไม่ใช่ ImGuiWindow จะทำให้เกิด Lua error
</ParamField>

## Types

### ImGuiWindow

หมายเลขอ้างอิงส่งคืนโดย imgui.create วิธีการสร้างการควบคุมส่งคืนหมายเลขอ้างอิงเดียวกันเพื่อให้สามารถต่อสายได้

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `Button` | `(label: string, onClick: () -> ()) -> ImGuiWindow` | Yes | ผนวกปุ่มและเรียกกลับหลังจากการคลิก |
| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | ผนวกช่องทำเครื่องหมายที่เตรียมใช้งานกับสถานะที่ให้ไว้ |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | การควบคุมกลุ่มต่อท้ายด้วยการเรียกกลับเนื้อหาใต้ส่วนหัวที่ยุบ |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | ต่อท้ายโปรแกรมแก้ไข RGBA ละเว้นส่วนประกอบสีเริ่มต้นที่ 1.0 |
| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | ผนวกการป้อนข้อความบรรทัดเดียว ละเว้นค่าเริ่มต้นของข้อความเริ่มต้นเป็นสตริงว่าง |
| `SameLine` | `() -> ImGuiWindow` | Yes | วางตัวควบคุมถัดไปบนบรรทัดเดียวกัน |
| `Separator` | `() -> ImGuiWindow` | Yes | ผนวกตัวคั่นแนวนอน |
| `SliderFloat` | `(label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow` | Yes | เพิ่มแถบเลื่อนจุดลอยตัวต่อท้าย |
| `SliderInt` | `(label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow` | Yes | เพิ่มแถบเลื่อนจำนวนเต็มต่อท้าย |
| `Text` | `(text: string) -> ImGuiWindow` | Yes | ต่อท้ายข้อความที่ไม่โต้ตอบ |
| `destroy` | `() -> ()` | Yes | ลบหน้าต่างและปล่อยการเรียกกลับที่ลงทะเบียนไว้ |
