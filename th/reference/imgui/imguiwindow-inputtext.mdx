<div className="real-function-page">

```lua
ImGuiWindow.InputText(window: ImGuiWindow, label: string, text?: string, onChange: function): ImGuiWindow
```

## Arguments

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object ที่ส่งคืนโดย imgui.create window ที่ถูกทำลายหรือไม่ถูกต้องจะทำให้เกิด Lua error
</ParamField>

<ParamField path={"label"} type={"string"} required>
Input label string ที่ส่งไปยัง ImGui InputText widget ที่ render แล้ว
</ParamField>

<ParamField path={"text"} type={"string"}>
Initial text อ่านด้วย optional string handling ส่ง nil ที่นี่เมื่อคุณต้องการ default empty string แต่ยังส่ง onChange เป็น argument 4
</ParamField>

<ParamField path={"onChange"} type={"function"} required>
Function ที่เก็บไว้สำหรับ input นี้และถูกเรียกพร้อม current string หลังจาก edit event ถูกประมวลผล ต้องส่งเป็น argument 4
</ParamField>

## Returns

<ResponseField name={"window"} type={"ImGuiWindow"}>
ImGuiWindow object เดิม ทำให้สามารถ chain method calls ได้
</ResponseField>
