<div className="real-function-page">

```lua
rconsoleprint(...values?: ...any)
```

## Aliases

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Arguments

<ParamField path={"...values"} type={"...any"}>
ค่าเสริม หากมี console แต่ละ value จะถูกแปลงด้วย Lua string conversion และรวมด้วยอักขระ tab ก่อนเขียน
</ParamField>

## ตัวอย่าง

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
