เขียนค่าจำนวนศูนย์ค่าหรือมากกว่าไปยัง Windows console ปัจจุบันผ่าน stdout โดยไม่เปลี่ยน console text attribute ค่าแต่ละค่าถูกแปลงด้วย Lua string conversion และคั่นด้วยอักขระ tab function ไม่เพิ่ม newline หากไม่มี console window การเรียกจะกลับโดยไม่แปลงหรือเขียนอะไร

## ไวยากรณ์

```lua
rconsoleprint(...values?: ...any)
```

## Aliases

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `...values` | `...any` | No | ค่าเสริม หากมี console แต่ละ value จะถูกแปลงด้วย Lua string conversion และรวมด้วยอักขระ tab ก่อนเขียน |

## ตัวอย่าง

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
