ล้าง current Windows console screen buffer เมื่อมี console window ถ้าไม่มี console window, call จะ return โดยไม่ทำอะไร

## ไวยากรณ์

```lua
rconsoleclear()
```

## Aliases

- `consoleclear`

## ตัวอย่าง

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
