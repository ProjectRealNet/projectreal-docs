ซ่อน Windows console window ปัจจุบันด้วย Windows console visibility update โดยใช้ hide mode function ไม่เรียก console detachment ดังนั้นจึงไม่ detach จาก console และไม่ destroy console หากไม่มี console window การเรียกจะกลับโดยไม่ทำอะไร

## ไวยากรณ์

```lua
rconsolehide()
```

## Aliases

- `consolehide`

## ตัวอย่าง

Hide the current Windows console without detaching from it.

```lua
rconsolecreate()
rconsolehide()
```
