```lua
rconsoleinfo(...values?: ...any)
```

## Aliases

- `consoleinfo`

## Arguments

<ParamField path={"...values"} type={"...any"}>
ค่าเสริม หากมี console แต่ละ value จะถูกแปลงด้วย Lua string conversion และรวมด้วยอักขระ tab ก่อนเขียน
</ParamField>

## ตัวอย่าง

Write a bright blue message to the current Windows console.

```lua
rconsolecreate()
rconsoleinfo("Connected", "
")
```
