แสดง Windows console window ปัจจุบันด้วย Windows console visibility update โดยใช้ show mode function นี้ไม่สร้าง console หากไม่มี console window อยู่ การเรียกจะกลับโดยไม่ทำอะไร

## ไวยากรณ์

```lua
rconsoleshow()
```

## Aliases

- `consoleshow`

## ตัวอย่าง

Show the current Windows console window when one exists.

```lua
rconsolecreate()
rconsolehide()
rconsoleshow()
```
