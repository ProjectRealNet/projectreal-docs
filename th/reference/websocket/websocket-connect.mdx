```lua
WebSocket.connect(url: string): WebSocket
```

## Aliases

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## Arguments

<ParamField path={"url"} type={"string"} required>
URL string ที่ส่งให้ CURLOPT_URL ก่อนที่ WebSocket client จะทำ WebSocket connection attempt
</ParamField>

## Returns

<ResponseField name={"socket"} type={"WebSocket"}>
WebSocket table ที่มี OnMessage, OnClose และ connection state Send และ Close ถูก resolve ผ่าน WebSocket object methods
</ResponseField>

## ตัวอย่าง

เปิด WebSocket เชื่อม OnMessage และ OnClose แล้วใช้ socket methods เพื่อส่งและปิด

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
