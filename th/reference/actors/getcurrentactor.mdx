```lua
getcurrentactor(): Instance | nil
```

## Aliases

- `get_current_actor`

## Returns

<ResponseField name={"actor"} type={"Instance | nil"}>
Actor Instance ที่ resolve จาก the associated Actor weak reference ของ current thread หรือ nil เมื่อไม่มี valid actor reference
</ResponseField>

## ตัวอย่าง

Resolve the Actor Instance associated with the current Luau thread.

```lua
local actor = getcurrentactor()

print(actor)
```
