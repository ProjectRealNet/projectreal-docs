คืน array table ของ Luau threads จาก actor thread list function นี้ไม่รับ arguments อ่าน actor list bounds จาก ScriptContext เดินผ่านแต่ละ actor state entry, decrypt stored global state เป็น Luau thread และรวมเฉพาะ entries ที่เป็น valid threads

## ไวยากรณ์

```lua
getactorthreads(): {thread}
```

## Aliases

- `getactorstates`

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `threads` | `&#123;thread&#125;` | Array table ของ actor Luau thread values ที่ถูก push เป็น Luau threads. |

## ตัวอย่าง

List Luau threads from the ScriptContext actor state list.

```lua
for _, thread in ipairs(getactorthreads()) do
    print(thread)
end
```
