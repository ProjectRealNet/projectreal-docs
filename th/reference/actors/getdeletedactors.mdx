คืน array table ของ Luau threads จาก actor list ที่ thread data มี Actor reference, reference count มากกว่า 0 และ the associated Actor เป็น expired weak reference function นี้ไม่รับ arguments และไม่คืน Actor Instance values

## ไวยากรณ์

```lua
getdeletedactors(): table
```

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `threads` | `table` | Array table ที่มี Luau thread values สำหรับ actor entries ที่ Actor weak reference เป็น expired |

## ตัวอย่าง

List actor threads whose Actor weak reference is expired.

```lua
local deletedActorThreads = getdeletedactors()

for _, thread in ipairs(deletedActorThreads) do
    print(thread)
end
```
