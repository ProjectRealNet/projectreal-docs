```lua
json.keys(object: table): table
```

## Arguments

<ParamField path={"object"} type={"table"} required>
Table ที่จะ inspect. function ต้องการให้ argument นี้เป็น table.
</ParamField>

## Returns

<ResponseField name={"keys"} type={"table"}>
New array table ที่มี source table keys โดยไม่รวม Real JSON type marker. Order ตาม table iteration iteration และ function นี้ไม่ได้ sorted.
</ResponseField>

## ตัวอย่าง

Collect visible keys ของ table เข้า new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
