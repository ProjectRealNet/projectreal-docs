<div className="real-function-page">

```lua
json.object(source?: table): table
```

## Arguments

<ParamField path={"source"} type={"table"}>
Optional source table สำหรับ copy เข้า new object table. ถ้า omitted หรือ nil จะคืน empty object table.
</ParamField>

## Returns

<ResponseField name={"object"} type={"table"}>
New table marked ด้วย Real JSON object marker. Source entries ถูก copy ยกเว้น Real JSON type marker.
</ResponseField>

## ตัวอย่าง

Create new table marked as a JSON object รวมถึง empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
