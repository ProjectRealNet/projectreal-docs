สร้าง new table marked as a JSON object เพื่อให้ Real JSON encoder จัดการเป็น object.

## ไวยากรณ์

```lua
json.object(source?: table): table
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table สำหรับ copy เข้า new object table. ถ้า omitted หรือ nil จะคืน empty object table. |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `object` | `table` | New table marked ด้วย Real JSON object marker. Source entries ถูก copy ยกเว้น Real JSON type marker. |

## ตัวอย่าง

Create new table marked as a JSON object รวมถึง empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
