<div className="real-function-page">

```lua
json.quote(text: string): string
```

## Arguments

<ParamField path={"text"} type={"string"} required>
String ที่จะ quote. function อ่าน argument นี้ด้วย string type checking.
</ParamField>

## Returns

<ResponseField name={"quoted"} type={"string"}>
Complete JSON string literal ที่รวม opening และ closing quote. Quotes, backslashes, common control characters และ bytes below 0x20 จะถูก escape.
</ResponseField>

## ตัวอย่าง

Convert string เป็น complete quoted JSON string literal.

```lua
local source = "Real Docs" .. string.char(10) .. [[Documentation "A"]]
local quoted = json.quote(source)

print(quoted)
```
