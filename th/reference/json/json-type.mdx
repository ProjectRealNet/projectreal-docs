<div className="real-function-page">

```lua
json.type(value: any): string
```

## Arguments

<ParamField path={"value"} type={"any"} required>
ค่าที่จะ classify การส่ง no value จะคืน runtime type name สำหรับ stack value ที่ขาดหายไป
</ParamField>

## Returns

<ResponseField name={"jsonType"} type={"string"}>
Type name string. JSON-specific returns ที่ตรวจสอบแล้วคือ "null", "array" และ "object" ค่า non-table และ non-json.null ใช้ Lua type name เช่น "nil", "boolean", "number", "integer", "string", "function", "object", "thread", "buffer", "class", "object", "vector" หรือ "no value" ตาม runtime value
</ResponseField>

## ตัวอย่าง

ตรวจสอบ exact type string ที่ JSON helper ส่งคืน

```lua
print(json.type(json.array({ "red", "blue" })))
print(json.type(json.object({ enabled = true })))
print(json.type(json.null))
print(json.type(nil))
print(json.type())
```
