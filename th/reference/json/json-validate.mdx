Validate JSON string โดย parse complete JSON value หนึ่งค่า เมื่อ success จะ return เฉพาะ true เมื่อ parse failure จะ return false พร้อม parser error details

## ไวยากรณ์

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Arguments

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string ที่จะ validate function อ่าน argument นี้ด้วย string type checking |
| `options` | `DecodeOptions` | No | Optional decode options. boolean ตั้งค่า useNull. table สามารถตั้งค่า useNull และ maxDepth. maxDepth ถูก clamp จาก 1 ถึง 4096 |

## Returns

| Name | Type | คำอธิบาย |
| --- | --- | --- |
| `valid` | `boolean` | true เมื่อ parsing complete JSON value หนึ่งค่าสำเร็จ false เมื่อ parsing ล้มเหลวภายใน protected parse block |
| `errorMessage` | `string \| nil` | Error message เมื่อ parse failure. message มี prefix json.validate และมี near-position suffix. return นี้มีเฉพาะตอน failure |
| `errorPosition` | `number \| nil` | Parser byte position จาก parser เมื่อ parse failure. return นี้มีเฉพาะตอน failure |

## Types

### DecodeOptions

ควบคุมพฤติกรรมการแยกวิเคราะห์ JSON

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | แสดงถึง JSON null ด้วย null sentinel ของไลบรารีแทนที่จะเป็น nil |
| `maxDepth` | `integer` | No | ตั้งค่าความลึกของการซ้อนสูงสุด โดยยึดไว้ตั้งแต่ 1 ถึง 4096 |

## ตัวอย่าง

ตรวจสอบว่า string มี complete JSON value เพียงหนึ่งค่าแบบพอดีหรือไม่

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
