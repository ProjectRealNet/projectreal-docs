<div className="real-function-page">

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Arguments

<ParamField path={"json"} type={"string"} required>
JSON string ที่จะ validate function อ่าน argument นี้ด้วย string type checking
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean ตั้งค่า useNull. table สามารถตั้งค่า useNull และ maxDepth. maxDepth ถูก clamp จาก 1 ถึง 4096
</ParamField>

## Returns

<ResponseField name={"valid"} type={"boolean"}>
true เมื่อ parsing complete JSON value หนึ่งค่าสำเร็จ false เมื่อ parsing ล้มเหลวภายใน protected parse block
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message เมื่อ parse failure. message มี prefix json.validate และมี near-position suffix. return นี้มีเฉพาะตอน failure
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position จาก parser เมื่อ parse failure. return นี้มีเฉพาะตอน failure
</ResponseField>

## Types

### DecodeOptions

ควบคุมพฤติกรรมการแยกวิเคราะห์ JSON

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | แสดงถึง JSON null ด้วย null sentinel ของไลบรารีแทนที่จะเป็น nil |
| `maxDepth` | `integer` | No | ตั้งค่าความลึกของการซ้อนสูงสุด โดยยึดไว้ตั้งแต่ 1 ถึง 4096 |

## ตัวอย่าง

ตรวจสอบว่า string มี complete JSON value เพียงหนึ่งค่าแบบพอดีหรือไม่

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
