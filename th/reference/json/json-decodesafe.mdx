<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Arguments

<ParamField path={"json"} type={"string"} required>
JSON text สำหรับ parse. argument นี้ถูกตรวจเป็น string ก่อนที่ parse errors จะถูก catch.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean ตั้งค่า useNull โดยตรง. table สามารถตั้ง useNull และ maxDepth; maxDepth ถูก clamp จาก 1 ถึง 4096. Invalid option argument types ถูกตรวจก่อนที่ parse errors จะถูก catch.
</ParamField>

## Returns

<ResponseField name={"success"} type={"boolean"}>
True เมื่อ parsing สำเร็จ, false เมื่อ parser รายงาน error.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value เมื่อสำเร็จ, nil เมื่อ parse failure. JSON false ที่ valid จะคืน success เป็น true และ decoded เป็น false ดังนั้นให้ตรวจ success return value.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message เมื่อ parse failure, ไม่เช่นนั้น nil. message มี json.decodeSafe prefix และ parser position.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position เมื่อ parse failure, ไม่เช่นนั้น nil.
</ResponseField>

## Types

### DecodeOptions

ควบคุมพฤติกรรมการแยกวิเคราะห์ JSON

| Name | Type | Required | คำอธิบาย |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | แสดงถึง JSON null ด้วย null sentinel ของไลบรารีแทนที่จะเป็น nil |
| `maxDepth` | `integer` | No | ตั้งค่าความลึกของการซ้อนสูงสุด โดยยึดไว้ตั้งแต่ 1 ถึง 4096 |

## ตัวอย่าง

Parse JSON แล้วใช้ success return value เพื่อแยก valid false หรือ nil results จาก parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
