<div className="real-function-page">

```lua
json.values(object: table): table
```

## Arguments

<ParamField path={"object"} type={"table"} required>
Table ที่จะ enumerate. function ตรวจ argument นี้ด้วย type checking
</ParamField>

## Returns

<ResponseField name={"values"} type={"table"}>
New array-style table ที่มี direct values จาก input table. output ถูก marked as JSON array. Enumeration ใช้ table iteration ดังนั้นไม่มี ordering guarantee ที่เห็นได้ใน function
</ResponseField>

## ตัวอย่าง

รวบรวม direct values จาก table เข้า JSON array-marked table

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
