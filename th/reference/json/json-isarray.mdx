<div className="real-function-page">

```lua
json.isArray(value: any): boolean
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Value ที่จะ inspect. Non-table values คืน false.
</ParamField>

## Returns

<ResponseField name={"isArray"} type={"boolean"}>
true เมื่อ value เป็น table marked as a JSON array หรือ unmarked table ที่มี contiguous positive integer keys จาก 1 ถึง maximum index. Empty unmarked tables คืน false.
</ResponseField>

## ตัวอย่าง

Check ว่า table ถูก treated as a JSON array โดย Real JSON encoder หรือไม่.

```lua
local items = json.array({ "one", "two" })
local record = json.object({ name = "Real" })
local inferred = { "one", "two" }

print(json.isArray(items))
print(json.isArray(record))
print(json.isArray(inferred))
```
