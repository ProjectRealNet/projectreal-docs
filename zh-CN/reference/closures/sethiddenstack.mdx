<div className="real-function-page">

```lua
sethiddenstack(target: function | number, hidden?: boolean)
```

## 别名

- `setstackhidden`

## 参数

<ParamField path={"target"} type={"function | number"} required>
Function or stack level number to mark or unmark.
</ParamField>

<ParamField path={"hidden"} type={"boolean"}>
Whether the resolved function should be marked hidden. Defaults to true; false removes the mark.
</ParamField>

## 示例

Add or remove a function closure from hidden stack tracking.

```lua
local function target()
end

sethiddenstack(target)
print(ishiddenstack(target))

sethiddenstack(target, false)
print(ishiddenstack(target))
```
