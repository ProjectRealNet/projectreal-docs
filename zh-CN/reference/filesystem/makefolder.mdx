使用 recursive folder creation 在 workspace 内创建 directory，包括 missing parent directories。

## 语法

```lua
makefolder(path: string)
```

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | 经过 separator normalization 和 workspace-boundary checks 后在 workspace 内解析的 directory path。empty、invalid 或 outside-workspace paths 会在尝试创建前 error。 |

## 示例

创建 workspace directory 和 missing parent directories。

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
