将已存在的 regular workspace file 复制到 ExtraContent/&lt;hwid>/，并为复制后的 asset path 返回 rbxasset:// string。

## 语法

```lua
getcustomasset(path: string): string
```

## 别名

- `getsynasset`

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | 经过 separator normalization 和 workspace-boundary checks 后在 workspace 内解析的 path。目标必须存在并且是 regular file；不接受 folders、invalid filenames、DOS device names 和 blocked extensions。 |

## 返回值

| Name | Type | 说明 |
| --- | --- | --- |
| `assetId` | `string` | 格式为 rbxasset://&lt;hwid>/&lt;workspace-relative-path> 的 String，relative path 使用 forward slashes。 |

## 示例

将已存在的 workspace file 复制到 asset folder，并打印返回的 rbxasset path。

```lua
local path = "assets/example.txt"
writefile(path, "asset bytes")

local assetId = getcustomasset(path)
print(assetId)
print(getsynasset(path))
```
