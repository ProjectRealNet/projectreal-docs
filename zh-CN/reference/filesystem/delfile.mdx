删除 workspace 内已存在的 regular file。

## 语法

```lua
delfile(path: string)
```

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | 经过 separator normalization 和 workspace-boundary checks 后在 workspace 内解析的 path。目标必须存在并且是 regular file；不接受 folders。 |

## 示例

删除已存在的 workspace file。

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
