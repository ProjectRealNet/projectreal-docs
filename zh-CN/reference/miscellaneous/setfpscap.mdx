<div className="real-function-page">

```lua
setfpscap(value: number)
```

## 别名

- `set_fps_cap`

## 参数

<ParamField path={"value"} type={"number"} required>
Requested FPS cap.
</ParamField>

## 示例

Set the TaskScheduler FPS cap field and read it back with getfpscap.

```lua
setfpscap(240)
print(getfpscap())
```
