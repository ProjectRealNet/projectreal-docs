```lua
getgenv(): table
```

## 返回值

<ResponseField name={"environment"} type={"table"}>
此 state 当前存储在 LUA_ENVIRONINDEX 的 table。
</ResponseField>

## 示例

Read and write values on the current executor environment table.

```lua
local env = getgenv()

env.RealDocsValue = "ready"

print(getgenv().RealDocsValue)
```
