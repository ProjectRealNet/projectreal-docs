<div className="real-function-page">

```lua
lz4decompress(data: string, originalSize?: number): string
```

## 别名

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## 参数

<ParamField path={"data"} type={"string"} required>
传递给 LZ4 block decompression 的 raw compressed bytes。
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
作为 dstCapacity 传递的 output buffer size。对于 lz4compress 输出，传入原始未压缩 byte 长度；省略时使用压缩输入长度。
</ParamField>

## 返回值

<ResponseField name={"decompressed"} type={"string"}>
以 Lua 字符串返回的 raw decompressed bytes。输出可能短于 originalSize。
</ResponseField>

## 示例

通过传入原始未压缩大小来解压 LZ4 bytes。

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
