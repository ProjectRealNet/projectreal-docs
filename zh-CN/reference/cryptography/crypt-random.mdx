使用 random byte generator 生成 raw random bytes，并作为 Lua string 返回。

## 语法

```lua
crypt.random(size: number): string
```

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `size` | `number` | Yes | allocation 前传入 integer conversion 的数字。小于或等于 0 的值会触发 argument error。 |

## 返回值

| Name | Type | 说明 |
| --- | --- | --- |
| `bytes` | `string` | 以 Lua string 返回的 raw generated bytes。返回的 string 长度与分配的字节数一致。 |

## 示例

生成 raw bytes 并打印返回的 Lua string 长度。

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
