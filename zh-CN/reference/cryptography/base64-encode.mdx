使用 Base64 encoder 编码 Lua string 的字节，使用 = padding 且不插入换行。

## 语法

```lua
base64_encode(data: string): string
```

## 别名

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `data` | `string` | Yes | 传递给 Base64 encoder 的 Lua string 字节。 |

## 返回值

| Name | Type | 说明 |
| --- | --- | --- |
| `encoded` | `string` | 以 Lua string 返回的 Base64 输出。 |

## 示例

编码一个 Lua string 并打印 Base64 输出。

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
