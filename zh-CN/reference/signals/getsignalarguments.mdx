返回从 RBXScriptSignal event descriptor signature 读取的 type names array table。第一个 argument 必须是 Luau type name 为 RBXScriptSignal 的 object。该 function 会读取 signal 的 event descriptor，使用 function 的 argument stride 遍历 signature slots，读取每个 argument type reference，并为每个 slot push 解析出的 type name string。它不会返回 captured runtime argument values。如果 signature 无法读取或没有 push 任何 entries，返回的 table 会包含一个 fallback entry: "Variant"。

## 语法

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | 要检查 event descriptor signature 的 signal。非 RBXScriptSignal object 会抛出 type error。 |

## 返回值

| Name | Type | 说明 |
| --- | --- | --- |
| `arguments` | `&#123;string&#125;` | argument type name strings 的 array table。当 signature data 无法读取或没有生成 argument entries 时，会返回包含 "Variant" 的 fallback table。 |

## 示例

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
