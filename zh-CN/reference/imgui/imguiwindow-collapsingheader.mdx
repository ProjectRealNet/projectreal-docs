sidebarTitle: "ImGuiWindow.CollapsingHeader"
description: "追加一个 collapsing header start marker，立即以相同的 ImGuiWindow object 调用 content callback，让它可以追加 nested elements，然后追加 header end marker。在 rendering 期间，当 header 处于 collapsed 状态时会跳过 nested elements。Callback errors 会被捕获，并且不会由此 method 返回。"
keywords: ["ImGuiWindow.CollapsingHeader","ImGui"]

<div className="real-function-page">

```lua
ImGuiWindow.CollapsingHeader(window: ImGuiWindow, label: string, content: function): ImGuiWindow
```

## 参数

<ParamField path={"window"} type={"ImGuiWindow"} required>
imgui.create 返回的 ImGuiWindow object。已销毁或无效的 window 会触发 Lua error。
</ParamField>

<ParamField path={"label"} type={"string"} required>
传给渲染出的 ImGui collapsing header 的 header label string。
</ParamField>

<ParamField path={"content"} type={"function"} required>
立即以相同 ImGuiWindow object 调用的 Function。Return values 会被忽略；错误会被 method 捕获。
</ParamField>

## 返回值

<ResponseField name={"window"} type={"ImGuiWindow"}>
相同的 ImGuiWindow object，因此可以链式调用 method calls。
</ResponseField>

## 类型

### ImGuiWindow

imgui.create 返回的句柄。控制构建方法返回相同的句柄，因此可以链接调用。

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |

| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | 追加单行文本输入；省略的初始文本默认为空字符串。 |
