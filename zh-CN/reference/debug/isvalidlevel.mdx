检查 numeric stack level 是否位于 current call stack range 内。level 必填且必须是 number，因为 function 会调用 requires a number。value 会用 integer conversion 转换。当 level &lt; 0 或 level >= the current call stack depth 时，function 返回 false，否则返回 true。它不会检查 frame closure，也不会对 invalid numeric levels 抛出 "Level out of range"。validlevel 是 global alias，debug.isvalidlevel 和 debug.validlevel 通过 debug table aliases 暴露。

## 语法

```lua
isvalidlevel(level: number): boolean
```

## 别名

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## 参数

| Name | Type | Required | 说明 |
| --- | --- | --- | --- |
| `level` | `number` | Yes | 用 integer conversion 转换并按 0 &lt;= level &lt; the current call stack depth 检查的 Stack level number。 |

## 返回值

| Name | Type | 说明 |
| --- | --- | --- |
| `valid` | `boolean` | numeric level 位于 current call stack range 内时为 true，否则为 false。 |

## 示例

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
