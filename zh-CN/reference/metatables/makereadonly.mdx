<div className="real-function-page">

```lua
makereadonly(target: table)
```

## 参数

<ParamField path={"target"} type={"table"} required>
Table to mark as readonly.
</ParamField>

## 示例

Set a table's readonly flag to true.

```lua
local target = {}

makereadonly(target)

print(isreadonly(target))
```
