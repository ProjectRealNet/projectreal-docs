Comprueba si un numeric stack level está dentro del current call stack range. level es obligatorio y debe ser number porque la function llama a requires a number. El value se convierte con integer conversion. La function devuelve false cuando level &lt; 0 o level >= the current call stack depth; en caso contrario devuelve true. No inspecciona la frame closure y no lanza "Level out of range" para invalid numeric levels. validlevel es un global alias, y debug.isvalidlevel junto con debug.validlevel están expuestos mediante los debug table aliases.

## Sintaxis

```lua
isvalidlevel(level: number): boolean
```

## Alias

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `level` | `number` | Yes | Stack level number convertido con integer conversion y comprobado contra 0 &lt;= level &lt; the current call stack depth. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `valid` | `boolean` | true cuando el numeric level está dentro del current call stack range; en caso contrario false. |

## Ejemplo

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
