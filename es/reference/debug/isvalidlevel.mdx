title: "isvalidlevel"
sidebarTitle: "isvalidlevel"
description: "Comprueba si un numeric stack level está dentro del current call stack range. level es obligatorio y debe ser number porque la function llama a requires a number. El value se convierte con integer conversion. La function devuelve false cuando level < 0 o level >= the current call stack depth; en caso contrario devuelve true. No inspecciona la frame closure y no lanza \"Level out of range\" para invalid numeric levels. validlevel es un global alias, y debug.isvalidlevel junto con debug.validlevel están expuestos mediante los debug table aliases."
keywords: ["isvalidlevel","Debug","validlevel","debug.isvalidlevel","debug.validlevel"]
---

<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Alias

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argumentos

<ParamField path={"level"} type={"number"} required>
Stack level number convertido con integer conversion y comprobado contra 0 &lt;= level &lt; the current call stack depth.
</ParamField>

## Retornos

<ResponseField name={"valid"} type={"boolean"}>
true cuando el numeric level está dentro del current call stack range; en caso contrario false.
</ResponseField>

## Ejemplo

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
