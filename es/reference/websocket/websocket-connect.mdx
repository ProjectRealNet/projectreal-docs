```lua
WebSocket.connect(url: string): WebSocket
```

## Alias

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## Argumentos

<ParamField path={"url"} type={"string"} required>
URL string que se pasa a CURLOPT_URL antes de que WebSocket client ejecute el WebSocket connection attempt.
</ParamField>

## Retornos

<ResponseField name={"socket"} type={"WebSocket"}>
WebSocket table que contiene OnMessage, OnClose e connection state. Send y Close se resuelven mediante la WebSocket object methods.
</ResponseField>

## Ejemplo

Abre un WebSocket, conecta OnMessage y OnClose, y usa socket methods para enviar y cerrar.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
