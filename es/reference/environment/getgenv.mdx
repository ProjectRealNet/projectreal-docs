Los call-sites del repository usan la returned table para leer y escribir shared executor globals como __siApiCache y saveinstance."
keywords: ["getgenv","Environment"]

<div className="real-function-page">

```lua
getgenv(): table
```

## Retornos

<ResponseField name={"environment"} type={"table"}>
La table almacenada actualmente en LUA_ENVIRONINDEX para este state.
</ResponseField>

## Ejemplo

Read and write values on the current executor environment table.

```lua
local env = getgenv()

env.RealDocsValue = "ready"

print(getgenv().RealDocsValue)
```
