Escribe uno o más valores en la Windows console actual mediante stdout después de establecer el console text attribute en error text color. Los valores se convierten con Lua string conversion, se separan con caracteres tab y el text attribute se restablece después. Si no existe ninguna console window, la llamada vuelve sin convertir ni escribir nada.

## Sintaxis

```lua
rconsoleerr(...values?: ...any)
```

## Alias

- `consoleerr`

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Valores opcionales. Si existe una console, cada value se convierte con Lua string conversion y se une con caracteres tab antes de escribirse. |

## Ejemplo

Write a bright red message to the current Windows console without throwing a Luau error.

```lua
rconsolecreate()
rconsoleerr("Request failed", 500, "
")
```
