---
title: "rconsoleinfo"
sidebarTitle: "rconsoleinfo"
description: "Escribe uno o más valores en la Windows console actual mediante stdout después de establecer el console text attribute en info text color. Los valores se convierten con Lua string conversion, se separan con caracteres tab y el text attribute se restablece después. Si no existe ninguna console window, la llamada vuelve sin convertir ni escribir nada."
keywords: ["rconsoleinfo","Console","consoleinfo"]
---

<div className="real-function-page">

```lua
rconsoleinfo(...values?: ...any)
```

## Alias

- `consoleinfo`

## Argumentos

<ParamField path={"...values"} type={"...any"}>
Valores opcionales. Si existe una console, cada value se convierte con Lua string conversion y se une con caracteres tab antes de escribirse.
</ParamField>

## Ejemplo

Write a bright blue message to the current Windows console.

```lua
rconsolecreate()
rconsoleinfo("Connected", "
")
```
