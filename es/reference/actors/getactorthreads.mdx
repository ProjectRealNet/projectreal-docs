Devuelve una array table de Luau threads desde la actor thread list. La function no toma arguments. Lee los actor list bounds desde ScriptContext, recorre cada actor state entry, descifra el stored global state en un Luau thread e incluye solo entries que son valid threads.

## Sintaxis

```lua
getactorthreads(): {thread}
```

## Alias

- `getactorstates`

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `threads` | `&#123;thread&#125;` | Array table de actor Luau thread values insertados como Luau threads. |

## Ejemplo

List Luau threads from the ScriptContext actor state list.

```lua
for _, thread in ipairs(getactorthreads()) do
    print(thread)
end
```
