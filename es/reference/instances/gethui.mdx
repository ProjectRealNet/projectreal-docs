Devuelve game:CoreGui lookup.RobloxGui. La function no toma arguments. Si CoreGui lookup devuelve nil, o si RobloxGui en ese valor es nil, la function devuelve nil. La function no crea ningun container y no usa el valor cacheado CoreGui.

## Sintaxis

```lua
gethui(): Instance | nil
```

## Alias

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | El valor RobloxGui leido desde CoreGui, o nil cuando CoreGui o RobloxGui no esta disponible. |
