Devuelve el resultado de leer la hidden property "NetworkOwnerV3" de una Instance y comprobar si el primer valor devuelto, convertido con integer conversion, es mayor que 2. El argumento debe ser Instance object. La function llama internamente a the hidden property reader y no captura errores de esa llamada, por lo que Invalid Instance values, missing properties o non-property metadata pueden lanzar los mismos errores que gethiddenproperty. Devuelve un boolean. Si peer_id > 2 significa exactamente local network ownership es: Nicht aus der Codebasis verifizierbar.

## Sintaxis

```lua
isnetworkowner(instance: Instance): boolean
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `instance` | `Instance` | Yes | Instance object pasada a the hidden property reader con el property name "NetworkOwnerV3". |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `isOwner` | `boolean` | true cuando integer conversion sobre el primer valor devuelto de "NetworkOwnerV3" es mayor que 2; de lo contrario false. |

## Ejemplo

Check network ownership for a BasePart Instance.

```lua
local part = workspace:FindFirstChildWhichIsA("BasePart", true)

if part then
    local ownsNetwork = isnetworkowner(part)
    print(ownsNetwork)
end
```
