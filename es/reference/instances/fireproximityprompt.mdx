Si el valor no es object, la llamada lanza un type error. Si ClassName falta o no es string, lanza \"Invalid Instance\". Si ClassName no es \"ProximityPrompt\", lanza \"ProximityPrompt expected\". La function no toma optional arguments y no devuelve nada."

<div className="real-function-page">

```lua
fireproximityprompt(prompt: Instance)
```

## Argumentos

<ParamField path={"prompt"} type={"Instance"} required>
Instance cuyo ClassName debe ser ProximityPrompt.
</ParamField>

## Ejemplo

Activa un ProximityPrompt con el unico argumento requerido.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
