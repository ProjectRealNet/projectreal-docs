Activa un ProximityPrompt mediante el ProximityPrompt trigger de Real. El argumento prompt debe ser object con un campo ClassName igual a "ProximityPrompt". Si el valor no es object, la llamada lanza un type error. Si ClassName falta o no es string, lanza "Invalid Instance". Si ClassName no es "ProximityPrompt", lanza "ProximityPrompt expected". La function no toma optional arguments y no devuelve nada.

## Sintaxis

```lua
fireproximityprompt(prompt: Instance)
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `prompt` | `Instance` | Yes | Instance cuyo ClassName debe ser ProximityPrompt. |

## Ejemplo

Activa un ProximityPrompt con el unico argumento requerido.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
