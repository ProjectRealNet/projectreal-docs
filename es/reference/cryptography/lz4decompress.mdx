```lua
lz4decompress(data: string, originalSize?: number): string
```

## Alias

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes que se pasan a LZ4 block decompression.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size que se pasa como dstCapacity. Para la salida de lz4compress, pasa la longitud original sin comprimir en bytes; si se omite, se usa la longitud de la entrada comprimida.
</ParamField>

## Retornos

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes devueltos como una cadena Lua. La salida puede ser mas corta que originalSize.
</ResponseField>

## Ejemplo

Descomprime LZ4 bytes pasando el tamano original sin comprimir.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
