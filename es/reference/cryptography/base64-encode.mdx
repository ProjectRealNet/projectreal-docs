
## Alias

## Argumentos

<ParamField path={"data"} type={"string"} required>
Bytes de cadena Lua que se pasan a Base64 encoder.
</ParamField>

## Retornos

<ResponseField name={"encoded"} type={"string"}>
Salida Base64 devuelta como una cadena Lua.
</ResponseField>

## Ejemplo

Codifica una cadena Lua e imprime la salida Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))

```
