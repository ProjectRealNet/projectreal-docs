<div className="real-function-page">

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Argumentos

<ParamField path={"data"} type={"string"} required>
Base64 ciphertext que se decodifica antes del descifrado.
</ParamField>

<ParamField path={"key"} type={"string"} required>
Key Base64 que se decodifica antes de pasarse a AES.
</ParamField>

<ParamField path={"iv"} type={"string"} required>
Base64 IV que se decodifica antes de procesar mode. Este argumento es obligatorio, incluso con ECB.
</ParamField>

<ParamField path={"mode"} type={"\"CBC\" | \"ECB\" | \"AES-CBC\" | \"AES-ECB\""}>
AES mode. El prefijo AES- se elimina cuando esta presente. El valor predeterminado es AES-CBC.
</ParamField>

## Retornos

<ResponseField name={"plaintext"} type={"string"}>
Bytes plaintext devueltos como una cadena Lua.
</ResponseField>

## Ejemplo

Descifra el ciphertext devuelto por crypt.encrypt usando el IV devuelto.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
