Descifra Base64 ciphertext con una key decodificada desde Base64 y un Base64 IV requerido usando AES CBC o ECB.

## Sintaxis

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Base64 ciphertext que se decodifica antes del descifrado. |
| `key` | `string` | Yes | Key Base64 que se decodifica antes de pasarse a AES. |
| `iv` | `string` | Yes | Base64 IV que se decodifica antes de procesar mode. Este argumento es obligatorio, incluso con ECB. |
| `mode` | `"CBC" \| "ECB" \| "AES-CBC" \| "AES-ECB"` | No | AES mode. El prefijo AES- se elimina cuando esta presente. El valor predeterminado es AES-CBC. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `plaintext` | `string` | Bytes plaintext devueltos como una cadena Lua. |

## Ejemplo

Descifra el ciphertext devuelto por crypt.encrypt usando el IV devuelto.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
