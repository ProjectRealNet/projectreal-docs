<div className="real-function-page">

```lua
base64_decode(data: string): string
```

## Alias

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Entrada Base64 que se pasa a Base64 decoder.
</ParamField>

## Retornos

<ResponseField name={"decoded"} type={"string"}>
Bytes decodificados devueltos como una cadena Lua con longitud explicita.
</ResponseField>

## Ejemplo

Decodifica datos Base64 y lee la cadena Lua devuelta.

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
