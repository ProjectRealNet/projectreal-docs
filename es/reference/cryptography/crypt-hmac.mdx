Calcula un crypto library HMAC sobre bytes de cadena Lua usando una raw Lua string key y devuelve un Base64 digest.

## Sintaxis

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `key` | `string` | Yes | Bytes de raw Lua string usados como HMAC key. La key no se Base64-decode. |
| `data` | `string` | Yes | Bytes de cadena Lua pasados al HMAC calculation. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Nombre de HMAC algorithm case-sensitive. El valor predeterminado es sha256. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `digest` | `string` | Base64-encoded HMAC output sin line breaks. |

## Ejemplo

Calcula un Base64 HMAC output desde una raw Lua string key y data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
