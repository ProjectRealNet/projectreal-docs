<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumentos

<ParamField path={"key"} type={"string"} required>
Bytes de raw Lua string usados como HMAC key. La key no se Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Bytes de cadena Lua pasados al HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Nombre de HMAC algorithm case-sensitive. El valor predeterminado es sha256.
</ParamField>

## Retornos

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output sin line breaks.
</ResponseField>

## Ejemplo

Calcula un Base64 HMAC output desde una raw Lua string key y data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
