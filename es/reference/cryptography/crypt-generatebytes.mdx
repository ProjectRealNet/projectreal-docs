```lua
crypt.generatebytes(size: number): string
```

## Argumentos

<ParamField path={"size"} type={"number"} required>
Numero que pasa por integer conversion antes de la asignacion. Los valores menores o iguales a 0 se cambian a 1.
</ParamField>

## Retornos

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding de los raw bytes generados. La longitud de la cadena devuelta no es la cantidad de bytes solicitada.
</ResponseField>

## Ejemplo

Genera bytes y decodifica el resultado Base64 cuando se necesiten raw bytes.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
