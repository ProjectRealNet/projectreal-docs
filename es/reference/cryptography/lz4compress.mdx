<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## Alias

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Bytes de cadena Lua que se pasan a LZ4 block compression.
</ParamField>

## Retornos

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes devueltos como una cadena Lua. El original size no se almacena en la salida.
</ResponseField>

## Ejemplo

Comprime bytes de una cadena Lua y restauralos pasando el original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
