Cifra bytes de una cadena Lua con AES CBC, ECB o CTR usando una key decodificada desde Base64, luego devuelve Base64 ciphertext y el resultado IV.

## Sintaxis

```lua
crypt.encrypt(data: string, key: string, iv?: string, mode?: "CBC" | "ECB" | "CTR" | "AES-CBC" | "AES-ECB" | "AES-CTR"): string | string | nil
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Bytes plaintext leidos desde una cadena Lua. |
| `key` | `string` | Yes | Base64 key que se decodifica antes de pasarse a AES. |
| `iv` | `string` | No | Base64 IV opcional para CBC o CTR. Cuando se omite para CBC o CTR, se genera un IV nuevo de AES block size. |
| `mode` | `"CBC" \| "ECB" \| "CTR" \| "AES-CBC" \| "AES-ECB" \| "AES-CTR"` | No | AES mode. El prefijo AES- se elimina cuando esta presente. El valor predeterminado es AES-CBC. CBC y ECB usan crypto library DEFAULT_PADDING; CTR no usa padding. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `ciphertext` | `string` | Base64-encoded ciphertext. |
| `initializationVector` | `string \| nil` | Base64-encoded IV para CBC y CTR; nil para ECB. |

## Ejemplo

Cifra una cadena Lua y descifra el ciphertext devuelto con el IV devuelto.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(ciphertext)
print(iv)
print(plaintext)
```
