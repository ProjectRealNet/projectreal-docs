<div className="real-function-page">

```lua
crypt.encrypt(data: string, key: string, iv?: string, mode?: "CBC" | "ECB" | "CTR" | "AES-CBC" | "AES-ECB" | "AES-CTR"): string | string | nil
```

## Argumentos

<ParamField path={"data"} type={"string"} required>
Bytes plaintext leidos desde una cadena Lua.
</ParamField>

<ParamField path={"key"} type={"string"} required>
Base64 key que se decodifica antes de pasarse a AES.
</ParamField>

<ParamField path={"iv"} type={"string"}>
Base64 IV opcional para CBC o CTR. Cuando se omite para CBC o CTR, se genera un IV nuevo de AES block size.
</ParamField>

<ParamField path={"mode"} type={"\"CBC\" | \"ECB\" | \"CTR\" | \"AES-CBC\" | \"AES-ECB\" | \"AES-CTR\""}>
AES mode. El prefijo AES- se elimina cuando esta presente. El valor predeterminado es AES-CBC. CBC y ECB usan crypto library DEFAULT_PADDING; CTR no usa padding.
</ParamField>

## Retornos

<ResponseField name={"ciphertext"} type={"string"}>
Base64-encoded ciphertext.
</ResponseField>

<ResponseField name={"initializationVector"} type={"string | nil"}>
Base64-encoded IV para CBC y CTR; nil para ECB.
</ResponseField>

## Ejemplo

Cifra una cadena Lua y descifra el ciphertext devuelto con el IV devuelto.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(ciphertext)
print(iv)
print(plaintext)
```
