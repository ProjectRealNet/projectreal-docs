Genera raw random bytes con random byte generator y los devuelve como una cadena Lua.

## Sintaxis

```lua
crypt.random(size: number): string
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Numero que pasa por integer conversion antes de la asignacion. Los valores menores o iguales a 0 generan un argument error. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes devueltos como una cadena Lua. La longitud de la cadena devuelta coincide con el conteo de bytes asignado. |

## Ejemplo

Genera raw bytes e imprime la longitud de la cadena Lua devuelta.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
