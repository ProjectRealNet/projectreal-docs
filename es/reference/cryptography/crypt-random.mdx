<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Argumentos

<ParamField path={"size"} type={"number"} required>
Numero que pasa por integer conversion antes de la asignacion. Los valores menores o iguales a 0 generan un argument error.
</ParamField>

## Retornos

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes devueltos como una cadena Lua. La longitud de la cadena devuelta coincide con el conteo de bytes asignado.
</ResponseField>

## Ejemplo

Genera raw bytes e imprime la longitud de la cadena Lua devuelta.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
