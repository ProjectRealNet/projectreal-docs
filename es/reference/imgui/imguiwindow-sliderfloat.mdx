Agrega un SliderFloat element a la ventana. label, value, minimum y maximum se leen de los argumentos 2 a 5, y los argumentos numericos se comprueban con number type checking. Durante el rendering, Real llama a a floating-point slider con el valor y el rango almacenados. Cuando ImGui informa un valor cambiado, onChange se coloca en una queue y luego se llama con un Lua number. Real no agrega una validacion minimum &lt;= maximum separada en este closure.

## Sintaxis

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow devuelta por imgui.create. Si la object no es valida o ya fue destruida, la method lanza un Lua error. |
| `label` | `string` | Yes | Slider label leida con string type checking. |
| `value` | `number` | Yes | Valor inicial del slider leido con number type checking y almacenado como valor float actual. |
| `minimum` | `number` | Yes | Minimum value leida con number type checking y pasada a a floating-point slider. |
| `maximum` | `number` | Yes | Maximum value leida con number type checking y pasada a a floating-point slider. |
| `onChange` | `(number) -> ()` | Yes | Callback function almacenada en Lua registry. Cuando el slider cambia durante el rendering, se llama despues con el valor numerico actualizado. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `window` | `ImGuiWindow` | La misma ImGuiWindow object, lo que permite llamadas de method encadenadas. |
