---
title: "ImGuiWindow.InputText"
sidebarTitle: "ImGuiWindow.InputText"
description: "Agrega un single-line ImGui InputText element a un ImGuiWindow y almacena el callback. El initial text se lee con optional string handling y se copia al fixed 256-byte text buffer del elemento. Cuando cambia el input renderizado, el callback se coloca en una queue y luego se invoca con el current string. La method devuelve el mismo ImGuiWindow object."
keywords: ["ImGuiWindow.InputText","ImGui"]
---

<div className="real-function-page">

```lua
ImGuiWindow.InputText(window: ImGuiWindow, label: string, text?: string, onChange: function): ImGuiWindow
```

## Argumentos

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object devuelto por imgui.create. Un window destruido o no valido genera un Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Input label string pasado al ImGui InputText widget renderizado.
</ParamField>

<ParamField path={"text"} type={"string"}>
Initial text leido con optional string handling. Pasa nil aqui cuando quieras el default empty string y aun asi suministrar onChange como argument 4.
</ParamField>

<ParamField path={"onChange"} type={"function"} required>
Function almacenada para este input e invocada con el current string despues de procesar un edit event. Debe suministrarse como argument 4.
</ParamField>

## Retornos

<ResponseField name={"window"} type={"ImGuiWindow"}>
El mismo ImGuiWindow object, lo que permite encadenar method calls.
</ResponseField>

## Tipos

### ImGuiWindow

Identificador devuelto por imgui.create. Los métodos de creación de control devuelven el mismo identificador para que las llamadas se puedan encadenar.

| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | Agrega una entrada de texto de una sola línea; El texto inicial omitido tiene por defecto una cadena vacía. |
