Comprueba si un RBXScriptSignal es legal para enviarse mediante el NetworkClient replication layer actual. La function valida el primer argument como RBXScriptSignal, lee la source instance y el event descriptor del signal, y devuelve el resultado boolean de replication layer signal replication validation. Si el valor de puntero replication layer resuelto es 0, devuelve false. No lee arguments adicionales. Esta function solo comprueba el signal y no lo dispara ni lo replica. La tabla whitelist devuelta por getsignalwhitelist no se usa en esta ruta de codigo.

## Sintaxis

```lua
cansignalreplicate(signal: RBXScriptSignal): boolean
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | Signal que se va a comprobar. El primer argument debe ser object cuyo Luau type name sea RBXScriptSignal. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `canReplicate` | `boolean` | El boolean devuelto por la comprobacion replication layer signal replication validation, o false cuando el valor de puntero replication layer resuelto es 0. |

## Ejemplo

Check whether an RBXScriptSignal is legal to send before attempting to replicate it.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    print(cansignalreplicate(remote.OnClientEvent))
end
```
