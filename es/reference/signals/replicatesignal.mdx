Invoca la replication path para un RBXScriptSignal. La función lee la signal signature, convierte los Lua arguments proporcionados en Roblox signal values para cada signature type, recorta los Lua arguments extra después de la signature length y luego llama a la owning instance event invocation function.

## Sintaxis

```lua
replicatesignal(signal: RBXScriptSignal, ...arguments?: ...any)
```

## Alias

- `replicateevent`

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | El RBXScriptSignal cuya owning instance event invocation function se debe llamar. |
| `...arguments` | `...any` | No | Lua arguments convertidos según la signal signature. Los extra arguments después de la signature length se ignoran. |

## Ejemplo

Replicate for a RemoteEvent signal with values that match the signal signature.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote and remote:IsA("RemoteEvent") then
    replicatesignal(remote.OnClientEvent, "hello")
end
```
