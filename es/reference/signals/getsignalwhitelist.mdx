Devuelve una nueva array table con las seis entradas whitelist estaticas definidas por la function: OnClientEvent/RemoteEvent, OnServerEvent/RemoteEvent, OnClientInvoke/RemoteFunction, OnServerInvoke/RemoteFunction, OnClientEventUnreliable/UnreliableRemoteEvent, and OnServerEventUnreliable/UnreliableRemoteEvent. Cada entry es una table con campos string Event y Parent. La function no acepta arguments y no inspecciona el estado actual del juego.

## Sintaxis

```lua
getsignalwhitelist(): table
```

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `signals` | `table` | Array table de entradas whitelist estaticas. Cada entry tiene campos string Event y Parent. |
