No compara function bytecode, source, behavior, hashes, upvalues ni newcclosure mappings. comparefunction es un alias de la misma function."

<div className="real-function-page">

```lua
comparefunctions(func1: function, func2: function): boolean
```

## Alias

- `comparefunction`

## Argumentos

<ParamField path={"func1"} type={"function"} required>
First function value que se convierte con function identity.
</ParamField>

<ParamField path={"func2"} type={"function"} required>
Second function value que se convierte con function identity.
</ParamField>

## Retornos

<ResponseField name={"equal"} type={"boolean"}>
true cuando ambos function values se resuelven al mismo function identity; de lo contrario false.
</ResponseField>

## Ejemplo

Compare two functions by their function identity.

```lua
local function sample()
    return "ok"
end

local same = comparefunctions(sample, sample)
print(same)
```
