Devuelve si el valor es object con Drawing object type. Esto es solo un methods check; no comprueba si el Drawing object interno sigue active, tracked o destroyed. the Drawing API registra esta API solo cuando the required rendering environment is active es true; cuando esa comprobacion es false, el initializer vuelve antes de crear estos globals.

## Sintaxis

```lua
isrenderobj(object: any): boolean
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `object` | `any` | Yes | Valor a probar. Non-object values y object sin Drawing object type devuelven false. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `isDrawingObject` | `boolean` | True cuando el valor es object cuya methods coincide con RealDrawingObject; de lo contrario false. |

## Ejemplo

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
