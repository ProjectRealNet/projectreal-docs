Elimina un regular file existente dentro del workspace.

## Sintaxis

```lua
delfile(path: string)
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path resuelto dentro del workspace despues de separator normalization y workspace-boundary checks. El destino debe existir y ser un regular file; folders no se aceptan. |

## Ejemplo

Elimina un workspace file existente.

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
