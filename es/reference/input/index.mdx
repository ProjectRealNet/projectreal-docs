Eventos de entrada de teclado y mouse.

## Funciones disponibles

<CardGroup cols={2}>
<Card title="isrbxactive" href="./isrbxactive">
Devuelve si la current foreground window es la Roblox window encontrada por Real. Real encuentra esa ventana enumerating windows del proceso actual y seleccionando una window cuyo class name es Roblox window. La function no toma arguments y devuelve false cuando no hay foreground window o no hay matching Roblox window disponible.
</Card>
<Card title="keyclick" href="./keyclick">
Envia un key down event seguido de un key up event cuando la Roblox window esta activa. El argumento keyCode se comprueba como Lua number, se convierte con integer conversion, se mapea de Windows virtual-key code a scan code con Windows key mapping, y se envia mediante keyboard input con KEYEVENTF_SCANCODE. Si isrbxactive seria false, la function vuelve sin enviar input.
</Card>
<Card title="keypress" href="./keypress">
Envia un key down event cuando la Roblox window esta activa. El argumento keyCode se comprueba como Lua number, se convierte con integer conversion, se mapea de Windows virtual-key code a scan code con Windows key mapping, y se envia mediante keyboard input con KEYEVENTF_SCANCODE. Esta function no envia un key up event. Si isrbxactive seria false, la function vuelve sin enviar input.
</Card>
<Card title="keyrelease" href="./keyrelease">
Envia un key up event cuando la Roblox window esta activa. El argumento keyCode se comprueba como Lua number, se convierte con integer conversion, se mapea de Windows virtual-key code a scan code con Windows key mapping, y se envia mediante keyboard input con KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP. Esta function no envia un key down event. Si isrbxactive seria false, la function vuelve sin enviar input.
</Card>
<Card title="mouse1click" href="./mouse1click">
Envia un left mouse down event y un left mouse up event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mouse1press" href="./mouse1press">
Envia un left mouse down event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada, no envia un left mouse up event correspondiente y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mouse1release" href="./mouse1release">
Envia un left mouse up event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada, no envia un left mouse down event correspondiente y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mouse2click" href="./mouse2click">
Envia un right mouse down event y un right mouse up event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mouse2press" href="./mouse2press">
Envia un right mouse down event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada, no envia un right mouse up event correspondiente y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mouse2release" href="./mouse2release">
Envia un right mouse up event cuando la Roblox window esta activa. Real llama a mouse input con the requested mouse action y sin movement ni wheel data. La function no toma arguments, no devuelve nada, no envia un right mouse down event correspondiente y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mousemoveabs" href="./mousemoveabs">
Mueve el mouse usando Windows absolute mouse input cuando la Roblox window esta activa. Los argumentos x e y se comprueban como Lua numbers y se convierten con integer conversion. Real los trata como coordenadas relative to active foreground window client area, suma la posicion en pantalla de esa client area con ClientToScreen, los escala usando GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) - 1 e integer math, y luego llama a mouse input con the requested mouse action. Si isrbxactive seria false, la function vuelve sin enviar input.
</Card>
<Card title="mousemoverel" href="./mousemoverel">
Mueve el mouse por un relative delta cuando la Roblox window esta activa. Los argumentos x e y se comprueban como Lua numbers y se convierten con integer conversion, luego se pasan directamente a mouse input con the requested mouse action como dx y dy. La function no usa the requested mouse action, no realiza client-area conversion, no devuelve nada y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
<Card title="mousescroll" href="./mousescroll">
Envia un mouse wheel event cuando la Roblox window esta activa. El argumento amount se comprueba como Lua number, se convierte con integer conversion y se pasa directamente como valor dwData a mouse input con the requested mouse action. Real no normaliza amount ni agrega movement data. La function no devuelve nada y vuelve sin enviar input cuando isrbxactive seria false.
</Card>
</CardGroup>
