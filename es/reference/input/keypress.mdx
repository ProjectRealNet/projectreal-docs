title: "keypress"
sidebarTitle: "keypress"
description: "Envia un key down event cuando la Roblox window esta activa. El argumento keyCode se comprueba como Lua number, se convierte con integer conversion, se mapea de Windows virtual-key code a scan code con Windows key mapping, y se envia mediante keyboard input con KEYEVENTF_SCANCODE. Esta function no envia un key up event. Si isrbxactive seria false, la function vuelve sin enviar input."
keywords: ["keypress","Input"]
---

```lua
keypress(keyCode: number)
```

## Argumentos

<ParamField path={"keyCode"} type={"number"} required>
Windows virtual-key code leido como Lua number y convertido con integer conversion antes de llamar a Windows key mapping.
