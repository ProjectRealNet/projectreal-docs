Los argumentos x e y se comprueban como Lua numbers y se convierten con integer conversion, luego se pasan directamente a mouse input con the requested mouse action como dx y dy. La function no usa the requested mouse action, no realiza client-area conversion, no devuelve nada y vuelve sin enviar input cuando isrbxactive seria false."

```lua
mousemoverel(x: number, y: number)
```

</ParamField>
