Analiza, codifica, inspecciona y transforma JSON.

## Funciones disponibles

<CardGroup cols={2}>
<Card title="json.array" href="./json-array">
Crea una new table marcada como JSON array para json.encode, copiando la sequence 1.#source cuando se proporciona una source table.
</Card>
<Card title="json.clone" href="./json-clone">
Clona un value haciendo encoding con json.encode semantics y luego decoding del generated JSON de vuelta a Lua values.
</Card>
<Card title="json.decode" href="./json-decode">
Parsea un JSON string con Real JSON parser y devuelve el decoded Lua value, marcando decoded arrays y objects para los JSON helpers.
</Card>
<Card title="json.decodeSafe" href="./json-decodesafe">
Parsea JSON con el mismo parser que json.decode y devuelve un success flag en lugar de lanzar para parse errors.
</Card>
<Card title="json.encode" href="./json-encode">
Serializa un Lua value a JSON string usando Real JSON encoder. json.stringify esta registrado a la misma function.
</Card>
<Card title="json.encodePretty" href="./json-encodepretty">
Serializa un Lua value a un JSON string formateado y legible usando Real JSON encoder. json.pretty esta registrado en la misma function.
</Card>
<Card title="json.escape" href="./json-escape">
Escapa un string usando Real JSON string escaping rules y devuelve el escaped content sin surrounding quotes.
</Card>
<Card title="json.format" href="./json-format">
Parsea un JSON string y lo vuelve a encode como readable formatted JSON usando Real JSON parser y encoder.
</Card>
<Card title="json.getPath" href="./json-getpath">
Lee un nested value desde una table usando un dotted string path o una array table of keys.
</Card>
<Card title="json.isArray" href="./json-isarray">
Devuelve si un value se treated as a JSON array por Real JSON table detection.
</Card>
<Card title="json.isNull" href="./json-isnull">
Devuelve si un value es Real JSON null sentinel, json.null.
</Card>
<Card title="json.isObject" href="./json-isobject">
Devuelve si un value se treated as a JSON object por Real JSON table detection.
</Card>
<Card title="json.keys" href="./json-keys">
Devuelve las visible keys de una table en una new table marked as a JSON array.
</Card>
<Card title="json.minify" href="./json-minify">
Parsea un JSON string y lo vuelve a encode usando Real default non-pretty JSON encoder output.
</Card>
<Card title="json.object" href="./json-object">
Crea una new table marked as a JSON object para que Real JSON encoder la trate como object.
</Card>
<Card title="json.parse" href="./json-parse">
Parsea un JSON string usando la misma function que json.decode.
</Card>
<Card title="json.pretty" href="./json-pretty">
Serializa un Lua value a un readable formatted JSON string usando la misma function que json.encodePretty.
</Card>
<Card title="json.quote" href="./json-quote">
Escapa un string usando Real JSON string escaping rules y devuelve un complete quoted JSON string literal.
</Card>
<Card title="json.stringify" href="./json-stringify">
Serializa un Lua value a un JSON string usando la misma function que json.encode.
</Card>
<Card title="json.tryDecode" href="./json-trydecode">
Intenta parsear un JSON string usando la misma function que json.decodeSafe y devuelve status values para parse errors.
</Card>
<Card title="json.type" href="./json-type">
Devuelve un string type name para un valor. json.null devuelve "null". Las tablas devuelven "array" u "object" usando la misma table classification que json.isArray y json.isObject. Otros valores devuelven el runtime Lua type name result.
</Card>
<Card title="json.unescape" href="./json-unescape">
Decodifica JSON string escape sequences desde escaped string content o desde un complete quoted JSON string literal. La entrada se parsea con el JSON string parser, no como full JSON document.
</Card>
<Card title="json.validate" href="./json-validate">
Valida un JSON string parseando un unico complete JSON value. En success devuelve solo true. En parse failure devuelve false mas parser error details.
</Card>
<Card title="json.values" href="./json-values">
Devuelve los direct values de una table en una nueva table marked as JSON array. Se omiten los JSON type marker entries.
</Card>
</CardGroup>
