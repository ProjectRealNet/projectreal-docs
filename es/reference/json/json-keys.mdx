<div className="real-function-page">

```lua
json.keys(object: table): table
```

## Argumentos

<ParamField path={"object"} type={"table"} required>
Table que se inspect. La function requiere que este argument sea una table.
</ParamField>

## Retornos

<ResponseField name={"keys"} type={"table"}>
New array table que contiene las source table keys, excluyendo Real JSON type marker. El order sigue table iteration iteration y esta function no lo sorted.
</ResponseField>

## Ejemplo

Collect las visible keys de una table en una new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
