Crea una new table marcada como JSON array para json.encode, copiando la sequence 1.#source cuando se proporciona una source table.

## Sintaxis

```lua
json.array(source?: table): table
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table. Cuando se omite o es nil, json.array devuelve una new empty array-marked table. Cuando se proporciona, solo se copian numeric sequence entries de 1 with #source a la new table. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `array` | `table` | New table con JSON array marker. json.encode la serializes como JSON array; no se devuelve la original source table. |

## Ejemplo

Crea una array-marked copy para que json.encode serializes el valor como JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
