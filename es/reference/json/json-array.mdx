<div className="real-function-page">

```lua
json.array(source?: table): table
```

## Argumentos

<ParamField path={"source"} type={"table"}>
Optional source table. Cuando se omite o es nil, json.array devuelve una new empty array-marked table. Cuando se proporciona, solo se copian numeric sequence entries de 1 with #source a la new table.
</ParamField>

## Retornos

<ResponseField name={"array"} type={"table"}>
New table con JSON array marker. json.encode la serializes como JSON array; no se devuelve la original source table.
</ResponseField>

## Ejemplo

Crea una array-marked copy para que json.encode serializes el valor como JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
