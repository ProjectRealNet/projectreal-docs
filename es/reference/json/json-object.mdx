<div className="real-function-page">

```lua
json.object(source?: table): table
```

## Argumentos

<ParamField path={"source"} type={"table"}>
Optional source table que se copy dentro de la new object table. Si se omitted o es nil, se devuelve una empty object table.
</ParamField>

## Retornos

<ResponseField name={"object"} type={"table"}>
New table marked con Real JSON object marker. Source entries se copy, excepto Real JSON type marker.
</ResponseField>

## Ejemplo

Create una new table marked as a JSON object, incluyendo un empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
