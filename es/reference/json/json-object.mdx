Crea una new table marked as a JSON object para que Real JSON encoder la trate como object.

## Sintaxis

```lua
json.object(source?: table): table
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table que se copy dentro de la new object table. Si se omitted o es nil, se devuelve una empty object table. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `object` | `table` | New table marked con Real JSON object marker. Source entries se copy, excepto Real JSON type marker. |

## Ejemplo

Create una new table marked as a JSON object, incluyendo un empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
