Parsea JSON con el mismo parser que json.decode y devuelve un success flag en lugar de lanzar para parse errors.

## Sintaxis

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON text para parsear. Este argument se comprueba como string antes de capturar parse errors. |
| `options` | `DecodeOptions` | No | Optional decode options. Un boolean establece useNull directamente. Una table puede establecer useNull y maxDepth; maxDepth se clampa de 1 a 4096. Invalid option argument types se comprueban antes de capturar parse errors. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `success` | `boolean` | True cuando parsing tiene exito, false cuando el parser informa un error. |
| `decoded` | `any \| nil` | Decoded value en exito, nil en parse failure. JSON false valido devuelve success como true y decoded como false, asi que comprueba el success return value. |
| `errorMessage` | `string \| nil` | Error message en parse failure, si no nil. El mensaje incluye el json.decodeSafe prefix y parser position. |
| `errorPosition` | `number \| nil` | Parser byte position en parse failure, si no nil. |

## Tipos

### DecodeOptions

Controla el comportamiento de análisis de JSON.

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo con el centinela nulo de la biblioteca en lugar de nulo. |
| `maxDepth` | `integer` | No | Establece la profundidad máxima de anidamiento, sujeta de 1 a 4096. |

## Ejemplo

Parsea JSON y usa el success return value para separar valid false o nil results de parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
