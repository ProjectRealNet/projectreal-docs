<div className="real-function-page">

```lua
json.values(object: table): table
```

## Argumentos

<ParamField path={"object"} type={"table"} required>
Table que se va a enumerate. La function comprueba este argument con type checking.
</ParamField>

## Retornos

<ResponseField name={"values"} type={"table"}>
New array-style table que contiene los direct values de la input table. El output queda marked as JSON array. Enumeration usa table iteration, por lo que no hay ordering guarantee visible en la function.
</ResponseField>

## Ejemplo

Recoge los direct values de una table en una JSON array-marked table.

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
