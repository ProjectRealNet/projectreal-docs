Valida un JSON string parseando un unico complete JSON value. En success devuelve solo true. En parse failure devuelve false mas parser error details.

## Sintaxis

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Argumentos

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string que se va a validate. La function lee este argument con string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options. Un boolean establece useNull. Una table puede establecer useNull y maxDepth. maxDepth se clamp de 1 a 4096. |

## Retornos

| Name | Type | Descripción |
| --- | --- | --- |
| `valid` | `boolean` | true cuando el parsing de un unico complete JSON value tiene exito. false cuando el parsing falla dentro del protected parse block. |
| `errorMessage` | `string \| nil` | Error message en parse failure. La message tiene prefix json.validate e incluye near-position suffix. Este return solo esta presente en failure. |
| `errorPosition` | `number \| nil` | Parser byte position del parser en parse failure. Este return solo esta presente en failure. |

## Tipos

### DecodeOptions

Controla el comportamiento de análisis de JSON.

| Name | Type | Required | Descripción |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo con el centinela nulo de la biblioteca en lugar de nulo. |
| `maxDepth` | `integer` | No | Establece la profundidad máxima de anidamiento, sujeta de 1 a 4096. |

## Ejemplo

Comprueba si un string contiene exactamente un complete JSON value.

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
