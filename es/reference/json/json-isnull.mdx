<div className="real-function-page">

```lua
json.isNull(value: any): boolean
```

## Argumentos

<ParamField path={"value"} type={"any"} required>
Value que se inspect. Solo el json.null value devuelve true; Lua nil y other values devuelven false.
</ParamField>

## Retornos

<ResponseField name={"isNull"} type={"boolean"}>
true cuando el value es el exact json.null sentinel, otherwise false.
</ResponseField>

## Ejemplo

Check si un value es el json.null sentinel en vez de Lua nil.

```lua
local value = json.decode("null")

if json.isNull(value) then
    print("The value is JSON null")
end

print(json.isNull(nil))
```
