game:CoreGui lookup.RobloxGui degerini dondurur. Function arguments almaz. CoreGui lookup nil dondururse veya bu degerdeki RobloxGui nil ise function nil dondurur. Function container olusturmaz ve cached CoreGui degerini kullanmaz.

```lua
gethui(): Instance | nil
```
