Örnek keşfi ve etkileşim yardımcıları.

## Kullanılabilir fonksiyonlar

<CardGroup cols={2}>
<Card title="fireclickdetector" href="./fireclickdetector">
Yerel oyuncu icin bir ClickDetector interaction tetikler. Ilk arguman ClassName degeri ClickDetector olan bir Instance olmalidir. distance istege baglidir ve varsayilan degeri 0 dir. clickOption istege baglidir, buyuk kucuk harfe duyarsiz karsilastirilir ve varsayilan degeri "mouseclick" olur. Desteklenen option degerleri "mouseclick", "rightmouseclick", "mousehoverenter" ve "mousehoverleave" olur. Click option degerleri distance degerini Roblox click helper icine float olarak iletir, hover option degerleri distance degerini yok sayar. Players veya Players.LocalPlayer kullanilabilir degilse function hicbir sey tetiklemeden doner. Bilinmeyen clickOption degeri de interaction olusturmaz. Function herhangi bir deger dondurmez.
</Card>
<Card title="fireproximityprompt" href="./fireproximityprompt">
Real ProximityPrompt trigger uzerinden bir ProximityPrompt tetikler. prompt argumani ClassName alani "ProximityPrompt" olan object olmalidir. Deger object degilse cagri type error uretir. ClassName yoksa veya string degilse "Invalid Instance" uretir. ClassName "ProximityPrompt" degilse "ProximityPrompt expected" uretir. Function optional arguments almaz ve herhangi bir deger dondurmez.
</Card>
<Card title="firetouchinterest" href="./firetouchinterest">
Iki BasePart instances icin Real touch interest event tetikler. Ilk iki arguman Instance object olmalidir ve iki deger de IsA("BasePart") kontrolunden gecmelidir. state argumani zorunludur ve number veya boolean olmalidir. state number oldugunda yalnizca 1 true olur ve diger her number false olur. state boolean oldugunda boolean degeri dogrudan iletilir. Herhangi bir part touch data tasimiyorsa veya ilk part overlap reference tasimiyorsa function hicbir sey tetiklemeden doner. Function herhangi bir deger dondurmez. helper icine iletilen boolean icin kesin begin/end anlami: Nicht aus der Codebasis verifizierbar.
</Card>
<Card title="getcallbackvalue" href="./getcallbackvalue">
Bir Instance uzerindeki callback property icinde saklanan Lua callback function degerini okur. Ilk arguman Instance object olmalidir ve ikinci arguman string property name olmalidir. instance reference gecerli olmalidir. property name Roblox property metadata uzerinden cozulur ve tipi LUA_CALLBACK olan bir property degerine isaret etmelidir. property descriptor yoksa, property LUA_CALLBACK degilse, callback field offset yoksa, saklanan callback yoksa, LiveLuaRef yoksa, callback farkli bir Lua global state icine aitse veya referans verilen deger function degilse function nil dondurur. Ilk callback slot callback icermediginde async callback field fallback de kontrol edilir. Function property degerini guncellemez.
</Card>
<Card title="gethui" href="./gethui">
game:CoreGui lookup.RobloxGui degerini dondurur. Function arguments almaz. CoreGui lookup nil dondururse veya bu degerdeki RobloxGui nil ise function nil dondurur. Function container olusturmaz ve cached CoreGui degerini kullanmaz.
</Card>
<Card title="getinstances" href="./getinstances">
Instance cache icinde su anda saklanan her object value iceren yeni bir array table dondurur. Function arguments almaz. Her registry value object mi kontrolu disinda Parent, ClassName, DataModel fieldship, nil-parent state veya Instance validity ile filtreleme yapmaz. Entries donen tabloya 1 den baslayan sequential numeric indexes ile kopyalanir. iteration order cache uzerindeki table iteration kaynagindan gelir ve function tarafindan siralanmaz.
</Card>
<Card title="getnilinstances" href="./getnilinstances">
Returns a new array table containing cached Instance values whose Parent field is nil. The function takes no arguments. It does not sort the returned entries.
</Card>
<Card title="isnetworkowner" href="./isnetworkowner">
Bir Instance uzerinden hidden property "NetworkOwnerV3" degerini okuyup ilk donen degerin integer conversion ile donusturuldugunde 2 den buyuk olup olmadigini dondurur. Arguman Instance object olmalidir. Function iceride the hidden property reader cagirir ve bu cagridan gelen hatalari yakalamaz, bu nedenle Invalid Instance values, missing properties veya non-property metadata gethiddenproperty ile ayni hatalari uretebilir. Bir boolean dondurur. peer_id > 2 degerinin tam olarak local network ownership anlamina gelip gelmedigi: Nicht aus der Codebasis verifizierbar.
</Card>
</CardGroup>
