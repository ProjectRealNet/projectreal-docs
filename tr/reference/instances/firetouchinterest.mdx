Iki BasePart instances icin Real touch interest event tetikler. Ilk iki arguman Instance object olmalidir ve iki deger de IsA("BasePart") kontrolunden gecmelidir. state argumani zorunludur ve number veya boolean olmalidir. state number oldugunda yalnizca 1 true olur ve diger her number false olur. state boolean oldugunda boolean degeri dogrudan iletilir. Herhangi bir part touch data tasimiyorsa veya ilk part overlap reference tasimiyorsa function hicbir sey tetiklemeden doner. Function herhangi bir deger dondurmez. helper icine iletilen boolean icin kesin begin/end anlami: Nicht aus der Codebasis verifizierbar.

## Söz dizimi

```lua
firetouchinterest(partA: Instance, partB: Instance, state: number | boolean)
```

## Aliaslar

- `firetouchtransmitter`

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `partA` | `Instance` | Yes | Ilk Instance object. IsA("BasePart") kontrolunden gecmelidir. touch data ve overlap reference degerleri call icin kullanilir. |
| `partB` | `Instance` | Yes | Ikinci Instance object. IsA("BasePart") kontrolunden gecmelidir. touch data degeri call icin kullanilir. |
| `state` | `number \| boolean` | Yes | Zorunlu state degeri. Numbers state == 1 ile donusturulur; booleans dogrudan iletilir. |

## Örnek

Iki BasePart degeri ve acik bir state degerini firetouchinterest icine iletir.

```lua
local players = game:GetService("Players")
local character = players.LocalPlayer.Character or players.LocalPlayer.CharacterAdded:Wait()
local rootPart = character:WaitForChild("HumanoidRootPart")
local targetPart = workspace.TouchTarget

firetouchinterest(rootPart, targetPart, true)
```
