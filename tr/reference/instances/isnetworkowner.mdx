Bir Instance uzerinden hidden property "NetworkOwnerV3" degerini okuyup ilk donen degerin integer conversion ile donusturuldugunde 2 den buyuk olup olmadigini dondurur. Arguman Instance object olmalidir. Function iceride the hidden property reader cagirir ve bu cagridan gelen hatalari yakalamaz, bu nedenle Invalid Instance values, missing properties veya non-property metadata gethiddenproperty ile ayni hatalari uretebilir. Bir boolean dondurur. peer_id > 2 degerinin tam olarak local network ownership anlamina gelip gelmedigi: Nicht aus der Codebasis verifizierbar.

## Söz dizimi

```lua
isnetworkowner(instance: Instance): boolean
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `instance` | `Instance` | Yes | property name "NetworkOwnerV3" ile the hidden property reader icine iletilen Instance object. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `isOwner` | `boolean` | "NetworkOwnerV3" ilk donus degeri uzerindeki integer conversion 2 den buyukse true; aksi halde false. |

## Örnek

Check network ownership for a BasePart Instance.

```lua
local part = workspace:FindFirstChildWhichIsA("BasePart", true)

if part then
    local ownsNetwork = isnetworkowner(part)
    print(ownsNetwork)
end
```
