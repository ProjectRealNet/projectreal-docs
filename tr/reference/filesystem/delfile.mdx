Workspace icindeki mevcut bir regular file degerini siler.

## Söz dizimi

```lua
delfile(path: string)
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Separator normalization ve workspace-boundary checks sonrasinda workspace icinde cozumlenen path. Hedef mevcut olmali ve regular file olmalidir; folders kabul edilmez. |

## Örnek

Mevcut bir workspace file degerini silin.

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
