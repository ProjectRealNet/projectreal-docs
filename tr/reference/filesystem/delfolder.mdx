<div className="real-function-page">

```lua
delfolder(path: string)
```

## Argümanlar

<ParamField path={"path"} type={"string"} required>
Separator normalization ve workspace-boundary checks sonrasinda workspace icinde cozumlenen path. Hedef mevcut olmali ve directory olmalidir; files kabul edilmez.
</ParamField>

## Örnek

Mevcut bir workspace folder degerini ve icerigini silin.

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
