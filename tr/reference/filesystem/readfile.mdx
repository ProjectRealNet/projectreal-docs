workspace icindeki existing regular file degerini binary mode ile okur ve bytes degerlerini Lua string olarak dondurur.

## Söz dizimi

```lua
readfile(path: string): string
```

## Aliaslar

- `readfileasync`

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `path` | `string` | Yes | separator normalization, workspace-boundary checks ve filename/extension checks sonrasinda workspace icinde cozulun File path. Absolute paths yalnizca workspace icinde resolve olursa kabul edilir. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `content` | `string` | File contents acik uzunluklu Lua string olarak dondurulur. null bytes, line endings ve BOM bytes gibi bytes degerleri readfile tarafindan transform edilmez. |

## Örnek

existing workspace file icinden bytes oku.

```lua
local path = "examples/config.json"
writefile(path, '{"enabled":true}')

local content = readfile(path)
print(content)
print(#content)
```
