<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Aliaslar

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argümanlar

<ParamField path={"level"} type={"number"} required>
integer conversion ile dönüştürülen ve 0 &lt;= level &lt; the current call stack depth koşuluna göre kontrol edilen Stack level number.
</ParamField>

## Dönüşler

<ResponseField name={"valid"} type={"boolean"}>
numeric level current call stack range içindeyse true, aksi halde false.
</ResponseField>

## Örnek

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
