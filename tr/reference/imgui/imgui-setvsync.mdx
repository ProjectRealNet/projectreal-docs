ImGui renderer icin vertical synchronization preference degerini gunceller. Gecerli presentation path bu preference degerini saklar ama uygulamaz.

## Söz dizimi

```lua
imgui.setvsync(enabled: boolean)
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `enabled` | `boolean` | Yes | vertical synchronization istemek icin `true`; uncapped presentation istemek icin `false`. |
