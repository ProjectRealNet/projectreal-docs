<div className="real-function-page">

```lua
ImGuiWindow.Button(window: ImGuiWindow, label: string, onClick: function): ImGuiWindow
```

## Argümanlar

<ParamField path={"window"} type={"ImGuiWindow"} required>
imgui.create tarafindan dondurulen ImGuiWindow object. Yok edilmis veya gecersiz window Lua error uretir.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Render edilen ImGui button icine iletilen button label string.
</ParamField>

<ParamField path={"onClick"} type={"function"} required>
Bu button icin saklanan ve click event islendikten sonra arguments olmadan cagrilan Function.
</ParamField>

## Dönüşler

<ResponseField name={"window"} type={"ImGuiWindow"}>
Ayni ImGuiWindow object; method calls zincirlenebilir.
</ResponseField>

## Tipler

### ImGuiWindow

imgui.create tarafından döndürülen tanıtıcı. Kontrol oluşturma yöntemleri aynı tanıtıcıyı döndürür, böylece çağrılar zincirlenebilir.

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `Button` | `(label: string, onClick: () -> ()) -> ImGuiWindow` | Yes | Bir düğme ekler ve tıklamanın ardından geri aramayı başlatır. |
| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | Sağlanan duruma başlatılan bir onay kutusu ekler. |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | İçerik geri çağrısı tarafından daraltılan bir başlığın altına eklenen grup kontrolleri. |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | Bir RGBA düzenleyicisi ekler; atlanan renk bileşenleri varsayılan olarak 1,0'dır. |
| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | Tek satırlık bir metin girişi ekler; atlanan ilk metin varsayılan olarak boş bir dizeye dönüştürülür. |
| `SameLine` | `() -> ImGuiWindow` | Yes | Sonraki kontrolü aynı satıra yerleştirir. |
| `Separator` | `() -> ImGuiWindow` | Yes | Yatay bir ayırıcı ekler. |
| `SliderFloat` | `(label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow` | Yes | Kayan nokta kaydırıcısını ekler. |
| `SliderInt` | `(label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow` | Yes | Bir tamsayı kaydırıcısı ekler. |
| `Text` | `(text: string) -> ImGuiWindow` | Yes | Etkileşimli olmayan metin ekler. |
| `destroy` | `() -> ()` | Yes | Pencereyi kaldırır ve kayıtlı geri aramalarını serbest bırakır. |
