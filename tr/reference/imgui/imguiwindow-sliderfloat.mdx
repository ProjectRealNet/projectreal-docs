Window icine bir SliderFloat element ekler. label, value, minimum ve maximum 2 ile 5 arasindaki argumanlardan okunur; sayisal argumanlar number type checking ile kontrol edilir. Rendering sirasinda Real, saklanan deger ve aralikla a floating-point slider cagirir. ImGui degisen bir deger bildirdiginde onChange queue icine alinir ve daha sonra bir Lua number ile cagrilir. Real bu closure icinde ayri bir minimum &lt;= maximum dogrulamasi eklemez.

## Söz dizimi

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | imgui.create tarafindan dondurulen ImGuiWindow. object gecersizse veya zaten destroy edildiyse method bir Lua error olusturur. |
| `label` | `string` | Yes | string type checking ile okunan slider label. |
| `value` | `number` | Yes | number type checking ile okunan ve gecerli float degeri olarak saklanan slider baslangic degeri. |
| `minimum` | `number` | Yes | number type checking ile okunan ve a floating-point slider icine iletilen minimum value. |
| `maximum` | `number` | Yes | number type checking ile okunan ve a floating-point slider icine iletilen maximum value. |
| `onChange` | `(number) -> ()` | Yes | Lua registry icinde saklanan callback function. slider rendering sirasinda degistiginde daha sonra guncellenmis sayisal degerle cagrilir. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `window` | `ImGuiWindow` | Ayni ImGuiWindow object; method cagrilarinin zincirlenmesine izin verir. |
