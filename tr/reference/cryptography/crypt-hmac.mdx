<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argümanlar

<ParamField path={"key"} type={"string"} required>
HMAC key olarak kullanilan raw Lua string byte degerleri. key Base64-decode edilmez.
</ParamField>

<ParamField path={"data"} type={"string"} required>
HMAC calculation icine aktarilan Lua string byte degerleri.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Case-sensitive HMAC algorithm adi. Varsayilan deger sha256.
</ParamField>

## Dönüşler

<ResponseField name={"digest"} type={"string"}>
Line breaks olmayan Base64-encoded HMAC output.
</ResponseField>

## Örnek

Raw Lua string key ve data ile Base64 HMAC output hesapla.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
