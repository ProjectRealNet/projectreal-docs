Lua string byte degerlerini Base64 encoder ile encode eder, = padding kullanir ve satir sonu eklemez.

## Söz dizimi

```lua
base64_encode(data: string): string
```

## Aliaslar

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Base64 encoder icine aktarilan Lua string byte degerleri. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `encoded` | `string` | Lua string olarak dondurulen Base64 ciktisi. |

## Örnek

Bir Lua string degerini encode et ve Base64 ciktisini yazdir.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
