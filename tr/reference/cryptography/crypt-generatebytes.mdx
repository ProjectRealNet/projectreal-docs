<div className="real-function-page">

```lua
crypt.generatebytes(size: number): string
```

## Argümanlar

<ParamField path={"size"} type={"number"} required>
Allocation oncesinde integer conversion icinden gecen sayi. 0 veya daha kucuk degerler 1 olarak degistirilir.
</ParamField>

## Dönüşler

<ResponseField name={"encoded"} type={"string"}>
Uretilen raw bytes icin Base64 encoding. Dondurulen string uzunlugu istenen byte sayisi degildir.
</ResponseField>

## Örnek

Raw bytes gerektiginde byte uret ve Base64 sonucunu decode et.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
