Lua string byte degerlerini desteklenen bir crypto library hash algoritmasi ile hash eder ve lowercase hexadecimal digest dondurur.

## Söz dizimi

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `data` | `string` | Yes | crypto library HashFilter icine aktarilan Lua string byte degerleri. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Case-sensitive hash algoritma adi. Varsayilan deger sha256. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `digest` | `string` | Prefix veya separators olmayan lowercase hexadecimal digest. |

## Örnek

Lua string byte degerlerini varsayilan algoritma veya acik desteklenen ad ile hash et.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
