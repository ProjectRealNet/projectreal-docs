random byte generator ile raw random bytes uretir ve bunlari Lua string olarak dondurur.

## Söz dizimi

```lua
crypt.random(size: number): string
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Allocation oncesinde integer conversion icinden gecen sayi. 0 veya daha kucuk degerler argument error olusturur. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `bytes` | `string` | Lua string olarak dondurulen raw generated bytes. Dondurulen string uzunlugu allocate edilen byte sayisiyla eslesir. |

## Örnek

Raw bytes uret ve dondurulen Lua string uzunlugunu yazdir.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
