<div className="real-function-page">

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## Argümanlar

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Event descriptor signature degeri incelenecek signal. RBXScriptSignal olmayan object type error olusturur.
</ParamField>

## Dönüşler

<ResponseField name={"arguments"} type={"{string}"}>
Argument type name strings iceren array table. Signature data okunamadiginda veya argument entries uretilmediginde "Variant" iceren fallback table dondurulur.
</ResponseField>

## Örnek

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
