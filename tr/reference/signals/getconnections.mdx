Bir RBXScriptSignal icin RealConnection closures iceren array table dondurur. Ilk argument, Luau type name degeri RBXScriptSignal olan object olmalidir. Function signal icindeki Connect method degerini okur, temporary blank callback baglar, gecici connection icin next reference degerinden baslayan linked list degerini okur, gecici connection degerini disconnect eder ve her gecerli connection reference degerini closure haline getirir. Gecici connection sonrasinda connection reference bulunmazsa bos table dondurur. Daha once closure haline getirilen underlying references ayni cached closure table degerini dondurebilir. getsignals ve get_signal_cons ayni function icin aliases degerleridir.

## Söz dizimi

```lua
getconnections(signal: RBXScriptSignal): {RealConnection}
```

## Aliaslar

- `getsignals`
- `get_signal_cons`

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | Incelenecek signal. RBXScriptSignal olmayan object type error olusturur, cagrilabilir Connect field olmayan signal ise "Signal does not have 'Connect' method" olusturur. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `connections` | `&#123;RealConnection&#125;` | Connection closure tables iceren array table. Her closure, methods uzerinden fields ve methods sunar; mevcut olduklarinda Enabled, Disabled, LuaConnection, ForeignState, Function, Thread, Disconnect, Disable, Enable, Fire ve Defer buna dahildir. |

## Örnek

Inspect an RBXScriptSignal and list the wrapped connections Real can expose.

```lua
local Players = game:GetService("Players")

for _, connection in ipairs(getconnections(Players.PlayerAdded)) do
    print(connection.Enabled, connection.LuaConnection)
end
```
