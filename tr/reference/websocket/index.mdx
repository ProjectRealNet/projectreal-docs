Çift yönlü WebSocket bağlantıları.

| Fonksiyon gezinmesi | Açıklama |
| --- | --- |
| [`WebSocket.Close`](./websocket-close) | WebSocket.connect tarafından döndürülen WebSocket object değerini kapatır. İlk argument bir table olmalıdır. Function object içindeki connection state değerini okur. live state varsa ve henüz destroyed veya closed değilse, isClosed değerini true yapar ve saklanan WebSocket connection üzerinden boş bir close frame frame gönderir. close code veya reason kabul etmez ve values döndürmez. |
| [`WebSocket.connect`](./websocket-connect) | İki BindableEvents oluşturur, verilen URL için WebSocket client WebSocket connection açar ve bağlantı denemesi bitene kadar yield eder. Başarılı olursa OnMessage ve OnClose events, methods tarafından sağlanan Send ve Close methods ve connection state içeren bir WebSocket table döndürür. Incoming message data, OnMessage üzerinden string olarak fire edilir. receive loop bittiğinde OnClose arguments olmadan fire edilir. Bağlantı başarısız olursa function "WebSocket connection failed" ile başlayan bir error string fırlatır. |
| [`WebSocket.Send`](./websocket-send) | WebSocket.connect tarafından döndürülen WebSocket object üzerinden bir Lua string gönderir. Method ilk argument olarak WebSocket table, ikinci argument olarak message string bekler. Object içindeki connection state değerini okur, bu object yoksa "WebSocket state is missing" fırlatır, state destroyed veya closed ise göndermeden döner ve varsayılan olarak CURLWS_TEXT ile ya da isteğe bağlı üçüncü argument boolean true ise CURLWS_BINARY ile curl_ws_send çağırır. values döndürmez ve gönderilen bytes sayısını raporlamaz. |
