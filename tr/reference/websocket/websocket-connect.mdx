```lua
WebSocket.connect(url: string): WebSocket
```

## Aliaslar

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## Argümanlar

<ParamField path={"url"} type={"string"} required>
WebSocket client WebSocket connection attempt yapmadan önce CURLOPT_URL değerine geçirilen URL string.
</ParamField>

## Dönüşler

<ResponseField name={"socket"} type={"WebSocket"}>
OnMessage, OnClose ve connection state içeren WebSocket table. Send ve Close, WebSocket object methods üzerinden çözümlenir.
</ResponseField>

## Örnek

Bir WebSocket aç, OnMessage ve OnClose bağla, ardından göndermek ve kapatmak için socket methods kullan.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
