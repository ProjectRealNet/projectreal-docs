<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argümanlar

<ParamField path={"json"} type={"string"} required>
Parse edilecek JSON text. Bu argument parse errors catch edilmeden once string olarak kontrol edilir.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean useNull degerini dogrudan ayarlar. table useNull ve maxDepth ayarlayabilir; maxDepth 1 ile 4096 arasinda clamp edilir. Invalid option argument types parse errors catch edilmeden once kontrol edilir.
</ParamField>

## Dönüşler

<ResponseField name={"success"} type={"boolean"}>
parsing basariliysa True, parser error bildirirse false.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Basarida Decoded value, parse failure durumunda nil. Gecerli JSON false, success degerini true ve decoded degerini false olarak dondurur, bu yuzden success return value kontrol edin.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
parse failure durumunda Error message, aksi halde nil. message json.decodeSafe prefix ve parser position icerir.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
parse failure durumunda Parser byte position, aksi halde nil.
</ResponseField>

## Tipler

### DecodeOptions

JSON ayrıştırma davranışını kontrol eder.

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Nil yerine kütüphanenin null sentinel'i ile JSON null'u temsil eder. |
| `maxDepth` | `integer` | No | 1'den 4096'ya kadar kenetlenmiş maksimum yuvalama derinliğini ayarlar. |

## Örnek

JSON parse edin ve valid false veya nil results ile parse failures durumlarini ayirmak icin success return value kullanin.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
