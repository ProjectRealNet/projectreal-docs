json.encode icin JSON array olarak isaretlenmis new table olusturur ve source table verildiginde 1.#source sequence degerini kopyalar.

## Söz dizimi

```lua
json.array(source?: table): table
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table. Atlanirsa veya nil ise json.array new empty array-marked table dondurur. Verilirse, yalnizca 1 with #source arasindaki numeric sequence entries new table icine kopyalanir. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `array` | `table` | JSON array marker iceren new table. json.encode bunu JSON array olarak serializes eder; original source table dondurulmez. |

## Örnek

json.encode degerini JSON array olarak serializes etsin diye array-marked copy olusturun.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
