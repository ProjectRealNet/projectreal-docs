Dotted string path veya array table of keys kullanarak table icinden nested value okur.

## Söz dizimi

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliaslar

- `json.getpath`

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `object` | `table` | Yes | Okunacak root table. Function bu argument degerinin table olmasini ister. |
| `path` | `string \| table` | Yes | Takip edilecek path. string dots uzerinden split edilir; integer string tokens raw array indexing ile okunur. table path, 1'den #path'e kadar array entries degerlerini keys olarak kullanir. |
| `defaultValue` | `any` | No | Traversal path tamamlanmadan nil veya non-table degerine ulasirsa dondurulen fallback value. |

## Dönüşler

| Name | Type | Açıklama |
| --- | --- | --- |
| `pathValue` | `any \| nil` | Requested path konumundaki value. path missing ise defaultValue saglandiysa onu, aksi halde nil dondurur. |

## Örnek

Dotted string path veya array table of keys ile nested table value oku.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
