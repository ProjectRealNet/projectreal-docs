Klavye ve fare giriş olayları.

| Fonksiyon gezinmesi | Açıklama |
| --- | --- |
| [`isrbxactive`](./isrbxactive) | Current foreground window degerinin Real tarafindan bulunan Roblox window olup olmadigini dondurur. Real bu pencereyi gecerli process icin windows enumerating yaparak ve class name degeri Roblox window olan window secerek bulur. Function arguments almaz ve foreground window ya da matching Roblox window yoksa false dondurur. |
| [`keyclick`](./keyclick) | Roblox window active oldugunda bir key down event ve ardindan bir key up event gonderir. keyCode argumani Lua number olarak kontrol edilir, integer conversion ile donusturulur, Windows key mapping ile Windows virtual-key code degerinden scan code degerine map edilir ve KEYEVENTF_SCANCODE ile keyboard input uzerinden gonderilir. isrbxactive false olacaksa function input gondermeden doner. |
| [`keypress`](./keypress) | Roblox window active oldugunda bir key down event gonderir. keyCode argumani Lua number olarak kontrol edilir, integer conversion ile donusturulur, Windows key mapping ile Windows virtual-key code degerinden scan code degerine map edilir ve KEYEVENTF_SCANCODE ile keyboard input uzerinden gonderilir. Bu function key up event gondermez. isrbxactive false olacaksa function input gondermeden doner. |
| [`keyrelease`](./keyrelease) | Roblox window active oldugunda bir key up event gonderir. keyCode argumani Lua number olarak kontrol edilir, integer conversion ile donusturulur, Windows key mapping ile Windows virtual-key code degerinden scan code degerine map edilir ve KEYEVENTF_SCANCODE \| KEYEVENTF_KEYUP ile keyboard input uzerinden gonderilir. Bu function key down event gondermez. isrbxactive false olacaksa function input gondermeden doner. |
| [`mouse1click`](./mouse1click) | Roblox window active oldugunda left mouse down event ve left mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mouse1press`](./mouse1press) | Roblox window active oldugunda left mouse down event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen left mouse up event gondermez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mouse1release`](./mouse1release) | Roblox window active oldugunda left mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen left mouse down event gondermez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mouse2click`](./mouse2click) | Roblox window active oldugunda right mouse down event ve right mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mouse2press`](./mouse2press) | Roblox window active oldugunda right mouse down event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen right mouse up event gondermez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mouse2release`](./mouse2release) | Roblox window active oldugunda right mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen right mouse down event gondermez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mousemoveabs`](./mousemoveabs) | Roblox window active oldugunda Windows absolute mouse input kullanarak mouse hareket ettirir. x ve y argumanlari Lua numbers olarak kontrol edilir ve integer conversion ile donusturulur. Real bunlari active foreground window client area icine gore koordinatlar olarak ele alir, ClientToScreen ile bu client area screen position degerini ekler, GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) - 1 ve integer math ile scale eder, ardindan the requested mouse action ile mouse input cagirir. isrbxactive false olacaksa function input gondermeden doner. |
| [`mousemoverel`](./mousemoverel) | Roblox window active oldugunda mouse degerini relative delta kadar hareket ettirir. x ve y argumanlari Lua numbers olarak kontrol edilir ve integer conversion ile donusturulur, sonra the requested mouse action ile mouse input fonksiyonuna dogrudan dx ve dy olarak iletilir. Function the requested mouse action kullanmaz, client-area conversion yapmaz, bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner. |
| [`mousescroll`](./mousescroll) | Roblox window active oldugunda mouse wheel event gonderir. amount argumani Lua number olarak kontrol edilir, integer conversion ile donusturulur ve the requested mouse action ile mouse input fonksiyonuna dogrudan dwData degeri olarak iletilir. Real amount degerini normalize etmez ve movement data eklemez. Function bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner. |
