Roblox window active oldugunda right mouse down event ve right mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner.

## Söz dizimi

```lua
mouse2click()
```
