Roblox window active oldugunda mouse wheel event gonderir. amount argumani Lua number olarak kontrol edilir, integer conversion ile donusturulur ve the requested mouse action ile mouse input fonksiyonuna dogrudan dwData degeri olarak iletilir. Real amount degerini normalize etmez ve movement data eklemez. Function bir sey dondurmez ve isrbxactive false olacaksa input gondermeden doner.

## Söz dizimi

```lua
mousescroll(amount: number)
```

## Argümanlar

| Name | Type | Required | Açıklama |
| --- | --- | --- | --- |
| `amount` | `number` | Yes | mouse input icine iletilmeden once Lua number olarak okunan ve integer conversion ile donusturulen wheel dwData value. |
