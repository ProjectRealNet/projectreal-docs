Roblox window active oldugunda right mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen right mouse down event gondermez ve isrbxactive false olacaksa input gondermeden doner.

## Söz dizimi

```lua
mouse2release()
```
