<div className="real-function-page">

```lua
checkcaller(): boolean
```

## Retours

<ResponseField name={"isCaller"} type={"boolean"}>
true lorsque le current Luau thread est tracked dans Real caller context; sinon false.
</ResponseField>

## Exemple

Check whether the current thread is tracked by Real.

```lua
local tracked = checkcaller()
print(tracked)
```
