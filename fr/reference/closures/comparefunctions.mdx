---
title: "comparefunctions"
sidebarTitle: "comparefunctions"
description: "Compare deux function values par leur function identity. Les deux arguments doivent être des functions. La function renvoie le boolean result de function identity(L, 1) == function identity(L, 2). Elle ne compare pas function bytecode, source, behavior, hashes, upvalues ni newcclosure mappings. comparefunction est un alias de la même function."
keywords: ["comparefunctions","Closures","comparefunction"]
---

<div className="real-function-page">

```lua
comparefunctions(func1: function, func2: function): boolean
```

## Alias

- `comparefunction`

## Arguments

<ParamField path={"func1"} type={"function"} required>
First function value convertie avec function identity.
</ParamField>

<ParamField path={"func2"} type={"function"} required>
Second function value convertie avec function identity.
</ParamField>

## Retours

<ResponseField name={"equal"} type={"boolean"}>
true lorsque les deux function values se résolvent au même function identity; sinon false.
</ResponseField>

## Exemple

Compare two functions by their function identity.

```lua
local function sample()
    return "ok"
end

local same = comparefunctions(sample, sample)
print(same)
```
