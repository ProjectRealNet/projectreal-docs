Ajoute un SliderFloat element a la fenetre. label, value, minimum et maximum sont lus depuis les arguments 2 a 5, les arguments numeriques etant verifies avec number type checking. Pendant le rendering, Real appelle a floating-point slider avec la valeur et la plage stockees. Quand ImGui signale une valeur modifiee, onChange est place dans une queue puis appele plus tard avec un Lua number. Real n ajoute pas de validation minimum &lt;= maximum separee dans ce closure.

## Syntaxe

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow renvoyee par imgui.create. Si la object est invalide ou deja detruite, la method declenche une Lua error. |
| `label` | `string` | Yes | Slider label lu avec string type checking. |
| `value` | `number` | Yes | Valeur initiale du slider lue avec number type checking et stockee comme valeur float actuelle. |
| `minimum` | `number` | Yes | Minimum value lue avec number type checking et transmise a a floating-point slider. |
| `maximum` | `number` | Yes | Maximum value lue avec number type checking et transmise a a floating-point slider. |
| `onChange` | `(number) -> ()` | Yes | Callback function stockee dans le Lua registry. Quand le slider change pendant le rendering, elle est appelee plus tard avec la valeur numerique mise a jour. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `window` | `ImGuiWindow` | La meme ImGuiWindow object, ce qui permet les appels de method chaines. |
