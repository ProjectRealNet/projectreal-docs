Pendant le rendering, Real appelle a floating-point slider avec la valeur et la plage stockees. Quand ImGui signale une valeur modifiee, onChange est place dans une queue puis appele plus tard avec un Lua number. Real n ajoute pas de validation minimum <= maximum separee dans ce closure."

<div className="real-function-page">

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Arguments

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow renvoyee par imgui.create. Si la object est invalide ou deja detruite, la method declenche une Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Slider label lu avec string type checking.
</ParamField>

<ParamField path={"value"} type={"number"} required>
Valeur initiale du slider lue avec number type checking et stockee comme valeur float actuelle.
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
Minimum value lue avec number type checking et transmise a a floating-point slider.
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
Maximum value lue avec number type checking et transmise a a floating-point slider.
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Callback function stockee dans le Lua registry. Quand le slider change pendant le rendering, elle est appelee plus tard avec la valeur numerique mise a jour.
</ParamField>

## Retours

<ResponseField name={"window"} type={"ImGuiWindow"}>
La meme ImGuiWindow object, ce qui permet les appels de method chaines.
</ResponseField>
