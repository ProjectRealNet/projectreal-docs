Met a jour la vertical synchronization preference du ImGui renderer. Le presentation path actuel stocke cette preference, mais ne l applique pas.

## Syntaxe

```lua
imgui.setvsync(enabled: boolean)
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `enabled` | `boolean` | Yes | `true` pour demander vertical synchronization; `false` pour demander uncapped presentation. |
