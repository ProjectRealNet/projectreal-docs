<div className="real-function-page">

```lua
json.array(source?: table): table
```

## Arguments

<ParamField path={"source"} type={"table"}>
Optional source table. Si elle est omise ou nil, json.array renvoie une new empty array-marked table. Si elle est fournie, seuls les numeric sequence entries de 1 with #source sont copies dans la new table.
</ParamField>

## Retours

<ResponseField name={"array"} type={"table"}>
New table avec JSON array marker. json.encode la serializes comme JSON array; l original source table n est pas renvoyee.
</ResponseField>

## Exemple

Cree une array-marked copy afin que json.encode serializes la valeur comme JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
