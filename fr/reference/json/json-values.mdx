<div className="real-function-page">

```lua
json.values(object: table): table
```

## Arguments

<ParamField path={"object"} type={"table"} required>
Table a enumerate. L function verifie cet argument avec type checking.
</ParamField>

## Retours

<ResponseField name={"values"} type={"table"}>
New array-style table contenant les direct values de l input table. L output est marked as JSON array. Enumeration utilise table iteration, donc aucune ordering guarantee n est visible dans l function.
</ResponseField>

## Exemple

Collecte les direct values d une table dans une JSON array-marked table.

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
