<div className="real-function-page">

```lua
json.quote(text: string): string
```

## Arguments

<ParamField path={"text"} type={"string"} required>
String a quote. L'function lit cet argument avec string type checking.
</ParamField>

## Retours

<ResponseField name={"quoted"} type={"string"}>
Complete JSON string literal incLua runtime opening et closing quote. Quotes, backslashes, common control characters et bytes below 0x20 sont escaped.
</ResponseField>

## Exemple

Convert un string en complete quoted JSON string literal.

```lua
local source = "Real Docs" .. string.char(10) .. [[Documentation "A"]]
local quoted = json.quote(source)

print(quoted)
```
