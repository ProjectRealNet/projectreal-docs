<div className="real-function-page">

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Arguments

<ParamField path={"json"} type={"string"} required>
JSON string a validate. L function lit cet argument avec string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. Un boolean definit useNull. Une table peut definir useNull et maxDepth. maxDepth est clamp de 1 a 4096.
</ParamField>

## Retours

<ResponseField name={"valid"} type={"boolean"}>
true quand le parsing d une seule complete JSON value reussit. false quand le parsing echoue dans le protected parse block.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message en parse failure. La message est prefixed avec json.validate et inclut un near-position suffix. Ce return existe seulement en failure.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position depuis l parser en parse failure. Ce return existe seulement en failure.
</ResponseField>

## Types

### DecodeOptions

Contrôle le comportement d'analyse JSON.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Représente JSON null avec la sentinelle nulle de la bibliothèque au lieu de nil. |
| `maxDepth` | `integer` | No | Définit la profondeur d'imbrication maximale, comprise entre 1 et 4 096. |

## Exemple

Verifie si un string contient exactement une complete JSON value.

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
