<div className="real-function-page">

```lua
json.type(value: any): string
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Valeur a classify. Passer no value retourne le runtime type name pour une stack value absente.
</ParamField>

## Retours

<ResponseField name={"jsonType"} type={"string"}>
Type name string. Les returns JSON-specific verifies sont "null", "array" et "object". Les valeurs non-table et non-json.null utilisent Lua type name, comme "nil", "boolean", "number", "integer", "string", "function", "object", "thread", "buffer", "class", "object", "vector" ou "no value", selon la runtime value.
</ResponseField>

## Exemple

Verifie le exact type string retourne par le JSON helper.

```lua
print(json.type(json.array({ "red", "blue" })))
print(json.type(json.object({ enabled = true })))
print(json.type(json.null))
print(json.type(nil))
print(json.type())
```
