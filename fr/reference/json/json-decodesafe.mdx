Parse JSON avec le meme parser que json.decode et renvoie un success flag au lieu de lancer pour les parse errors.

## Syntaxe

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON text a parser. Cet argument est verifie comme string avant que les parse errors soient capturees. |
| `options` | `DecodeOptions` | No | Optional decode options. Un boolean definit useNull directement. Une table peut definir useNull et maxDepth; maxDepth est clamp de 1 a 4096. Invalid option argument types sont verifies avant que les parse errors soient capturees. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `success` | `boolean` | True lorsque parsing reussit, false lorsque le parser signale un error. |
| `decoded` | `any \| nil` | Decoded value en cas de succes, nil en cas de parse failure. Un JSON false valide renvoie success comme true et decoded comme false, donc verifie le success return value. |
| `errorMessage` | `string \| nil` | Error message en cas de parse failure, sinon nil. Le message inclut le json.decodeSafe prefix et parser position. |
| `errorPosition` | `number \| nil` | Parser byte position en cas de parse failure, sinon nil. |

## Types

### DecodeOptions

Contrôle le comportement d'analyse JSON.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Représente JSON null avec la sentinelle nulle de la bibliothèque au lieu de nil. |
| `maxDepth` | `integer` | No | Définit la profondeur d'imbrication maximale, comprise entre 1 et 4 096. |

## Exemple

Parse JSON et utilise le success return value pour separer les valid false ou nil results des parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
