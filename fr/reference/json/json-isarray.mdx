<div className="real-function-page">

```lua
json.isArray(value: any): boolean
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Value a inspect. Non-table values renvoient false.
</ParamField>

## Retours

<ResponseField name={"isArray"} type={"boolean"}>
true quand la value est une table marked as a JSON array ou une unmarked table avec contiguous positive integer keys de 1 a son maximum index. Empty unmarked tables renvoient false.
</ResponseField>

## Exemple

Check si une table est treated as a JSON array par Real JSON encoder.

```lua
local items = json.array({ "one", "two" })
local record = json.object({ name = "Real" })
local inferred = { "one", "two" }

print(json.isArray(items))
print(json.isArray(record))
print(json.isArray(inferred))
```
