<div className="real-function-page">

```lua
json.isNull(value: any): boolean
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Value a inspect. Seul le json.null value renvoie true; Lua nil et other values renvoient false.
</ParamField>

## Retours

<ResponseField name={"isNull"} type={"boolean"}>
true quand la value est le exact json.null sentinel, otherwise false.
</ResponseField>

## Exemple

Check si une value est le json.null sentinel au lieu de Lua nil.

```lua
local value = json.decode("null")

if json.isNull(value) then
    print("The value is JSON null")
end

print(json.isNull(nil))
```
