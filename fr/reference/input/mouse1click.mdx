Envoie un left mouse down event et un left mouse up event lorsque la Roblox window est active. Real appelle mouse input avec the requested mouse action et sans movement ni wheel data. La function ne prend aucun arguments, ne renvoie rien et retourne sans envoyer d input lorsque isrbxactive serait false.

## Syntaxe

```lua
mouse1click()
```
