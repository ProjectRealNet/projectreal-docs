La function renvoie d abord une valeur scriptable en cache lorsqu elle existe pour le meme instance reference et property name. En cas de cache miss, le property name est resolu with Roblox property metadata et l Instance class descriptor. Si aucun descriptor n existe, ou si le field resolu manque ou n est pas une property entry, la function renvoie nil. Lorsqu une property entry est trouvee, elle lit scriptable state, stocke cette valeur dans scriptable override cache pour l instance et la property, puis renvoie le boolean. La function ne modifie pas le scriptable flag."

<div className="real-function-page">

```lua
isscriptable(instance: Instance, property: string): boolean | nil
```

## Arguments

<ParamField path={"instance"} type={"Instance"} required>
Instance object dont le property scriptable state doit etre verifie.
</ParamField>

<ParamField path={"property"} type={"string"} required>
Property name resolu with Roblox property metadata et l Instance class descriptor.
</ParamField>

## Retours

<ResponseField name={"scriptable"} type={"boolean | nil"}>
Valeur scriptable state en cache ou actuelle, ou nil lorsque le property descriptor/field manque ou n est pas une property entry.
</ResponseField>

## Exemple

Check whether a property is scriptable on an Instance.

```lua
local scriptable = isscriptable(workspace, "Name")
print(scriptable)
```
