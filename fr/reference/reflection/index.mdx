Aides à la réflexion pour les instances et les propriétés.

| Navigation des fonctions | Description |
| --- | --- |
| [`gethiddenproperty`](./gethiddenproperty) | Lit une Roblox property with reflection metadata, y compris les non-scriptable properties. Le premier argument doit etre Instance object et le deuxieme argument doit etre un string property name. Le instance reference doit etre valide. Si le property descriptor manque dans Roblox property metadata, la function retourne seulement nil. Si le descriptor existe mais ne se resout pas en property entry, elle leve "Not a property". Pour les reflection types Bool, Int, Float, Double, String, SystemAddress, SharedString et Vector3, la function appelle le getter et retourne le value plus un boolean egal a !IsScriptable(). SystemAddress retourne RemoteId.PeerId comme integer. SharedString retourne Content comme string. Vector3 lit depuis le instance primitive Size offset et leve "can't get value" si le touch data manque. Les autres property types sont lus with normal Lua field access apres avoir temporairement mis le property scriptable flag a true; BinaryString est temporairement traite comme String pour cette lecture. Le original scriptable flag et le BinaryString type sont restaures avant le retour. |
| [`isscriptable`](./isscriptable) | Verifie le scriptable flag d une Roblox property sur une Instance. La function renvoie d abord une valeur scriptable en cache lorsqu elle existe pour le meme instance reference et property name. En cas de cache miss, le property name est resolu with Roblox property metadata et l Instance class descriptor. Si aucun descriptor n existe, ou si le field resolu manque ou n est pas une property entry, la function renvoie nil. Lorsqu une property entry est trouvee, elle lit scriptable state, stocke cette valeur dans scriptable override cache pour l instance et la property, puis renvoie le boolean. La function ne modifie pas le scriptable flag. |
| [`sethiddenproperty`](./sethiddenproperty) | Sets a Roblox property with reflection metadata. The first argument must be Instance object, the second argument must be a string property name, and the third argument must be present. The instance reference must be valid. If the property descriptor is missing from Roblox property metadata, the function returns nil. If the descriptor exists but does not resolve to a property entry, it raises "Not a property". Bool values use luaL_checkboolean. Int and SystemAddress values use integer type checking, with SystemAddress writing RemoteId.PeerId. Float and Double values use number type checking. String, SharedString, and BinaryString values use string type checking before calling the setter. For other property types, the function temporarily calls setscriptable(instance, property, true), assigns instance[property] = value with normal Lua field assignment, then restores the original scriptable state with setscriptable(instance, property, isScriptable). On successful writes, the return value is a boolean equal to !IsScriptable() from before the write. |
| [`setscriptable`](./setscriptable) | Stocke un scriptable override pour une Roblox property dans scriptable override cache et renvoie le previous scriptable state. Le premier argument doit etre Instance object, le deuxieme argument doit etre un string property name, et le troisieme argument doit etre boolean. Si un cache entry existe deja pour le meme instance reference et property name, le cached scriptable value est remplace et l ancienne valeur du cache est renvoyee. En cas de cache miss, le property name est resolu with Roblox property metadata et l Instance class descriptor. Si aucun descriptor n existe, ou si le field resolu manque ou n est pas une property entry, la function renvoie nil. Lorsqu une property entry est trouvee, la function lit scriptable state, stocke le boolean demande avec le property reference dans scriptable override cache, puis renvoie le previous scriptable state value. GameIndexHook et GameNewIndexHook utilisent ensuite ce cache en definissant temporairement le property field scriptable flag pour une seule lecture ou ecriture indexed, puis restaurent le previous field flag. |
