Ecrit zero ou plusieurs valeurs dans la Windows console actuelle with stdout avec le warning console text attribute. Si aucune console window n existe, l appel retourne sans convertir ni ecrire quoi que ce soit. Quand une console existe, chaque argument est converti avec Lua string conversion, joint avec des caracteres tab, puis ecrit with runtime value. Si Lua string conversion leve une erreur, rconsolewarn ne la capture pas. La function definit le console text attribute sur FOREGROUND_RED | FOREGROUND_GREEN | FOREGROUND_INTENSITY avant l ecriture, puis sur default console text color apres. Elle n ajoute pas de newline, n ajoute pas de warning prefix, ne cree pas et n affiche pas la console, et n appelle pas Luau warn ni Roblox Output. consolewarn est un alias de la meme function.

## Syntaxe

```lua
rconsolewarn(...values?: ...any)
```

## Alias

- `consolewarn`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Valeurs optionnelles. Si une console existe, chaque value est convertie avec Lua string conversion et jointe avec des caracteres tab avant l ecriture. |

## Exemple

Write values to the current Windows console with the warning console text attribute. Values are tab-separated, no newline or warning prefix is added, and consolewarn is the same function.

```lua
rconsolecreate()
rconsolewarn("Retrying request", 3)
rconsolewarn("\n")
```
