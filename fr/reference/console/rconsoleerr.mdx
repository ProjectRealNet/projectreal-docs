Écrit zero ou plusieurs valeurs dans la Windows console actuelle with stdout après avoir défini le console text attribute sur error text color. Les valeurs sont converties avec Lua string conversion, séparées par des caractères tab, puis le text attribute est defini sur default console text color. Si aucune console window n’existe, l’appel revient sans convertir ni ecrire quoi que ce soit.

## Syntaxe

```lua
rconsoleerr(...values?: ...any)
```

## Alias

- `consoleerr`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Valeurs optionnelles. Si une console existe, chaque value est convertie avec Lua string conversion et jointe avec des caracteres tab avant l ecriture. |

## Exemple

Write a bright red message to the current Windows console without throwing a Luau error.

```lua
rconsolecreate()
rconsoleerr("Request failed", 500, "
")
```
