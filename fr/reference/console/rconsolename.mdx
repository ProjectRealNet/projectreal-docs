Définit le title de la Windows console window actuelle avec Windows console title update. Le premier argument doit être un string et il est vérifié avant le console existence check. Si aucune console window n’existe après la réussite du string check, l’appel revient sans rien faire.

## Syntaxe

```lua
rconsolename(text: string)
```

## Alias

- `consolename`
- `rconsolesettitle`
- `consolesettitle`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `text` | `string` | Yes | Valeur de texte utilisée par l'opération. |

## Exemple

Set the current Windows console window title.

```lua
rconsolecreate()
rconsolename("Real Console")
```
