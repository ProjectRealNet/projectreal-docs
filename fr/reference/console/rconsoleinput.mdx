Effectue un yield pendant la lecture d’une line depuis stdin avec console input après avoir nettoyé l’état de console input et ignoré input jusqu’au prochain newline. Le string retourné est poussé avec string return et n’inclut pas le newline final. Si aucune console window n’existe, l’appel revient sans values.

## Syntaxe

```lua
rconsoleinput(): string
```

## Alias

- `consoleinput`

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `input` | `string` | Ligne de texte lue depuis la console. |

## Exemple

Read one submitted line from the current Windows console.

```lua
rconsolecreate()
rconsoleprint("Name: ")
local name = rconsoleinput()
rconsoleprint("Hello, ", name, "
")
```
