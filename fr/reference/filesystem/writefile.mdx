<div className="real-function-page">

```lua
writefile(path: string, content: string)
```

## Alias

- `writefileasync`

## Arguments

<ParamField path={"path"} type={"string"} required>
File path resolu dans le workspace apres separator normalization, workspace-boundary checks et filename/extension checks. Absolute paths sont acceptes seulement s ils se resolvent dans le workspace.
</ParamField>

<ParamField path={"content"} type={"string"} required>
Lua string bytes a ecrire. Les donnees sont ecrites en binary truncate mode; writefile n ajoute pas de newlines, BOM bytes, null terminators ou autres extra bytes.
</ParamField>

## Exemple

Ecris des bytes dans un workspace file et remplace tout existing contents.

```lua
local path = "examples/config.json"

writefile(path, '{"enabled":true}')
print(readfile(path))

writefile(path, "")
print(#readfile(path))
```
