<div className="real-function-page">

```lua
readfile(path: string): string
```

## Alias

- `readfileasync`

## Arguments

<ParamField path={"path"} type={"string"} required>
File path resolu dans le workspace apres separator normalization, workspace-boundary checks et filename/extension checks. Absolute paths sont acceptes seulement s ils se resolvent dans le workspace.
</ParamField>

## Retours

<ResponseField name={"content"} type={"string"}>
File contents sont renvoyes comme Lua string avec longueur explicite. Les bytes comme null bytes, line endings et BOM bytes ne sont pas transformes par readfile.
</ResponseField>

## Exemple

Lis les bytes depuis un existing workspace file.

```lua
local path = "examples/config.json"
writefile(path, '{"enabled":true}')

local content = readfile(path)
print(content)
print(#content)
```
