Cree un directory dans le workspace avec recursive folder creation, y compris les missing parent directories.

## Syntaxe

```lua
makefolder(path: string)
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Directory path resolu dans le workspace apres separator normalization et workspace-boundary checks. Empty, invalid ou outside-workspace paths produisent une error avant la tentative de creation. |

## Exemple

Cree un workspace directory et les missing parent directories.

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
