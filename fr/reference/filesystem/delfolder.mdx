<div className="real-function-page">

```lua
delfolder(path: string)
```

## Arguments

<ParamField path={"path"} type={"string"} required>
Path resolu dans le workspace apres separator normalization et workspace-boundary checks. La cible doit exister et etre un directory; les files ne sont pas acceptes.
</ParamField>

## Exemple

Supprime un workspace folder existant et son contenu.

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
