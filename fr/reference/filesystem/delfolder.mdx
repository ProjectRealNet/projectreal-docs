Supprime un folder existant dans le workspace de facon recursive avec recursive folder deletion.

## Syntaxe

```lua
delfolder(path: string)
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path resolu dans le workspace apres separator normalization et workspace-boundary checks. La cible doit exister et etre un directory; les files ne sont pas acceptes. |

## Exemple

Supprime un workspace folder existant et son contenu.

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
