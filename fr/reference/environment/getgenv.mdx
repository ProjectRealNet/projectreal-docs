Les call-sites du repository utilisent la returned table pour lire et ecrire des shared executor globals comme __siApiCache et saveinstance."

<div className="real-function-page">

```lua
getgenv(): table
```

## Retours

<ResponseField name={"environment"} type={"table"}>
La table actuellement stockee dans LUA_ENVIRONINDEX pour ce state.
</ResponseField>

## Exemple

Read and write values on the current executor environment table.

```lua
local env = getgenv()

env.RealDocsValue = "ready"

print(getgenv().RealDocsValue)
```
