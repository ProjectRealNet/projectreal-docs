description: "Renvoie les instances de la Instance cache table dont le ClassName field correspond exactement au string demande. Le premier argument est lu avec string type checking. Un empty string leve \"ClassName required\". La function cree une nouvelle array table, parcourt la cache stockee sous Instance cache, garde seulement les values dont le Lua type est object, lit le ClassName field de chaque object value, puis le compare avec strcmp au className demande. Les matches sont inseres sequential a partir de index 1. La correspondance est exact et case-sensitive. L function n utilise pas IsA, n inclut pas les subclasses, ne fait pas de walk descendants, ne filtre pas par Parent et ne trie pas le result. getinstancesofclass est un alias de la meme function."
