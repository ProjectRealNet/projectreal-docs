```lua
WebSocket.connect(url: string): WebSocket
```

## Alias

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## Arguments

<ParamField path={"url"} type={"string"} required>
URL string transmise à CURLOPT_URL avant que WebSocket client effectue le WebSocket connection attempt.
</ParamField>

## Retours

<ResponseField name={"socket"} type={"WebSocket"}>
WebSocket table contenant OnMessage, OnClose et connection state. Send et Close sont résolus with la WebSocket object methods.
</ResponseField>

## Exemple

Ouvre un WebSocket, connecte OnMessage et OnClose, puis utilise les socket methods pour envoyer et fermer.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
