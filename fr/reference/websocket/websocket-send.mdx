Elle lit le connection state de l'object, lance \"WebSocket state is missing\" si ce object est absent, revient sans envoyer lorsque le state est destroyed ou closed, et appelle curl_ws_send avec CURLWS_TEXT par défaut ou CURLWS_BINARY lorsque le troisième argument optionnel est boolean true. Elle ne renvoie aucune value et ne signale pas le nombre de bytes envoyés."

<div className="real-function-page">

```lua
WebSocket.Send(socket: WebSocket, message: string, isBinary?: boolean)
```

## Arguments

<ParamField path={"socket"} type={"WebSocket"} required>
WebSocket table renvoyée par WebSocket.connect. Send est résolu depuis la WebSocket object methods, donc la forme d'appel documentée est socket:Send(..).
</ParamField>

<ParamField path={"message"} type={"string"} required>
Lua string payload transmis à curl_ws_send avec son explicit byte length.
</ParamField>

<ParamField path={"isBinary"} type={"boolean"}>
Lorsque cet argument est présent et vaut true, Send utilise CURLWS_BINARY. Sinon, elle utilise CURLWS_TEXT.
</ParamField>

## Exemple

Send text or binary data through a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Send("hello")
socket:Send(string.char(0, 1, 2, 3), true)
```
