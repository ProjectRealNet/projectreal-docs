Encode les octets d une chaine Lua avec Base64 encoder, avec = padding et sans sauts de ligne.

## Syntaxe

```lua
base64_encode(data: string): string
```

## Alias

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Octets de chaine Lua transmis a Base64 encoder. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `encoded` | `string` | Sortie Base64 renvoyee sous forme de chaine Lua. |

## Exemple

Encode une chaine Lua et affiche la sortie Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
