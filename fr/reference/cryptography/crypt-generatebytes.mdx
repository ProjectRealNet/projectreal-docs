```lua
crypt.generatebytes(size: number): string
```

## Arguments

<ParamField path={"size"} type={"number"} required>
Nombre passe par integer conversion avant l allocation. Les valeurs inferieures ou egales a 0 sont changees en 1.
</ParamField>

## Retours

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding des raw bytes generes. La longueur de la chaine renvoyee n est pas le nombre d octets demande.
</ResponseField>

## Exemple

Genere des octets et decode le resultat Base64 lorsque des raw bytes sont necessaires.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
