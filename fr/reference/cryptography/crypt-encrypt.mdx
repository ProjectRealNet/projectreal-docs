Chiffre les octets d une chaine Lua avec AES CBC, ECB ou CTR avec une key decodee depuis Base64, puis renvoie Base64 ciphertext et le resultat IV.

## Syntaxe

```lua
crypt.encrypt(data: string, key: string, iv?: string, mode?: "CBC" | "ECB" | "CTR" | "AES-CBC" | "AES-ECB" | "AES-CTR"): string | string | nil
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Octets plaintext lus depuis une chaine Lua. |
| `key` | `string` | Yes | Base64 key decodee avant d etre transmise a AES. |
| `iv` | `string` | No | Base64 IV optionnel pour CBC ou CTR. S il est omis avec CBC ou CTR, un nouvel IV de taille AES block size est genere. |
| `mode` | `"CBC" \| "ECB" \| "CTR" \| "AES-CBC" \| "AES-ECB" \| "AES-CTR"` | No | AES mode. Le prefixe AES- est supprime quand il est present. La valeur par defaut est AES-CBC. CBC et ECB utilisent crypto library DEFAULT_PADDING; CTR n utilise pas de padding. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `ciphertext` | `string` | Base64-encoded ciphertext. |
| `initializationVector` | `string \| nil` | Base64-encoded IV pour CBC et CTR; nil pour ECB. |

## Exemple

Chiffre une chaine Lua et dechiffre le ciphertext renvoye avec le IV renvoye.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(ciphertext)
print(iv)
print(plaintext)
```
