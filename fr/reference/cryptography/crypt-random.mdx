<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Arguments

<ParamField path={"size"} type={"number"} required>
Nombre passe par integer conversion avant l allocation. Les valeurs inferieures ou egales a 0 declenchent une argument error.
</ParamField>

## Retours

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes renvoyes sous forme de chaine Lua. La longueur de la chaine renvoyee correspond au nombre d octets alloues.
</ResponseField>

## Exemple

Genere des raw bytes et affiche la longueur de la chaine Lua renvoyee.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
