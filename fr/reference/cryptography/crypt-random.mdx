Genere des raw random bytes avec random byte generator et les renvoie sous forme de chaine Lua.

## Syntaxe

```lua
crypt.random(size: number): string
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Nombre passe par integer conversion avant l allocation. Les valeurs inferieures ou egales a 0 declenchent une argument error. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes renvoyes sous forme de chaine Lua. La longueur de la chaine renvoyee correspond au nombre d octets alloues. |

## Exemple

Genere des raw bytes et affiche la longueur de la chaine Lua renvoyee.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
