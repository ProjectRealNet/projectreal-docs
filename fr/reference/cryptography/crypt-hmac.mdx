<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Arguments

<ParamField path={"key"} type={"string"} required>
Octets raw Lua string utilises comme HMAC key. La key n est pas Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Octets de chaine Lua transmis au HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Nom de HMAC algorithm case-sensitive. La valeur par defaut est sha256.
</ParamField>

## Retours

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output sans line breaks.
</ResponseField>

## Exemple

Calcule un Base64 HMAC output a partir d une raw Lua string key et de data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
