```lua
lz4decompress(data: string, originalSize?: number): string
```

## Alias

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Arguments

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes transmis a LZ4 block decompression.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size transmise comme dstCapacity. Pour une sortie de lz4compress, passe la longueur originale non compressee en bytes; si elle est omise, la longueur de l entree compressee est utilisee.
</ParamField>

## Retours

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes renvoyes sous forme de chaine Lua. La sortie peut etre plus courte que originalSize.
</ResponseField>

## Exemple

Decompresse des LZ4 bytes en passant la taille originale non compressee.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
