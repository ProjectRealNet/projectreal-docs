## Alias

## Arguments

<ParamField path={"data"} type={"string"} required>
Octets de chaine Lua transmis a LZ4 block compression.
</ParamField>

## Retours

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes renvoyes sous forme de chaine Lua. L original size n est pas stocke dans la sortie.
</ResponseField>

## Exemple

Compresse les octets d une chaine Lua et restaure-les en passant l original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
