```lua
base64_decode(data: string): string
```

## Alias

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Arguments

<ParamField path={"data"} type={"string"} required>
Entree Base64 transmise a Base64 decoder.
</ParamField>

## Retours

<ResponseField name={"decoded"} type={"string"}>
Octets decodes renvoyes sous forme de chaine Lua avec une longueur explicite.
</ResponseField>

## Exemple

Decode des donnees Base64 et lis la chaine Lua renvoyee.

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
