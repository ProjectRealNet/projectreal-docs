description: "Verifie si un RBXScriptSignal est legal a envoyer with le NetworkClient replication layer actuel. La function valide le premier argument comme RBXScriptSignal, lit la source instance et l event descriptor du signal, puis retourne le resultat boolean de replication layer signal replication validation. Si la valeur du pointeur replication layer resolu est 0, elle retourne false. Les arguments supplementaires ne sont pas lus. Cette function verifie seulement le signal et ne le declenche ni ne le replique. La table whitelist retournee par getsignalwhitelist n est pas utilisee par ce chemin de code."

<div className="real-function-page">

```lua
cansignalreplicate(signal: RBXScriptSignal): boolean
```

## Arguments

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal a verifier. Le premier argument doit etre un object dont le Luau type name est RBXScriptSignal.
</ParamField>

## Retours

<ResponseField name={"canReplicate"} type={"boolean"}>
Le boolean retourne par la verification replication layer signal replication validation, ou false quand la valeur du pointeur replication layer resolu est 0.
</ResponseField>

## Exemple

Check whether an RBXScriptSignal is legal to send before attempting to replicate it.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    print(cansignalreplicate(remote.OnClientEvent))
end
```
