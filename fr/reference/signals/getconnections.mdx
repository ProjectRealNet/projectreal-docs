L function lit la Connect method du signal, connecte un temporary blank callback, lit l linked list a partir du next reference de la connexion temporaire, deconnecte la connexion temporaire, puis enveloppe chaque connection reference valide. Si aucun connection reference n est trouve apres la connexion temporaire, elle retourne une table vide. Les underlying references deja enveloppes peuvent retourner la meme cached closure table. getsignals et get_signal_cons sont des aliases de la meme function."

<div className="real-function-page">

```lua
getconnections(signal: RBXScriptSignal): {RealConnection}
```

## Alias

- `getsignals`
- `get_signal_cons`

## Arguments

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal a inspecter. Un object non RBXScriptSignal declenche un type error, et un signal sans Connect field appelable declenche "Signal does not have 'Connect' method".
</ParamField>

## Retours

<ResponseField name={"connections"} type={"{RealConnection}"}>
Array table de connection closure tables. Chaque closure expose fields et methods with sa methods, notamment Enabled, Disabled, LuaConnection, ForeignState, Function, Thread, Disconnect, Disable, Enable, Fire et Defer quand ils sont disponibles.
</ResponseField>

## Exemple

Inspect an RBXScriptSignal and list the wrapped connections Real can expose.

```lua
local Players = game:GetService("Players")

for _, connection in ipairs(getconnections(Players.PlayerAdded)) do
    print(connection.Enabled, connection.LuaConnection)
end
```
