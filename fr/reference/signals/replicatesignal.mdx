La fonction lit la signal signature, convertit les Lua arguments fournis en Roblox signal values pour chaque signature type, tronque les Lua arguments en trop au-delà de la signature length, puis appelle la owning instance event invocation function."
keywords: ["replicatesignal","Signals","replicateevent"]

<div className="real-function-page">

```lua
replicatesignal(signal: RBXScriptSignal, ...arguments?: ...any)
```

## Alias

- `replicateevent`

## Arguments

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Le RBXScriptSignal dont la owning instance event invocation function doit être appelée.
</ParamField>

<ParamField path={"...arguments"} type={"...any"}>
Lua arguments convertis selon la signal signature. Les extra arguments au-delà de la signature length sont ignorés.
</ParamField>

## Exemple

Replicate for a RemoteEvent signal with values that match the signal signature.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote and remote:IsA("RemoteEvent") then
    replicatesignal(remote.OnClientEvent, "hello")
end
```
