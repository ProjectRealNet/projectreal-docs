Aides à la découverte et à l'interaction d'instances.

| Navigation des fonctions | Description |
| --- | --- |
| [`fireclickdetector`](./fireclickdetector) | Declenche une interaction ClickDetector pour le joueur local. Le premier argument doit etre une Instance dont ClassName est ClickDetector. distance est optionnel et vaut 0 par defaut. clickOption est optionnel, compare sans tenir compte de la casse, et vaut "mouseclick" par defaut. Les options prises en charge sont "mouseclick", "rightmouseclick", "mousehoverenter" et "mousehoverleave". Les options de clic transmettent distance comme float au Roblox click helper, tandis que les options hover ignorent distance. Si Players ou Players.LocalPlayer n est pas disponible, la function retourne sans rien declencher. Un clickOption inconnu ne produit pas non plus d interaction. La function ne retourne rien. |
| [`fireproximityprompt`](./fireproximityprompt) | Declenche un ProximityPrompt with le ProximityPrompt trigger de Real. L argument prompt doit etre object avec un champ ClassName egal a "ProximityPrompt". Si la valeur n est pas object, l appel leve un type error. Si ClassName est absent ou n est pas string, il leve "Invalid Instance". Si ClassName n est pas "ProximityPrompt", il leve "ProximityPrompt expected". La function ne prend aucun optional arguments et ne retourne rien. |
| [`firetouchinterest`](./firetouchinterest) | Declenche le Real touch interest event pour deux BasePart instances. Les deux premiers arguments doivent etre Instance object et les deux valeurs doivent passer IsA("BasePart"). L argument state est requis et doit etre number ou boolean. Quand state est number, seul 1 devient true et tout autre number devient false. Quand state est boolean, sa valeur boolean est transmise directement. Si une des deux parties n a pas de touch data, ou si la premiere partie n a pas de overlap reference, la function retourne sans rien declencher. La function ne retourne rien. La signification exacte begin/end du boolean transmis au helper est: Nicht aus der Codebasis verifizierbar. |
| [`getcallbackvalue`](./getcallbackvalue) | Lit une Lua callback function stockee dans une callback property sur une Instance. Le premier argument doit etre Instance object et le deuxieme argument doit etre un string property name. Le instance reference doit etre valide. Le property name est resolu with Roblox property metadata et doit viser une property dont le type est LUA_CALLBACK. Si le property descriptor est absent, si la property n est pas LUA_CALLBACK, si le callback field offset est absent, si aucun callback n est stocke, si LiveLuaRef est absent, si le callback appartient a un autre Lua global state, ou si la valeur referencee n est pas une function, la function retourne nil. Elle verifie aussi le async callback field fallback lorsque le premier callback slot n a pas de callback. La function ne met pas a jour la property. |
| [`gethui`](./gethui) | Retourne game:CoreGui lookup.RobloxGui. La function ne prend aucun arguments. Si CoreGui lookup retourne nil, ou si RobloxGui sur cette valeur est nil, la function retourne nil. L function ne cree aucun container et n utilise pas la valeur mise en cache CoreGui. |
| [`getinstances`](./getinstances) | Retourne une nouvelle array table contenant chaque object value actuellement stockee dans la Instance cache. La function ne prend aucun arguments. Elle ne filtre pas par Parent, ClassName, DataModel fieldship, nil-parent state ou Instance validity, sauf pour verifier que chaque registry value est object. Les entries sont copies dans la table retournee a des sequential numeric indexes commencant a 1. L iteration order vient de table iteration sur la cache et n est pas trie par l function. |
| [`getnilinstances`](./getnilinstances) | Returns a new array table containing cached Instance values whose Parent field is nil. The function takes no arguments. It does not sort the returned entries. |
| [`isnetworkowner`](./isnetworkowner) | Retourne le resultat de la lecture de la hidden property "NetworkOwnerV3" depuis une Instance et verifie si la premiere valeur retournee, convertie avec integer conversion, est superieure a 2. L argument doit etre Instance object. La function appelle the hidden property reader en interne et ne capture pas les erreurs de cet appel, donc Invalid Instance values, missing properties ou non-property metadata peuvent lever les memes erreurs que gethiddenproperty. Elle retourne un boolean. Savoir si peer_id > 2 signifie exactement local network ownership est: Nicht aus der Codebasis verifizierbar. |
