<div className="real-function-page">

```lua
fireproximityprompt(prompt: Instance)
```

## Arguments

<ParamField path={"prompt"} type={"Instance"} required>
Instance dont ClassName doit etre ProximityPrompt.
</ParamField>

## Exemple

Declenche un ProximityPrompt avec le seul argument requis.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
