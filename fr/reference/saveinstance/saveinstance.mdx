<div className="real-function-page">

```lua
saveinstance(rootOrOptions?: Instance | SaveInstanceOptions, options?: SaveInstanceOptions): string
```

## Alias

- `SaveInstance`
- `save_instance`

## Arguments

<ParamField path={"rootOrOptions"} type={"Instance | SaveInstanceOptions"}>
Optional root Instance to save, or the options table when no root is passed separately.
</ParamField>

<ParamField path={"options"} type={"SaveInstanceOptions"}>
Optional save options table. Used as argument 2 when argument 1 is an Instance.
</ParamField>

## Retours

<ResponseField name={"path"} type={"string"}>
Filesystem path string of the saved .rbxlx, .rbxl, .rbxmx, or .rbxm file.
</ResponseField>

## Types

### SaveInstanceOptions

Options table read by saveinstance.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `Object` | `Instance` | No | Root Instance used when no root Instance is passed as argument 1. |
| `FilePath` | `string` | No | Output name or path string. Path separators and colons are replaced before saving. |
| `Path` | `string` | No | Alternative output name field. It is read after FilePath. |
| `FileName` | `string` | No | Alternative output name field. It is read after Path. |
| `NullifyScripts` | `boolean` | No | Writes empty Source values for script classes when no source is emitted. |
| `Decompile` | `boolean` | No | Controls whether script bytecode is decompiled when source is not supplied and scripts are not nullified. |
| `DecompileScripts` | `boolean` | No | Alternative field for Decompile. It is read after Decompile. |
| `noscripts` | `boolean` | No | When true, disables script decompilation. When false, enables it. |
| `scriptcache` | `boolean` | No | Controls reuse of decompiled source by bytecode hash during one save operation. |
| `EmbedBytecode` | `boolean` | No | Writes captured bytecode for script classes when bytecode is available. |
| `SaveBytecode` | `boolean` | No | Alternative field for EmbedBytecode. It is read after EmbedBytecode. |
| `IgnoreDefaultProperties` | `boolean` | No | Skips properties whose serialized value matches the default value when default comparison is available. |
| `IgnoreSpecialProperties` | `boolean` | No | Controls whether special property reads are skipped. |
| `SourceCache` | `&#123;[Instance]: string&#125;` | No | Optional table mapping script Instances to source strings. |
| `IgnoreList` | `&#123;string&#125;` | No | Class names to skip during serialization. Built-in ignored class names are also applied. |
| `IgnoreProperties` | `&#123;string&#125; \| &#123;[string]: boolean&#125;` | No | Property names to skip during serialization. |
| `IsModel` | `boolean` | No | Overrides whether the output is treated as a model file or place file for default name and extension handling. |

## Exemple

Save a selected model to a Roblox XML model file and read the path returned by saveinstance.

```lua
local model = Instance.new("Model")
model.Name = "SavedModel"

local outputPath = saveinstance(model, {
    FileName = "SavedModel.rbxmx",
    Decompile = false,
    NullifyScripts = true,
})

print(outputPath)
model:Destroy()
```
