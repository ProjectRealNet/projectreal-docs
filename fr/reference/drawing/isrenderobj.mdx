<div className="real-function-page">

```lua
isrenderobj(object: any): boolean
```

## Arguments

<ParamField path={"object"} type={"any"} required>
Valeur a tester. Les non-object values et object sans Drawing object type retournent false.
</ParamField>

## Retours

<ResponseField name={"isDrawingObject"} type={"boolean"}>
True lorsque la valeur est object et que sa methods correspond a RealDrawingObject; sinon false.
</ResponseField>

## Exemple

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
