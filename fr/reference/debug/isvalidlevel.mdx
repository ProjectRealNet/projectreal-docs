Vérifie si un numeric stack level se trouve dans le current call stack range. level est requis et doit être un number parce que la function appelle requires a number. Le value est converti avec integer conversion. La function retourne false quand level &lt; 0 ou level >= the current call stack depth, sinon true. Elle n'inspecte pas la frame closure et ne lève pas "Level out of range" pour les invalid numeric levels. validlevel est un global alias, et debug.isvalidlevel ainsi que debug.validlevel sont exposés with les debug table aliases.

## Syntaxe

```lua
isvalidlevel(level: number): boolean
```

## Alias

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `level` | `number` | Yes | Stack level number converti avec integer conversion et vérifié contre 0 &lt;= level &lt; the current call stack depth. |

## Retours

| Name | Type | Description |
| --- | --- | --- |
| `valid` | `boolean` | true quand le numeric level est dans le current call stack range, sinon false. |

## Exemple

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
