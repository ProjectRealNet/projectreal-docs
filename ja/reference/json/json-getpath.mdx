Dotted string path または array table of keys を使って table から nested value を読みます。

## 構文

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## エイリアス

- `json.getpath`

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `object` | `table` | Yes | 読み取り元の root table。function はこの argument が table であることを要求します。 |
| `path` | `string \| table` | Yes | たどる path。string は dots で split されます。integer string tokens は raw array indexing で読まれます。table path は 1 から #path までの array entries を keys として使います。 |
| `defaultValue` | `any` | No | Traversal が path 完了前に nil または non-table に到達した場合に返す fallback value。 |

## 戻り値

| Name | Type | 説明 |
| --- | --- | --- |
| `pathValue` | `any \| nil` | Requested path の value。path が missing の場合、defaultValue が提供されていればそれを返し、それ以外は nil を返します。 |

## 例

Dotted string path または array table of keys から nested table value を読みます。

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
