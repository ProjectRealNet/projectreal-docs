<div className="real-function-page">

```lua
imgui.create(title?: string): ImGuiWindow
```

## 引数

<ParamField path={"title"} type={"string"}>
Optional window title。省略された場合、または nil の場合は "REAL_IM_UI" が使われます。現在追跡されている ImGui windows 内で重複する title は Lua error を発生させます。
</ParamField>

## 戻り値

<ResponseField name={"window"} type={"ImGuiWindow"}>
methods に window methods が登録された ImGuiWindow object。
</ResponseField>

## 型

### ImGuiWindow

imgui.create によって返されるハンドル。コントロール構築メソッドは同じハンドルを返すため、呼び出しを連鎖させることができます。

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `Button` | `(label: string, onClick: () -> ()) -> ImGuiWindow` | Yes | ボタンを追加し、クリック後にコールバックを呼び出します。 |
| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | 指定された状態に初期化されたチェックボックスを追加します。 |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | 折りたたみヘッダーの下にコンテンツ コールバックによって追加されるコントロールをグループ化します。 |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | RGBA エディタを追加します。省略された色コンポーネントのデフォルトは 1.0 です。 |
| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | 単一行のテキスト入力を追加します。省略された初期テキストはデフォルトで空の文字列になります。 |
| `SameLine` | `() -> ImGuiWindow` | Yes | 次のコントロールを同じ行に配置します。 |
| `Separator` | `() -> ImGuiWindow` | Yes | 水平方向の区切り文字を追加します。 |
| `SliderFloat` | `(label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow` | Yes | 浮動小数点スライダーを追加します。 |
| `SliderInt` | `(label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow` | Yes | 整数スライダーを追加します。 |
| `Text` | `(text: string) -> ImGuiWindow` | Yes | 非対話型テキストを追加します。 |
| `destroy` | `() -> ()` | Yes | ウィンドウを削除し、登録されているコールバックを解放します。 |

## 例

ImGui window を作成し、返された ImGuiWindow object に controls を追加します。

```lua
local window = imgui.create("Runtime settings")

window:Text("Controls")
window:Separator()

window:Checkbox("Enabled", true, function(enabled)
    print("Enabled:", enabled)
end)

window:SliderFloat("Opacity", 0.8, 0, 1, function(value)
    print("Opacity:", value)
end)

window:InputText("Label", "Real", function(text)
    print("Label:", text)
end)

window:ColorPicker("Accent", 0.3, 0.6, 1, 1, function(red, green, blue, alpha)
    print(red, green, blue, alpha)
end)

window:CollapsingHeader("Advanced", function(section)
    section:Text("Advanced controls go here")
end)
```
