```lua
checkcaller(): boolean
```

## 戻り値

<ResponseField name={"isCaller"} type={"boolean"}>
current Luau thread が Real caller context で tracked されている場合は true。それ以外は false。
</ResponseField>

## 例

Check whether the current thread is tracked by Real.

```lua
local tracked = checkcaller()
print(tracked)
```
