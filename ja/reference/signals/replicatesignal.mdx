RBXScriptSignal の replication path を呼び出します。この関数は signal signature を読み取り、渡された Lua arguments を各 signature type の Roblox signal values に変換し、signature length を超える余分な Lua arguments を切り捨ててから、owning instance event invocation function を呼び出します。

## 構文

```lua
replicatesignal(signal: RBXScriptSignal, ...arguments?: ...any)
```

## エイリアス

- `replicateevent`

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | owning instance event invocation function を呼び出す RBXScriptSignal。 |
| `...arguments` | `...any` | No | signal signature に従って変換される Lua arguments。signature length を超える extra arguments は無視されます。 |

## 例

Replicate for a RemoteEvent signal with values that match the signal signature.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote and remote:IsA("RemoteEvent") then
    replicatesignal(remote.OnClientEvent, "hello")
end
```
