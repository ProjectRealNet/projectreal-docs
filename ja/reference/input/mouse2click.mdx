Roblox window が active のとき、right mouse down event と right mouse up event を送信します。Real は the requested mouse action を指定し、movement や wheel data なしで mouse input を呼び出します。この function は arguments を受け取らず、何も返さず、isrbxactive が false になる場合は input を送信せずに戻ります。

## 構文

```lua
mouse2click()
```
