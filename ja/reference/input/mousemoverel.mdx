<div className="real-function-page">

```lua
mousemoverel(x: number, y: number)
```

## 引数

<ParamField path={"x"} type={"number"} required>
Lua number として読み取られ、mouse input に dx として渡される前に integer conversion で変換される relative X movement delta。
</ParamField>

<ParamField path={"y"} type={"number"} required>
Lua number として読み取られ、mouse input に dy として渡される前に integer conversion で変換される relative Y movement delta。
</ParamField>
