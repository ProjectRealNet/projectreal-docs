workspace 内に存在する folder を recursive folder deletion で recursive に削除します。

## 構文

```lua
delfolder(path: string)
```

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | separator normalization と workspace-boundary checks の後、workspace 内で解決される path。対象は存在する directory である必要があります。files は受け付けません。 |

## 例

存在する workspace folder とその内容を削除します。

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
