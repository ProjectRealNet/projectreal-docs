workspace 内に存在する regular file を削除します。

## 構文

```lua
delfile(path: string)
```

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | separator normalization と workspace-boundary checks の後、workspace 内で解決される path。対象は存在する regular file である必要があります。folders は受け付けません。 |

## 例

存在する workspace file を削除します。

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
