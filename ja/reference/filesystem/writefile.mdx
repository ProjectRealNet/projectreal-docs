workspace 内のファイルへ Lua string bytes を書き込み、missing parent directories を作成し、ファイルがすでに存在する場合は file contents を置き換えます。

## 構文

```lua
writefile(path: string, content: string)
```

## エイリアス

- `writefileasync`

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | separator normalization、workspace-boundary checks、filename/extension checks の後に workspace 内へ解決される File path。Absolute paths は workspace 内に解決される場合だけ受け入れられます。 |
| `content` | `string` | Yes | 書き込む Lua string bytes。データは binary truncate mode で書き込まれます。writefile は newlines、BOM bytes、null terminators、その他の extra bytes を追加しません。 |

## 例

workspace file に bytes を書き込み、existing contents を置き換えます。

```lua
local path = "examples/config.json"

writefile(path, '{"enabled":true}')
print(readfile(path))

writefile(path, "")
print(#readfile(path))
```
