```lua
WebSocket.connect(url: string): WebSocket
```

## エイリアス

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## 引数

<ParamField path={"url"} type={"string"} required>
WebSocket client が WebSocket connection attempt を実行する前に CURLOPT_URL に渡される URL string。
</ParamField>

## 戻り値

<ResponseField name={"socket"} type={"WebSocket"}>
OnMessage、OnClose、connection state を含む WebSocket table。Send と Close は WebSocket object methods から解決されます。
</ResponseField>

## 例

WebSocket を開き、OnMessage と OnClose を接続し、socket methods で送信と終了を行います。

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
