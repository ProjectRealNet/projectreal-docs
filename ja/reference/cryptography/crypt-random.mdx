random byte generator で raw random bytes を生成し、Lua string として返します。

## 構文

```lua
crypt.random(size: number): string
```

## 引数

| Name | Type | Required | 説明 |
| --- | --- | --- | --- |
| `size` | `number` | Yes | 割り当て前に integer conversion を通る数値。0 以下の値は argument error を発生させます。 |

## 戻り値

| Name | Type | 説明 |
| --- | --- | --- |
| `bytes` | `string` | Lua string として返される raw generated bytes。返される string の長さは割り当てられたバイト数と一致します。 |

## 例

raw bytes を生成し、返された Lua string の長さを表示します。

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
