<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## エイリアス

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## 引数

<ParamField path={"data"} type={"string"} required>
LZ4 block compression に渡される Lua string のバイト。
</ParamField>

## 戻り値

<ResponseField name={"compressed"} type={"string"}>
Lua string として返される raw compressed bytes。original size は出力に保存されません。
</ResponseField>

## 例

Lua string のバイトを圧縮し、original size を渡して復元します。

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
