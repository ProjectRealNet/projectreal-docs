<div className="real-function-page">

```lua
isnetworkowner(instance: Instance): boolean
```

## 引数

<ParamField path={"instance"} type={"Instance"} required>
property name "NetworkOwnerV3" と一緒に the hidden property reader へ渡される Instance object。
</ParamField>

## 戻り値

<ResponseField name={"isOwner"} type={"boolean"}>
"NetworkOwnerV3" の最初の戻り値に対する integer conversion が 2 より大きい場合は true、それ以外は false。
</ResponseField>

## 例

Check network ownership for a BasePart Instance.

```lua
local part = workspace:FindFirstChildWhichIsA("BasePart", true)

if part then
    local ownsNetwork = isnetworkowner(part)
    print(ownsNetwork)
end
```
