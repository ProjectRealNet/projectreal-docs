<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Alias

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Đối số

<ParamField path={"level"} type={"number"} required>
Stack level number được chuyển bằng integer conversion và kiểm tra với 0 &lt;= level &lt; the current call stack depth.
</ParamField>

## Giá trị trả về

<ResponseField name={"valid"} type={"boolean"}>
true khi numeric level nằm trong current call stack range, ngược lại false.
</ResponseField>

## Ví dụ

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
