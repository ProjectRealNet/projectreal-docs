Tra ve mot array table moi chua moi object value hien dang duoc luu trong Instance cache. Function khong nhan arguments. No khong loc theo Parent, ClassName, DataModel fieldship, nil-parent state, hoac Instance validity ngoai viec kiem tra moi registry value la object. Entries duoc copy vao table tra ve tai sequential numeric indexes bat dau tu 1. iteration order den tu table iteration tren cache va khong duoc function sap xep.

## Cú pháp

```lua
getinstances(): { Instance }
```
