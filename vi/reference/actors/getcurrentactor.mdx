<div className="real-function-page">

```lua
getcurrentactor(): Instance | nil
```

## Alias

- `get_current_actor`

## Giá trị trả về

<ResponseField name={"actor"} type={"Instance | nil"}>
Actor Instance được resolve từ the associated Actor weak reference của thread hiện tại, hoặc nil khi không có valid actor reference.
</ResponseField>

## Ví dụ

Resolve the Actor Instance associated with the current Luau thread.

```lua
local actor = getcurrentactor()

print(actor)
```
