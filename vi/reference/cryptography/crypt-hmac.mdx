<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Đối số

<ParamField path={"key"} type={"string"} required>
Cac byte raw Lua string duoc dung lam HMAC key. key khong duoc Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Cac byte Lua string duoc truyen vao HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Ten HMAC algorithm case-sensitive. Mac dinh la sha256.
</ParamField>

## Giá trị trả về

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output khong co line breaks.
</ResponseField>

## Ví dụ

Tinh Base64 HMAC output tu raw Lua string key va data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
