Tinh crypto library HMAC tren cac byte cua Lua string bang raw Lua string key va tra ve Base64 digest.

## Cú pháp

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `key` | `string` | Yes | Cac byte raw Lua string duoc dung lam HMAC key. key khong duoc Base64-decode. |
| `data` | `string` | Yes | Cac byte Lua string duoc truyen vao HMAC calculation. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Ten HMAC algorithm case-sensitive. Mac dinh la sha256. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `digest` | `string` | Base64-encoded HMAC output khong co line breaks. |

## Ví dụ

Tinh Base64 HMAC output tu raw Lua string key va data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
