Tao raw random bytes bang random byte generator va tra ve chung duoi dang Lua string.

## Cú pháp

```lua
crypt.random(size: number): string
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `size` | `number` | Yes | So duoc dua qua integer conversion truoc khi allocation. Cac gia tri nho hon hoac bang 0 gay ra argument error. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes duoc tra ve duoi dang Lua string. Do dai string duoc tra ve khop voi so byte da allocation. |

## Ví dụ

Tao raw bytes va in do dai Lua string duoc tra ve.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
