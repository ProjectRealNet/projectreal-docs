<div className="real-function-page">

```lua
lz4decompress(data: string, originalSize?: number): string
```

## Alias

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Đối số

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes duoc truyen vao LZ4 block decompression.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size duoc truyen lam dstCapacity. Voi output cua lz4compress, hay truyen do dai byte goc chua nen; neu bo qua, do dai input da nen se duoc dung.
</ParamField>

## Giá trị trả về

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes duoc tra ve duoi dang chuoi Lua. Output co the ngan hon originalSize.
</ResponseField>

## Ví dụ

Giai nen LZ4 bytes bang cach truyen kich thuoc goc chua nen.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
