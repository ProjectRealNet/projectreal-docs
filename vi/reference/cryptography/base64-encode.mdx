Ma hoa cac byte cua Lua string bang Base64 encoder, dung = padding va khong co line break.

## Cú pháp

```lua
base64_encode(data: string): string
```

## Alias

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Cac byte Lua string duoc truyen vao Base64 encoder. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `encoded` | `string` | Dau ra Base64 duoc tra ve duoi dang Lua string. |

## Ví dụ

Ma hoa mot Lua string va in dau ra Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
