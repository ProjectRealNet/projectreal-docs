Hash cac byte cua Lua string bang mot thuat toan crypto library hash duoc ho tro va tra ve lowercase hexadecimal digest.

## Cú pháp

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Cac byte Lua string duoc truyen vao crypto library HashFilter. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Ten thuat toan hash case-sensitive. Mac dinh la sha256. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest khong co prefix hoac separators. |

## Ví dụ

Hash cac byte Lua string bang thuat toan mac dinh hoac mot ten duoc ho tro ro rang.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
