Giai ma Base64 ciphertext bang key da decode tu Base64 va Base64 IV bat buoc voi AES CBC hoac ECB.

## Cú pháp

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Base64 ciphertext duoc decode truoc khi giai ma. |
| `key` | `string` | Yes | Base64 key duoc decode truoc khi truyen vao AES. |
| `iv` | `string` | Yes | Base64 IV duoc decode truoc khi xu ly mode. Doi so nay bat buoc, ke ca voi ECB. |
| `mode` | `"CBC" \| "ECB" \| "AES-CBC" \| "AES-ECB"` | No | AES mode. Prefix AES- se bi xoa khi co. Mac dinh la AES-CBC. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `plaintext` | `string` | Cac byte plaintext duoc tra ve duoi dang Lua string. |

## Ví dụ

Giai ma ciphertext do crypt.encrypt tra ve bang IV duoc tra ve.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
