```lua
lz4compress(data: string): string
```

## Alias

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Đối số

<ParamField path={"data"} type={"string"} required>
Cac byte Lua string duoc truyen vao LZ4 block compression.
</ParamField>

## Giá trị trả về

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes duoc tra ve duoi dang Lua string. original size khong duoc luu trong output.
</ResponseField>

## Ví dụ

Nen cac byte Lua string va khoi phuc chung bang cach truyen original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
