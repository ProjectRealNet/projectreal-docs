Ma hoa cac byte cua Lua string bang AES CBC, ECB hoac CTR voi key da decode tu Base64, sau do tra ve Base64 ciphertext va ket qua IV.

## Cú pháp

```lua
crypt.encrypt(data: string, key: string, iv?: string, mode?: "CBC" | "ECB" | "CTR" | "AES-CBC" | "AES-ECB" | "AES-CTR"): string | string | nil
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Cac byte plaintext duoc doc tu Lua string. |
| `key` | `string` | Yes | Base64 key duoc decode truoc khi truyen vao AES. |
| `iv` | `string` | No | Base64 IV optional cho CBC hoac CTR. Khi bo qua voi CBC hoac CTR, mot IV moi co AES block size se duoc tao. |
| `mode` | `"CBC" \| "ECB" \| "CTR" \| "AES-CBC" \| "AES-ECB" \| "AES-CTR"` | No | AES mode. Prefix AES- se bi xoa khi co. Mac dinh la AES-CBC. CBC va ECB dung crypto library DEFAULT_PADDING; CTR khong dung padding. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `ciphertext` | `string` | Base64-encoded ciphertext. |
| `initializationVector` | `string \| nil` | Base64-encoded IV cho CBC va CTR; nil cho ECB. |

## Ví dụ

Ma hoa mot Lua string va giai ma ciphertext duoc tra ve bang IV duoc tra ve.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(ciphertext)
print(iv)
print(plaintext)
```
