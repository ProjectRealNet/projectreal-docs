<div className="real-function-page">

```lua
WebSocket.Send(socket: WebSocket, message: string, isBinary?: boolean)
```

## Đối số

<ParamField path={"socket"} type={"WebSocket"} required>
WebSocket table được trả về bởi WebSocket.connect. Send được resolve từ WebSocket object methods, vì vậy dạng gọi được ghi trong tài liệu là socket:Send(..).
</ParamField>

<ParamField path={"message"} type={"string"} required>
Lua string payload được truyền vào curl_ws_send cùng explicit byte length.
</ParamField>

<ParamField path={"isBinary"} type={"boolean"}>
Khi argument này có mặt và là true, Send dùng CURLWS_BINARY. Nếu không, nó dùng CURLWS_TEXT.
</ParamField>

## Ví dụ

Send text or binary data through a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Send("hello")
socket:Send(string.char(0, 1, 2, 3), true)
```
