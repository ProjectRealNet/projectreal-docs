Gui key up event khi Roblox window active. Doi so keyCode duoc kiem tra la Lua number, chuyen doi bang integer conversion, map tu Windows virtual-key code sang scan code bang Windows key mapping, va gui qua keyboard input voi KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP. Function nay khong gui key down event. Neu isrbxactive se la false, function tra ve ma khong gui input.

## Cú pháp

```lua
keyrelease(keyCode: number)
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `keyCode` | `number` | Yes | Windows virtual-key code duoc doc nhu Lua number va chuyen doi bang integer conversion truoc khi goi Windows key mapping. |
