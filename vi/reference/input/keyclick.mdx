Gui key down event roi key up event khi Roblox window active. Doi so keyCode duoc kiem tra la Lua number, chuyen doi bang integer conversion, map tu Windows virtual-key code sang scan code bang Windows key mapping, va gui qua keyboard input voi KEYEVENTF_SCANCODE. Neu isrbxactive se la false, function tra ve ma khong gui input.

## Cú pháp

```lua
keyclick(keyCode: number)
```

- `keytap`
