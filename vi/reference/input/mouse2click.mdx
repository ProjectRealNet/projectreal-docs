Gui right mouse down event va right mouse up event khi Roblox window active. Real goi mouse input voi the requested mouse action va khong co movement hoac wheel data. Function nay khong nhan arguments, khong tra ve gi va tra ve ma khong gui input khi isrbxactive se la false.

## Cú pháp

```lua
mouse2click()
```
