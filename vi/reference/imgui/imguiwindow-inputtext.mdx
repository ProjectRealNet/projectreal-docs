Them single-line ImGui InputText element vao ImGuiWindow va luu callback. Initial text duoc doc bang optional string handling va duoc sao chep vao fixed 256-byte text buffer cua element. Khi input duoc render thay doi, callback duoc dua vao queue va sau do duoc goi voi current string. Method tra ve cung ImGuiWindow object.

## Cú pháp

```lua
ImGuiWindow.InputText(window: ImGuiWindow, label: string, text?: string, onChange: function): ImGuiWindow
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow object duoc tra ve boi imgui.create. Window da bi huy hoac khong hop le gay Lua error. |
| `label` | `string` | Yes | Input label string duoc truyen cho ImGui InputText widget duoc render. |
| `text` | `string` | No | Initial text duoc doc bang optional string handling. Truyen nil tai day khi muon default empty string nhung van cung cap onChange lam argument 4. |
| `onChange` | `function` | Yes | Function duoc luu cho input nay va duoc goi voi current string sau khi edit event duoc xu ly. No phai duoc cung cap lam argument 4. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `window` | `ImGuiWindow` | Cung ImGuiWindow object, cho phep noi chuoi method calls. |

## Kiểu

### ImGuiWindow

Xử lý được trả về bởi imgui.create. Các phương pháp xây dựng điều khiển trả về cùng một thẻ điều khiển để các cuộc gọi có thể được xâu chuỗi.

| Name | Type | Required | Mô tả |

| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | Nối một hộp kiểm được khởi tạo vào trạng thái được cung cấp. |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | Các điều khiển nhóm được thêm vào bởi lệnh gọi lại nội dung bên dưới tiêu đề thu gọn. |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | Nối thêm trình soạn thảo RGBA; các thành phần màu bị bỏ qua mặc định là 1.0. |
