Them SliderFloat element vao window. label, value, minimum va maximum duoc doc tu doi so 2 den 5, cac doi so so duoc kiem tra bang number type checking. Trong luc rendering, Real goi a floating-point slider voi gia tri va khoang da luu. Khi ImGui bao gia tri da thay doi, onChange duoc dua vao queue va sau do duoc goi voi mot Lua number. Real khong them kiem tra minimum &lt;= maximum rieng trong closure nay.

## Cú pháp

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow duoc tra ve boi imgui.create. Neu object khong hop le hoac da bi destroy, method se gay Lua error. |
| `label` | `string` | Yes | Slider label duoc doc bang string type checking. |
| `value` | `number` | Yes | Gia tri ban dau cua slider duoc doc bang number type checking va luu lam gia tri float hien tai. |
| `minimum` | `number` | Yes | Minimum value duoc doc bang number type checking va truyen vao a floating-point slider. |
| `maximum` | `number` | Yes | Maximum value duoc doc bang number type checking va truyen vao a floating-point slider. |
| `onChange` | `(number) -> ()` | Yes | Callback function duoc luu trong Lua registry. Khi slider thay doi trong luc rendering, no duoc goi sau do voi gia tri so da cap nhat. |

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `window` | `ImGuiWindow` | Cung ImGuiWindow object, cho phep goi method theo chuoi. |
