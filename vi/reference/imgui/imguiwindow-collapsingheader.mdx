
## Đối số

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object duoc tra ve boi imgui.create. Window da bi huy hoac khong hop le gay Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Header label string duoc truyen cho ImGui collapsing header duoc render.
</ParamField>

<ParamField path={"content"} type={"function"} required>
Function duoc goi ngay lap tuc voi cung ImGuiWindow object. Return values bi bo qua; loi duoc method bat.
</ParamField>

## Giá trị trả về

<ResponseField name={"window"} type={"ImGuiWindow"}>
Cung ImGuiWindow object, cho phep noi chuoi method calls.
</ResponseField>
