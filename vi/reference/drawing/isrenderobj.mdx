```lua
isrenderobj(object: any): boolean
```

## Đối số

<ParamField path={"object"} type={"any"} required>
Gia tri can kiem tra. Non-object values va object khong co Drawing object type se tra ve false.
</ParamField>

## Giá trị trả về

<ResponseField name={"isDrawingObject"} type={"boolean"}>
True khi gia tri la object co methods khop voi RealDrawingObject; neu khong thi false.
</ResponseField>

## Ví dụ

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
