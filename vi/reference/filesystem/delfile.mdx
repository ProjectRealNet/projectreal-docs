Xoa mot regular file dang ton tai ben trong workspace.

## Cú pháp

```lua
delfile(path: string)
```

## Đối số

| Name | Type | Required | Mô tả |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path duoc resolve ben trong workspace sau separator normalization va workspace-boundary checks. Target phai ton tai va la regular file; folders khong duoc chap nhan. |

## Ví dụ

Xoa mot workspace file dang ton tai.

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
