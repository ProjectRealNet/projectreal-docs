Returns Real's executor version as one string.

## Cú pháp

```lua
getexecutorversion(): string
```

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `executorVersion` | `string` | Executor version string. |

## Ví dụ

Read the executor version string exposed by Real.

```lua
local version = getexecutorversion()
print(version)
```
