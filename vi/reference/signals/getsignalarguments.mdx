<div className="real-function-page">

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## Đối số

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal can kiem tra event descriptor signature. Userdata khong phai RBXScriptSignal gay type error.
</ParamField>

## Giá trị trả về

<ResponseField name={"arguments"} type={"{string}"}>
Array table cua argument type name strings. Fallback table chua "Variant" duoc tra ve khi khong doc duoc signature data hoac khong tao duoc argument entries.
</ResponseField>

## Ví dụ

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
