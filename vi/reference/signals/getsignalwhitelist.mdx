Tra ve mot array table moi voi sau entry whitelist tinh duoc dinh nghia trong function: OnClientEvent/RemoteEvent, OnServerEvent/RemoteEvent, OnClientInvoke/RemoteFunction, OnServerInvoke/RemoteFunction, OnClientEventUnreliable/UnreliableRemoteEvent, and OnServerEventUnreliable/UnreliableRemoteEvent. Moi entry la mot table co cac string field Event va Parent. Function khong nhan arguments va khong kiem tra game state hien tai.

## Cú pháp

```lua
getsignalwhitelist(): table
```

## Giá trị trả về

| Name | Type | Mô tả |
| --- | --- | --- |
| `signals` | `table` | Array table cac entry whitelist tinh. Moi entry co cac string field Event va Parent. |
