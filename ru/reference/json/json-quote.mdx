Escape для string по Real JSON string escaping rules и возврат complete quoted JSON string literal.

## Синтаксис

```lua
json.quote(text: string): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `text` | `string` | Yes | String для quote. Function читает этот argument через string type checking. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `quoted` | `string` | Complete JSON string literal с opening и closing quote. Quotes, backslashes, common control characters и bytes below 0x20 проходят escape. |

## Пример

Convert string в complete quoted JSON string literal.

```lua
local source = "Real Docs" .. string.char(10) .. [[Documentation "A"]]
local quoted = json.quote(source)

print(quoted)
```
