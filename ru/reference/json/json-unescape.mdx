Декодирует JSON string escape sequences из escaped string content или из complete quoted JSON string literal. Вход parse через JSON string parser, а не как full JSON document.

## Синтаксис

```lua
json.unescape(text: string): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `text` | `string` | Yes | Escaped JSON string content или complete quoted JSON string literal, у которого first and last bytes являются quotes. Function читает этот argument через string type checking. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `text` | `string` | Decoded string. Supported escapes включают \", \\, \/, \b, \f, \n, \r, \t и \uXXXX с surrogate-pair handling. Invalid escapes, unescaped control characters, unterminated strings и trailing characters после quoted literal выбрасывают Luau error с near-position suffix. |

## Пример

Декодирует JSON string escapes из escaped content или quoted JSON string literal.

```lua
local escaped = json.escape("Real Docs" .. string.char(10) .. "Docs")
local restored = json.unescape(escaped)

print(restored)
```
