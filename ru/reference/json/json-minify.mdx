Parse для JSON string и повторный encode через Real default non-pretty JSON encoder output.

## Синтаксис

```lua
json.minify(json: string, options?: DecodeOptions): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string, который parse перед minifying. Function читает этот argument через string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options для parsing input JSON. boolean задает useNull. table может задавать useNull и maxDepth. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `minified` | `string` | JSON string, созданный после parsing и re-encoding input с default encode options. |

## Типы

### DecodeOptions

Управляет поведением анализа JSON.

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Представляет значение JSON null с нулевым контрольным значением библиотеки вместо nil. |
| `maxDepth` | `integer` | No | Устанавливает максимальную глубину вложенности от 1 до 4096. |

## Пример

Parse valid JSON и re-encode через default compact JSON output.

```lua
local formatted = [[{
    "name": "Real",
    "enabled": true,
    "missing": null
}]]

print(json.minify(formatted, {
    useNull = true,
}))
```
