<div className="real-function-page">

```lua
json.clone(value: any, options?: EncodeOptions): any
```

## Аргументы

<ParamField path={"value"} type={"any"} required>
Value для encode и decode. Supported JSON values проходят round-trip через JSON; unsupported types кодируются как null, если encode options не требуют ошибку.
</ParamField>

<ParamField path={"options"} type={"EncodeOptions"}>
Optional encode options, передаваемые в encode step, такие как sortKeys, emptyTableAsArray, errorOnUnsupported, encodeInvalidNumbersAsNull, maxDepth, pretty и indent.
</ParamField>

## Возвраты

<ResponseField name={"clone"} type={"any"}>
Decoded value, созданный из encoded JSON. Objects и arrays это new tables с JSON kind markers из decoder; JSON null values становятся json.null.
</ResponseField>

## Типы

### EncodeOptions

Управляет сериализацией и форматированием JSON.

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `pretty` | `boolean` | No | Включает форматированный многострочный вывод JSON. |
| `sortKeys` | `boolean` | No | Сортирует ключи объекта перед кодированием. |
| `emptyTableAsArray` | `boolean` | No | Кодирует пустую таблицу как массив вместо объекта. |
| `errorOnUnsupported` | `boolean` | No | Вызывает ошибку вместо замены неподдерживаемых значений. |
| `encodeInvalidNumbersAsNull` | `boolean` | No | Кодирует NaN и бесконечные числа как значение JSON null. |
| `maxDepth` | `integer` | No | Устанавливает максимальную глубину вложенности от 1 до 4096. |
| `indent` | `string` | No | Устанавливает строку отступа, ограниченную 32 символами. |

## Пример

Выполните round-trip JSON-compatible value через json.encode и json.decode перед изменением nested values.

```lua
local original = {
    profile = { name = "Guest" },
}

local copy = json.clone(original)
copy.profile.name = "Developer"

print(original.profile.name)
print(copy.profile.name)
print(json.type(copy))
```
