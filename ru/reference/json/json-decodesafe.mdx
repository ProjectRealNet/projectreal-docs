<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Аргументы

<ParamField path={"json"} type={"string"} required>
JSON text для парсинга. Этот argument проверяется как string до перехвата parse errors.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean напрямую задает useNull. table может задать useNull и maxDepth; maxDepth clamp от 1 до 4096. Invalid option argument types проверяются до перехвата parse errors.
</ParamField>

## Возвраты

<ResponseField name={"success"} type={"boolean"}>
True, если parsing успешен, false, если parser сообщает error.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value при успехе, nil при parse failure. Валидный JSON false возвращает success как true и decoded как false, поэтому проверяйте success return value.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message при parse failure, иначе nil. Message содержит json.decodeSafe prefix и parser position.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position при parse failure, иначе nil.
</ResponseField>

## Типы

### DecodeOptions

Управляет поведением анализа JSON.

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Представляет значение JSON null с нулевым контрольным значением библиотеки вместо nil. |
| `maxDepth` | `integer` | No | Устанавливает максимальную глубину вложенности от 1 до 4096. |

## Пример

Parse JSON и используйте success return value, чтобы отличать valid false или nil results от parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
