<div className="real-function-page">

```lua
json.object(source?: table): table
```

## Аргументы

<ParamField path={"source"} type={"table"}>
Optional source table для copy в new object table. Если omitted или nil, возвращается empty object table.
</ParamField>

## Возвраты

<ResponseField name={"object"} type={"table"}>
New table marked с Real JSON object marker. Source entries copy, кроме Real JSON type marker.
</ResponseField>

## Пример

Create new table marked as a JSON object, включая empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
