Делает yield во время чтения одной line из stdin через console input после очистки состояния console input и игнорирования input до следующего newline. Возвращаемый string отправляется через string return и не включает завершающий newline. Если console window не существует, вызов возвращается без values.

## Синтаксис

```lua
rconsoleinput(): string
```

## Алиасы

- `consoleinput`

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `input` | `string` | Строка текста, прочитанная из консоли. |

## Пример

Read one submitted line from the current Windows console.

```lua
rconsolecreate()
rconsoleprint("Name: ")
local name = rconsoleinput()
rconsoleprint("Hello, ", name, "
")
```
