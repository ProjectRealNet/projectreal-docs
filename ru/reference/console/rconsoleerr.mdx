Записывает одно или несколько значений в текущую Windows console через stdout после установки console text attribute в error text color. Значения преобразуются через Lua string conversion, разделяются символами tab, а затем text attribute сбрасывается. Если console window не существует, вызов возвращается без действий.

## Синтаксис

```lua
rconsoleerr(...values?: ...any)
```

## Алиасы

- `consoleerr`

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Необязательные значения. Если console существует, каждый value преобразуется через Lua string conversion и объединяется символами tab перед записью. |

## Пример

Write a bright red message to the current Windows console without throwing a Luau error.

```lua
rconsolecreate()
rconsoleerr("Request failed", 500, "
")
```
