---
title: "rconsoleerr"
sidebarTitle: "rconsoleerr"
description: "Записывает одно или несколько значений в текущую Windows console через stdout после установки console text attribute в error text color. Значения преобразуются через Lua string conversion, разделяются символами tab, а затем text attribute сбрасывается. Если console window не существует, вызов возвращается без действий."
keywords: ["rconsoleerr","Console","consoleerr"]
---

<div className="real-function-page">

```lua
rconsoleerr(...values?: ...any)
```

## Алиасы

- `consoleerr`

## Аргументы

<ParamField path={"...values"} type={"...any"}>
Необязательные значения. Если console существует, каждый value преобразуется через Lua string conversion и объединяется символами tab перед записью.
</ParamField>

## Пример

Write a bright red message to the current Windows console without throwing a Luau error.

```lua
rconsolecreate()
rconsoleerr("Request failed", 500, "
")
```
