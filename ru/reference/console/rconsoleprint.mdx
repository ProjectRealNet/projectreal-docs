---
title: "rconsoleprint"
sidebarTitle: "rconsoleprint"
description: "Записывает одно или несколько значений в текущую Windows console через stdout без изменения console text attribute. Значения преобразуются через Lua string conversion и разделяются символами tab. function не добавляет newline. Если console window не существует, вызов возвращается без действий."
keywords: ["rconsoleprint","Console","consoleprint","rconsolewrite","consolewrite"]
---

<div className="real-function-page">

```lua
rconsoleprint(...values?: ...any)
```

## Алиасы

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Аргументы

<ParamField path={"...values"} type={"...any"}>
Необязательные значения. Если console существует, каждый value преобразуется через Lua string conversion и объединяется символами tab перед записью.
</ParamField>

## Пример

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
