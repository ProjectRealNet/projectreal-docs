---
title: "rconsoleinfo"
sidebarTitle: "rconsoleinfo"
description: "Записывает одно или несколько значений в текущую Windows console через stdout после установки console text attribute в info text color. Значения преобразуются через Lua string conversion, разделяются символами tab, а затем text attribute сбрасывается. Если console window не существует, вызов возвращается без действий."
keywords: ["rconsoleinfo","Console","consoleinfo"]
---

<div className="real-function-page">

```lua
rconsoleinfo(...values?: ...any)
```

## Алиасы

- `consoleinfo`

## Аргументы

<ParamField path={"...values"} type={"...any"}>
Необязательные значения. Если console существует, каждый value преобразуется через Lua string conversion и объединяется символами tab перед записью.
</ParamField>

## Пример

Write a bright blue message to the current Windows console.

```lua
rconsolecreate()
rconsoleinfo("Connected", "
")
```
