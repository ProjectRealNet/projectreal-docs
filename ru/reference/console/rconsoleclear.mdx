Очищает current Windows console screen buffer, если существует console window. Если console window не существует, call возвращается без действий.

## Синтаксис

```lua
rconsoleclear()
```

## Алиасы

- `consoleclear`

## Пример

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
