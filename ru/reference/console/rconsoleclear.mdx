<div className="real-function-page">

```lua
rconsoleclear()
```

## Алиасы

- `consoleclear`

## Пример

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
