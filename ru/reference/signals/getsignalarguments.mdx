description: "Возвращает array table из type names, прочитанных из event descriptor signature для RBXScriptSignal. Первый argument должен быть object с Luau type name RBXScriptSignal. Function читает event descriptor сигнала, проходит signature slots с argument stride из function, читает каждый argument type reference и помещает разрешенный type name string для каждого slot. Она не возвращает captured runtime argument values. Если signature не удается прочитать или entries не добавлены, возвращаемая table содержит один fallback entry: \"Variant\"."

<div className="real-function-page">

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## Аргументы

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal, чей event descriptor signature нужно проверить. Userdata, не являющийся RBXScriptSignal, вызывает type error.
</ParamField>

## Возвраты

<ResponseField name={"arguments"} type={"{string}"}>
Array table из argument type name strings. Fallback table с "Variant" возвращается, когда signature data не удается прочитать или argument entries не создаются.
</ResponseField>

## Пример

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
