description: "Проверяет, является ли RBXScriptSignal допустимым для отправки через текущий NetworkClient replication layer. Function проверяет первый argument как RBXScriptSignal, читает source instance и event descriptor сигнала, затем возвращает boolean результат replication layer signal replication validation. Если разрешенное значение указателя replication layer равно 0, возвращает false. Дополнительные arguments не читаются. Эта function только проверяет signal и не запускает и не реплицирует его. Таблица whitelist, возвращаемая getsignalwhitelist, в этом пути кода не используется."

<div className="real-function-page">

```lua
cansignalreplicate(signal: RBXScriptSignal): boolean
```

## Аргументы

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal для проверки. Первый argument должен быть object с Luau type name RBXScriptSignal.
</ParamField>

## Возвраты

<ResponseField name={"canReplicate"} type={"boolean"}>
Boolean, возвращаемый проверкой replication layer signal replication validation, или false, когда разрешенное значение указателя replication layer равно 0.
</ResponseField>

## Пример

Check whether an RBXScriptSignal is legal to send before attempting to replicate it.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    print(cansignalreplicate(remote.OnClientEvent))
end
```
