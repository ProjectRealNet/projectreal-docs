<div className="real-function-page">

```lua
disassemble(callback: function, options?: DisassembleOptions): string
```

## Аргументы

<ParamField path={"callback"} type={"function"} required>
Luau function to disassemble. C closures are rejected.
</ParamField>

<ParamField path={"options"} type={"DisassembleOptions"}>
Optional table read for Recursive, ShowLines, ShowConstants, and StringPreviewMax. Missing fields or fields with the wrong type leave the default value unchanged.
</ParamField>

## Возвраты

<ResponseField name={"assembly"} type={"string"}>
Formatted disassembly text with a trailing newline.
</ResponseField>

## Типы

### DisassembleOptions

Управляет тем, как байт-код Luau отображается в результатах дизассемблирования.

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `Recursive` | `boolean` | No | Включает в вывод вложенные дочерние прототипы. |
| `ShowLines` | `boolean` | No | Показывает номера исходных строк рядом с инструкциями, если данные строки доступны. |
| `ShowConstants` | `boolean` | No | Выводит таблицу констант для каждого прототипа. |
| `StringPreviewMax` | `integer` | No | Ограничивает количество символов, отображаемых при предварительном просмотре строковых констант. |

## Пример

Disassemble a callback with selected output options.

```lua
local assembly = disassemble(function(value)
    return value * 2
end, {
    Recursive = false,
    ShowLines = true,
    ShowConstants = true,
})

print(assembly)
```
