Returns Real's executor name as one string.

## Синтаксис

```lua
getexecutorname(): string
```

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `executorName` | `string` | Executor name string. |

## Пример

Read the executor name string exposed by Real.

```lua
local name = getexecutorname()
print(name)
```
