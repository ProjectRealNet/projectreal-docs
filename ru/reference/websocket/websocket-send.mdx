Отправляет Lua string через WebSocket object, возвращенный WebSocket.connect. Method ожидает WebSocket table первым argument и message string вторым argument. Она читает connection state объекта, выбрасывает "WebSocket state is missing", если это object отсутствует, возвращается без отправки, когда state destroyed или closed, и вызывает curl_ws_send с CURLWS_TEXT по умолчанию или CURLWS_BINARY, когда необязательный третий argument является boolean true. Она не возвращает values и не сообщает количество отправленных bytes.

## Синтаксис

```lua
WebSocket.Send(socket: WebSocket, message: string, isBinary?: boolean)
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `socket` | `WebSocket` | Yes | WebSocket table, возвращенная WebSocket.connect. Send разрешается через WebSocket object methods, поэтому документированная форма вызова: socket:Send(..). |
| `message` | `string` | Yes | Lua string payload, передаваемый в curl_ws_send с explicit byte length. |
| `isBinary` | `boolean` | No | Когда этот argument присутствует и равен true, Send использует CURLWS_BINARY. Иначе используется CURLWS_TEXT. |

## Пример

Send text or binary data through a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Send("hello")
socket:Send(string.char(0, 1, 2, 3), true)
```
