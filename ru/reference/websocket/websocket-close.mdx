Если live state существует и еще не destroyed или closed, она устанавливает isClosed в true и отправляет пустой close frame frame через сохраненный WebSocket connection. Она не принимает close code или reason и не возвращает values."
keywords: ["WebSocket.Close","WebSocket"]

<div className="real-function-page">

```lua
WebSocket.Close(socket: WebSocket)
```

## Аргументы

<ParamField path={"socket"} type={"WebSocket"} required>
WebSocket table, возвращенная WebSocket.connect. Function ожидает, что эта table содержит connection state.
</ParamField>

## Пример

Close a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Close()
```
