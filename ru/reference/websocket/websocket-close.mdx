Закрывает WebSocket object, возвращенный WebSocket.connect. Первый argument должен быть table. Функция читает field connection state объекта. Если live state существует и еще не destroyed или closed, она устанавливает isClosed в true и отправляет пустой close frame frame через сохраненный WebSocket connection. Она не принимает close code или reason и не возвращает values.

## Синтаксис

```lua
WebSocket.Close(socket: WebSocket)
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `socket` | `WebSocket` | Yes | WebSocket table, возвращенная WebSocket.connect. Function ожидает, что эта table содержит connection state. |

## Пример

Close a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Close()
```
