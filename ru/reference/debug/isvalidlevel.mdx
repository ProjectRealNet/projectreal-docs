Проверяет, находится ли numeric stack level в current call stack range. level обязателен и должен быть number, потому что function вызывает requires a number. value преобразуется через integer conversion. function возвращает false, если level &lt; 0 или level >= the current call stack depth, иначе true. Она не проверяет frame closure и не вызывает "Level out of range" для invalid numeric levels. validlevel является global alias, а debug.isvalidlevel и debug.validlevel доступны через debug table aliases.

## Синтаксис

```lua
isvalidlevel(level: number): boolean
```

## Алиасы

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `level` | `number` | Yes | Stack level number, преобразуемый через integer conversion и проверяемый по условию 0 &lt;= level &lt; the current call stack depth. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `valid` | `boolean` | true, если numeric level находится в current call stack range, иначе false. |

## Пример

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
