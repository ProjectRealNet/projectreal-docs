<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Алиасы

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Аргументы

<ParamField path={"level"} type={"number"} required>
Stack level number, преобразуемый через integer conversion и проверяемый по условию 0 &lt;= level &lt; the current call stack depth.
</ParamField>

## Возвраты

<ResponseField name={"valid"} type={"boolean"}>
true, если numeric level находится в current call stack range, иначе false.
</ResponseField>

## Пример

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
