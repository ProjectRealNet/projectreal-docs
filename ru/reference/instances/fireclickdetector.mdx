description: "Запускает взаимодействие ClickDetector для локального игрока. Первый аргумент должен быть Instance, у которого ClassName равен ClickDetector. distance необязателен и по умолчанию равен 0. clickOption необязателен, сравнивается без учета регистра и по умолчанию равен \"mouseclick\". Поддерживаемые варианты: \"mouseclick\", \"rightmouseclick\", \"mousehoverenter\" и \"mousehoverleave\". Варианты клика передают distance как float в Roblox click helper, а варианты hover игнорируют distance. Если Players или Players.LocalPlayer недоступны, function возвращается, ничего не запуская. Неизвестный clickOption также не вызывает interaction. Function ничего не возвращает."

<div className="real-function-page">

```lua
fireclickdetector(detector: Instance, distance?: number, clickOption?: "mouseclick" | "rightmouseclick" | "mousehoverenter" | "mousehoverleave")
```

## Аргументы

<ParamField path={"detector"} type={"Instance"} required>
Instance, у которого ClassName должен быть ClickDetector.
</ParamField>

<ParamField path={"distance"} type={"number"}>
Необязательное значение distance. По умолчанию 0, передается как float для "mouseclick" и "rightmouseclick".
</ParamField>

<ParamField path={"clickOption"} type={"\"mouseclick\" | \"rightmouseclick\" | \"mousehoverenter\" | \"mousehoverleave\""}>
Необязательный selector interaction. Читается как string, сравнивается без учета регистра и по умолчанию равен "mouseclick".
</ParamField>

## Пример

Запускает interaction "mouseclick" по умолчанию для ClickDetector.

```lua
local detector = workspace.InteractivePart.ClickDetector

fireclickdetector(detector)
```
