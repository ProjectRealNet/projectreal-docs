Возвращает game:CoreGui lookup.RobloxGui. Function не принимает arguments. Если CoreGui lookup возвращает nil, или если RobloxGui у этого значения равен nil, function возвращает nil. Function не создает container и не использует кэшированное значение CoreGui.

## Синтаксис

```lua
gethui(): Instance | nil
```

## Алиасы

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | Значение RobloxGui, прочитанное из CoreGui, или nil, когда CoreGui или RobloxGui недоступны. |
