Если значение не object, вызов вызывает type error. Если ClassName отсутствует или не является string, он вызывает \"Invalid Instance\". Если ClassName не равен \"ProximityPrompt\", он вызывает \"ProximityPrompt expected\". Function не принимает optional arguments и ничего не возвращает."

<div className="real-function-page">

```lua
fireproximityprompt(prompt: Instance)
```

## Аргументы

<ParamField path={"prompt"} type={"Instance"} required>
Instance, у которого ClassName должен быть ProximityPrompt.
</ParamField>

## Пример

Запускает ProximityPrompt с единственным обязательным аргументом.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
