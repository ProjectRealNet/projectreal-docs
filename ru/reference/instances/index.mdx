Помощники по обнаружению экземпляров и взаимодействию.

| Навигация по функциям | Описание |
| --- | --- |
| [`fireclickdetector`](./fireclickdetector) | Запускает взаимодействие ClickDetector для локального игрока. Первый аргумент должен быть Instance, у которого ClassName равен ClickDetector. distance необязателен и по умолчанию равен 0. clickOption необязателен, сравнивается без учета регистра и по умолчанию равен "mouseclick". Поддерживаемые варианты: "mouseclick", "rightmouseclick", "mousehoverenter" и "mousehoverleave". Варианты клика передают distance как float в Roblox click helper, а варианты hover игнорируют distance. Если Players или Players.LocalPlayer недоступны, function возвращается, ничего не запуская. Неизвестный clickOption также не вызывает interaction. Function ничего не возвращает. |
| [`fireproximityprompt`](./fireproximityprompt) | Запускает ProximityPrompt через ProximityPrompt trigger Real. Аргумент prompt должен быть object с полем ClassName, равным "ProximityPrompt". Если значение не object, вызов вызывает type error. Если ClassName отсутствует или не является string, он вызывает "Invalid Instance". Если ClassName не равен "ProximityPrompt", он вызывает "ProximityPrompt expected". Function не принимает optional arguments и ничего не возвращает. |
| [`firetouchinterest`](./firetouchinterest) | Запускает Real touch interest event для двух BasePart instances. Первые два аргумента должны быть Instance object, и оба значения должны проходить IsA("BasePart"). Аргумент state обязателен и должен быть number или boolean. Когда state является number, только 1 становится true, а любое другое number становится false. Когда state является boolean, его boolean значение передается напрямую. Если у любой part нет touch data, или у первой part нет overlap reference, function возвращается, ничего не запуская. Function ничего не возвращает. Точное значение begin/end для boolean, передаваемого в helper: Nicht aus der Codebasis verifizierbar. |
| [`getcallbackvalue`](./getcallbackvalue) | Читает Lua callback function, сохраненную в callback property у Instance. Первый аргумент должен быть Instance object, а второй аргумент должен быть string property name. instance reference должен быть валидным. property name разрешается через Roblox property metadata и должен указывать на property с типом LUA_CALLBACK. Если property descriptor отсутствует, property не является LUA_CALLBACK, callback field offset отсутствует, callback не сохранен, LiveLuaRef отсутствует, callback принадлежит другому Lua global state, или указанное значение не является function, function возвращает nil. Она также проверяет async callback field fallback, когда первый callback slot не содержит callback. Function не обновляет property. |
| [`gethui`](./gethui) | Возвращает game:CoreGui lookup.RobloxGui. Function не принимает arguments. Если CoreGui lookup возвращает nil, или если RobloxGui у этого значения равен nil, function возвращает nil. Function не создает container и не использует кэшированное значение CoreGui. |
| [`getinstances`](./getinstances) | Возвращает новую array table, содержащую каждый object value, сейчас сохраненный в Instance cache. Function не принимает arguments. Она не фильтрует по Parent, ClassName, DataModel fieldship, nil-parent state или Instance validity, кроме проверки, что каждый registry value является object. Entries копируются в возвращаемую таблицу по sequential numeric indexes, начиная с 1. iteration order берется из table iteration по cache и не сортируется function. |
| [`getnilinstances`](./getnilinstances) | Returns a new array table containing cached Instance values whose Parent field is nil. The function takes no arguments. It does not sort the returned entries. |
| [`isnetworkowner`](./isnetworkowner) | Возвращает результат чтения hidden property "NetworkOwnerV3" из Instance и проверки, больше ли первое возвращенное значение, преобразованное через integer conversion, чем 2. Аргумент должен быть Instance object. Function внутри вызывает the hidden property reader и не перехватывает ошибки из этого вызова, поэтому Invalid Instance values, missing properties или non-property metadata могут вызывать те же ошибки, что и gethiddenproperty. Возвращает один boolean. Означает ли peer_id > 2 точно local network ownership: Nicht aus der Codebasis verifizierbar. |
