Запускает Real touch interest event для двух BasePart instances. Первые два аргумента должны быть Instance object, и оба значения должны проходить IsA("BasePart"). Аргумент state обязателен и должен быть number или boolean. Когда state является number, только 1 становится true, а любое другое number становится false. Когда state является boolean, его boolean значение передается напрямую. Если у любой part нет touch data, или у первой part нет overlap reference, function возвращается, ничего не запуская. Function ничего не возвращает. Точное значение begin/end для boolean, передаваемого в helper: Nicht aus der Codebasis verifizierbar.

## Синтаксис

```lua
firetouchinterest(partA: Instance, partB: Instance, state: number | boolean)
```

## Алиасы

- `firetouchtransmitter`

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `partA` | `Instance` | Yes | Первое Instance object. Должно проходить IsA("BasePart"). Его touch data и overlap reference используются для call. |
| `partB` | `Instance` | Yes | Второе Instance object. Должно проходить IsA("BasePart"). Его touch data используется для call. |
| `state` | `number \| boolean` | Yes | Обязательное значение state. Numbers преобразуются через state == 1; booleans передаются напрямую. |

## Пример

Передает два значения BasePart и явное значение state в firetouchinterest.

```lua
local players = game:GetService("Players")
local character = players.LocalPlayer.Character or players.LocalPlayer.CharacterAdded:Wait()
local rootPart = character:WaitForChild("HumanoidRootPart")
local targetPart = workspace.TouchTarget

firetouchinterest(rootPart, targetPart, true)
```
