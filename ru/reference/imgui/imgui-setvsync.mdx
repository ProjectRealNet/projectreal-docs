```lua
imgui.setvsync(enabled: boolean)
```

## Аргументы

<ParamField path={"enabled"} type={"boolean"} required>
`true`, чтобы запросить vertical synchronization; `false`, чтобы запросить uncapped presentation.
</ParamField>
