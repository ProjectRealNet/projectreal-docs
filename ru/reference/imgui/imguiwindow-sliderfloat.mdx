---
title: "ImGuiWindow.SliderFloat"
sidebarTitle: "ImGuiWindow.SliderFloat"
description: "Добавляет в окно SliderFloat element. label, value, minimum и maximum читаются из аргументов 2-5, а числовые аргументы проверяются через number type checking. Во время rendering Real вызывает a floating-point slider с сохраненным значением и диапазоном. Когда ImGui сообщает об измененном значении, onChange помещается в queue и позже вызывается с одним Lua number. Real не добавляет отдельную проверку minimum <= maximum в этом closure."
keywords: ["ImGuiWindow.SliderFloat","ImGui"]
---

<div className="real-function-page">

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Аргументы

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow, возвращенное imgui.create. Если object недействительна или уже была destroy, method вызывает Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Slider label, читаемый через string type checking.
</ParamField>

<ParamField path={"value"} type={"number"} required>
Начальное значение slider, читаемое через number type checking и сохраняемое как текущее float значение.
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
Minimum value, читаемое через number type checking и передаваемое в a floating-point slider.
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
Maximum value, читаемое через number type checking и передаваемое в a floating-point slider.
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Callback function, сохраняемая в Lua registry. Когда slider изменяется во время rendering, она позже вызывается с обновленным числовым значением.
</ParamField>

## Возвраты

<ResponseField name={"window"} type={"ImGuiWindow"}>
Та же ImGuiWindow object, позволяющая цепочкой вызывать method.
</ResponseField>

## Типы

### ImGuiWindow

Дескриптор, возвращаемый imgui.create. Методы создания элементов управления возвращают один и тот же дескриптор, поэтому вызовы можно объединять в цепочки.

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `Button` | `(label: string, onClick: () -> ()) -> ImGuiWindow` | Yes | Добавляет кнопку и вызывает обратный вызов после щелчка. |
| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | Добавляет флажок, инициализированный в указанное состояние. |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | Элементы управления группами, добавляемые обратным вызовом содержимого под сворачивающимся заголовком. |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | Добавляет редактор RGBA; опущенные цветовые компоненты по умолчанию равны 1.0. |
| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | Добавляет однострочный текстовый ввод; опущенный начальный текст по умолчанию представляет собой пустую строку. |

| `SliderFloat` | `(label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow` | Yes | Добавляет ползунок с плавающей запятой. |
| `SliderInt` | `(label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow` | Yes | Добавляет целочисленный ползунок. |
| `Text` | `(text: string) -> ImGuiWindow` | Yes | Добавляет неинтерактивный текст. |
| `destroy` | `() -> ()` | Yes | Удаляет окно и освобождает зарегистрированные обратные вызовы. |
