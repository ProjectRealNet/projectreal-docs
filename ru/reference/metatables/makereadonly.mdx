Marks a table as readonly and returns no values.

## Синтаксис

```lua
makereadonly(target: table)
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `target` | `table` | Yes | Table to mark as readonly. |

## Пример

Set a table's readonly flag to true.

```lua
local target = {}

makereadonly(target)

print(isreadonly(target))
```
