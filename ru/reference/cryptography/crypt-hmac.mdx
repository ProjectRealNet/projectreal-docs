Вычисляет crypto library HMAC по байтам Lua string с raw Lua string key и возвращает Base64 digest.

## Синтаксис

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `key` | `string` | Yes | Байты raw Lua string, используемые как HMAC key. key не Base64-decode. |
| `data` | `string` | Yes | Байты Lua string, передаваемые в HMAC calculation. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Case-sensitive имя HMAC algorithm. Значение по умолчанию sha256. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `digest` | `string` | Base64-encoded HMAC output без line breaks. |

## Пример

Вычислите Base64 HMAC output из raw Lua string key и data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
