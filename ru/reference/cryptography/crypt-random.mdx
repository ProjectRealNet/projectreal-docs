Генерирует raw random bytes через random byte generator и возвращает их как Lua string.

## Синтаксис

```lua
crypt.random(size: number): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Число, проходящее через integer conversion перед выделением. Значения меньше или равные 0 вызывают argument error. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes, возвращаемые как Lua string. Длина возвращенной string совпадает с выделенным числом байтов. |

## Пример

Сгенерируйте raw bytes и выведите длину возвращенной Lua string.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
