Кодирует байты Lua string через Base64 encoder, используя = padding и без переносов строк.

## Синтаксис

```lua
base64_encode(data: string): string
```

## Алиасы

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Байты Lua string, передаваемые в Base64 encoder. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `encoded` | `string` | Вывод Base64, возвращаемый как Lua string. |

## Пример

Закодируйте Lua string и выведите результат Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
