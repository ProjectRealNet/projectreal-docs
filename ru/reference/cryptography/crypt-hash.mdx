Хэширует байты Lua string поддерживаемым алгоритмом crypto library hash и возвращает lowercase hexadecimal digest.

## Синтаксис

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Байты Lua string, передаваемые в crypto library HashFilter. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Case-sensitive имя алгоритма hash. Значение по умолчанию sha256. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest без prefix или separators. |

## Пример

Хэшируйте байты Lua string алгоритмом по умолчанию или явно указанным поддерживаемым именем.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
