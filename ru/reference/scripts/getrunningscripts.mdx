sidebarTitle: "getrunningscripts"
description: "Возвращает новую array table с unique script Instances, взятыми из live Lua threads. Function не принимает arguments. Она проходит по the live Luau thread list, читает каждый thread node и пропускает entries без thread node, без weak thread ref, без LiveLuaRef, без Lua state, без object или с expired Script stored reference. Для каждого оставшегося thread она блокирует scriptThread->object->Script(), удаляет дубликаты по script reference, помещает Instance через Instance cache и вставляет его в последовательные array indexes, начиная с 1. Function не сканирует DataModel, не проверяет ClassName и не сортирует result."
keywords: ["getrunningscripts","Scripts"]
