Возвращает, является ли значение object с Drawing object type. Это только methods check; он не проверяет, остается ли внутренний Drawing object active, tracked или destroyed. the Drawing API регистрирует эту API только когда the required rendering environment is active имеет значение true; если эта проверка false, initializer возвращается до создания этих globals.

## Синтаксис

```lua
isrenderobj(object: any): boolean
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `object` | `any` | Yes | Значение для проверки. Non-object values и object без Drawing object type возвращают false. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `isDrawingObject` | `boolean` | True, когда значение является object, methods которого совпадает с RealDrawingObject; иначе false. |

## Пример

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
