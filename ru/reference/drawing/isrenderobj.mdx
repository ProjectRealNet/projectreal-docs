<div className="real-function-page">

```lua
isrenderobj(object: any): boolean
```

## Аргументы

<ParamField path={"object"} type={"any"} required>
Значение для проверки. Non-object values и object без Drawing object type возвращают false.
</ParamField>

## Возвраты

<ResponseField name={"isDrawingObject"} type={"boolean"}>
True, когда значение является object, methods которого совпадает с RealDrawingObject; иначе false.
</ResponseField>

## Пример

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
