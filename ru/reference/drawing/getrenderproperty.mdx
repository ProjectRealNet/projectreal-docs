<div className="real-function-page">

```lua
getrenderproperty(object: any, property: any): any
```

## Аргументы

<ParamField path={"object"} type={"any"} required>
Значение для индексирования. С Drawing object используется RealDrawingObject __index handler.
</ParamField>

<ParamField path={"property"} type={"any"} required>
property key, используемый для индексирования. Drawing object properties основаны на strings.
</ParamField>

## Возвраты

<ResponseField name={"propertyValue"} type={"any"}>
Значение, возвращенное при индексировании object через property, или nil, если Drawing __index handler не имеет значения для этой property.
</ResponseField>

## Пример

Read a Drawing property like direct indexing.

```lua
local line = Drawing.new("Line")
line.Thickness = 3

print(getrenderproperty(line, "Thickness"))
print(getrenderproperty(line, "MissingProperty"))
```
