Unknown Drawing properties игнорируются, а destroyed Drawing objects не изменяются. Третий аргумент должен присутствовать. the Drawing API регистрирует эту API только когда the required rendering environment is active имеет значение true; если эта проверка false, initializer возвращается до создания этих globals."

<div className="real-function-page">

```lua
setrenderproperty(object: any, property: any, value: any)
```

## Аргументы

<ParamField path={"object"} type={"any"} required>
Значение для индексирования и присваивания. С Drawing object используется RealDrawingObject __newindex handler.
</ParamField>

<ParamField path={"property"} type={"any"} required>
property key, используемый для присваивания. Drawing object properties основаны на strings.
</ParamField>

<ParamField path={"value"} type={"any"} required>
Значение, присваиваемое object[property]. Этот аргумент должен быть передан; nil все равно является переданным значением.
</ParamField>

## Пример

Обновите свойство чертежа с помощью помощника по универсальным свойствам.

```lua
local line = Drawing.new("Line")
setrenderproperty(line, "Thickness", 3)
setrenderproperty(line, "Visible", true)

print(line.Thickness)
print(line.Visible)
```
