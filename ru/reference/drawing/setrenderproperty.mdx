Присваивает value в object[property]. Для Drawing object используется то же Drawing property assignment, что и direct property assignment. Unknown Drawing properties игнорируются, а destroyed Drawing objects не изменяются. Третий аргумент должен присутствовать. the Drawing API регистрирует эту API только когда the required rendering environment is active имеет значение true; если эта проверка false, initializer возвращается до создания этих globals.

## Синтаксис

```lua
setrenderproperty(object: any, property: any, value: any)
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `object` | `any` | Yes | Значение для индексирования и присваивания. С Drawing object используется RealDrawingObject __newindex handler. |
| `property` | `any` | Yes | property key, используемый для присваивания. Drawing object properties основаны на strings. |
| `value` | `any` | Yes | Значение, присваиваемое object[property]. Этот аргумент должен быть передан; nil все равно является переданным значением. |

## Пример

Обновите свойство чертежа с помощью помощника по универсальным свойствам.

```lua
local line = Drawing.new("Line")
setrenderproperty(line, "Thickness", 3)
setrenderproperty(line, "Visible", true)

print(line.Thickness)
print(line.Visible)
```
