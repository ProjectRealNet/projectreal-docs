---
title: "mousemoverel"
sidebarTitle: "mousemoverel"
description: "Перемещает мышь на relative delta, когда Roblox window active. Аргументы x и y проверяются как Lua numbers и преобразуются через integer conversion, затем напрямую передаются в mouse input с the requested mouse action как dx и dy. Function не использует the requested mouse action, не выполняет client-area conversion, ничего не возвращает и возвращается без отправки input, когда isrbxactive вернул бы false."
keywords: ["mousemoverel","Input"]
---

<div className="real-function-page">

```lua
mousemoverel(x: number, y: number)
```

## Аргументы

<ParamField path={"x"} type={"number"} required>
Relative X movement delta, читаемый как Lua number и преобразуемый через integer conversion перед передачей как dx в mouse input.
</ParamField>

<ParamField path={"y"} type={"number"} required>
Relative Y movement delta, читаемый как Lua number и преобразуемый через integer conversion перед передачей как dy в mouse input.
</ParamField>
