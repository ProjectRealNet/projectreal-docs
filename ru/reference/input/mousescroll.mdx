Отправляет mouse wheel event, когда Roblox window active. Аргумент amount проверяется как Lua number, преобразуется через integer conversion и напрямую передается как значение dwData в mouse input с the requested mouse action. Real не нормализует amount и не добавляет movement data. Function ничего не возвращает и возвращается без отправки input, когда isrbxactive вернул бы false.

## Синтаксис

```lua
mousescroll(amount: number)
```

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `amount` | `number` | Yes | Wheel dwData value, читаемый как Lua number и преобразуемый через integer conversion перед передачей в mouse input. |
