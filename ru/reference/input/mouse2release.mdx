Отправляет right mouse up event, когда Roblox window active. Real вызывает mouse input с the requested mouse action и без movement или wheel data. Function не принимает arguments, ничего не возвращает, не отправляет соответствующий right mouse down event и возвращается без отправки input, когда isrbxactive вернул бы false.

## Синтаксис

```lua
mouse2release()
```
