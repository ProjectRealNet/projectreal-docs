---
title: "keypress"
sidebarTitle: "keypress"
description: "Отправляет key down event, когда Roblox window active. Аргумент keyCode проверяется как Lua number, преобразуется через integer conversion, сопоставляется из Windows virtual-key code в scan code через Windows key mapping и отправляется через keyboard input с KEYEVENTF_SCANCODE. Эта function не отправляет key up event. Если isrbxactive вернул бы false, function возвращается без отправки input."
keywords: ["keypress","Input"]
---

<div className="real-function-page">

```lua
keypress(keyCode: number)
```

## Аргументы

<ParamField path={"keyCode"} type={"number"} required>
Windows virtual-key code, читаемый как Lua number и преобразуемый через integer conversion перед вызовом Windows key mapping.
</ParamField>
