Отправляет left mouse down event, когда Roblox window active. Real вызывает mouse input с the requested mouse action и без movement или wheel data. Function не принимает arguments, ничего не возвращает, не отправляет соответствующий left mouse up event и возвращается без отправки input, когда isrbxactive вернул бы false.

## Синтаксис

```lua
mouse1press()
```
