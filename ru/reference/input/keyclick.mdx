title: "keyclick"
sidebarTitle: "keyclick"
description: "Отправляет key down event, затем key up event, когда Roblox window active. Аргумент keyCode проверяется как Lua number, преобразуется через integer conversion, сопоставляется из Windows virtual-key code в scan code через Windows key mapping и отправляется через keyboard input с KEYEVENTF_SCANCODE. Если isrbxactive вернул бы false, function возвращается без отправки input."
keywords: ["keyclick","Input","keytap"]
