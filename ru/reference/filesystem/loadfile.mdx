Reads a workspace file, compiles its contents with the Luau compiler, and returns the loaded Luau function without executing it.

## Синтаксис

```lua
loadfile(path: string, chunkName?: string): function | nil | string | nil
```

## Алиасы

- `loadfileasync`
- `dofile`
- `dofileasync`

## Аргументы

| Name | Type | Required | Описание |
| --- | --- | --- | --- |
| `path` | `string` | Yes | File path resolved inside the workspace after separator normalization, workspace-boundary checks, and extension checks. Path, open, and read-size errors are thrown. |
| `chunkName` | `string` | No | Optional chunk name passed to luau_load. Defaults to = when omitted or nil. |

## Возвраты

| Name | Type | Описание |
| --- | --- | --- |
| `chunk` | `function \| nil` | Loaded Luau function when luau_load succeeds. The function is not executed by loadfile. |
| `errorMessage` | `string \| nil` | Error string returned as the second value only when luau_load fails. Filesystem and path errors are thrown instead. |

## Пример

Загрузите workspace Luau file как function, затем вызовите ее самостоятельно.

```lua
writefile("examples/module.luau", "return 2 + 3")

local chunk, message = loadfile("examples/module.luau", "ExampleModule")

if chunk then
    print(chunk())
else
    warn(message)
end
```
