يحسب hash لبايتات Lua string باستخدام خوارزمية crypto library hash مدعومة ويعيد lowercase hexadecimal digest.

## الصيغة

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## الوسائط

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
| `data` | `string` | Yes | بايتات Lua string التي تمرر إلى crypto library HashFilter. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | اسم خوارزمية hash case-sensitive. القيمة الافتراضية هي sha256. |

## القيم الراجعة

| Name | Type | الوصف |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest بدون prefix او separators. |

## مثال

احسب hash لبايتات Lua string بالخوارزمية الافتراضية او باسم مدعوم صريح.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
