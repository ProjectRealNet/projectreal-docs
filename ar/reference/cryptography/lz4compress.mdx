```lua
lz4compress(data: string): string
```

## أسماء بديلة

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## الوسائط

<ParamField path={"data"} type={"string"} required>
بايتات Lua string التي تمرر إلى LZ4 block compression.
</ParamField>

## القيم الراجعة

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes تعاد كسلسلة Lua. لا يتم تخزين original size في الناتج.
</ResponseField>

## مثال

اضغط بايتات Lua string واستعدها بتمرير original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
