ينشئ raw random bytes باستخدام random byte generator ويعيدها كسلسلة Lua.

## الصيغة

```lua
crypt.random(size: number): string
```

## الوسائط

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
| `size` | `number` | Yes | رقم يمر عبر integer conversion قبل التخصيص. القيم الاقل من او تساوي 0 تسبب argument error. |

## القيم الراجعة

| Name | Type | الوصف |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes تعاد كسلسلة Lua. طول السلسلة المعادة يطابق عدد البايتات المخصصة. |

## مثال

انشئ raw bytes واطبع طول Lua string المعادة.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
