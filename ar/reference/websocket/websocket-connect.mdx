<ResponseField name={"socket"} type={"WebSocket"}>
WebSocket table تحتوي OnMessage و OnClose و connection state. يتم حل Send و Close عبر WebSocket object methods.
</ResponseField>

## مثال

افتح WebSocket، اربط OnMessage و OnClose، ثم استخدم socket methods للإرسال والإغلاق.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
