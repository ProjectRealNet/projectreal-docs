<div className="real-function-page">

```lua
getcurrentactor(): Instance | nil
```

## أسماء بديلة

- `get_current_actor`

## القيم الراجعة

<ResponseField name={"actor"} type={"Instance | nil"}>
Actor Instance المحلولة من the associated Actor weak reference الخاصة بالthread الحالي، أو nil عندما لا توجد valid actor reference.
</ResponseField>

## مثال

Resolve the Actor Instance associated with the current Luau thread.

```lua
local actor = getcurrentactor()

print(actor)
```
