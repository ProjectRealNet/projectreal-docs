يخصص Windows console للعملية عندما لا توجد console window. إذا كانت console window موجودة بالفعل، يرجع call بدون فعل شيء. بعد allocation تقوم function بعمل redirect لـ stdout إلى console output و stdin إلى console input.

## الصيغة

```lua
rconsolecreate()
```

## أسماء بديلة

- `consolecreate`

## مثال

Create the Windows console once before writing console output.

```lua
rconsolecreate()
rconsoleprint("Console ready")
```
