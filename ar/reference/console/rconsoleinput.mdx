تعمل كـ yield أثناء قراءة line واحدة من stdin باستخدام console input بعد مسح حالة console input وتجاهل input حتى newline التالية. يتم دفع string المرتجع باستخدام string return ولا يتضمن newline النهائية. إذا لم تكن هناك console window، يرجع الاستدعاء بدون values.

## الصيغة

```lua
rconsoleinput(): string
```

## أسماء بديلة

- `consoleinput`

## القيم الراجعة

| Name | Type | الوصف |
| --- | --- | --- |
| `input` | `string` | سطر النص المقروء من وحدة التحكم. |

## مثال

Read one submitted line from the current Windows console.

```lua
rconsolecreate()
rconsoleprint("Name: ")
local name = rconsoleinput()
rconsoleprint("Hello, ", name, "
")
```
