يشغل ProximityPrompt عبر Real ProximityPrompt trigger. يجب أن يكون وسيط prompt عبارة عن object لديه حقل ClassName يساوي "ProximityPrompt". إذا لم تكن القيمة object، يطلق الاستدعاء type error. إذا كان ClassName مفقودا أو ليس string، يطلق "Invalid Instance". إذا لم يكن ClassName هو "ProximityPrompt"، يطلق "ProximityPrompt expected". لا تأخذ function أي optional arguments ولا ترجع أي شيء.

## الصيغة

```lua
fireproximityprompt(prompt: Instance)
```

## الوسائط

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
| `prompt` | `Instance` | Yes | Instance يجب أن تكون ClassName الخاصة به ProximityPrompt. |

## مثال

يشغل ProximityPrompt واحدا بالوسيطة المطلوبة فقط.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
