```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## الوسائط

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow المعادة من imgui.create. اذا كانت object غير صالحة او تم destroy لها مسبقا، ترفع method ‏Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Slider label تتم قراءته باستخدام string type checking.
</ParamField>

<ParamField path={"value"} type={"number"} required>
قيمة slider الابتدائية تقرأ باستخدام number type checking وتخزن كقيمة float الحالية.
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
Minimum value تقرأ باستخدام number type checking وتمرر إلى a floating-point slider.
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
Maximum value تقرأ باستخدام number type checking وتمرر إلى a floating-point slider.
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Callback function تخزن في Lua registry. عندما يتغير slider اثناء rendering، يتم استدعاؤها لاحقا بالقيمة الرقمية المحدثة.
</ParamField>

## القيم الراجعة

<ResponseField name={"window"} type={"ImGuiWindow"}>
نفس ImGuiWindow object، مما يسمح باستدعاءات method متسلسلة.
</ResponseField>
