<div className="real-function-page">

```lua
ImGuiWindow.CollapsingHeader(window: ImGuiWindow, label: string, content: function): ImGuiWindow
```

## الوسائط

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object المعادة من imgui.create. Window مدمرة أو غير صالحة ترفع Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Header label string الذي يمرر إلى ImGui collapsing header المعروض.
</ParamField>

<ParamField path={"content"} type={"function"} required>
Function يتم استدعاؤها فورا مع نفس ImGuiWindow object. يتم تجاهل return values؛ وتلتقط method الأخطاء.
</ParamField>

## القيم الراجعة

<ResponseField name={"window"} type={"ImGuiWindow"}>
نفس ImGuiWindow object، مما يسمح بتسلسل method calls.
</ResponseField>

## الأنواع

### ImGuiWindow

تم إرجاع المقبض بواسطة imgui.create. تقوم أساليب بناء التحكم بإرجاع نفس المقبض بحيث يمكن ربط المكالمات بالتسلسل.

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
