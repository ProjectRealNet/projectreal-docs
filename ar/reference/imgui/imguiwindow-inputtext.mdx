<div className="real-function-page">

```lua
ImGuiWindow.InputText(window: ImGuiWindow, label: string, text?: string, onChange: function): ImGuiWindow
```

## الوسائط

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object المعادة من imgui.create. Window مدمرة أو غير صالحة ترفع Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Input label string الذي يمرر إلى ImGui InputText widget المعروض.
</ParamField>

<ParamField path={"text"} type={"string"}>
Initial text يقرأ باستخدام optional string handling. مرر nil هنا عندما تريد default empty string مع الاستمرار في تمرير onChange كـ argument 4.
</ParamField>

<ParamField path={"onChange"} type={"function"} required>
Function مخزنة لهذا input ويتم استدعاؤها مع current string بعد معالجة edit event. يجب تمريرها كـ argument 4.
</ParamField>

## القيم الراجعة

<ResponseField name={"window"} type={"ImGuiWindow"}>
نفس ImGuiWindow object، مما يسمح بتسلسل method calls.
</ResponseField>
