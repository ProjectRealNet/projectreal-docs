يعيد array table من type names المقروءة من event descriptor signature الخاصة بـ RBXScriptSignal. يجب أن يكون argument الأول object يحمل Luau type name بقيمة RBXScriptSignal. تقرأ function event descriptor الخاص بالsignal، وتمشي عبر signature slots باستخدام argument stride في function، وتقرأ argument type reference لكل slot، ثم تدفع type name string المحلول لكل slot. لا تعيد captured runtime argument values. إذا تعذرت قراءة signature أو لم تتم إضافة أي entries، تحتوي table المعادة على fallback entry واحد: "Variant".

## الصيغة

```lua
getsignalarguments(signal: RBXScriptSignal): {string}
```

## الوسائط

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | Signal الذي يجب فحص event descriptor signature الخاص به. object غير RBXScriptSignal يرفع type error. |

## القيم الراجعة

| Name | Type | الوصف |
| --- | --- | --- |
| `arguments` | `&#123;string&#125;` | Array table من argument type name strings. يتم إرجاع fallback table تحتوي على "Variant" عندما لا يمكن قراءة signature data أو لا يتم إنتاج أي argument entries. |

## مثال

Inspect an RBXScriptSignal signature and print the argument type names Real can read.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, typeName in ipairs(getsignalarguments(remote.OnClientEvent)) do
        print(typeName)
    end
end
```
