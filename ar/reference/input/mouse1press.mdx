يرسل left mouse down event عندما تكون Roblox window نشطة. تستدعي Real ‏mouse input مع the requested mouse action وبدون movement او wheel data. لا تأخذ function أي arguments ولا تعيد شيئا، ولا ترسل left mouse up event مطابقا، وتعود بدون ارسال input عندما تكون isrbxactive ستعيد false.

## الصيغة

```lua
mouse1press()
```
