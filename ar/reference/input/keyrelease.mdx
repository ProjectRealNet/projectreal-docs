يرسل key up event عندما تكون Roblox window نشطة. يتم فحص وسيط keyCode كـ Lua number، وتحويله باستخدام integer conversion، ثم تحويله من Windows virtual-key code إلى scan code بواسطة Windows key mapping، وإرساله عبر keyboard input مع KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP. هذه function لا ترسل key down event. اذا كانت isrbxactive ستعيد false، تعود function بدون ارسال input.

## الصيغة

```lua
keyrelease(keyCode: number)
```

## الوسائط

| Name | Type | Required | الوصف |
| --- | --- | --- | --- |
| `keyCode` | `number` | Yes | Windows virtual-key code يقرأ كـ Lua number ويتم تحويله باستخدام integer conversion قبل استدعاء Windows key mapping. |
