يرسل right mouse up event عندما تكون Roblox window نشطة. تستدعي Real ‏mouse input مع the requested mouse action وبدون movement او wheel data. لا تأخذ function أي arguments ولا تعيد شيئا، ولا ترسل right mouse down event مطابقا، وتعود بدون ارسال input عندما تكون isrbxactive ستعيد false.

## الصيغة

```lua
mouse2release()
```
