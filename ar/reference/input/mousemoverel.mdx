```lua
mousemoverel(x: number, y: number)
```

## الوسائط

<ParamField path={"x"} type={"number"} required>
Relative X movement delta يقرأ كـ Lua number ويتم تحويله باستخدام integer conversion قبل تمريره كـ dx إلى mouse input.
</ParamField>

<ParamField path={"y"} type={"number"} required>
Relative Y movement delta يقرأ كـ Lua number ويتم تحويله باستخدام integer conversion قبل تمريره كـ dy إلى mouse input.
</ParamField>
