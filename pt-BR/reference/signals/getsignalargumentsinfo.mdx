Retorna uma array table de informações de argumentos a partir da assinatura de um RBXScriptSignal. Ela não retorna valores de argumentos capturados em tempo de execução.

## Sintaxe

```lua
getsignalargumentsinfo(signal: RBXScriptSignal): {{Name: string, Type: string}}
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | O RBXScriptSignal cuja event descriptor signature deve ser inspecionada. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `argumentInfo` | `&#123;&#123;Name: string, Type: string&#125;&#125;` | Uma array table em que cada entrada tem strings Name e Type. Se a assinatura não puder ser lida ou não tiver entradas, a função retorna uma única fallback entry com Name definido como arg1 e Type definido como Variant. |

## Exemplo

Inspect an RBXScriptSignal signature and print each argument name with its type name.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, argument in ipairs(getsignalargumentsinfo(remote.OnClientEvent)) do
        print(argument.Name, argument.Type)
    end
end
```
