Invoca a replication path para um RBXScriptSignal. A função lê a signal signature, converte os Lua arguments fornecidos em Roblox signal values para cada signature type, corta Lua arguments extras além da signature length e então chama a owning instance event invocation function.

## Sintaxe

```lua
replicatesignal(signal: RBXScriptSignal, ...arguments?: ...any)
```

## Aliases

- `replicateevent`

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `signal` | `RBXScriptSignal` | Yes | O RBXScriptSignal cuja owning instance event invocation function deve ser chamada. |
| `...arguments` | `...any` | No | Lua arguments convertidos de acordo com a signal signature. Extra arguments além da signature length são ignorados. |

## Exemplo

Replicate for a RemoteEvent signal with values that match the signal signature.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote and remote:IsA("RemoteEvent") then
    replicatesignal(remote.OnClientEvent, "hello")
end
```
