<div className="real-function-page">

```lua
cansignalreplicate(signal: RBXScriptSignal): boolean
```

## Argumentos

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Signal a verificar. O primeiro argument deve ser object cujo Luau type name seja RBXScriptSignal.
</ParamField>

## Retornos

<ResponseField name={"canReplicate"} type={"boolean"}>
O boolean retornado pela verificacao replication layer signal replication validation, ou false quando o valor de ponteiro replication layer resolvido e 0.
</ResponseField>

## Exemplo

Check whether an RBXScriptSignal is legal to send before attempting to replicate it.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    print(cansignalreplicate(remote.OnClientEvent))
end
```
