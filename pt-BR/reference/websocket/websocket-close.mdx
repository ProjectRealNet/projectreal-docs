Fecha um WebSocket object retornado por WebSocket.connect. O primeiro argument deve ser uma table. A função lê o field connection state do object; quando existe um live state e ele ainda não está destroyed ou closed, define isClosed como true e envia um frame close frame vazio pelo WebSocket connection armazenado. Ela não aceita close code nem reason e não retorna values.

## Sintaxe

```lua
WebSocket.Close(socket: WebSocket)
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `socket` | `WebSocket` | Yes | WebSocket table retornada por WebSocket.connect. A function espera que essa table contenha o connection state. |

## Exemplo

Close a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Close()
```
