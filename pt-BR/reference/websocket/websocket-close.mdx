A função lê o field connection state do object; quando existe um live state e ele ainda não está destroyed ou closed, define isClosed como true e envia um frame close frame vazio pelo WebSocket connection armazenado. Ela não aceita close code nem reason e não retorna values."

<div className="real-function-page">

```lua
WebSocket.Close(socket: WebSocket)
```

## Argumentos

<ParamField path={"socket"} type={"WebSocket"} required>
WebSocket table retornada por WebSocket.connect. A function espera que essa table contenha o connection state.
</ParamField>

## Exemplo

Close a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Close()
```
