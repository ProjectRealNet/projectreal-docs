```lua
WebSocket.connect(url: string): WebSocket
```

## Aliases

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## Argumentos

<ParamField path={"url"} type={"string"} required>
URL string passada para CURLOPT_URL antes de WebSocket client executar o WebSocket connection attempt.
</ParamField>

## Retornos

<ResponseField name={"socket"} type={"WebSocket"}>
WebSocket table contendo OnMessage, OnClose e connection state. Send e Close são resolvidos pela WebSocket object methods.
</ResponseField>

## Exemplo

Abra um WebSocket, conecte OnMessage e OnClose, depois use socket methods para enviar e fechar.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
