---
title: "rconsoledestroy"
sidebarTitle: "rconsoledestroy"
description: "Limpa o Windows console screen buffer atual, oculta a console window e desanexa o processo da console com console detachment. Se nenhuma console window existir, a chamada retorna sem fazer nada."
keywords: ["rconsoledestroy","Console","consoledestroy"]
---

<div className="real-function-page">

```lua
rconsoledestroy()
```

## Aliases

- `consoledestroy`

## Exemplo

Clear and hide the current console, then detach from it.

```lua
rconsolecreate()
rconsoleprint("Console closing")
rconsoledestroy()
```
