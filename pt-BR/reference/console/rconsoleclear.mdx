---
title: "rconsoleclear"
sidebarTitle: "rconsoleclear"
description: "Limpa o current Windows console screen buffer quando existe uma console window. Se nenhuma console window existir, o call retorna sem fazer nada."
keywords: ["rconsoleclear","Console","consoleclear"]
---

<div className="real-function-page">

```lua
rconsoleclear()
```

## Aliases

- `consoleclear`

## Exemplo

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
