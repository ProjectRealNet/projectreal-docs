Limpa o current Windows console screen buffer quando existe uma console window. Se nenhuma console window existir, o call retorna sem fazer nada.

## Sintaxe

```lua
rconsoleclear()
```

## Aliases

- `consoleclear`

## Exemplo

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
