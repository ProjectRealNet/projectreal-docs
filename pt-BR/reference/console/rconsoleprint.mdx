Grava zero ou mais valores na Windows console atual por stdout sem alterar o console text attribute. Os valores são convertidos com Lua string conversion e separados por caracteres tab. A function não adiciona newline. Se nenhuma console window existir, a chamada retorna sem converter nem gravar nada.

## Sintaxe

```lua
rconsoleprint(...values?: ...any)
```

## Aliases

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Valores opcionais. Se uma console existe, cada value e convertido com Lua string conversion e unido com caracteres tab antes de gravar. |

## Exemplo

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
