sidebarTitle: "rconsoleprint"
description: "Grava zero ou mais valores na Windows console atual por stdout sem alterar o console text attribute. Os valores são convertidos com Lua string conversion e separados por caracteres tab. A function não adiciona newline. Se nenhuma console window existir, a chamada retorna sem converter nem gravar nada."
keywords: ["rconsoleprint","Console","consoleprint","rconsolewrite","consolewrite"]

<div className="real-function-page">

```lua
rconsoleprint(...values?: ...any)
```

## Aliases

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Argumentos

<ParamField path={"...values"} type={"...any"}>
Valores opcionais. Se uma console existe, cada value e convertido com Lua string conversion e unido com caracteres tab antes de gravar.
</ParamField>

## Exemplo

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
