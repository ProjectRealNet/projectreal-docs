Ela percorre the live Luau thread list, le cada thread node e ignora entries sem thread node, sem weak thread ref, sem LiveLuaRef, sem Lua state, sem object ou com expired Script stored reference. Para cada thread restante, bloqueia scriptThread->object->Script(), deduplica pelo script reference, envia a Instance com Instance cache e a insere em array indexes sequenciais comecando em 1. A function nao escaneia o DataModel, nao verifica ClassName e nao ordena o result."
