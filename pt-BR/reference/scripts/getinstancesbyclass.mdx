Retorna instances da Instance cache table cujo ClassName field corresponde exatamente ao string solicitado. O primeiro argumento e lido com string type checking. Um empty string gera "ClassName required". A function cria uma nova array table, itera a cache armazenada em Instance cache, mantem apenas values cujo Lua type e object, le o ClassName field de cada object value e compara com strcmp contra o className solicitado. Matches sao inseridos sequential a partir de index 1. A correspondencia e exact e case-sensitive. A function nao usa IsA, nao inclui subclasses, nao faz walk descendants, nao filtra por Parent e nao ordena o result. getinstancesofclass e um alias para a mesma function.

## Sintaxe

```lua
getinstancesbyclass(className: string): table
```

## Aliases

- `getinstancesofclass`

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `className` | `string` | Yes | Exact ClassName string para corresponder. Empty strings geram "ClassName required". |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `instances` | `table` | New array table contendo matching object values da Instance cache table. |
