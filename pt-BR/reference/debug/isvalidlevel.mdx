description: "Verifica se um numeric stack level está dentro do current call stack range. level é obrigatório e deve ser number porque a function chama requires a number. O value é convertido com integer conversion. A function retorna false quando level < 0 ou level >= the current call stack depth; caso contrário, true. Ela não inspeciona a frame closure e não lança \"Level out of range\" para invalid numeric levels. validlevel é um global alias, e debug.isvalidlevel junto com debug.validlevel são expostos pelos debug table aliases."

<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Aliases

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argumentos

<ParamField path={"level"} type={"number"} required>
Stack level number convertido com integer conversion e verificado contra 0 &lt;= level &lt; the current call stack depth.
</ParamField>

## Retornos

<ResponseField name={"valid"} type={"boolean"}>
true quando o numeric level está dentro do current call stack range; caso contrário, false.
</ResponseField>

## Exemplo

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
