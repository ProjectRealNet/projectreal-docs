<div className="real-function-page">

```lua
setstack(level: number, index: number, value: any)
```

## Aliases

- `debug.setstack`

## Argumentos

<ParamField path={"level"} type={"number"} required>
Stack level number. Must satisfy 0 &lt;= level &lt; the current call stack depth.
</ParamField>

<ParamField path={"index"} type={"number"} required>
One-based stack slot index.
</ParamField>

<ParamField path={"value"} type={"any"} required>
New value for the stack slot.
</ParamField>

## Exemplo

Replace one stack slot value in a Lua stack frame.

```lua
local function inspect(value)
    print(getstack(1, 1))

    setstack(1, 1, "updated")
    print(getstack(1, 1))

    debug.setstack(1, 1, value)
end

inspect("ready")
```
