```lua
json.escape(text: string): string
```

## Argumentos

<ParamField path={"text"} type={"string"} required>
String que sera escapada. A function le este argument com string type checking.
</ParamField>

## Retornos

<ResponseField name={"escaped"} type={"string"}>
Escaped JSON string content sem opening e closing quote. Quotes, backslashes, common control characters e bytes below 0x20 sao escapados.
</ResponseField>

## Exemplo

Escape uma string para dentro de um JSON string sem adicionar surrounding quotes.

```lua
local source = "line 1" .. string.char(10) .. [[line "2"]]
local escaped = json.escape(source)

print(escaped)
```
