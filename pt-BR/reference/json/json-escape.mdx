Escapa uma string usando Real JSON string escaping rules e retorna o escaped content sem surrounding quotes.

## Sintaxe

```lua
json.escape(text: string): string
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `text` | `string` | Yes | String que sera escapada. A function le este argument com string type checking. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `escaped` | `string` | Escaped JSON string content sem opening e closing quote. Quotes, backslashes, common control characters e bytes below 0x20 sao escapados. |

## Exemplo

Escape uma string para dentro de um JSON string sem adicionar surrounding quotes.

```lua
local source = "line 1" .. string.char(10) .. [[line "2"]]
local escaped = json.escape(source)

print(escaped)
```
