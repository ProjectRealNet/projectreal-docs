<div className="real-function-page">

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Argumentos

<ParamField path={"json"} type={"string"} required>
JSON string a ser validate. A function le este argument com string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. Um boolean define useNull. Uma table pode definir useNull e maxDepth. maxDepth e clamp de 1 a 4096.
</ParamField>

## Retornos

<ResponseField name={"valid"} type={"boolean"}>
true quando o parsing de um unico complete JSON value tem sucesso. false quando o parsing falha dentro do protected parse block.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message em parse failure. A message recebe prefix json.validate e inclui near-position suffix. Este return so existe em failure.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position do parser em parse failure. Este return so existe em failure.
</ResponseField>

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Verifica se um string contem exatamente um complete JSON value.

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
