Valida um JSON string fazendo parse de um unico complete JSON value. Em success retorna apenas true. Em parse failure retorna false mais parser error details.

## Sintaxe

```lua
json.validate(json: string, options?: DecodeOptions): boolean | string | nil | number | nil
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string a ser validate. A function le este argument com string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options. Um boolean define useNull. Uma table pode definir useNull e maxDepth. maxDepth e clamp de 1 a 4096. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `valid` | `boolean` | true quando o parsing de um unico complete JSON value tem sucesso. false quando o parsing falha dentro do protected parse block. |
| `errorMessage` | `string \| nil` | Error message em parse failure. A message recebe prefix json.validate e inclui near-position suffix. Este return so existe em failure. |
| `errorPosition` | `number \| nil` | Parser byte position do parser em parse failure. Este return so existe em failure. |

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Verifica se um string contem exatamente um complete JSON value.

```lua
print(json.validate('{"value":42}'))

local valid, message, position = json.validate('{"value":42 trailing')

if not valid then
    warn(message, position)
end
```
