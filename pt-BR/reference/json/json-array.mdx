<div className="real-function-page">

```lua
json.array(source?: table): table
```

## Argumentos

<ParamField path={"source"} type={"table"}>
Optional source table. Quando omitida ou nil, json.array retorna uma new empty array-marked table. Quando fornecida, apenas numeric sequence entries de 1 with #source sao copiadas para a new table.
</ParamField>

## Retornos

<ResponseField name={"array"} type={"table"}>
New table com JSON array marker. json.encode a serializes como JSON array; a original source table nao e retornada.
</ResponseField>

## Exemplo

Crie uma array-marked copy para que json.encode serializes o valor como JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
