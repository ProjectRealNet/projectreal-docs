Faz parse de um JSON string usando a mesma function que json.decode.

## Sintaxe

```lua
json.parse(json: string, options?: DecodeOptions): any
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string que recebe parse. A function le este argument com string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options. Um boolean define useNull. Uma table pode definir useNull e maxDepth. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `decoded` | `any` | Decoded value. JSON objects e arrays viram tables com JSON type markers, strings viram Lua strings, numbers viram Lua numbers, booleans viram booleans, e null vira json.null a menos que useNull seja false. |

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Parse JSON com a mesma function usada por json.decode.

```lua
local settings = json.parse('{"volume":0.75,"theme":"dark","missing":null}', {
    useNull = true,
})

print(settings.volume)
print(settings.theme)
print(json.isNull(settings.missing))
```
