<div className="real-function-page">

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliases

- `json.getpath`

## Argumentos

<ParamField path={"object"} type={"table"} required>
Root table de onde a leitura acontece. A function exige que este argument seja uma table.
</ParamField>

<ParamField path={"path"} type={"string | table"} required>
Path a seguir. Uma string e split por dots; integer string tokens sao lidos com raw array indexing. Uma table path usa suas array entries de 1 ate #path como keys.
</ParamField>

<ParamField path={"defaultValue"} type={"any"}>
Fallback value retornado quando traversal chega a nil ou a non-table antes de completar o path.
</ParamField>

## Retornos

<ResponseField name={"pathValue"} type={"any | nil"}>
Value no requested path. Se o path estiver missing, retorna defaultValue quando fornecido, caso contrario nil.
</ResponseField>

## Exemplo

Leia um nested table value de um dotted string path ou uma array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
