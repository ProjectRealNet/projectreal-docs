Cria uma new table marked as a JSON object para que Real JSON encoder a trate como object.

## Sintaxe

```lua
json.object(source?: table): table
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table para copy na new object table. Se omitted ou nil, retorna uma empty object table. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `object` | `table` | New table marked com Real JSON object marker. Source entries sao copy, exceto Real JSON type marker. |

## Exemplo

Create uma new table marked as a JSON object, incluindo empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
