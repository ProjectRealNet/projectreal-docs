Faz parse de JSON com o mesmo parser de json.decode e retorna um success flag em vez de lancar para parse errors.

## Sintaxe

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON text para parse. Este argument e verificado como string antes de parse errors serem capturados. |
| `options` | `DecodeOptions` | No | Optional decode options. Um boolean define useNull diretamente. Uma table pode definir useNull e maxDepth; maxDepth e clamp de 1 a 4096. Invalid option argument types sao verificados antes de parse errors serem capturados. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `success` | `boolean` | True quando parsing tem sucesso, false quando o parser relata um error. |
| `decoded` | `any \| nil` | Decoded value em sucesso, nil em parse failure. JSON false valido retorna success como true e decoded como false, entao verifique o success return value. |
| `errorMessage` | `string \| nil` | Error message em parse failure, caso contrario nil. A message inclui o json.decodeSafe prefix e parser position. |
| `errorPosition` | `number \| nil` | Parser byte position em parse failure, caso contrario nil. |

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Faca parse de JSON e use o success return value para separar valid false ou nil results de parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
