<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumentos

<ParamField path={"json"} type={"string"} required>
JSON text para parse. Este argument e verificado como string antes de parse errors serem capturados.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. Um boolean define useNull diretamente. Uma table pode definir useNull e maxDepth; maxDepth e clamp de 1 a 4096. Invalid option argument types sao verificados antes de parse errors serem capturados.
</ParamField>

## Retornos

<ResponseField name={"success"} type={"boolean"}>
True quando parsing tem sucesso, false quando o parser relata um error.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value em sucesso, nil em parse failure. JSON false valido retorna success como true e decoded como false, entao verifique o success return value.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message em parse failure, caso contrario nil. A message inclui o json.decodeSafe prefix e parser position.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position em parse failure, caso contrario nil.
</ResponseField>

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Faca parse de JSON e use o success return value para separar valid false ou nil results de parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
