<div className="real-function-page">

```lua
json.tryDecode(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumentos

<ParamField path={"json"} type={"string"} required>
JSON string que recebe parse. A function le este argument com string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. Um boolean define useNull. Uma table pode definir useNull e maxDepth.
</ParamField>

## Retornos

<ResponseField name={"success"} type={"boolean"}>
true quando parsing tem sucesso, false quando parsing falha dentro do protected parse block.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value no success. Em parse failure, este return e nil.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message em parse failure. A message e prefixed com json.decodeSafe e inclui near-position suffix.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position do parser em parse failure. Este return so existe em failure.
</ResponseField>

## Tipos

### DecodeOptions

Controla o comportamento de análise JSON.

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Representa JSON nulo com o sentinela nulo da biblioteca em vez de nulo. |
| `maxDepth` | `integer` | No | Define a profundidade máxima de aninhamento, fixada de 1 a 4096. |

## Exemplo

Decode JSON com status returns usando o json.decodeSafe-compatible alias.

```lua
local ok, value, message, position = json.tryDecode('{"ready":true,"missing":null}', {
    useNull = true,
})

if ok then
    print(value.ready)
    print(json.isNull(value.missing))
else
    warn(message, position)
end
```
