Retorna as visible keys de uma table em uma new table marked as a JSON array.

## Sintaxe

```lua
json.keys(object: table): table
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `object` | `table` | Yes | Table para inspect. A function exige que este argument seja uma table. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `keys` | `table` | New array table contendo as source table keys, excluindo Real JSON type marker. A order segue table iteration iteration e nao e sorted por esta function. |

## Exemplo

Collect as visible keys de uma table em uma new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
