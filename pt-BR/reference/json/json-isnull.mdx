<div className="real-function-page">

```lua
json.isNull(value: any): boolean
```

## Argumentos

<ParamField path={"value"} type={"any"} required>
Value para inspect. Somente o json.null value retorna true; Lua nil e other values retornam false.
</ParamField>

## Retornos

<ResponseField name={"isNull"} type={"boolean"}>
true quando o value e o exact json.null sentinel, otherwise false.
</ResponseField>

## Exemplo

Check se um value e o json.null sentinel em vez de Lua nil.

```lua
local value = json.decode("null")

if json.isNull(value) then
    print("The value is JSON null")
end

print(json.isNull(nil))
```
