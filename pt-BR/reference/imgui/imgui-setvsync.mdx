Atualiza a vertical synchronization preference do ImGui renderer. O presentation path atual armazena essa preference, mas nao a aplica.

## Sintaxe

```lua
imgui.setvsync(enabled: boolean)
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `enabled` | `boolean` | Yes | `true` para solicitar vertical synchronization; `false` para solicitar uncapped presentation. |
