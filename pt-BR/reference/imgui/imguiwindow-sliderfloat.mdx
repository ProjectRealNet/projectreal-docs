Anexa um SliderFloat element a janela. label, value, minimum e maximum sao lidos dos argumentos 2 a 5, com os argumentos numericos verificados por number type checking. Durante o rendering, Real chama a floating-point slider com o valor e o intervalo armazenados. Quando ImGui informa uma mudanca de valor, onChange entra em uma queue e depois e chamado com um Lua number. Real nao adiciona uma validacao minimum &lt;= maximum separada neste closure.

## Sintaxe

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow retornada por imgui.create. Se a object for invalida ou ja tiver sido destruida, a method gera um Lua error. |
| `label` | `string` | Yes | Slider label lida com string type checking. |
| `value` | `number` | Yes | Valor inicial do slider lido com number type checking e armazenado como o valor float atual. |
| `minimum` | `number` | Yes | Minimum value lida com number type checking e passada para a floating-point slider. |
| `maximum` | `number` | Yes | Maximum value lida com number type checking e passada para a floating-point slider. |
| `onChange` | `(number) -> ()` | Yes | Callback function armazenada no Lua registry. Quando o slider muda durante o rendering, ela e chamada depois com o valor numerico atualizado. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `window` | `ImGuiWindow` | A mesma ImGuiWindow object, permitindo chamadas de method encadeadas. |
