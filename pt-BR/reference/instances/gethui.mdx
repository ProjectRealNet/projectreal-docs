Retorna game:CoreGui lookup.RobloxGui. A function nao recebe arguments. Se CoreGui lookup retornar nil, ou se RobloxGui nesse valor for nil, a function retorna nil. A function nao cria um container e nao usa o valor em cache CoreGui.

## Sintaxe

```lua
gethui(): Instance | nil
```

## Aliases

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | O valor RobloxGui lido de CoreGui, ou nil quando CoreGui ou RobloxGui esta indisponivel. |
