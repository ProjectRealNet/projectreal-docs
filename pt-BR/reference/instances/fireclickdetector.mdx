description: "Dispara uma interacao ClickDetector para o jogador local. O primeiro argumento deve ser uma Instance cujo ClassName seja ClickDetector. distance e opcional e o padrao e 0. clickOption e opcional, comparado sem diferenciar maiusculas de minusculas, e o padrao e \"mouseclick\". As opcoes aceitas sao \"mouseclick\", \"rightmouseclick\", \"mousehoverenter\" e \"mousehoverleave\". As opcoes de clique passam distance como float para o Roblox click helper, enquanto as opcoes hover ignoram distance. Se Players ou Players.LocalPlayer nao estiver disponivel, a function retorna sem disparar nada. Um clickOption desconhecido tambem nao gera interacao. A function nao retorna nada."

<div className="real-function-page">

```lua
fireclickdetector(detector: Instance, distance?: number, clickOption?: "mouseclick" | "rightmouseclick" | "mousehoverenter" | "mousehoverleave")
```

## Argumentos

<ParamField path={"detector"} type={"Instance"} required>
Instance cujo ClassName deve ser ClickDetector.
</ParamField>

<ParamField path={"distance"} type={"number"}>
Valor distance opcional. O padrao e 0 e e passado como float para "mouseclick" e "rightmouseclick".
</ParamField>

<ParamField path={"clickOption"} type={"\"mouseclick\" | \"rightmouseclick\" | \"mousehoverenter\" | \"mousehoverleave\""}>
Seletor interaction opcional. E lido como string, comparado sem diferenciar maiusculas de minusculas, e o padrao e "mouseclick".
</ParamField>

## Exemplo

Dispara a interaction "mouseclick" padrao em um ClickDetector.

```lua
local detector = workspace.InteractivePart.ClickDetector

fireclickdetector(detector)
```
