description: "Dispara o Real touch interest event para duas BasePart instances. Os dois primeiros argumentos devem ser Instance object e ambos os valores devem passar em IsA(\"BasePart\"). O argumento state e obrigatorio e deve ser number ou boolean. Quando state e number, somente 1 vira true e qualquer outro number vira false. Quando state e boolean, seu valor boolean e passado diretamente. Se qualquer part nao tiver touch data, ou se a primeira part nao tiver overlap reference, a function retorna sem disparar nada. A function nao retorna nada. O significado exato begin/end do boolean passado ao helper e: Nicht aus der Codebasis verifizierbar."

<div className="real-function-page">

```lua
firetouchinterest(partA: Instance, partB: Instance, state: number | boolean)
```

## Aliases

- `firetouchtransmitter`

## Argumentos

<ParamField path={"partA"} type={"Instance"} required>
Primeira Instance object. Deve passar em IsA("BasePart"). Seu touch data e overlap reference sao usados no call.
</ParamField>

<ParamField path={"partB"} type={"Instance"} required>
Segunda Instance object. Deve passar em IsA("BasePart"). Seu touch data e usado no call.
</ParamField>

<ParamField path={"state"} type={"number | boolean"} required>
Valor state obrigatorio. Numbers sao convertidos com state == 1; booleans sao passados diretamente.
</ParamField>

## Exemplo

Passa dois valores BasePart e um valor state explicito para firetouchinterest.

```lua
local players = game:GetService("Players")
local character = players.LocalPlayer.Character or players.LocalPlayer.CharacterAdded:Wait()
local rootPart = character:WaitForChild("HumanoidRootPart")
local targetPart = workspace.TouchTarget

firetouchinterest(rootPart, targetPart, true)
```
