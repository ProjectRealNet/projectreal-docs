Se ClassName nao for \"ProximityPrompt\", gera \"ProximityPrompt expected\". A function nao recebe optional arguments e nao retorna nada."

<div className="real-function-page">

```lua
fireproximityprompt(prompt: Instance)
```

## Argumentos

<ParamField path={"prompt"} type={"Instance"} required>
Instance cujo ClassName deve ser ProximityPrompt.
</ParamField>

## Exemplo

Dispara um ProximityPrompt com o unico argumento obrigatorio.

```lua
local prompt = workspace.InteractivePart.ProximityPrompt

fireproximityprompt(prompt)
```
