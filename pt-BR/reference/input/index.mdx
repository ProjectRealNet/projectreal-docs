Eventos de entrada de teclado e mouse.

| Navegação de funções | Descrição |
| --- | --- |
| [`isrbxactive`](./isrbxactive) | Retorna se a current foreground window e a Roblox window encontrada pela Real. Real encontra essa janela fazendo enumerating windows do processo atual e selecionando uma window cujo class name e Roblox window. A function nao recebe arguments e retorna false quando nao ha foreground window ou matching Roblox window disponivel. |
| [`keyclick`](./keyclick) | Envia um key down event seguido de um key up event quando a Roblox window esta ativa. O argumento keyCode e verificado como Lua number, convertido com integer conversion, mapeado de Windows virtual-key code para scan code com Windows key mapping, e enviado por keyboard input com KEYEVENTF_SCANCODE. Se isrbxactive seria false, a function retorna sem enviar input. |
| [`keypress`](./keypress) | Envia um key down event quando a Roblox window esta ativa. O argumento keyCode e verificado como Lua number, convertido com integer conversion, mapeado de Windows virtual-key code para scan code com Windows key mapping, e enviado por keyboard input com KEYEVENTF_SCANCODE. Esta function nao envia um key up event. Se isrbxactive seria false, a function retorna sem enviar input. |
| [`keyrelease`](./keyrelease) | Envia um key up event quando a Roblox window esta ativa. O argumento keyCode e verificado como Lua number, convertido com integer conversion, mapeado de Windows virtual-key code para scan code com Windows key mapping, e enviado por keyboard input com KEYEVENTF_SCANCODE \| KEYEVENTF_KEYUP. Esta function nao envia um key down event. Se isrbxactive seria false, a function retorna sem enviar input. |
| [`mouse1click`](./mouse1click) | Envia um left mouse down event e um left mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada e volta sem enviar input quando isrbxactive seria false. |
| [`mouse1press`](./mouse1press) | Envia um left mouse down event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada, nao envia um left mouse up event correspondente e volta sem enviar input quando isrbxactive seria false. |
| [`mouse1release`](./mouse1release) | Envia um left mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada, nao envia um left mouse down event correspondente e volta sem enviar input quando isrbxactive seria false. |
| [`mouse2click`](./mouse2click) | Envia um right mouse down event e um right mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada e volta sem enviar input quando isrbxactive seria false. |
| [`mouse2press`](./mouse2press) | Envia um right mouse down event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada, nao envia um right mouse up event correspondente e volta sem enviar input quando isrbxactive seria false. |
| [`mouse2release`](./mouse2release) | Envia um right mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada, nao envia um right mouse down event correspondente e volta sem enviar input quando isrbxactive seria false. |
| [`mousemoveabs`](./mousemoveabs) | Move o mouse usando Windows absolute mouse input quando a Roblox window esta ativa. Os argumentos x e y sao verificados como Lua numbers e convertidos com integer conversion. Real os trata como coordenadas relative to active foreground window client area, adiciona a screen position dessa client area com ClientToScreen, escala usando GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) - 1 e integer math, e entao chama mouse input com the requested mouse action. Se isrbxactive seria false, a function retorna sem enviar input. |
| [`mousemoverel`](./mousemoverel) | Move o mouse por um relative delta quando a Roblox window esta ativa. Os argumentos x e y sao verificados como Lua numbers e convertidos com integer conversion, depois passados diretamente para mouse input com the requested mouse action como dx e dy. A function nao usa the requested mouse action, nao faz client-area conversion, nao retorna nada e volta sem enviar input quando isrbxactive seria false. |
| [`mousescroll`](./mousescroll) | Envia um mouse wheel event quando a Roblox window esta ativa. O argumento amount e verificado como Lua number, convertido com integer conversion e passado diretamente como valor dwData para mouse input com the requested mouse action. Real nao normaliza amount nem adiciona movement data. A function nao retorna nada e volta sem enviar input quando isrbxactive seria false. |
