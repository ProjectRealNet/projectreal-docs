Envia um right mouse down event e um right mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada e volta sem enviar input quando isrbxactive seria false.

## Sintaxe

```lua
mouse2click()
```
