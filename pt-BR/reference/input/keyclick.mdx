O argumento keyCode e verificado como Lua number, convertido com integer conversion, mapeado de Windows virtual-key code para scan code com Windows key mapping, e enviado por keyboard input com KEYEVENTF_SCANCODE. Se isrbxactive seria false, a function retorna sem enviar input."
