Envia um left mouse up event quando a Roblox window esta ativa. Real chama mouse input com the requested mouse action e sem movement ou wheel data. A function nao recebe arguments, nao retorna nada, nao envia um left mouse down event correspondente e volta sem enviar input quando isrbxactive seria false.

## Sintaxe

```lua
mouse1release()
```
