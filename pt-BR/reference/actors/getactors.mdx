---
title: "getactors"
sidebarTitle: "getactors"
description: "Retorna uma array table de live Actor Instances resolvidas a partir da ScriptContext actor thread list. A function não recebe arguments. Ela percorre a actor thread list, descriptografa cada actor Lua state, mantém entries que são valid threads e então lê o thread data e a the associated Actor weak reference de cada thread. Apenas non-expired actor references são enviadas como Instances. Entries sem container, sem Actor reference, com reference count <= 0 ou com expired actor reference são ignoradas."
keywords: ["getactors","Actors"]
---

<div className="real-function-page">

```lua
getactors(): {Instance}
```

## Retornos

<ResponseField name={"actors"} type={"{Instance}"}>
Array table de Actor Instances cujas actor weak references ainda são valid.
</ResponseField>

## Exemplo

List live Actor Instances resolved from actor threads.

```lua
for _, actor in ipairs(getactors()) do
    print(actor)
end
```
