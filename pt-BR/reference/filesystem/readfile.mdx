Le um existing regular file dentro do workspace em binary mode e retorna seus bytes como Lua string.

## Sintaxe

```lua
readfile(path: string): string
```

## Aliases

- `readfileasync`

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `path` | `string` | Yes | File path resolvido dentro do workspace apos separator normalization, workspace-boundary checks e filename/extension checks. Absolute paths so sao aceitos se resolverem dentro do workspace. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `content` | `string` | File contents sao retornados como Lua string com comprimento explicito. Bytes como null bytes, line endings e BOM bytes nao sao transformados por readfile. |

## Exemplo

Leia bytes de um existing workspace file.

```lua
local path = "examples/config.json"
writefile(path, '{"enabled":true}')

local content = readfile(path)
print(content)
print(#content)
```
