<div className="real-function-page">

```lua
makefolder(path: string)
```

## Argumentos

<ParamField path={"path"} type={"string"} required>
Directory path resolvido dentro do workspace apos separator normalization e workspace-boundary checks. Empty, invalid ou outside-workspace paths geram error antes da tentativa de criacao.
</ParamField>

## Exemplo

Crie um workspace directory e quaisquer missing parent directories.

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
