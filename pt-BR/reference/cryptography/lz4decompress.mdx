```lua
lz4decompress(data: string, originalSize?: number): string
```

## Aliases

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes passados para LZ4 block decompression.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size passado como dstCapacity. Para a saida de lz4compress, passe o tamanho original descompactado em bytes; quando omitido, o tamanho da entrada compactada e usado.
</ParamField>

## Retornos

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes retornados como uma string Lua. A saida pode ser menor que originalSize.
</ResponseField>

## Exemplo

Descompacte LZ4 bytes passando o tamanho original descompactado.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
