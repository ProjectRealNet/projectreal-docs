<div className="real-function-page">

```lua
crypt.generatebytes(size: number): string
```

## Argumentos

<ParamField path={"size"} type={"number"} required>
Numero passado por integer conversion antes da alocacao. Valores menores ou iguais a 0 sao alterados para 1.
</ParamField>

## Retornos

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding dos raw bytes gerados. O comprimento da string retornada nao e a contagem de bytes solicitada.
</ResponseField>

## Exemplo

Gere bytes e decodifique o resultado Base64 quando raw bytes forem necessarios.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
