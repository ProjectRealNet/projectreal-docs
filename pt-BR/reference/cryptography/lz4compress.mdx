<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## Aliases

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Bytes da string Lua passados para LZ4 block compression.
</ParamField>

## Retornos

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes retornados como uma string Lua. O original size nao e armazenado na saida.
</ResponseField>

## Exemplo

Comprima bytes de uma string Lua e restaure-os passando o original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
