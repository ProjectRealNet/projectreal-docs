```lua
base64_decode(data: string): string
```

## Aliases

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Argumentos

<ParamField path={"data"} type={"string"} required>
Entrada Base64 passada para Base64 decoder.
</ParamField>

## Retornos

<ResponseField name={"decoded"} type={"string"}>
Bytes decodificados retornados como uma string Lua com comprimento explicito.
</ResponseField>

## Exemplo

Decodifique dados Base64 e leia a string Lua retornada.

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
