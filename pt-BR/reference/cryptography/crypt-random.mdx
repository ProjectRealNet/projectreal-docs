Gera raw random bytes com random byte generator e os retorna como uma string Lua.

## Sintaxe

```lua
crypt.random(size: number): string
```

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Numero passado por integer conversion antes da alocacao. Valores menores ou iguais a 0 geram um argument error. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes retornados como uma string Lua. O comprimento da string retornada corresponde a contagem de bytes alocada. |

## Exemplo

Gere raw bytes e imprima o comprimento da string Lua retornada.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
