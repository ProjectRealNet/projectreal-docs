<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Argumentos

<ParamField path={"size"} type={"number"} required>
Numero passado por integer conversion antes da alocacao. Valores menores ou iguais a 0 geram um argument error.
</ParamField>

## Retornos

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes retornados como uma string Lua. O comprimento da string retornada corresponde a contagem de bytes alocada.
</ResponseField>

## Exemplo

Gere raw bytes e imprima o comprimento da string Lua retornada.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
