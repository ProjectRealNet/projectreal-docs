<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumentos

<ParamField path={"key"} type={"string"} required>
Bytes de raw Lua string usados como HMAC key. A key nao e Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Bytes da string Lua passados para HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Nome do HMAC algorithm case-sensitive. O padrao e sha256.
</ParamField>

## Retornos

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output sem line breaks.
</ResponseField>

## Exemplo

Calcule um Base64 HMAC output a partir de uma raw Lua string key e data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
