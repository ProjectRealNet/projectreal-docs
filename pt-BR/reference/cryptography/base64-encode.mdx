## Argumentos

<ParamField path={"data"} type={"string"} required>
Bytes da string Lua passados para Base64 encoder.
</ParamField>

## Retornos

<ResponseField name={"encoded"} type={"string"}>
Saida Base64 retornada como uma string Lua.
</ResponseField>

## Exemplo

Codifique uma string Lua e imprima a saida Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))

```
