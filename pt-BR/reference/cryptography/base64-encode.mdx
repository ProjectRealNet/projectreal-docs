Codifica os bytes de uma string Lua com Base64 encoder, usando = padding e sem quebras de linha.

## Sintaxe

```lua
base64_encode(data: string): string
```

## Aliases

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Argumentos

| Name | Type | Required | Descrição |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Bytes da string Lua passados para Base64 encoder. |

## Retornos

| Name | Type | Descrição |
| --- | --- | --- |
| `encoded` | `string` | Saida Base64 retornada como uma string Lua. |

## Exemplo

Codifique uma string Lua e imprima a saida Base64.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
