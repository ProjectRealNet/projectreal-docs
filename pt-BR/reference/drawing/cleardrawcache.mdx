---
title: "cleardrawcache"
sidebarTitle: "cleardrawcache"
description: "Limpa a Real global Drawing object list. Cada Drawing object rastreado e marcado como destroyed, image resources sao liberados quando existem, e a object list e esvaziada. Lua references existentes para Drawing objects limpos ainda podem existir, mas os objects nao sao mais considerados active Drawing objects. the Drawing API registra esta API somente quando the required rendering environment is active e true; quando essa verificacao e false, o initializer retorna antes de criar estes globals."
keywords: ["cleardrawcache","Drawing"]
---

<div className="real-function-page">

```lua
cleardrawcache()
```

## Exemplo

Clear every Drawing object currently tracked by Real.

```lua
local square = Drawing.new("Square")
square.Visible = true

cleardrawcache()
print(square.Visible)
```
