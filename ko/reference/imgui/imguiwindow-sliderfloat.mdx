ImGui가 변경된 값을 보고하면 onChange는 queue에 들어가고 나중에 하나의 Lua number로 호출됩니다. Real은 이 closure에서 별도의 minimum <= maximum 검사를 추가하지 않습니다."

<div className="real-function-page">

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## 인수

<ParamField path={"window"} type={"ImGuiWindow"} required>
imgui.create가 반환한 ImGuiWindow입니다. object가 유효하지 않거나 이미 destroy된 경우 method는 Lua error를 발생시킵니다.
</ParamField>

<ParamField path={"label"} type={"string"} required>
string type checking으로 읽는 slider label입니다.
</ParamField>

<ParamField path={"value"} type={"number"} required>
number type checking로 읽고 현재 float 값으로 저장하는 slider 초기값입니다.
</ParamField>

<ParamField path={"minimum"} type={"number"} required>
number type checking로 읽고 a floating-point slider에 전달하는 minimum value입니다.
</ParamField>

<ParamField path={"maximum"} type={"number"} required>
number type checking로 읽고 a floating-point slider에 전달하는 maximum value입니다.
</ParamField>

<ParamField path={"onChange"} type={"(number) -> ()"} required>
Lua registry에 저장되는 callback function입니다. rendering 중 slider가 변경되면 나중에 업데이트된 숫자 값으로 호출됩니다.
</ParamField>

## 반환값

<ResponseField name={"window"} type={"ImGuiWindow"}>
동일한 ImGuiWindow object이며 method 호출을 체인으로 연결할 수 있습니다.
</ResponseField>

## 타입

### ImGuiWindow

imgui.create에서 반환된 핸들입니다. 컨트롤 구축 메서드는 동일한 핸들을 반환하므로 호출을 연결할 수 있습니다.

| Name | Type | Required | 설명 |
| --- | --- | --- | --- |

| `Checkbox` | `(label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow` | Yes | 제공된 상태에 초기화된 체크박스를 추가합니다. |
| `CollapsingHeader` | `(label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow` | Yes | 접는 헤더 아래에 콘텐츠 콜백이 추가된 그룹 컨트롤입니다. |
| `ColorPicker` | `(label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow` | Yes | RGBA 편집기를 추가합니다. 생략된 색상 구성 요소의 기본값은 1.0입니다. |
| `InputText` | `(label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow` | Yes | 한 줄 텍스트 입력을 추가합니다. 생략된 초기 텍스트의 기본값은 빈 문자열입니다. |
| `SameLine` | `() -> ImGuiWindow` | Yes | 같은 줄에 다음 컨트롤을 배치합니다. |

| `SliderFloat` | `(label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow` | Yes | 부동 소수점 슬라이더를 추가합니다. |
| `SliderInt` | `(label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow` | Yes | 정수 슬라이더를 추가합니다. |
| `Text` | `(text: string) -> ImGuiWindow` | Yes | 비대화형 텍스트를 추가합니다. |
| `destroy` | `() -> ()` | Yes | 창을 제거하고 등록된 콜백을 해제합니다. |
