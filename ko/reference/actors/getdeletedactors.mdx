thread data에 Actor reference가 있고 reference count가 0보다 크며 the associated Actor가 expired weak reference인 actor list의 Luau threads array table을 반환합니다. 이 function은 arguments를 받지 않습니다. Actor Instance values를 반환하지 않습니다.

## 문법

```lua
getdeletedactors(): table
```

## 반환값

| Name | Type | 설명 |
| --- | --- | --- |
| `threads` | `table` | Actor weak reference가 expired인 actor entries의 Luau thread values를 포함하는 array table입니다. |

## 예제

List actor threads whose Actor weak reference is expired.

```lua
local deletedActorThreads = getdeletedactors()

for _, thread in ipairs(deletedActorThreads) do
    print(thread)
end
```
