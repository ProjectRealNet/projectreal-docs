recursive folder creation로 missing parent directories를 포함해 workspace 안에 directory를 생성합니다.

## 문법

```lua
makefolder(path: string)
```

## 인수

| Name | Type | Required | 설명 |
| --- | --- | --- | --- |
| `path` | `string` | Yes | separator normalization 및 workspace-boundary checks 후 workspace 안에서 해석되는 directory path입니다. empty, invalid 또는 outside-workspace paths는 생성 시도 전에 error를 발생시킵니다. |

## 예제

workspace directory와 missing parent directories를 생성합니다.

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
