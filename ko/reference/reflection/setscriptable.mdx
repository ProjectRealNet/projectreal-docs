GameIndexHook 및 GameNewIndexHook은 나중에 이 cache를 사용하여 단일 indexed read 또는 write 동안 property field scriptable flag를 임시로 설정한 뒤 previous field flag를 복원합니다."

<div className="real-function-page">

```lua
setscriptable(instance: Instance, property: string, value: boolean): boolean | nil
```

## 인수

<ParamField path={"instance"} type={"Instance"} required>
scriptable override cache key의 일부로 사용되는 Instance object.
</ParamField>

<ParamField path={"property"} type={"string"} required>
cache miss 시 Roblox property metadata 및 Instance class descriptor로 해석되는 property name.
</ParamField>

<ParamField path={"value"} type={"boolean"} required>
scriptable override cache에 저장할 scriptable override value.
</ParamField>

## 반환값

<ResponseField name={"previousState"} type={"boolean | nil"}>
Previous cached scriptable value, previous scriptable state value, 또는 property가 property entry로 해석되지 않으면 nil입니다.
</ResponseField>

## 예제

Temporarily change whether a property is scriptable, then restore the previous state when available.

```lua
local previous = setscriptable(workspace, "Name", true)
print(previous)

if previous ~= nil then
    setscriptable(workspace, "Name", previous)
end
```
