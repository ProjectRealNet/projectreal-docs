<div className="real-function-page">

```lua
HttpGet(context: DataModel, url: string, noCache?: boolean | number): string
```

## 인수

<ParamField path={"context"} type={"DataModel"} required>
Method-call self value. Use game:HttpGet(url, noCache) or game:HttpGetAsync(url, noCache).
</ParamField>

<ParamField path={"url"} type={"string"} required>
URL string to request.
</ParamField>

<ParamField path={"noCache"} type={"boolean | number"}>
Optional cache bypass. true or numeric 1 skips an existing cached response and performs a new request.
</ParamField>

## 반환값

<ResponseField name={"body"} type={"string"}>
Downloaded response body string, cached body string, or an empty string when the request cannot be opened.
</ResponseField>

## 예제

Run a DataModel-style GET request and return the response body string.

```lua
local body = game:HttpGet("https://example.com", true)
print(body)
```
