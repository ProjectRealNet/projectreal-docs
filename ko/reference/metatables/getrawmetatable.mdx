<div className="real-function-page">

```lua
getrawmetatable(target: any): table | nil
```

## 별칭

- `debug.getmetatable`

## 인수

<ParamField path={"target"} type={"any"} required>
Value whose metatable is returned.
</ParamField>

## 반환값

<ResponseField name={"metatable"} type={"table | nil"}>
Target metatable when present; otherwise nil.
</ResponseField>

## 예제

Return the metatable currently attached to a value.

```lua
local target = {}
local meta = {
    label = "Real",
}

setrawmetatable(target, meta)

print(getrawmetatable(target) == meta)
print(debug.getmetatable(target) == meta)
```
