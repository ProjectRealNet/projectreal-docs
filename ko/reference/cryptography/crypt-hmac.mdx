Raw Lua string key를 사용해 Lua string 바이트에 crypto library HMAC을 계산하고 Base64 digest를 반환합니다.

## 문법

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## 인수

| Name | Type | Required | 설명 |
| --- | --- | --- | --- |
| `key` | `string` | Yes | HMAC key로 사용되는 raw Lua string 바이트입니다. key는 Base64-decode되지 않습니다. |
| `data` | `string` | Yes | HMAC calculation에 전달되는 Lua string 바이트입니다. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Case-sensitive HMAC algorithm 이름입니다. 기본값은 sha256입니다. |

## 반환값

| Name | Type | 설명 |
| --- | --- | --- |
| `digest` | `string` | line breaks가 없는 Base64-encoded HMAC output입니다. |

## 예제

raw Lua string key와 data에서 Base64 HMAC output을 계산합니다.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
