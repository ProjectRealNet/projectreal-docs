<div className="real-function-page">

```lua
restorefunction(firstFunction: function, secondFunction?: function)
```

## 별칭

- `restorefunc`
- `restoreclosure`

## 인수

<ParamField path={"firstFunction"} type={"function"} required>
argument 하나에서는 hook records에서 복원할 hooked closure입니다. function second argument가 있으면 secondFunction에 설치할 function입니다.
</ParamField>

<ParamField path={"secondFunction"} type={"function"}>
firstFunction으로 patch할 optional closure입니다. 이 branch는 second argument가 function일 때만 사용됩니다.
</ParamField>

## 예제

Restore a hooked closure to its original function.

```lua
local function target()
    return "original"
end

hookfunction(target, function()
    return "hooked"
end)

print(target())

restorefunction(target)

print(target())
```
