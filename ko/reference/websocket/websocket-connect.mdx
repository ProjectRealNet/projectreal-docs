```lua
WebSocket.connect(url: string): WebSocket
```

## 별칭

- `WebSocket.Connect`
- `websocket.connect`
- `websocket.Connect`

## 인수

<ParamField path={"url"} type={"string"} required>
WebSocket client이 WebSocket connection attempt를 수행하기 전에 CURLOPT_URL에 전달되는 URL string입니다.
</ParamField>

## 반환값

<ResponseField name={"socket"} type={"WebSocket"}>
OnMessage, OnClose, connection state를 포함하는 WebSocket table입니다. Send와 Close는 WebSocket object methods을 통해 resolve됩니다.
</ResponseField>

## 예제

WebSocket을 열고 OnMessage 및 OnClose를 연결한 다음 socket methods로 보내고 닫습니다.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket.OnMessage:Connect(function(message)
    print(message)
end)

socket.OnClose:Connect(function()
    print("closed")
end)

socket:Send("hello")
socket:Close()
```
