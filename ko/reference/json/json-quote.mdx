```lua
json.quote(text: string): string
```

## 인수

<ParamField path={"text"} type={"string"} required>
Quote할 string입니다. function은 이 argument를 string type checking으로 읽습니다.
</ParamField>

## 반환값

<ResponseField name={"quoted"} type={"string"}>
Opening 및 closing quote를 포함하는 complete JSON string literal입니다. Quotes, backslashes, common control characters, bytes below 0x20은 escape됩니다.
</ResponseField>

## 예제

String을 complete quoted JSON string literal로 convert합니다.

```lua
local source = "Real Docs" .. string.char(10) .. [[Documentation "A"]]
local quoted = json.quote(source)

print(quoted)
```
