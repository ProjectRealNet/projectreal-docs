table의 direct values를 JSON array로 marked된 새 table로 반환합니다. JSON type marker entries는 건너뜁니다.

## 문법

```lua
json.values(object: table): table
```

## 인수

| Name | Type | Required | 설명 |
| --- | --- | --- | --- |
| `object` | `table` | Yes | enumerate할 table입니다. function은 이 argument를 type checking으로 검사합니다. |

## 반환값

| Name | Type | 설명 |
| --- | --- | --- |
| `values` | `table` | input table의 direct values를 포함하는 new array-style table입니다. output은 JSON array로 marked됩니다. Enumeration은 table iteration를 사용하므로 function에서 ordering guarantee는 보이지 않습니다. |

## 예제

table의 direct values를 JSON array-marked table로 모읍니다.

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
