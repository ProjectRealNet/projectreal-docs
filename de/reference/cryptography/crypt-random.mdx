<div className="real-function-page">

```lua
crypt.random(size: number): string
```

## Argumente

<ParamField path={"size"} type={"number"} required>
Zahl, die vor der Allocation durch integer conversion laeuft. Werte kleiner oder gleich 0 werfen einen argument error.
</ParamField>

## Rückgaben

<ResponseField name={"bytes"} type={"string"}>
Raw generated bytes, die als Lua-String zurueckgegeben werden. Die zurueckgegebene String-Laenge entspricht der allozierten Byte-Anzahl.
</ResponseField>

## Beispiel

Erzeuge raw bytes und gib die Laenge des zurueckgegebenen Lua-Strings aus.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
