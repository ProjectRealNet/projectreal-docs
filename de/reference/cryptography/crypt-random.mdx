Erzeugt raw random bytes mit random byte generator und gibt sie als Lua-String zurueck.

## Syntax

```lua
crypt.random(size: number): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Zahl, die vor der Allocation durch integer conversion laeuft. Werte kleiner oder gleich 0 werfen einen argument error. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes, die als Lua-String zurueckgegeben werden. Die zurueckgegebene String-Laenge entspricht der allozierten Byte-Anzahl. |

## Beispiel

Erzeuge raw bytes und gib die Laenge des zurueckgegebenen Lua-Strings aus.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
