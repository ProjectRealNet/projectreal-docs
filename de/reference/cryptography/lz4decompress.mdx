<div className="real-function-page">

```lua
lz4decompress(data: string, originalSize?: number): string
```

## Aliase

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Argumente

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes, die an LZ4 block decompression uebergeben werden.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size, die als dstCapacity uebergeben wird. Fuer lz4compress output die originale unkomprimierte Byte-Laenge uebergeben; wenn ausgelassen, wird die komprimierte Eingabelaenge verwendet.
</ParamField>

## Rückgaben

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes als Lua-String. Die Ausgabe kann kuerzer als originalSize sein.
</ResponseField>

## Beispiel

Dekomprimiere LZ4 bytes, indem du die originale unkomprimierte Groesse uebergibst.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
