<div className="real-function-page">

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argumente

<ParamField path={"data"} type={"string"} required>
Lua-String-Bytes, die an crypto library HashFilter uebergeben werden.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\" | \"sha3-224\" | \"sha3-256\" | \"sha3-384\" | \"sha3-512\""}>
Case-sensitive hash Algorithmusname. Standard ist sha256.
</ParamField>

## Rückgaben

<ResponseField name={"digest"} type={"string"}>
Lowercase hexadecimal digest ohne Prefix oder Separatoren.
</ResponseField>

## Beispiel

Hashe Lua-String-Bytes mit dem Standardalgorithmus oder einem expliziten unterstuetzten Namen.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
