Hasht Lua-String-Bytes mit einem unterstuetzten crypto library hash Algorithmus und gibt einen lowercase hexadecimal digest zurueck.

## Syntax

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Lua-String-Bytes, die an crypto library HashFilter uebergeben werden. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Case-sensitive hash Algorithmusname. Standard ist sha256. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest ohne Prefix oder Separatoren. |

## Beispiel

Hashe Lua-String-Bytes mit dem Standardalgorithmus oder einem expliziten unterstuetzten Namen.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
