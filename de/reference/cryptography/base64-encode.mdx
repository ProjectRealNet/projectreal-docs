Kodiert die Bytes eines Lua-Strings mit Base64 encoder, mit = padding und ohne Zeilenumbrueche.

## Syntax

```lua
base64_encode(data: string): string
```

## Aliase

- `base64encode`
- `base64.encode`
- `crypt.base64.encode`
- `crypt.base64_encode`
- `crypt.base64encode`

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Lua-String-Bytes, die an Base64 encoder uebergeben werden. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `encoded` | `string` | Base64-Ausgabe, die als Lua-String zurueckgegeben wird. |

## Beispiel

Kodiere einen Lua-String und gib die Base64-Ausgabe aus.

```lua
local encoded = base64_encode("hello world")

print(encoded)
print(base64encode("hello world"))
print(base64.encode("hello world"))
```
