```lua
crypt.generatekey(): string
```

## Rückgaben

<ResponseField name={"key"} type={"string"}>
Base64 encoding der erzeugten 32 raw bytes. Der zurueckgegebene String ist nicht 32 Zeichen lang.
</ResponseField>

## Beispiel

Erzeuge einen Base64-Key und dekodiere ihn, um die raw byte Anzahl zu pruefen.

```lua
local key = crypt.generatekey()
local raw = base64_decode(key)

local ciphertext, iv = crypt.encrypt("hello world", key)

print(key)
print(#raw)
print(ciphertext, iv)
```
