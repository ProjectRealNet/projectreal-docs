<div className="real-function-page">

```lua
crypt.encrypt(data: string, key: string, iv?: string, mode?: "CBC" | "ECB" | "CTR" | "AES-CBC" | "AES-ECB" | "AES-CTR"): string | string | nil
```

## Argumente

<ParamField path={"data"} type={"string"} required>
Plaintext-Bytes, die aus einem Lua-String gelesen werden.
</ParamField>

<ParamField path={"key"} type={"string"} required>
Base64-Key, der dekodiert wird, bevor er an AES uebergeben wird.
</ParamField>

<ParamField path={"iv"} type={"string"}>
Optionales Base64 IV fuer CBC oder CTR. Wenn es bei CBC oder CTR fehlt, wird ein neues IV in AES block size erzeugt.
</ParamField>

<ParamField path={"mode"} type={"\"CBC\" | \"ECB\" | \"CTR\" | \"AES-CBC\" | \"AES-ECB\" | \"AES-CTR\""}>
AES mode. Der Prefix AES- wird entfernt, wenn er vorhanden ist. Standard ist AES-CBC. CBC und ECB verwenden crypto library DEFAULT_PADDING; CTR verwendet kein padding.
</ParamField>

## Rückgaben

<ResponseField name={"ciphertext"} type={"string"}>
Base64-encoded ciphertext.
</ResponseField>

<ResponseField name={"initializationVector"} type={"string | nil"}>
Base64-encoded IV fuer CBC und CTR; nil fuer ECB.
</ResponseField>

## Beispiel

Verschluessle einen Lua-String und entschluessle den zurueckgegebenen ciphertext mit dem zurueckgegebenen IV.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(ciphertext)
print(iv)
print(plaintext)
```
