<div className="real-function-page">

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Argumente

<ParamField path={"data"} type={"string"} required>
Base64 ciphertext, der vor der Entschluesselung dekodiert wird.
</ParamField>

<ParamField path={"key"} type={"string"} required>
Base64-Key, der dekodiert wird, bevor er an AES uebergeben wird.
</ParamField>

<ParamField path={"iv"} type={"string"} required>
Base64 IV, der vor der mode Verarbeitung dekodiert wird. Dieses Argument ist erforderlich, auch bei ECB.
</ParamField>

<ParamField path={"mode"} type={"\"CBC\" | \"ECB\" | \"AES-CBC\" | \"AES-ECB\""}>
AES mode. Der Prefix AES- wird entfernt, wenn er vorhanden ist. Standard ist AES-CBC.
</ParamField>

## Rückgaben

<ResponseField name={"plaintext"} type={"string"}>
Plaintext-Bytes, die als Lua-String zurueckgegeben werden.
</ResponseField>

## Beispiel

Entschluessle von crypt.encrypt zurueckgegebenen ciphertext mit dem zurueckgegebenen IV.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
