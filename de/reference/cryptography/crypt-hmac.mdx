Berechnet ein crypto library HMAC ueber Lua-String-Bytes mit einem raw Lua string key und gibt einen Base64 digest zurueck.

## Syntax

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `key` | `string` | Yes | Raw Lua-String-Bytes, die als HMAC key verwendet werden. Der key wird nicht Base64-decodiert. |
| `data` | `string` | Yes | Lua-String-Bytes, die in die HMAC calculation uebergeben werden. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Case-sensitive HMAC algorithm Name. Standard ist sha256. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `digest` | `string` | Base64-encoded HMAC output ohne line breaks. |

## Beispiel

Berechne einen Base64 HMAC output aus einem raw Lua string key und data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
