<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumente

<ParamField path={"key"} type={"string"} required>
Raw Lua-String-Bytes, die als HMAC key verwendet werden. Der key wird nicht Base64-decodiert.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Lua-String-Bytes, die in die HMAC calculation uebergeben werden.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Case-sensitive HMAC algorithm Name. Standard ist sha256.
</ParamField>

## Rückgaben

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output ohne line breaks.
</ResponseField>

## Beispiel

Berechne einen Base64 HMAC output aus einem raw Lua string key und data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
