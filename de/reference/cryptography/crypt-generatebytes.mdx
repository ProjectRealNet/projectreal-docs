<div className="real-function-page">

```lua
crypt.generatebytes(size: number): string
```

## Argumente

<ParamField path={"size"} type={"number"} required>
Zahl, die vor der Allocation durch integer conversion laeuft. Werte kleiner oder gleich 0 werden auf 1 geaendert.
</ParamField>

## Rückgaben

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding der erzeugten raw bytes. Die zurueckgegebene String-Laenge ist nicht die angeforderte Byte-Anzahl.
</ResponseField>

## Beispiel

Erzeuge Bytes und dekodiere das Base64-Ergebnis, wenn raw bytes benoetigt werden.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
