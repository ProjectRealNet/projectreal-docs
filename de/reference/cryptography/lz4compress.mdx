<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## Aliase

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Argumente

<ParamField path={"data"} type={"string"} required>
Lua-String-Bytes, die an LZ4 block compression uebergeben werden.
</ParamField>

## Rückgaben

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes, die als Lua-String zurueckgegeben werden. Die original size wird nicht in der Ausgabe gespeichert.
</ResponseField>

## Beispiel

Komprimiere Lua-String-Bytes und stelle sie wieder her, indem die original size uebergeben wird.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
