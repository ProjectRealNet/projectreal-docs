Weist value an object[property] zu. Für Drawing object nutzt das dasselbe Drawing property assignment wie direct property assignment. Unknown Drawing properties werden ignoriert, und destroyed Drawing objects werden nicht geändert. Das dritte Argument muss vorhanden sein. the Drawing API registriert diese API nur, wenn the required rendering environment is active true ist; wenn diese Prüfung false ist, kehrt der initializer zurück, bevor diese globals erstellt werden.

## Syntax

```lua
setrenderproperty(object: any, property: any, value: any)
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `object` | `any` | Yes | Wert, der indiziert und beschrieben wird. Bei Drawing object wird der RealDrawingObject __newindex handler verwendet. |
| `property` | `any` | Yes | property key für die Zuweisung. Drawing object properties sind string-basiert. |
| `value` | `any` | Yes | Wert, der object[property] zugewiesen wird. Dieses Argument muss übergeben werden; nil ist weiterhin ein übergebener Wert. |

## Beispiel

Aktualisieren Sie eine Zeichnungseigenschaft über den generischen Eigenschaften-Helfer.

```lua
local line = Drawing.new("Line")
setrenderproperty(line, "Thickness", 3)
setrenderproperty(line, "Visible", true)

print(line.Thickness)
print(line.Visible)
```
