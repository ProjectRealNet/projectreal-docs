Gibt zurück, ob der Wert object mit der Drawing object type ist. Das ist nur ein methods check; es wird nicht geprüft, ob das zugrunde liegende Drawing object noch active, tracked oder destroyed ist. the Drawing API registriert diese API nur, wenn the required rendering environment is active true ist; wenn diese Prüfung false ist, kehrt der initializer zurück, bevor diese globals erstellt werden.

## Syntax

```lua
isrenderobj(object: any): boolean
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `object` | `any` | Yes | Wert, der getestet wird. Non-object values und object ohne Drawing object type geben false zurück. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `isDrawingObject` | `boolean` | True, wenn der Wert object ist und seine methods RealDrawingObject entspricht; andernfalls false. |

## Beispiel

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
