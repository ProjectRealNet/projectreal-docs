Für Drawing object nutzt das dasselbe Drawing property lookup wie object[property], daher geben unknown properties und destroyed Drawing objects nil zurück. the Drawing API registriert diese API nur, wenn the required rendering environment is active true ist; wenn diese Prüfung false ist, kehrt der initializer zurück, bevor diese globals erstellt werden."

<div className="real-function-page">

```lua
getrenderproperty(object: any, property: any): any
```

## Argumente

<ParamField path={"object"} type={"any"} required>
Wert, der indiziert wird. Bei Drawing object wird der RealDrawingObject __index handler verwendet.
</ParamField>

<ParamField path={"property"} type={"any"} required>
property key für die Indizierung. Drawing object properties sind string-basiert.
</ParamField>

## Rückgaben

<ResponseField name={"propertyValue"} type={"any"}>
Wert, der durch Indizieren von object mit property zurückgegeben wird, oder nil, wenn der Drawing __index handler keinen Wert für diese property hat.
</ResponseField>

## Beispiel

Read a Drawing property like direct indexing.

```lua
local line = Drawing.new("Line")
line.Thickness = 3

print(getrenderproperty(line, "Thickness"))
print(getrenderproperty(line, "MissingProperty"))
```
