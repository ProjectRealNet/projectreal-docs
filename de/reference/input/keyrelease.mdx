Sendet ein key up event, wenn das Roblox window aktiv ist. Das keyCode-Argument wird als Lua number geprüft, mit integer conversion konvertiert, mit Windows key mapping von einem Windows virtual-key code in einen scan code gemappt und über keyboard input mit KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP gesendet. Diese function sendet kein key down event. Wenn isrbxactive false wäre, kehrt die function zurück, ohne input zu senden.

## Syntax

```lua
keyrelease(keyCode: number)
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `keyCode` | `number` | Yes | Windows virtual-key code, gelesen als Lua number und mit integer conversion konvertiert, bevor Windows key mapping aufgerufen wird. |
