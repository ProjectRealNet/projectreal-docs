Das amount-Argument wird als Lua number geprüft, mit integer conversion konvertiert und direkt als dwData-Wert an mouse input mit the requested mouse action übergeben. Real normalisiert amount nicht und fügt keine movement data hinzu. Die function gibt nichts zurück und kehrt ohne input zurück, wenn isrbxactive false wäre."
