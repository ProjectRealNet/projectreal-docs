---
title: "keyclick"
sidebarTitle: "keyclick"
description: "Sendet ein key down event gefolgt von einem key up event, wenn das Roblox window aktiv ist. Das keyCode-Argument wird als Lua number geprüft, mit integer conversion konvertiert, mit Windows key mapping von einem Windows virtual-key code in einen scan code gemappt und über keyboard input mit KEYEVENTF_SCANCODE gesendet. Wenn isrbxactive false wäre, kehrt die function zurück, ohne input zu senden."
keywords: ["keyclick","Input","keytap"]
---

keyclick(keyCode: number)

- `keytap`

## Argumente

<ParamField path={"keyCode"} type={"number"} required>
