---
title: "mousemoveabs"
sidebarTitle: "mousemoveabs"
description: "Bewegt die Maus mit Windows absolute mouse input, wenn das Roblox window aktiv ist. Die Argumente x und y werden als Lua numbers geprüft und mit integer conversion konvertiert. Real behandelt sie als Koordinaten relative to active foreground window client area, addiert die screen position dieser client area mit ClientToScreen, skaliert sie mit GetSystemMetrics(SM_CXSCREEN/SM_CYSCREEN) - 1 und integer math und ruft dann mouse input mit the requested mouse action auf. Wenn isrbxactive false wäre, kehrt die function zurück, ohne input zu senden."
keywords: ["mousemoveabs","Input"]
---

<div className="real-function-page">

```lua
mousemoveabs(x: number, y: number)
```

## Argumente

<ParamField path={"x"} type={"number"} required>
Client-area X coordinate, gelesen als Lua number und mit integer conversion konvertiert, bevor screen-position und absolute-input scaling angewendet werden.
</ParamField>

<ParamField path={"y"} type={"number"} required>
Client-area Y coordinate, gelesen als Lua number und mit integer conversion konvertiert, bevor screen-position und absolute-input scaling angewendet werden.
</ParamField>
