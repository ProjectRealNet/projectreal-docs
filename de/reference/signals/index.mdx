Signalverbindungen und Ereignisweiterleitung.

## Verfügbare Funktionen

<CardGroup cols={2}>
<Card title="cansignalreplicate" href="./cansignalreplicate">
Prüft, ob ein RBXScriptSignal über den aktuellen NetworkClient replication layer legal gesendet werden darf. Die function validiert das erste argument als RBXScriptSignal, liest source instance und event descriptor des Signals und gibt dann das boolean-Ergebnis von replication layer signal replication validation zurück. Wenn der aufgelöste replication layer-referencewert 0 ist, gibt sie false zurück. Zusätzliche arguments werden nicht gelesen. Diese function prüft das signal nur und feuert oder repliziert es nicht. Die von getsignalwhitelist zurückgegebene whitelist-Tabelle wird in diesem Codepfad nicht verwendet.
</Card>
<Card title="firesignal" href="./firesignal">
Runs the local connections for an RBXScriptSignal with the provided arguments. The first argument must be a valid signal. Invalid signal values raise an error.
</Card>
<Card title="getconnections" href="./getconnections">
Gibt eine array table von RealConnection closures für ein RBXScriptSignal zurück. Das erste argument muss object sein, dessen Luau type name RBXScriptSignal ist. Die function liest die Connect method des signal, verbindet einen temporary blank callback, liest die linked list ab dem next reference der temporären Verbindung, trennt die temporäre Verbindung und wrapped jeden gültigen connection reference. Wenn nach der temporären Verbindung kein connection reference gefunden wird, gibt sie eine leere table zurück. Bereits gewrappte underlying references können dieselbe cached closure table zurückgeben. getsignals und get_signal_cons sind aliases für dieselbe function.
</Card>
<Card title="getsignalarguments" href="./getsignalarguments">
Gibt eine array table von type names zurück, die aus der event descriptor signature eines RBXScriptSignal gelesen werden. Das erste argument muss object sein, dessen Luau type name RBXScriptSignal ist. Die function liest den event descriptor des signal, läuft mit dem argument stride der function durch die signature slots, liest für jeden slot den argument type reference und gibt den aufgelösten type name string für jeden slot aus. Sie gibt keine captured runtime argument values zurück. Wenn die signature nicht gelesen werden kann oder keine entries eingefügt werden, enthält die zurückgegebene table einen fallback entry: "Variant".
</Card>
<Card title="getsignalargumentsinfo" href="./getsignalargumentsinfo">
Gibt eine array table mit Argumentinformationen aus einer RBXScriptSignal-Signatur zurück. Die Funktion gibt keine erfassten Laufzeit-Argumentwerte zurück.
</Card>
<Card title="getsignalwhitelist" href="./getsignalwhitelist">
Gibt eine neue array table mit den sechs statischen whitelist-Einträgen zurück, die in der function definiert sind: OnClientEvent/RemoteEvent, OnServerEvent/RemoteEvent, OnClientInvoke/RemoteFunction, OnServerInvoke/RemoteFunction, OnClientEventUnreliable/UnreliableRemoteEvent, and OnServerEventUnreliable/UnreliableRemoteEvent. Jeder entry ist eine table mit den string-Feldern Event und Parent. Die function nimmt keine arguments an und prüft nicht den aktuellen Spielzustand.
</Card>
<Card title="replicatesignal" href="./replicatesignal">
Ruft den replication path für ein RBXScriptSignal auf. Die Funktion liest die signal signature, konvertiert übergebene Lua arguments in Roblox signal values für jeden signature type, kürzt zusätzliche Lua arguments nach der signature length und ruft dann die owning instance event invocation function auf.
</Card>
</CardGroup>
