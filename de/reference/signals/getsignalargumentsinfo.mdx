<div className="real-function-page">

```lua
getsignalargumentsinfo(signal: RBXScriptSignal): {{Name: string, Type: string}}
```

## Argumente

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Das RBXScriptSignal, dessen event descriptor signature gelesen werden soll.
</ParamField>

## Rückgaben

<ResponseField name={"argumentInfo"} type={"{{Name: string, Type: string}}"}>
Eine array table, in der jeder Eintrag die Strings Name und Type enthält. Wenn die Signatur nicht gelesen werden kann oder keine Einträge enthält, gibt die Funktion einen fallback entry zurück, bei dem Name auf arg1 und Type auf Variant gesetzt ist.
</ResponseField>

## Beispiel

Inspect an RBXScriptSignal signature and print each argument name with its type name.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local remote = ReplicatedStorage:FindFirstChild("RemoteEvent")

if remote then
    for _, argument in ipairs(getsignalargumentsinfo(remote.OnClientEvent)) do
        print(argument.Name, argument.Type)
    end
end
```
