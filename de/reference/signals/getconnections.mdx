description: "Gibt eine array table von RealConnection closures für ein RBXScriptSignal zurück. Das erste argument muss object sein, dessen Luau type name RBXScriptSignal ist. Die function liest die Connect method des signal, verbindet einen temporary blank callback, liest die linked list ab dem next reference der temporären Verbindung, trennt die temporäre Verbindung und wrapped jeden gültigen connection reference. Wenn nach der temporären Verbindung kein connection reference gefunden wird, gibt sie eine leere table zurück. Bereits gewrappte underlying references können dieselbe cached closure table zurückgeben. getsignals und get_signal_cons sind aliases für dieselbe function."

<div className="real-function-page">

```lua
getconnections(signal: RBXScriptSignal): {RealConnection}
```

## Aliase

- `getsignals`
- `get_signal_cons`

## Argumente

<ParamField path={"signal"} type={"RBXScriptSignal"} required>
Zu prüfendes Signal. Nicht-RBXScriptSignal object löst einen type error aus, und ein signal ohne aufrufbares Connect field löst "Signal does not have 'Connect' method" aus.
</ParamField>

## Rückgaben

<ResponseField name={"connections"} type={"{RealConnection}"}>
Array table von connection closure tables. Jeder closure stellt fields und methods über seine methods bereit, darunter Enabled, Disabled, LuaConnection, ForeignState, Function, Thread, Disconnect, Disable, Enable, Fire und Defer, wenn verfügbar.
</ResponseField>

## Beispiel

Inspect an RBXScriptSignal and list the wrapped connections Real can expose.

```lua
local Players = game:GetService("Players")

for _, connection in ipairs(getconnections(Players.PlayerAdded)) do
    print(connection.Enabled, connection.LuaConnection)
end
```
