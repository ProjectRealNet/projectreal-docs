Gibt den decompressed bytecode string fuer ein Roblox script object zurueck. dumpstring ist auf dieselbe C++ function wie getscriptbytecode registriert, daher ist das Verhalten identisch. Das argument muss object sein. Der gemeinsame bytecode behavior akzeptiert die ClassName-Werte ModuleScript, LocalScript, CoreScript und Script. Bei Script muss RunContext Client sein. Wenn ClassName fehlt, wirft die function "Invalid Instance". Wenn ClassName keine unterstuetzte script class ist, wirft sie "Script expected". Wenn der Wert ein Script mit anderem RunContext ist, wirft sie "Expected a Script with RunContext set to Client". Wenn der embedded bytecode reference ungueltig ist oder die stored bytecode-Laenge 8 bytes oder weniger betraegt, gibt die function nil zurueck. Andernfalls dekomprimiert sie den stored bytecode mit DecompressBytecode und gibt die resulting bytes als Luau string zurueck. Hash mismatch, too-short compressed data oder ZSTD decompression errors werden von DecompressBytecode als error text bytes zurueckgegeben, statt hier geworfen zu werden.

## Syntax

```lua
dumpstring(script: userdata): string | nil
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `script` | `userdata` | Yes | Script object, das gelesen werden soll. Unterstuetzte ClassName-Werte sind ModuleScript, LocalScript, CoreScript und Script mit RunContext Client. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `bytecode` | `string \| nil` | Decompressed bytecode bytes als Luau string, DecompressBytecode error text bytes oder nil, wenn kein usable embedded bytecode verfuegbar ist. |

## Beispiel

Read decompressed bytecode from a supported Roblox script Instance. dumpstring is an alias for getscriptbytecode.

```lua
local targetScript

for _, descendant in ipairs(game:GetDescendants()) do
    if descendant:IsA("LuaSourceContainer") then
        targetScript = descendant
        break
    end
end

if targetScript then
    local bytecode = dumpstring(targetScript)
    print(bytecode)
end
```
