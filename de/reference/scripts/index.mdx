Skript-, Bytecode- und Umgebungsabfragen.

## Verfügbare Funktionen

<CardGroup cols={2}>
<Card title="decompile" href="./decompile">
Dekompiliert ein Roblox script und gibt den erzeugten source text zurück, wenn bytecode verfügbar ist. Das argument muss eine unterstützte script Instance sein. Wenn kein nutzbarer bytecode verfügbar ist, gibt die function nil zurück.
</Card>
<Card title="dumpstring" href="./dumpstring">
Gibt den decompressed bytecode string fuer ein Roblox script object zurueck. dumpstring ist auf dieselbe C++ function wie getscriptbytecode registriert, daher ist das Verhalten identisch. Das argument muss object sein. Der gemeinsame bytecode behavior akzeptiert die ClassName-Werte ModuleScript, LocalScript, CoreScript und Script. Bei Script muss RunContext Client sein. Wenn ClassName fehlt, wirft die function "Invalid Instance". Wenn ClassName keine unterstuetzte script class ist, wirft sie "Script expected". Wenn der Wert ein Script mit anderem RunContext ist, wirft sie "Expected a Script with RunContext set to Client". Wenn der embedded bytecode reference ungueltig ist oder die stored bytecode-Laenge 8 bytes oder weniger betraegt, gibt die function nil zurueck. Andernfalls dekomprimiert sie den stored bytecode mit DecompressBytecode und gibt die resulting bytes als Luau string zurueck. Hash mismatch, too-short compressed data oder ZSTD decompression errors werden von DecompressBytecode als error text bytes zurueckgegeben, statt hier geworfen zu werden.
</Card>
<Card title="getcallingscript" href="./getcallingscript">
Gibt das script zurueck, das auf dem current Luau thread object gespeichert ist. Die function akzeptiert keine arguments. Sie liest the current thread script, einen stored reference. Wenn dieser stored reference nicht expired ist, pusht die function die script Instance mit Instance cache und gibt sie zurueck. Wenn der stored reference expired ist, gibt die function nil zurueck. Die function untersucht nicht den Lua call stack, sucht nicht nach ancestor scripts und prueft nicht die script ClassName.
</Card>
<Card title="getinstancesbyclass" href="./getinstancesbyclass">
Gibt instances aus der Instance cache table zurueck, deren ClassName field exakt mit dem angeforderten string uebereinstimmt. Das erste Argument wird mit string type checking gelesen. Ein empty string wirft "ClassName required". Die function erstellt eine neue array table, iteriert die cache unter Instance cache, behaelt nur values mit Lua type object, liest das ClassName field jedes object value und vergleicht es per strcmp mit dem angeforderten className. Treffer werden sequential ab index 1 eingefuegt. Der Match ist exact und case-sensitive. Die function verwendet kein IsA, schliesst keine subclasses ein, macht keinen walk descendants, filtert nicht nach Parent und sortiert das result nicht. getinstancesofclass ist ein alias fuer dieselbe function.
</Card>
<Card title="getloadedmodules" href="./getloadedmodules">
Returns a new array table containing live entries from loaded module list. The optional excludeCore argument is read with optional boolean handling and defaults to true when omitted or nil. If excludeCore is true, entries whose instance is a descendant of core packages or CoreGui are skipped. Expired weak entries and locked stored references without a value are skipped. The function pushes each remaining entry with Instance cache at sequential array indexes starting at 1. The function does not check ClassName, does not sort the result, and does not walk the DataModel.
</Card>
<Card title="getmenv" href="./getmenv">
Returns the environment table associated with a ModuleScript. The argument must be a ModuleScript object. Invalid objects raise "Invalid Instance", non-ModuleScript objects raise "ModuleScript expected", and ModuleScripts without an available thread raise "invalid thread". The function does not accept Script or LocalScript; use getsenv for those cases.
</Card>
<Card title="getreferencedby" href="./getreferencedby">
Returns cached Instance values whose supported reference properties point to the provided Instance. The argument must be an Instance.
</Card>
<Card title="getrunningscripts" href="./getrunningscripts">
Gibt eine neue array table mit unique script Instances zurück, die aus live Lua threads stammen. Die function nimmt keine arguments. Sie läuft über the live Luau thread list, liest jeden thread node und überspringt entries ohne thread node, ohne weak thread ref, ohne LiveLuaRef, ohne Lua state, ohne object oder mit expired Script stored reference. Für jeden verbleibenden thread lockt sie scriptThread->object->Script(), dedupliziert über den script reference, pusht die Instance mit Instance cache und fügt sie an fortlaufenden array indexes ab 1 ein. Die function scannt den DataModel nicht, prüft keinen ClassName und sortiert das result nicht.
</Card>
<Card title="getscriptbytecode" href="./getscriptbytecode">
Gibt den decompressed bytecode string fuer ein Roblox script object zurueck. getscriptbytecode ist auf dieselbe C++ function wie dumpstring registriert, daher ist das Verhalten identisch. Das argument muss object sein. Der gemeinsame bytecode behavior akzeptiert die ClassName-Werte ModuleScript, LocalScript, CoreScript und Script. Bei Script muss RunContext Client sein. Wenn ClassName fehlt, wirft die function "Invalid Instance". Wenn ClassName keine unterstuetzte script class ist, wirft sie "Script expected". Wenn der Wert ein Script mit anderem RunContext ist, wirft sie "Expected a Script with RunContext set to Client". Wenn der embedded bytecode reference ungueltig ist oder die stored bytecode-Laenge 8 bytes oder weniger betraegt, gibt die function nil zurueck. Andernfalls dekomprimiert sie den stored bytecode mit DecompressBytecode und gibt die resulting bytes als Luau string zurueck. Hash mismatch, too-short compressed data oder ZSTD decompression errors werden von DecompressBytecode als error text bytes zurueckgegeben, statt hier geworfen zu werden.
</Card>
<Card title="getscriptclosure" href="./getscriptclosure">
Loads the stored bytecode for a supported Roblox script Instance and returns it as a Lua closure. Returns nil when usable bytecode is not available.
</Card>
<Card title="getscripthash" href="./getscripthash">
Gibt einen uppercase SHA384 hex digest fuer den gespeicherten bytecode string einer Roblox script object zurueck. Das argument muss object sein. Der gemeinsame GetBytecode Helper akzeptiert ClassName Werte ModuleScript, LocalScript, CoreScript und Script. Bei Script muss RunContext Client sein. Wenn ClassName fehlt, wirft die function "Invalid Instance". Wenn ClassName keine der unterstuetzten script classes ist, wirft sie "Script expected". Wenn der Wert ein Script mit anderem RunContext ist, wirft sie "Expected a Script with RunContext set to Client". Wenn der embedded bytecode reference ungueltig ist oder die stored bytecode Laenge 8 bytes oder weniger betraegt, gibt die function nil zurueck. Andernfalls hasht sie die exakten stored bytecode bytes mit SHA384 und gibt den uppercase hex string zurueck. Die function ruft DecompressBytecode nicht auf und hasht keinen decompressed bytecode.
</Card>
<Card title="getscripts" href="./getscripts">
Gibt script object Werte zurueck, die aktuell im Instance cache vorhanden sind. Die function nimmt keine arguments. Sie iteriert die cache unter dem Instance cache und betrachtet nur entries, deren value object ist. Sie liest das ClassName Feld jedes value mit optional string handling. LocalScript und ModuleScript entries werden aufgenommen. Script entries werden nur aufgenommen, wenn ihr RunContext offset CLIENT oder PLUGIN entspricht. Andere ClassName Werte, entries ohne string ClassName und CoreScript entries werden uebersprungen. Das Ergebnis ist eine sequenzielle Luau table. Die function durchsucht nicht den DataModel und garantiert keine sorted order.
</Card>
<Card title="getscriptthread" href="./getscriptthread">
Gibt den Lua thread zurueck, der mit einer script object verbunden ist, wenn Real einen findet. Das argument muss object sein. Die function liest das ClassName Feld des Werts und wirft "not a valid Instance", wenn dieses Feld kein string ist. Akzeptierte ClassName Werte sind Script, LocalScript und ModuleScript; jeder andere Wert wirft "Script expected". Zuerst prueft sie Real's ScriptThreadCache ueber den script reference. Bei einem cache hit gibt sie den gecachten Luau thread als thread zurueck. Bei einem cache miss muessen Script Werte RunContext Client haben, sonst wirft die function "Expected a Script with RunContext set to Client". Danach laeuft sie durch the live Luau thread list, folgt bei jedem thread node der first weak thread reference zu LiveLuaRef, ueberspringt missing thread data oder expired Script stored references und vergleicht jeden script reference mit dem angefragten script. Wenn sie einen match findet, gibt sie diesen Luau thread als thread zurueck. Wenn kein match gefunden wird, gibt sie nil zurueck.
</Card>
<Card title="getsenv" href="./getsenv">
Returns the environment table associated with a LocalScript, Script, or ModuleScript. Unsupported script objects or scripts without an available thread raise the same errors as the underlying script lookup.
</Card>
<Card title="loadstring" href="./loadstring">
Compiles a Luau source string and returns the loaded function. If loading fails, it returns nil and an error message. The returned function is not executed automatically.
</Card>
</CardGroup>
