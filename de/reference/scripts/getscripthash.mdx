Wenn ClassName fehlt, wirft die function \"Invalid Instance\". Wenn ClassName keine der unterstuetzten script classes ist, wirft sie \"Script expected\". Wenn der Wert ein Script mit anderem RunContext ist, wirft sie \"Expected a Script with RunContext set to Client\". Wenn der embedded bytecode reference ungueltig ist oder die stored bytecode Laenge 8 bytes oder weniger betraegt, gibt die function nil zurueck. Andernfalls hasht sie die exakten stored bytecode bytes mit SHA384 und gibt den uppercase hex string zurueck. Die function ruft DecompressBytecode nicht auf und hasht keinen decompressed bytecode."

<div className="real-function-page">

```lua
getscripthash(script: userdata): string | nil
```

## Argumente

<ParamField path={"script"} type={"userdata"} required>
Script object, die gehasht werden soll. Unterstuetzte ClassName Werte sind ModuleScript, LocalScript, CoreScript und Script mit RunContext Client.
</ParamField>

## Rückgaben

<ResponseField name={"hash"} type={"string | nil"}>
Uppercase SHA384 hex digest der stored bytecode bytes, oder nil, wenn kein nutzbarer embedded bytecode verfuegbar ist.
</ResponseField>

## Beispiel

Hash the bytecode of a supported Roblox script Instance when bytecode is available.

```lua
local targetScript

for _, descendant in ipairs(game:GetDescendants()) do
    if descendant:IsA("LuaSourceContainer") then
        targetScript = descendant
        break
    end
end

if targetScript then
    local hash = getscripthash(targetScript)
    print(hash)
end
```
