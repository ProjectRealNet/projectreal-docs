Hängt ein SliderFloat element an das Fenster an. label, value, minimum und maximum werden aus den Argumenten 2 bis 5 gelesen, wobei die numerischen Argumente mit number type checking geprüft werden. Während des rendering ruft Real a floating-point slider mit dem gespeicherten Wert und Bereich auf. Wenn ImGui einen geänderten Wert meldet, wird onChange in eine queue gelegt und später mit einem Lua number aufgerufen. Real fügt in diesem closure keine separate minimum &lt;= maximum Prüfung hinzu.

## Syntax

```lua
ImGuiWindow.SliderFloat(window: ImGuiWindow, label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()): ImGuiWindow
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `window` | `ImGuiWindow` | Yes | ImGuiWindow, die von imgui.create zurückgegeben wurde. Wenn die object ungültig ist oder bereits zerstört wurde, wirft die method einen Lua error. |
| `label` | `string` | Yes | Slider label, gelesen mit string type checking. |
| `value` | `number` | Yes | Anfangswert des sliders, gelesen mit number type checking und als aktueller float-Wert gespeichert. |
| `minimum` | `number` | Yes | Minimum value, gelesen mit number type checking und an a floating-point slider übergeben. |
| `maximum` | `number` | Yes | Maximum value, gelesen mit number type checking und an a floating-point slider übergeben. |
| `onChange` | `(number) -> ()` | Yes | Callback function, gespeichert in der Lua registry. Wenn sich der slider während des rendering ändert, wird sie später mit dem aktualisierten numerischen Wert aufgerufen. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `window` | `ImGuiWindow` | Dieselbe ImGuiWindow object, wodurch verkettete method-Aufrufe möglich sind. |
