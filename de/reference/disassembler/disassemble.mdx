Disassembles a Luau function and returns a formatted bytecode listing string. Argument 1 must be a function; otherwise a type error reports expected function. The closure must be valid and must not be a C closure; invalid closures raise "invalid closure" and C closures raise "cannot disassemble C closure". When an optional second argument is present, the function reads Recursive, ShowLines, ShowConstants, and StringPreviewMax from it. Boolean option fields override the matching defaults, and a numeric StringPreviewMax overrides the default string preview length. Indata structureions are decoded with the bytecode decoder before formatting. The output always has one trailing newline and the function has no registered alias.

## Syntax

```lua
disassemble(callback: function, options?: DisassembleOptions): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `callback` | `function` | Yes | Luau function to disassemble. C closures are rejected. |
| `options` | `DisassembleOptions` | No | Optional table read for Recursive, ShowLines, ShowConstants, and StringPreviewMax. Missing fields or fields with the wrong type leave the default value unchanged. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `assembly` | `string` | Formatted disassembly text with a trailing newline. |

## Typen

### DisassembleOptions

Steuert, wie Luau-Bytecode in der Disassembly-Ausgabe gerendert wird.

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `Recursive` | `boolean` | No | Schließt verschachtelte untergeordnete function datatypen in die Ausgabe ein. |
| `ShowLines` | `boolean` | No | Zeigt Quellzeilennummern neben Anweisungen an, wenn Zeilendaten verfügbar sind. |
| `ShowConstants` | `boolean` | No | Listet die Konstantentabelle für jeden function datatyp auf. |
| `StringPreviewMax` | `integer` | No | Begrenzt die Anzahl der angezeigten Zeichen bei der Vorschau von Zeichenfolgenkonstanten. |

## Beispiel

Disassemble a callback with selected output options.

```lua
local assembly = disassemble(function(value)
    return value * 2
end, {
    Recursive = false,
    ShowLines = true,
    ShowConstants = true,
})

print(assembly)
```
