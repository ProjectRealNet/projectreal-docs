<div className="real-function-page">

```lua
openfilesdialog(options?: DialogOptions): { FileSystemItem } | nil
```

## Argumente

<ParamField path={"options"} type={"DialogOptions"}>
Optional table. Fuer openfilesdialog werden title, defaultPath und extensionFilter verwendet. extensionFilter ist eine table aus extension strings; fuehrendes . oder *. wird entfernt, bevor jeder filter zu *.&lt;extension> wird.
</ParamField>

## Rückgaben

<ResponseField name={"files"} type={"{ FileSystemItem } | nil"}>
Array table aus file item-Werten fuer die ausgewaehlten Dateien, oder nil, wenn der dialog abgebrochen wird oder keine selected filesystem paths zurueckgegeben werden. Dialog failures werfen Failed to open file dialog.
</ResponseField>

## Typen

### DialogOptions

Konfiguriert den n Datei- oder Ordnerauswahldialog.

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `title` | `string` | No | Legt den Titel des Dialogfensters fest. |
| `defaultPath` | `string` | No | Wählt das Verzeichnis aus, das beim Öffnen des Dialogs angezeigt wird. |
| `extensionFilter` | `&#123;string&#125;` | No | Beschränkt auswählbare Dateien auf die aufgelisteten Erweiterungen, mit oder ohne führenden Punkt. |
| `suggestedName` | `string` | No | Gibt den anfänglichen Dateinamen in Speicherdialogen an. |
| `defaultExtension` | `string` | No | Legt die Erweiterung fest, die verwendet wird, wenn der eingegebene Dateiname keine hat. |

## Beispiel

Oeffne einen file picker, um eine oder mehrere Dateien auszuwaehlen, und behandle jedes selected file item.

```lua
local files = openfilesdialog({
    title = "Choose source files",
    defaultPath = ".",
    extensionFilter = { "lua", "luau", "txt" },
})

if files then
    for _, file in ipairs(files) do
        print(file:GetName())
        print(file:IsFile())
    end
else
    print("No files selected")
end
```
