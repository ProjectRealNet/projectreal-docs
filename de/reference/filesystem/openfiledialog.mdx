Oeffnet einen Windows file-open dialog ueber Windows file picker und gibt die ausgewaehlte Datei als file item zurueck.

## Syntax

```lua
openfiledialog(options?: DialogOptions): FileSystemItem | nil
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `options` | `DialogOptions` | No | Optional table. Fuer openfiledialog werden title, defaultPath und extensionFilter verwendet. extensionFilter ist eine table aus extension strings; fuehrendes . oder *. wird entfernt, bevor jeder filter zu *.&lt;extension> wird. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `file` | `FileSystemItem \| nil` | Selected file item, oder nil, wenn der dialog abgebrochen wird oder kein selected filesystem path zurueckkommt. Dialog failures werfen Failed to open file dialog. |

## Typen

### DialogOptions

Konfiguriert den n Datei- oder Ordnerauswahldialog.

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `title` | `string` | No | Legt den Titel des Dialogfensters fest. |
| `defaultPath` | `string` | No | Wählt das Verzeichnis aus, das beim Öffnen des Dialogs angezeigt wird. |
| `extensionFilter` | `&#123;string&#125;` | No | Beschränkt auswählbare Dateien auf die aufgelisteten Erweiterungen, mit oder ohne führenden Punkt. |
| `suggestedName` | `string` | No | Gibt den anfänglichen Dateinamen in Speicherdialogen an. |
| `defaultExtension` | `string` | No | Legt die Erweiterung fest, die verwendet wird, wenn der eingegebene Dateiname keine hat. |

## Beispiel

Oeffne einen file picker und behandle selected file item oder cancellation.

```lua
local file = openfiledialog({
    title = "Choose a configuration",
    defaultPath = ".",
    extensionFilter = { "json", "txt" },
})

if file then
    print(file:GetName())
    print(file:IsFile())
else
    print("No file selected")
end
```
