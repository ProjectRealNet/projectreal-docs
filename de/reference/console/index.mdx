Laufzeitausgabe und Konsolensteuerelemente.

| Funktionsnavigation | Beschreibung |
| --- | --- |
| [`rconsoleclear`](./rconsoleclear) | Leert den current Windows console screen buffer, wenn eine console window existiert. Wenn keine console window existiert, kehrt der call ohne Aktion zurueck. |
| [`rconsolecreate`](./rconsolecreate) | Allocates eine Windows console fuer den Prozess, wenn keine console window existiert. Wenn bereits eine console window existiert, kehrt der call ohne Aktion zurueck. Nach allocation redirected die function stdout zu console output und stdin zu console input. |
| [`rconsoledestroy`](./rconsoledestroy) | Leert den aktuellen Windows console screen buffer, versteckt die console window und trennt den Prozess mit console detachment von der console. Wenn keine console window existiert, kehrt der Aufruf ohne Aktion zurück. |
| [`rconsoleerr`](./rconsoleerr) | Schreibt null oder mehr Werte in die aktuelle Windows console über stdout, nachdem das console text attribute auf error text color gesetzt wurde. Werte werden mit Lua string conversion konvertiert, mit Tab-Zeichen getrennt und das text attribute wird danach auf default console text color gesetzt. Wenn keine console window existiert, kehrt der Aufruf ohne etwas zu konvertieren oder zu schreiben zurück. |
| [`rconsolehide`](./rconsolehide) | Versteckt die aktuelle Windows console window mit Windows console visibility update und hide mode. Die function ruft console detachment nicht auf, trennt sich also nicht von der console und zerstört sie nicht. Wenn keine console window existiert, kehrt der Aufruf ohne Aktion zurück. |
| [`rconsoleinfo`](./rconsoleinfo) | Schreibt null oder mehr Werte in die aktuelle Windows console über stdout, nachdem das console text attribute auf info text color gesetzt wurde. Werte werden mit Lua string conversion konvertiert, mit Tab-Zeichen getrennt und das text attribute wird danach auf default console text color gesetzt. Wenn keine console window existiert, kehrt der Aufruf ohne etwas zu konvertieren oder zu schreiben zurück. |
| [`rconsoleinput`](./rconsoleinput) | Yieldet, während eine line aus stdin mit console input gelesen wird, nachdem der console input state geleert und input bis zum nächsten newline ignoriert wurde. Der zurückgegebene string wird mit string return gepusht und enthält den terminierenden newline nicht. Wenn keine console window existiert, kehrt der Aufruf ohne values zurück. |
| [`rconsolename`](./rconsolename) | Setzt den title der aktuellen Windows console window mit Windows console title update. Das erste argument muss ein string sein und wird vor dem console existence check geprüft. Wenn nach erfolgreichem string check keine console window existiert, kehrt der Aufruf ohne Aktion zurück. |
| [`rconsoleprint`](./rconsoleprint) | Schreibt null oder mehr Werte in die aktuelle Windows console über stdout, ohne das console text attribute zu ändern. Werte werden mit Lua string conversion konvertiert und mit Tab-Zeichen getrennt. Die function fügt keinen newline hinzu. Wenn keine console window existiert, kehrt der Aufruf ohne etwas zu konvertieren oder zu schreiben zurück. |
| [`rconsoleshow`](./rconsoleshow) | Zeigt das aktuelle Windows console window mit Windows console visibility update und show mode an. Die function erstellt keine console. Wenn kein console window existiert, kehrt der Aufruf zurück, ohne etwas zu tun. |
| [`rconsolewarn`](./rconsolewarn) | Schreibt null oder mehr Werte über stdout in die aktuelle Windows console mit dem warning console text attribute. Wenn kein console window existiert, kehrt der Aufruf zurück, ohne etwas zu konvertieren oder zu schreiben. Wenn eine console existiert, wird jedes argument mit Lua string conversion konvertiert, mit tab-Zeichen verbunden und über runtime value geschrieben. Wenn Lua string conversion einen Fehler auslöst, wird dieser von rconsolewarn nicht abgefangen. Die function setzt das console text attribute vor dem Schreiben auf FOREGROUND_RED \| FOREGROUND_GREEN \| FOREGROUND_INTENSITY und danach auf default console text color. Sie fügt keinen newline und kein warning prefix hinzu, erstellt oder zeigt keine console und ruft weder Luau warn noch Roblox Output auf. consolewarn ist ein alias für dieselbe function. |
