title: "rconsolewarn"
sidebarTitle: "rconsolewarn"
description: "Schreibt null oder mehr Werte über stdout in die aktuelle Windows console mit dem warning console text attribute. Wenn kein console window existiert, kehrt der Aufruf zurück, ohne etwas zu konvertieren oder zu schreiben. Wenn eine console existiert, wird jedes argument mit Lua string conversion konvertiert, mit tab-Zeichen verbunden und über runtime value geschrieben. Wenn Lua string conversion einen Fehler auslöst, wird dieser von rconsolewarn nicht abgefangen. Die function setzt das console text attribute vor dem Schreiben auf FOREGROUND_RED | FOREGROUND_GREEN | FOREGROUND_INTENSITY und danach auf default console text color. Sie fügt keinen newline und kein warning prefix hinzu, erstellt oder zeigt keine console und ruft weder Luau warn noch Roblox Output auf. consolewarn ist ein alias für dieselbe function."
keywords: ["rconsolewarn","Console","consolewarn"]

<div className="real-function-page">

```lua
rconsolewarn(...values?: ...any)
```

## Aliase

- `consolewarn`

## Argumente

<ParamField path={"...values"} type={"...any"}>
Optionale Werte. Wenn eine console existiert, wird jeder value mit Lua string conversion konvertiert und vor dem Schreiben mit tab-Zeichen verbunden.
</ParamField>

## Beispiel

Write values to the current Windows console with the warning console text attribute. Values are tab-separated, no newline or warning prefix is added, and consolewarn is the same function.

```lua
rconsolecreate()
rconsolewarn("Retrying request", 3)
rconsolewarn("\n")
```
