---
title: "rconsoleinfo"
sidebarTitle: "rconsoleinfo"
description: "Schreibt null oder mehr Werte in die aktuelle Windows console über stdout, nachdem das console text attribute auf info text color gesetzt wurde. Werte werden mit Lua string conversion konvertiert, mit Tab-Zeichen getrennt und das text attribute wird danach auf default console text color gesetzt. Wenn keine console window existiert, kehrt der Aufruf ohne etwas zu konvertieren oder zu schreiben zurück."
keywords: ["rconsoleinfo","Console","consoleinfo"]
---

<div className="real-function-page">

```lua
rconsoleinfo(...values?: ...any)
```

## Aliase

- `consoleinfo`

## Argumente

<ParamField path={"...values"} type={"...any"}>
Optionale Werte. Wenn eine console existiert, wird jeder value mit Lua string conversion konvertiert und vor dem Schreiben mit tab-Zeichen verbunden.
</ParamField>

## Beispiel

Write a bright blue message to the current Windows console.

```lua
rconsolecreate()
rconsoleinfo("Connected", "
")
```
