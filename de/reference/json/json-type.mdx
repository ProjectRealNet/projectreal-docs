Gibt einen string type name fuer einen Wert zurueck. json.null gibt "null" zurueck. Tabellen geben "array" oder "object" mit derselben table classification wie json.isArray und json.isObject zurueck. Andere Werte geben das runtime Lua type name result zurueck.

## Syntax

```lua
json.type(value: any): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `value` | `any` | Yes | Wert, der classified wird. Wenn no value uebergeben wird, wird der runtime type name fuer einen fehlenden stack value zurueckgegeben. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `jsonType` | `string` | Type name string. Verifizierte JSON-specific returns sind "null", "array" und "object". Non-table, non-json.null Werte verwenden Lua type name, zum Beispiel "nil", "boolean", "number", "integer", "string", "function", "object", "thread", "buffer", "class", "object", "vector" oder "no value", je nach runtime value. |

## Beispiel

Prueft den exact type string, den der JSON helper zurueckgibt.

```lua
print(json.type(json.array({ "red", "blue" })))
print(json.type(json.object({ enabled = true })))
print(json.type(json.null))
print(json.type(nil))
print(json.type())
```
