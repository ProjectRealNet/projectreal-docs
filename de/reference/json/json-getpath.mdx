Liest einen nested value aus einer table mit einem dotted string path oder einer array table of keys.

## Syntax

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliase

- `json.getpath`

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `object` | `table` | Yes | Root table, aus der gelesen wird. Die function verlangt, dass dieses argument eine table ist. |
| `path` | `string \| table` | Yes | Path, dem gefolgt wird. Ein string wird an dots gesplittet; integer string tokens werden mit raw array indexing gelesen. Eine table path nutzt ihre array entries von 1 bis #path als keys. |
| `defaultValue` | `any` | No | Fallback value, der zurueckgegeben wird, wenn traversal nil erreicht oder vor Abschluss des path auf eine non-table trifft. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `pathValue` | `any \| nil` | Value am requested path. Wenn der path fehlt, wird defaultValue zurueckgegeben, wenn er angegeben wurde, sonst nil. |

## Beispiel

Lies einen nested table value aus einem dotted string path oder einer array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
