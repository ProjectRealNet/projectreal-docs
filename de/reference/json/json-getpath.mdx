<div className="real-function-page">

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliase

- `json.getpath`

## Argumente

<ParamField path={"object"} type={"table"} required>
Root table, aus der gelesen wird. Die function verlangt, dass dieses argument eine table ist.
</ParamField>

<ParamField path={"path"} type={"string | table"} required>
Path, dem gefolgt wird. Ein string wird an dots gesplittet; integer string tokens werden mit raw array indexing gelesen. Eine table path nutzt ihre array entries von 1 bis #path als keys.
</ParamField>

<ParamField path={"defaultValue"} type={"any"}>
Fallback value, der zurueckgegeben wird, wenn traversal nil erreicht oder vor Abschluss des path auf eine non-table trifft.
</ParamField>

## Rückgaben

<ResponseField name={"pathValue"} type={"any | nil"}>
Value am requested path. Wenn der path fehlt, wird defaultValue zurueckgegeben, wenn er angegeben wurde, sonst nil.
</ResponseField>

## Beispiel

Lies einen nested table value aus einem dotted string path oder einer array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
