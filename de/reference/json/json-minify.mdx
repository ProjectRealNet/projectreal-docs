Parsed einen JSON string und encoded ihn mit Real default non-pretty JSON encoder output neu.

## Syntax

```lua
json.minify(json: string, options?: DecodeOptions): string
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `json` | `string` | Yes | JSON string, der vor dem minifying parsed wird. Die function liest dieses argument mit string type checking. |
| `options` | `DecodeOptions` | No | Optional decode options fuer das parsing des input JSON. Ein boolean setzt useNull. Eine table kann useNull und maxDepth setzen. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `minified` | `string` | JSON string, der nach parsing und re-encoding des input mit default encode options erzeugt wird. |

## Typen

### DecodeOptions

Steuert das JSON-Parsing-Verhalten.

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Stellt JSON Null mit dem Null-Sentinel der Bibliothek anstelle von Null dar. |
| `maxDepth` | `integer` | No | Legt die maximale Verschachtelungstiefe fest, geklemmt von 1 bis 4096. |

## Beispiel

Parse valid JSON und re-encode es mit default compact JSON output.

```lua
local formatted = [[{
    "name": "Real",
    "enabled": true,
    "missing": null
}]]

print(json.minify(formatted, {
    useNull = true,
}))
```
