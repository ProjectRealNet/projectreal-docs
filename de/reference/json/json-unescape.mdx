<div className="real-function-page">

```lua
json.unescape(text: string): string
```

## Argumente

<ParamField path={"text"} type={"string"} required>
Escaped JSON string content oder ein complete quoted JSON string literal, dessen first and last bytes quotes sind. Die function liest dieses argument mit string type checking.
</ParamField>

## Rückgaben

<ResponseField name={"text"} type={"string"}>
Decoded string. Supported escapes sind \", \\, \/, \b, \f, \n, \r, \t und \uXXXX mit surrogate-pair handling. Invalid escapes, unescaped control characters, unterminated strings und trailing characters nach einem quoted literal werfen einen Luau error mit near-position suffix.
</ResponseField>

## Beispiel

Dekodiert JSON string escapes aus escaped content oder einem quoted JSON string literal.

```lua
local escaped = json.escape("Real Docs" .. string.char(10) .. "Docs")
local restored = json.unescape(escaped)

print(restored)
```
