<div className="real-function-page">

```lua
json.keys(object: table): table
```

## Argumente

<ParamField path={"object"} type={"table"} required>
Table, die inspected wird. Die function verlangt, dass dieses argument eine table ist.
</ParamField>

## Rückgaben

<ResponseField name={"keys"} type={"table"}>
New array table mit den source table keys, ohne Real JSON type marker. Die order folgt table iteration iteration und wird von dieser function nicht sorted.
</ResponseField>

## Beispiel

Collect die visible keys einer table in eine new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
