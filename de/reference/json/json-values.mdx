<div className="real-function-page">

```lua
json.values(object: table): table
```

## Argumente

<ParamField path={"object"} type={"table"} required>
Table, die enumerated wird. Die function prueft dieses argument mit type checking.
</ParamField>

## Rückgaben

<ResponseField name={"values"} type={"table"}>
Neue array-style table mit den direct values aus der input table. Der output ist als JSON array markiert. Enumeration verwendet table iteration, daher ist in der function keine ordering guarantee sichtbar.
</ResponseField>

## Beispiel

Sammelt die direct values aus einer table in eine JSON array-marked table.

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
