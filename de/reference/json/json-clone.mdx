Klont einen value, indem er mit json.encode semantics encoded und der generated JSON wieder zu Lua values decoded wird.

## Syntax

```lua
json.clone(value: any, options?: EncodeOptions): any
```

## Argumente

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `value` | `any` | Yes | Value, der encoded und decoded wird. Supported JSON values laufen per round-trip durch JSON; unsupported types werden zu null encoded, ausser encode options fordern einen Fehler. |
| `options` | `EncodeOptions` | No | Optional encode options, die an den encode step uebergeben werden, zum Beispiel sortKeys, emptyTableAsArray, errorOnUnsupported, encodeInvalidNumbersAsNull, maxDepth, pretty und indent. |

## Rückgaben

| Name | Type | Beschreibung |
| --- | --- | --- |
| `clone` | `any` | Decoded value, der aus dem encoded JSON entsteht. Objects und arrays sind new tables mit JSON kind markers aus dem decoder; JSON null values werden zu json.null. |

## Typen

### EncodeOptions

Steuert die JSON-Serialisierung und -Formatierung.

| Name | Type | Required | Beschreibung |
| --- | --- | --- | --- |
| `pretty` | `boolean` | No | Ermöglicht eine formatierte, mehrzeilige JSON-Ausgabe. |
| `sortKeys` | `boolean` | No | Sortiert Objektschlüssel vor der Codierung. |
| `emptyTableAsArray` | `boolean` | No | Kodiert eine leere Tabelle als Array statt als Objekt. |
| `errorOnUnsupported` | `boolean` | No | Löst einen Fehler aus, anstatt nicht unterstützte Werte zu ersetzen. |
| `encodeInvalidNumbersAsNull` | `boolean` | No | Kodiert NaN und unendliche Zahlen als JSON-Null. |
| `maxDepth` | `integer` | No | Legt die maximale Verschachtelungstiefe fest, geklemmt von 1 bis 4096. |
| `indent` | `string` | No | Legt die Einrückungszeichenfolge fest, begrenzt auf 32 Zeichen. |

## Beispiel

Fuehre fuer einen JSON-compatible value einen round-trip durch json.encode und json.decode aus, bevor nested values geaendert werden.

```lua
local original = {
    profile = { name = "Guest" },
}

local copy = json.clone(original)
copy.profile.name = "Developer"

print(original.profile.name)
print(copy.profile.name)
print(json.type(copy))
```
