description: "Gibt einen boolean aus dem ScriptContext DataModel des aktuellen Luau thread zurück. Die function nimmt keine arguments. Sie liest the current parallel execution status, das den parallel execution status zurückgibt. Wenn the current DataModel keinen DataModel zurückgibt, gibt die function false zurück. checkparallel ist ein alias für dieselbe function."
keywords: ["isparallel","Actors","checkparallel"]
---

<div className="real-function-page">

```lua
isparallel(): boolean
```

## Aliase

- `checkparallel`

## Rückgaben

<ResponseField name={"parallel"} type={"boolean"}>
true, wenn der aktuelle DataModel parallel execution status gesetzt ist; false, wenn der flag nicht gesetzt ist oder kein DataModel verfügbar ist.
</ResponseField>

## Beispiel

Read whether the current DataModel is in the parallel phase.

```lua
local parallel = isparallel()
print(parallel)

print(checkparallel())
```
