<div className="real-function-page">

```lua
get_comm_channel(channelId: number): Instance | nil
```

## Argumente

<ParamField path={"channelId"} type={"number"} required>
Channel ID, die mit integer conversion konvertiert und in der internen communication channel list gesucht wird.
</ParamField>

## Rückgaben

<ResponseField name={"event"} type={"Instance | nil"}>
Gespeicherte BindableEvent Instance für die channel ID, oder nil, wenn die ID nicht in communication channels vorhanden ist.
</ResponseField>

## Beispiel

Look up the BindableEvent Instance stored for a communication channel ID.

```lua
local channelId = create_comm_channel()
local event = get_comm_channel(channelId)

print(event)
```
