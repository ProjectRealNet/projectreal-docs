<div className="real-function-page">

```lua
getactorfromthread(thread: thread): Instance | nil
```

## Aliase

- `getactorfromstate`

## Argumente

<ParamField path={"thread"} type={"thread"} required>
Luau thread, dessen thread data auf eine associated Actor weak reference geprüft werden soll.
</ParamField>

## Rückgaben

<ResponseField name={"actor"} type={"Instance | nil"}>
Actor Instance, die aus der the associated Actor weak reference des thread aufgelöst wurde, oder nil, wenn keine valid actor reference vorhanden ist.
</ResponseField>

## Beispiel

Resolve the Actor Instance associated with a Luau thread, when that thread has a valid actor reference.

```lua
for _, thread in ipairs(getactorthreads()) do
    local actor = getactorfromthread(thread)
    print(actor)
end
```
