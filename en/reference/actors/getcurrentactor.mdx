---
title: "getcurrentactor"
sidebarTitle: "getcurrentactor"
description: "Returns the Actor Instance associated with the current Luau thread. The function takes no arguments. It resolves the current Luau thread with the same lookup used by getactorfromthread: the thread data must exist, Actor reference must exist, reference count must be greater than 0, and the associated Actor must hold a non-expired weak reference. If no valid actor reference is present, the function returns nil."
keywords: ["getcurrentactor","Actors","get_current_actor"]
---

<div className="real-function-page">

```lua
getcurrentactor(): Instance | nil
```

## Aliases

- `get_current_actor`

## Returns

<ResponseField name={"actor"} type={"Instance | nil"}>
Actor Instance resolved from the current thread's the associated Actor weak reference, or nil when no valid actor reference is present.
</ResponseField>

## Example

Resolve the Actor Instance associated with the current Luau thread.

```lua
local actor = getcurrentactor()

print(actor)
```
