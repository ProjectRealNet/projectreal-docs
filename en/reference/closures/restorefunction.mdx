Restores a hooked function, or replaces one function with another when two function arguments are provided. The first argument must be a function.

## Syntax

```lua
restorefunction(firstFunction: function, secondFunction?: function)
```

## Aliases

- `restorefunc`
- `restoreclosure`

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `firstFunction` | `function` | Yes | With one argument, the hooked function to restore. With two function arguments, the function to replace. |
| `secondFunction` | `function` | No | Optional closure to patch with firstFunction. This branch is used only when the second argument is a function. |

## Example

Restore a hooked closure to its original function.

```lua
local function target()
    return "original"
end

hookfunction(target, function()
    return "hooked"
end)

print(target())

restorefunction(target)

print(target())
```
