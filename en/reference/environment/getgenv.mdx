Repository call-sites use the returned table to read and write shared executor globals such as __siApiCache and saveinstance."
keywords: ["getgenv","Environment"]

<div className="real-function-page">

```lua
getgenv(): table
```

## Returns

<ResponseField name={"environment"} type={"table"}>
The table currently stored at LUA_ENVIRONINDEX for this state.
</ResponseField>

## Example

Read and write values on the current executor environment table.

```lua
local env = getgenv()

env.RealDocsValue = "ready"

print(getgenv().RealDocsValue)
```
