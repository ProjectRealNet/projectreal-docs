Roblox XML place and model serialization.

| Function navigation | Description |
| --- | --- |
| [`saveinstance`](./saveinstance) | Serializes the DataModel or a selected Instance to a Roblox XML place or model file and returns the saved path string. The root can be passed as the first argument, supplied as options.Object, or omitted to use game. FilePath, Path, or FileName can select the output name. The function may yield while loading the API dump before saving. |
