Thread context and identity.

## Available functions

<CardGroup cols={2}>
<Card title="getscriptfromthread" href="./getscriptfromthread">
Returns the Script Instance associated with a Luau thread, or nil when no valid script reference is available.
</Card>
<Card title="getthreadidentity" href="./getthreadidentity">
Returns the identity for the current Luau thread, or for the first argument when that argument is a thread. Returned identities are 1 through 12; other stored values return 0.
</Card>
<Card title="isourthread" href="./isourthread">
Returns whether the supplied Luau thread is tracked as a Real-created thread. is_our_thread is an alias.
</Card>
<Card title="setthreadidentity" href="./setthreadidentity">
Sets the identity for the current Luau thread, or for a provided Luau thread. Identity values are converted to integers and clamped to the supported range 0 through 12.
</Card>
</CardGroup>
