---
title: "ImGuiWindow.CollapsingHeader"
sidebarTitle: "ImGuiWindow.CollapsingHeader"
description: "Appends a collapsing header start marker, immediately calls the content callback with the same ImGuiWindow object so it can append nested elements, then appends a header end marker. During rendering, nested elements are skipped while the header is collapsed. Callback errors are caught and not returned by this method."
keywords: ["ImGuiWindow.CollapsingHeader","ImGui"]
---

<div className="real-function-page">

```lua
ImGuiWindow.CollapsingHeader(window: ImGuiWindow, label: string, content: function): ImGuiWindow
```

## Arguments

<ParamField path={"window"} type={"ImGuiWindow"} required>
ImGuiWindow object returned by imgui.create. A destroyed or invalid window raises a Lua error.
</ParamField>

<ParamField path={"label"} type={"string"} required>
Header label string passed to the rendered ImGui collapsing header.
</ParamField>

<ParamField path={"content"} type={"function"} required>
Function invoked immediately with the same ImGuiWindow object. Return values are ignored; errors are caught by the method.
</ParamField>

## Returns

<ResponseField name={"window"} type={"ImGuiWindow"}>
The same ImGuiWindow object, allowing chained method calls.
</ResponseField>

## Types
