<div className="real-function-page">

```lua
json.object(source?: table): table
```

## Arguments

<ParamField path={"source"} type={"table"}>
Optional source table to copy into the new object table. If omitted or nil, an empty object table is returned.
</ParamField>

## Returns

<ResponseField name={"object"} type={"table"}>
New table marked with Real's JSON object marker. Source entries are copied, except Real's JSON type marker.
</ResponseField>

## Example

Create a new table marked as a JSON object, including an empty object.

```lua
local profile = json.object({
    name = "Guest",
    active = true,
})
local empty = json.object()

print(json.encode(profile))
print(json.encode(empty))
```
