<div className="real-function-page">

```lua
json.array(source?: table): table
```

## Arguments

<ParamField path={"source"} type={"table"}>
Optional source table. When omitted or nil, json.array returns a new empty array-marked table. When provided, only numeric sequence entries from 1 with #source are copied into the new table.
</ParamField>

## Returns

<ResponseField name={"array"} type={"table"}>
New table with the JSON array marker. json.encode serializes it as a JSON array; the original source table is not returned.
</ResponseField>

## Example

Create an array-marked copy so json.encode serializes the value as a JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
