<div className="real-function-page">

```lua
json.keys(object: table): table
```

## Arguments

<ParamField path={"object"} type={"table"} required>
Table to inspect. The function requires this argument to be a table.
</ParamField>

## Returns

<ResponseField name={"keys"} type={"table"}>
New array table containing the source table keys, excluding Real's JSON type marker. The order follows table iteration iteration and is not sorted by this function.
</ResponseField>

## Example

Collect the visible keys of a table into a new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
