```lua
json.minify(json: string, options?: DecodeOptions): string
```

## Arguments

<ParamField path={"json"} type={"string"} required>
JSON string to parse before minifying. The function reads this argument with string type checking.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options used while parsing the input JSON. A boolean sets useNull. A table can set useNull and maxDepth.
</ParamField>

## Returns

<ResponseField name={"minified"} type={"string"}>
JSON string produced after parsing and re-encoding the input with default encode options.
</ResponseField>

## Types

### DecodeOptions

Controls JSON parsing behavior.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Represents JSON null with the library's null sentinel instead of nil. |
| `maxDepth` | `integer` | No | Sets the maximum nesting depth, clamped from 1 to 4096. |

## Example

Parse valid JSON and re-encode it with default compact JSON output.

```lua
local formatted = [[{
    "name": "Real",
    "enabled": true,
    "missing": null
}]]

print(json.minify(formatted, {
    useNull = true,
}))
```
