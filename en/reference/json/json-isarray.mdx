```lua
json.isArray(value: any): boolean
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Value to inspect. Non-table values return false.
</ParamField>

## Returns

<ResponseField name={"isArray"} type={"boolean"}>
true when the value is a table marked as a JSON array or an unmarked table with contiguous positive integer keys from 1 with its maximum index. Empty unmarked tables return false.
</ResponseField>

## Example

Check whether a table is treated as a JSON array by Real's JSON encoder.

```lua
local items = json.array({ "one", "two" })
local record = json.object({ name = "Real" })
local inferred = { "one", "two" }

print(json.isArray(items))
print(json.isArray(record))
print(json.isArray(inferred))
```
