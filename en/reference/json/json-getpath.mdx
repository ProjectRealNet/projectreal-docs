<div className="real-function-page">

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliases

- `json.getpath`

## Arguments

<ParamField path={"object"} type={"table"} required>
Root table to read from. The function requires this argument to be a table.
</ParamField>

<ParamField path={"path"} type={"string | table"} required>
Path to follow. A string is split on dots; integer string tokens are read with raw array indexing. A table path uses its array entries from 1 with #path as keys.
</ParamField>

<ParamField path={"defaultValue"} type={"any"}>
Fallback value returned when traversal reaches nil or a non-table before the path is complete.
</ParamField>

## Returns

<ResponseField name={"pathValue"} type={"any | nil"}>
Value at the requested path. If the path is missing, returns defaultValue when it was provided, otherwise nil.
</ResponseField>

## Example

Read a nested table value from a dotted string path or an array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
