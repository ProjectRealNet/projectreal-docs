<div className="real-function-page">

```lua
json.isNull(value: any): boolean
```

## Arguments

<ParamField path={"value"} type={"any"} required>
Value to inspect. Only the json.null value returns true; Lua nil and other values return false.
</ParamField>

## Returns

<ResponseField name={"isNull"} type={"boolean"}>
true when the value is the exact json.null sentinel, otherwise false.
</ResponseField>

## Example

Check whether a value is the json.null sentinel instead of Lua nil.

```lua
local value = json.decode("null")

if json.isNull(value) then
    print("The value is JSON null")
end

print(json.isNull(nil))
```
