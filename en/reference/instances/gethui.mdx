Returns game:CoreGui lookup.RobloxGui. The function takes no arguments. If CoreGui lookup returns nil, or if RobloxGui on that value is nil, the function returns nil. The function does not create a container and does not use the cached CoreGui value.

## Syntax

```lua
gethui(): Instance | nil
```

## Aliases

- `gethiddenui`
- `gethiddengui`
- `get_hidden_ui`
- `get_hidden_gui`

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `robloxGui` | `Instance \| nil` | The RobloxGui value read from CoreGui, or nil when CoreGui or RobloxGui is unavailable. |
