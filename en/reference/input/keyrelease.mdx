description: "Sends a key up event when the Roblox window is active. The keyCode argument is checked as a Lua number, and sent with keyboard input with KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP. This function does not send a key down event. If isrbxactive would be false, the function returns without sending input."
keywords: ["keyrelease","Input"]
---

```lua
keyrelease(keyCode: number)
```

## Arguments

<ParamField path={"keyCode"} type={"number"} required>
Windows virtual-key code read as a Lua number and converted to an integer before Windows key mapping is called.
</ParamField>
