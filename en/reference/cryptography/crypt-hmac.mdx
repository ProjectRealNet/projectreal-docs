<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Arguments

<ParamField path={"key"} type={"string"} required>
Raw Lua string bytes used as the HMAC key. The key is not Base64-decoded.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Lua string bytes passed into the HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Case-sensitive HMAC algorithm name. Defaults to sha256.
</ParamField>

## Returns

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output with no line breaks.
</ResponseField>

## Example

Compute a Base64 HMAC output from a raw Lua string key and data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
