```lua
base64_decode(data: string): string
```

## Aliases

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Arguments

<ParamField path={"data"} type={"string"} required>
Base64 input passed to Base64 decoder.
</ParamField>

## Returns

<ResponseField name={"decoded"} type={"string"}>
Decoded bytes returned as a Lua string with explicit length.
</ResponseField>

## Example

Decode Base64 data and read the returned Lua string.

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
