Deletes an existing folder inside the workspace recursively with recursive folder deletion.

## Syntax

```lua
delfolder(path: string)
```

## Arguments

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Path resolved inside the workspace after separator normalization and workspace-boundary checks. The target must exist and be a directory; files are not accepted. |

## Example

Delete an existing workspace folder and its contents.

```lua
local path = "examples/temporary"
makefolder(path)
writefile(path .. "/note.txt", "temporary")

delfolder(path)
print(isfolder(path))
```
