<div className="real-function-page">

```lua
makefolder(path: string)
```

## Arguments

<ParamField path={"path"} type={"string"} required>
Directory path resolved inside the workspace after separator normalization and workspace-boundary checks. Empty, invalid, or outside-workspace paths error before creation is attempted.
</ParamField>

## Example

Create a workspace directory and any missing parent directories.

```lua
local path = "examples/generated/nested"

makefolder(path)
print(isfolder(path))
```
