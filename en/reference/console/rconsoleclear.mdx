---
title: "rconsoleclear"
sidebarTitle: "rconsoleclear"
description: "Clears the current Windows console screen buffer when a console window exists. If no console window exists, the call returns without doing anything."
keywords: ["rconsoleclear","Console","consoleclear"]
---

<div className="real-function-page">

```lua
rconsoleclear()
```

## Aliases

- `consoleclear`

## Example

Clear the current console screen when a console window exists.

```lua
rconsolecreate()
rconsoleprint("Preparing output...")
rconsoleclear()
```
