---
title: "rconsoleprint"
sidebarTitle: "rconsoleprint"
description: "Writes zero or more values to the current Windows console with stdout without changing the console text attribute. Values are converted to strings and separated with tabs. The function does not add a newline. If no console window exists, the call returns without converting or writing anything."
keywords: ["rconsoleprint","Console","consoleprint","rconsolewrite","consolewrite"]
---

<div className="real-function-page">

```lua
rconsoleprint(...values?: ...any)
```

## Aliases

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Arguments

<ParamField path={"...values"} type={"...any"}>
Optional values. If a console exists, each value is converted to strings and joined with tab characters before writing.
</ParamField>

## Example

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
