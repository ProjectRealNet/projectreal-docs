<div className="real-function-page">

```lua
isrenderobj(object: any): boolean
```

## Arguments

<ParamField path={"object"} type={"any"} required>
Value to test. Non-object values and object without the Drawing object type return false.
</ParamField>

## Returns

<ResponseField name={"isDrawingObject"} type={"boolean"}>
True when the value is object whose methods matches RealDrawingObject; otherwise false.
</ResponseField>

## Example

Check whether a value has Real's Drawing userdata metatable.

```lua
local square = Drawing.new("Square")

print(isrenderobj(square))
square:Destroy()
print(isrenderobj(square))
print(isrenderobj({}))
```
