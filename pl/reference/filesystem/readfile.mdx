<div className="real-function-page">

```lua
readfile(path: string): string
```

## Aliasy

- `readfileasync`

## Argumenty

<ParamField path={"path"} type={"string"} required>
File path rozwiazywany wewnatrz workspace po separator normalization, workspace-boundary checks oraz filename/extension checks. Absolute paths sa akceptowane tylko jesli rozwiazuja sie wewnatrz workspace.
</ParamField>

## Zwroty

<ResponseField name={"content"} type={"string"}>
File contents sa zwracane jako Lua string z jawna dlugoscia. Bytes takie jak null bytes, line endings i BOM bytes nie sa transformowane przez readfile.
</ResponseField>

## Przykład

Odczytaj bytes z existing workspace file.

```lua
local path = "examples/config.json"
writefile(path, '{"enabled":true}')

local content = readfile(path)
print(content)
print(#content)
```
