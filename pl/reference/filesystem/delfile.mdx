```lua
delfile(path: string)
```

## Argumenty

<ParamField path={"path"} type={"string"} required>
Path rozwiazywany wewnatrz workspace po separator normalization i workspace-boundary checks. Cel musi istniec i byc regular file; folders nie sa akceptowane.
</ParamField>

## Przykład

Usun istniejacy workspace file.

```lua
local path = "examples/temporary.txt"
writefile(path, "temporary")

delfile(path)
print(isfile(path))
```
