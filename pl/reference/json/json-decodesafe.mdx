<div className="real-function-page">

```lua
json.decodeSafe(json: string, options?: DecodeOptions): boolean | any | nil | string | nil | number | nil
```

## Argumenty

<ParamField path={"json"} type={"string"} required>
JSON text do parsowania. Ten argument jest sprawdzany jako string przed przechwyceniem parse errors.
</ParamField>

<ParamField path={"options"} type={"DecodeOptions"}>
Optional decode options. boolean ustawia useNull bezposrednio. table moze ustawic useNull i maxDepth; maxDepth jest clamp od 1 do 4096. Invalid option argument types sa sprawdzane przed przechwyceniem parse errors.
</ParamField>

## Zwroty

<ResponseField name={"success"} type={"boolean"}>
True gdy parsing sie powiedzie, false gdy parser zglosi error.
</ResponseField>

<ResponseField name={"decoded"} type={"any | nil"}>
Decoded value przy sukcesie, nil przy parse failure. Poprawne JSON false zwraca success jako true i decoded jako false, wiec sprawdzaj success return value.
</ResponseField>

<ResponseField name={"errorMessage"} type={"string | nil"}>
Error message przy parse failure, w przeciwnym razie nil. Message zawiera json.decodeSafe prefix i parser position.
</ResponseField>

<ResponseField name={"errorPosition"} type={"number | nil"}>
Parser byte position przy parse failure, w przeciwnym razie nil.
</ResponseField>

## Typy

### DecodeOptions

Kontroluje zachowanie analizy JSON.

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `useNull` | `boolean` | No | Reprezentuje JSON null ze wskaźnikiem null biblioteki zamiast nil. |
| `maxDepth` | `integer` | No | Ustawia maksymalną głębokość zagnieżdżenia, zaciśniętą w zakresie od 1 do 4096. |

## Przykład

Parsuj JSON i uzyj success return value, aby oddzielic valid false lub nil results od parse failures.

```lua
local ok, value = json.decodeSafe("false")

if ok then
    print(value == false)
end

local parsed, _, message, position = json.decodeSafe("{")
if not parsed then
    warn(message, position)
end
```
