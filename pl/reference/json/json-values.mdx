Zwraca direct values z table w nowej table marked as JSON array. JSON kind marker entries sa pomijane.

## Składnia

```lua
json.values(object: table): table
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `object` | `table` | Yes | Table do enumerate. Function sprawdza ten argument przez type checking. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `values` | `table` | New array-style table zawierajaca direct values z input table. Output jest marked as JSON array. Enumeration uzywa table iteration, wiec w function nie widac ordering guarantee. |

## Przykład

Zbiera direct values z table do JSON array-marked table.

```lua
local list = json.array({ "one", "two" })

for _, value in ipairs(json.values(list)) do
    print(value)
end
```
