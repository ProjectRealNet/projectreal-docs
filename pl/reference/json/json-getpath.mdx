<div className="real-function-page">

```lua
json.getPath(object: table, path: string | table, defaultValue?: any): any | nil
```

## Aliasy

- `json.getpath`

## Argumenty

<ParamField path={"object"} type={"table"} required>
Root table, z ktorej odbywa sie odczyt. Function wymaga, aby ten argument byl table.
</ParamField>

<ParamField path={"path"} type={"string | table"} required>
Path do przejscia. string jest split po dots; integer string tokens sa czytane przez raw array indexing. table path uzywa swoich array entries od 1 do #path jako keys.
</ParamField>

<ParamField path={"defaultValue"} type={"any"}>
Fallback value zwracany, gdy traversal trafi na nil albo non-table przed koncem path.
</ParamField>

## Zwroty

<ResponseField name={"pathValue"} type={"any | nil"}>
Value pod requested path. Jesli path jest missing, zwraca defaultValue gdy podane, w przeciwnym razie nil.
</ResponseField>

## Przykład

Czytaj nested table value z dotted string path albo array table of keys.

```lua
local document = {
    user = {
        profile = { name = "Guest" },
        items = { "first", "second" },
    },
}

local name = json.getPath(document, { "user", "profile", "name" }, "Unknown")
local second = json.getPath(document, "user.items.2")

print(name)
print(second)
```
