<div className="real-function-page">

```lua
json.keys(object: table): table
```

## Argumenty

<ParamField path={"object"} type={"table"} required>
Table do inspect. Function wymaga, aby ten argument byl table.
</ParamField>

## Zwroty

<ResponseField name={"keys"} type={"table"}>
New array table zawierajaca source table keys, z pominieciem Real JSON type marker. Order wynika z table iteration iteration i nie jest sorted przez te function.
</ResponseField>

## Przykład

Collect visible keys z table do new JSON array table.

```lua
local record = {
    name = "Real",
    enabled = true,
    [5] = "numeric key",
}

for _, key in ipairs(json.keys(record)) do
    print(key)
end
```
