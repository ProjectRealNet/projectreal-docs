Tworzy new table oznaczona jako JSON array dla json.encode, kopiujac sequence 1.#source, gdy podano source table.

## Składnia

```lua
json.array(source?: table): table
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `source` | `table` | No | Optional source table. Gdy pominieta lub nil, json.array zwraca new empty array-marked table. Gdy podana, tylko numeric sequence entries od 1 with #source sa kopiowane do new table. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `array` | `table` | New table z JSON array marker. json.encode serializes ja jako JSON array; original source table nie jest zwracana. |

## Przykład

Utworz array-marked copy, aby json.encode serializes wartosc jako JSON array.

```lua
local tags = json.array({ "api", "docs", "luau" })
local empty = json.array()

print(json.encode(tags))
print(json.encode(empty))
print(json.type(empty))
```
