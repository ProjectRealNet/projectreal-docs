Zapisuje jedną lub więcej wartości do bieżącej Windows console przez stdout bez zmiany console text attribute. Wartości są konwertowane za pomocą Lua string conversion i rozdzielane znakami tab. function nie dodaje newline. Jeśli nie istnieje żadna console window, wywołanie wraca bez wykonania akcji.

## Składnia

```lua
rconsoleprint(...values?: ...any)
```

## Aliasy

- `consoleprint`
- `rconsolewrite`
- `consolewrite`

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `...values` | `...any` | No | Opcjonalne wartosci. Jesli istnieje console, kazdy value jest konwertowany przez Lua string conversion i laczony znakami tab przed zapisem. |

## Przykład

Write values to the current Windows console without adding a newline.

```lua
rconsolecreate()
rconsoleprint("Loading", "
")
rconsoleprint("User", "	", 42, "
")
```
