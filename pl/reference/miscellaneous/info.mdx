---

<div className="real-function-page">

```lua
info(...values?: ...any)
```

## Argumenty

<ParamField path={"...values"} type={"...any"}>
Optional values to print as an informational message.
</ParamField>

## Przykład

Write an informational message to the active console output.

```lua
info("Loaded", "scripts", 3)
```
