title: "keyrelease"
sidebarTitle: "keyrelease"
description: "Wysyla key up event, gdy Roblox window jest active. Argument keyCode jest sprawdzany jako Lua number, konwertowany przez integer conversion, mapowany z Windows virtual-key code na scan code przez Windows key mapping, a potem wysylany przez keyboard input z KEYEVENTF_SCANCODE | KEYEVENTF_KEYUP. Ta function nie wysyla key down event. Jesli isrbxactive byloby false, function wraca bez wysylania input."
keywords: ["keyrelease","Input"]
---

<div className="real-function-page">

```lua
keyrelease(keyCode: number)
```

## Argumenty

<ParamField path={"keyCode"} type={"number"} required>
Windows virtual-key code czytany jako Lua number i konwertowany przez integer conversion przed wywolaniem Windows key mapping.
</ParamField>
