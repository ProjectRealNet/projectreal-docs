<div className="real-function-page">

```lua
mousemoverel(x: number, y: number)
```

## Argumenty

<ParamField path={"x"} type={"number"} required>
Relative X movement delta czytany jako Lua number i konwertowany przez integer conversion przed przekazaniem jako dx do mouse input.
</ParamField>

<ParamField path={"y"} type={"number"} required>
Relative Y movement delta czytany jako Lua number i konwertowany przez integer conversion przed przekazaniem jako dy do mouse input.
</ParamField>
