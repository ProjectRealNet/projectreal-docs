<div className="real-function-page">

```lua
getupvalue(target: function | number, index: number): any
```

## Aliasy

- `debug.getupvalue`

## Argumenty

<ParamField path={"target"} type={"function | number"} required>
Lua function or stack level whose upvalue is read.
</ParamField>

<ParamField path={"index"} type={"number"} required>
One-based upvalue index.
</ParamField>

## Zwroty

<ResponseField name={"upvalue"} type={"any"}>
Value stored in the requested upvalue slot.
</ResponseField>

## Przykład

Read one upvalue from a Lua closure or stack level.

```lua
local captured = "ready"

local function target()
    return captured
end

print(getupvalue(target, 1))
print(debug.getupvalue(target, 1))
```
