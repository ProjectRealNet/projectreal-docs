Sprawdza, czy numeric stack level mieści się w current call stack range. level jest wymagany i musi być number, ponieważ function wywołuje requires a number. value jest konwertowany przez integer conversion. function zwraca false, gdy level &lt; 0 albo level >= the current call stack depth, w przeciwnym razie true. Nie sprawdza frame closure i nie rzuca "Level out of range" dla invalid numeric levels. validlevel jest global alias, a debug.isvalidlevel oraz debug.validlevel są dostępne przez debug table aliases.

## Składnia

```lua
isvalidlevel(level: number): boolean
```

## Aliasy

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `level` | `number` | Yes | Stack level number konwertowany przez integer conversion i sprawdzany względem 0 &lt;= level &lt; the current call stack depth. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `valid` | `boolean` | true, gdy numeric level mieści się w current call stack range, w przeciwnym razie false. |

## Przykład

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
