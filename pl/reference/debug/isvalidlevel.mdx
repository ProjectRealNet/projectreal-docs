<div className="real-function-page">

```lua
isvalidlevel(level: number): boolean
```

## Aliasy

- `validlevel`
- `debug.isvalidlevel`
- `debug.validlevel`

## Argumenty

<ParamField path={"level"} type={"number"} required>
Stack level number konwertowany przez integer conversion i sprawdzany względem 0 &lt;= level &lt; the current call stack depth.
</ParamField>

## Zwroty

<ResponseField name={"valid"} type={"boolean"}>
true, gdy numeric level mieści się w current call stack range, w przeciwnym razie false.
</ResponseField>

## Przykład

Check whether a numeric stack level is inside the current call stack range.

```lua
print(isvalidlevel(0))
print(validlevel(0))
print(debug.isvalidlevel(0))
print(debug.validlevel(0))
```
