Generuje raw random bytes za pomoca random byte generator i zwraca je jako Lua string.

## Składnia

```lua
crypt.random(size: number): string
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `size` | `number` | Yes | Liczba przekazywana przez integer conversion przed alokacja. Wartosci mniejsze lub rowne 0 powoduja argument error. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `bytes` | `string` | Raw generated bytes zwracane jako Lua string. Dlugosc zwroconego string odpowiada zaalokowanej liczbie bajtow. |

## Przykład

Wygeneruj raw bytes i wypisz dlugosc zwroconego Lua string.

```lua
local bytes = crypt.random(16)

print(bytes)
print(#bytes)
```
