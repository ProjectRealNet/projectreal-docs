Odszyfrowuje Base64 ciphertext za pomoca key zdekodowanego z Base64 i wymaganego Base64 IV, uzywajac AES CBC albo ECB.

## Składnia

```lua
crypt.decrypt(data: string, key: string, iv: string, mode?: "CBC" | "ECB" | "AES-CBC" | "AES-ECB"): string
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Base64 ciphertext dekodowany przed odszyfrowaniem. |
| `key` | `string` | Yes | Key Base64 dekodowany przed przekazaniem do AES. |
| `iv` | `string` | Yes | Base64 IV dekodowany przed obsluga mode. Ten argument jest wymagany, takze dla ECB. |
| `mode` | `"CBC" \| "ECB" \| "AES-CBC" \| "AES-ECB"` | No | AES mode. Prefix AES- jest usuwany, gdy wystepuje. Wartosc domyslna to AES-CBC. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `plaintext` | `string` | Bajty plaintext zwracane jako Lua string. |

## Przykład

Odszyfruj ciphertext zwrocony przez crypt.encrypt, uzywajac zwroconego IV.

```lua
local key = crypt.generatekey()
local ciphertext, iv = crypt.encrypt("hello world", key)

local plaintext = crypt.decrypt(ciphertext, key, iv)

print(plaintext)
```
