<div className="real-function-page">

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argumenty

<ParamField path={"data"} type={"string"} required>
Bajty Lua string przekazywane do crypto library HashFilter.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\" | \"sha3-224\" | \"sha3-256\" | \"sha3-384\" | \"sha3-512\""}>
Nazwa algorytmu hash case-sensitive. Wartosc domyslna to sha256.
</ParamField>

## Zwroty

<ResponseField name={"digest"} type={"string"}>
Lowercase hexadecimal digest bez prefix ani separators.
</ResponseField>

## Przykład

Hashuj bajty Lua string algorytmem domyslnym albo jawna obslugiwana nazwa.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
