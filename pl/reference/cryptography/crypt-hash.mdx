Hashuje bajty Lua string obslugiwanym algorytmem crypto library hash i zwraca lowercase hexadecimal digest.

## Składnia

```lua
crypt.hash(data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5" | "sha3-224" | "sha3-256" | "sha3-384" | "sha3-512"): string
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `data` | `string` | Yes | Bajty Lua string przekazywane do crypto library HashFilter. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5" \| "sha3-224" \| "sha3-256" \| "sha3-384" \| "sha3-512"` | No | Nazwa algorytmu hash case-sensitive. Wartosc domyslna to sha256. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `digest` | `string` | Lowercase hexadecimal digest bez prefix ani separators. |

## Przykład

Hashuj bajty Lua string algorytmem domyslnym albo jawna obslugiwana nazwa.

```lua
local defaultDigest = crypt.hash("hello world")
local sha3Digest = crypt.hash("hello world", "sha3-256")

print(defaultDigest)
print(sha3Digest)
```
