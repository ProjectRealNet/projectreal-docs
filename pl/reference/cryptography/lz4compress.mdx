<div className="real-function-page">

```lua
lz4compress(data: string): string
```

## Aliasy

- `crypt.lz4compress`
- `crypt.lz4.compress`
- `lz4.compress`

## Argumenty

<ParamField path={"data"} type={"string"} required>
Bajty Lua string przekazywane do LZ4 block compression.
</ParamField>

## Zwroty

<ResponseField name={"compressed"} type={"string"}>
Raw compressed bytes zwracane jako Lua string. original size nie jest zapisywany w wyniku.
</ResponseField>

## Przykład

Skompresuj bajty Lua string i odtworz je, przekazujac original size.

```lua
local source = string.rep("Real Docs ", 100)
local compressed = lz4compress(source)
local restored = lz4decompress(compressed, #source)

print(#source, #compressed, restored == source)
```
