<div className="real-function-page">

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumenty

<ParamField path={"key"} type={"string"} required>
Bajty raw Lua string uzywane jako HMAC key. key nie jest Base64-decode.
</ParamField>

<ParamField path={"data"} type={"string"} required>
Bajty Lua string przekazywane do HMAC calculation.
</ParamField>

<ParamField path={"algorithm"} type={"\"sha256\" | \"sha1\" | \"sha224\" | \"sha384\" | \"sha512\" | \"md5\""}>
Nazwa HMAC algorithm case-sensitive. Wartosc domyslna to sha256.
</ParamField>

## Zwroty

<ResponseField name={"digest"} type={"string"}>
Base64-encoded HMAC output bez line breaks.
</ResponseField>

## Przykład

Oblicz Base64 HMAC output z raw Lua string key i data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
