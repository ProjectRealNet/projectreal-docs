Oblicza crypto library HMAC dla bajtow Lua string z raw Lua string key i zwraca Base64 digest.

## Składnia

```lua
crypt.hmac(key: string, data: string, algorithm?: "sha256" | "sha1" | "sha224" | "sha384" | "sha512" | "md5"): string
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `key` | `string` | Yes | Bajty raw Lua string uzywane jako HMAC key. key nie jest Base64-decode. |
| `data` | `string` | Yes | Bajty Lua string przekazywane do HMAC calculation. |
| `algorithm` | `"sha256" \| "sha1" \| "sha224" \| "sha384" \| "sha512" \| "md5"` | No | Nazwa HMAC algorithm case-sensitive. Wartosc domyslna to sha256. |

## Zwroty

| Name | Type | Opis |
| --- | --- | --- |
| `digest` | `string` | Base64-encoded HMAC output bez line breaks. |

## Przykład

Oblicz Base64 HMAC output z raw Lua string key i data.

```lua
local key = "shared secret"
local data = "payload"
local digest = crypt.hmac(key, data, "sha256")

print(digest)
```
