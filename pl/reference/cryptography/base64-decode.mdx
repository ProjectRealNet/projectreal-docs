```lua
base64_decode(data: string): string
```

## Aliasy

- `base64decode`
- `base64.decode`
- `crypt.base64.decode`
- `crypt.base64_decode`
- `crypt.base64decode`

## Argumenty

<ParamField path={"data"} type={"string"} required>
Wejscie Base64 przekazywane do Base64 decoder.
</ParamField>

## Zwroty

<ResponseField name={"decoded"} type={"string"}>
Zdekodowane bajty zwracane jako Lua string z jawna dlugoscia.
</ResponseField>

## Przykład

Zdekoduj dane Base64 i odczytaj zwrocony Lua string.

```lua
local encoded = base64_encode("hello world")
local decoded = base64_decode(encoded)

print(decoded)
print(base64decode(encoded))
print(base64.decode(encoded))
```
