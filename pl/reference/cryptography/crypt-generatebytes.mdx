```lua
crypt.generatebytes(size: number): string
```

## Argumenty

<ParamField path={"size"} type={"number"} required>
Liczba przekazywana przez integer conversion przed alokacja. Wartosci mniejsze lub rowne 0 sa zmieniane na 1.
</ParamField>

## Zwroty

<ResponseField name={"encoded"} type={"string"}>
Base64 encoding wygenerowanych raw bytes. Dlugosc zwroconego string nie jest zadana liczba bajtow.
</ResponseField>

## Przykład

Wygeneruj bajty i zdekoduj wynik Base64, gdy potrzebne sa raw bytes.

```lua
local encoded = crypt.generatebytes(16)
local raw = base64_decode(encoded)

print(encoded)
print(#encoded)
print(#raw)
```
