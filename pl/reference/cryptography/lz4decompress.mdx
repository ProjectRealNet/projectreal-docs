<div className="real-function-page">

```lua
lz4decompress(data: string, originalSize?: number): string
```

## Aliasy

- `crypt.lz4decompress`
- `crypt.lz4.decompress`
- `lz4.decompress`

## Argumenty

<ParamField path={"data"} type={"string"} required>
Raw compressed bytes przekazywane do LZ4 block decompression.
</ParamField>

<ParamField path={"originalSize"} type={"number"}>
Output buffer size przekazywany jako dstCapacity. Dla wyjscia lz4compress podaj oryginalna nieskompresowana dlugosc w bytes; po pominieciu uzywana jest dlugosc skompresowanego wejscia.
</ParamField>

## Zwroty

<ResponseField name={"decompressed"} type={"string"}>
Raw decompressed bytes zwracane jako lancuch Lua. Wyjscie moze byc krotsze niz originalSize.
</ResponseField>

## Przykład

Dekompresuj LZ4 bytes, podajac oryginalny nieskompresowany rozmiar.

```lua
local source = "Real Docs"
local compressed = lz4compress(source)
local decompressed = lz4decompress(compressed, #source)

print(decompressed)
print(decompressed == source)
```
