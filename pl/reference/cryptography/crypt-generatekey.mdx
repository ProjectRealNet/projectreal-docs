```lua
crypt.generatekey(): string
```

## Zwroty

<ResponseField name={"key"} type={"string"}>
Base64 encoding wygenerowanych 32 raw bytes. Zwrocony string nie ma 32 znakow.
</ResponseField>

## Przykład

Wygeneruj Base64 key i zdekoduj go, aby sprawdzic liczbe raw bytes.

```lua
local key = crypt.generatekey()
local raw = base64_decode(key)

local ciphertext, iv = crypt.encrypt("hello world", key)

print(key)
print(#raw)
print(ciphertext, iv)
```
