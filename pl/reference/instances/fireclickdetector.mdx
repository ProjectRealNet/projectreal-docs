Wywoluje interakcje ClickDetector dla lokalnego gracza. Pierwszy argument musi byc Instance, ktorej ClassName to ClickDetector. distance jest opcjonalne i domyslnie wynosi 0. clickOption jest opcjonalne, porownywane bez rozrozniania wielkosci liter i domyslnie ma wartosc "mouseclick". Obslugiwane opcje to "mouseclick", "rightmouseclick", "mousehoverenter" i "mousehoverleave". Opcje klikniecia przekazuja distance jako float do Roblox click helper, a opcje hover ignoruja distance. Jesli Players lub Players.LocalPlayer nie jest dostepne, function wraca bez wywolania czegokolwiek. Nieznany clickOption rowniez nie powoduje interakcji. Function nic nie zwraca.

## Składnia

```lua
fireclickdetector(detector: Instance, distance?: number, clickOption?: "mouseclick" | "rightmouseclick" | "mousehoverenter" | "mousehoverleave")
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `detector` | `Instance` | Yes | Instance, ktorego ClassName musi byc ClickDetector. |
| `distance` | `number` | No | Opcjonalna wartosc distance. Domyslnie 0, przekazywana jako float dla "mouseclick" i "rightmouseclick". |
| `clickOption` | `"mouseclick" \| "rightmouseclick" \| "mousehoverenter" \| "mousehoverleave"` | No | Opcjonalny selektor interaction. Odczytywany jako string, porownywany bez rozrozniania wielkosci liter i domyslnie ustawiony na "mouseclick". |

## Przykład

Wywoluje domyslna interaction "mouseclick" na ClickDetector.

```lua
local detector = workspace.InteractivePart.ClickDetector

fireclickdetector(detector)
```
