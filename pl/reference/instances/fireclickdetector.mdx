Pierwszy argument musi byc Instance, ktorej ClassName to ClickDetector. distance jest opcjonalne i domyslnie wynosi 0. clickOption jest opcjonalne, porownywane bez rozrozniania wielkosci liter i domyslnie ma wartosc \"mouseclick\". Opcje klikniecia przekazuja distance jako float do Roblox click helper, a opcje hover ignoruja distance. Jesli Players lub Players.LocalPlayer nie jest dostepne, function wraca bez wywolania czegokolwiek. Nieznany clickOption rowniez nie powoduje interakcji. Function nic nie zwraca."

<div className="real-function-page">

```lua
fireclickdetector(detector: Instance, distance?: number, clickOption?: "mouseclick" | "rightmouseclick" | "mousehoverenter" | "mousehoverleave")
```

## Argumenty

<ParamField path={"detector"} type={"Instance"} required>
Instance, ktorego ClassName musi byc ClickDetector.
</ParamField>

<ParamField path={"distance"} type={"number"}>
Opcjonalna wartosc distance. Domyslnie 0, przekazywana jako float dla "mouseclick" i "rightmouseclick".
</ParamField>

<ParamField path={"clickOption"} type={"\"mouseclick\" | \"rightmouseclick\" | \"mousehoverenter\" | \"mousehoverleave\""}>
Opcjonalny selektor interaction. Odczytywany jako string, porownywany bez rozrozniania wielkosci liter i domyslnie ustawiony na "mouseclick".
</ParamField>

## Przykład

Wywoluje domyslna interaction "mouseclick" na ClickDetector.

```lua
local detector = workspace.InteractivePart.ClickDetector

fireclickdetector(detector)
```
