Zamyka WebSocket object zwrócony przez WebSocket.connect. Pierwszy argument musi być table. Funkcja odczytuje field connection state obiektu. Gdy istnieje live state i nie jest jeszcze destroyed ani closed, ustawia isClosed na true i wysyła pusty frame close frame przez zapisany WebSocket connection. Nie przyjmuje close code ani reason i nie zwraca values.

## Składnia

```lua
WebSocket.Close(socket: WebSocket)
```

## Argumenty

| Name | Type | Required | Opis |
| --- | --- | --- | --- |
| `socket` | `WebSocket` | Yes | WebSocket table zwrócona przez WebSocket.connect. Function oczekuje, że ta table zawiera connection state. |

## Przykład

Close a WebSocket object returned by WebSocket.connect.

```lua
local socket = WebSocket.connect("wss://example.com/socket")

socket:Close()
```
